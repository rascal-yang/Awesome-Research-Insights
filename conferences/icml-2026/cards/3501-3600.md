## 3501 · Adaptive Sharpness-Aware Minimization with a Polyak-type Step size: A Theory-Grounded Scheduler

[原文](https://proceedings.mlr.press/v306/oikonomou26b.html)

<a id="oikonomou26b-optimization"></a>

**技术主题** · 扰动点 Polyak 步长

- **问题 / 瓶颈** · SAM 与未归一化 USAM 对学习率和扰动半径敏感，直接套用当前损失除以梯度平方的 Polyak 步长未考虑梯度求值点的偏移。
- **核心创新 / 方法** · 构造修正 Polyak 步长，用扰动点损失减下界并扣除梯度与扰动位移的内积，再除以扰动点梯度平方范数。随机版给步长上限。
- **Baseline** · 改进来源为传统和随机 Polyak 步长、USAM 与 SAM。实验对照为调参的常数学习率、余弦退火及其他自适应方法。
- **Benchmark** · 强凸岭回归验证 USAM 收敛，CIFAR-10/100 上用 ResNet 测一般训练。CIFAR-100 表为 ResNet-32、三个种子、不同扰动半径。
- **关键结果 / 消融** · 半径 0.3 时 CIFAR-100 的 USAM+随机 Polyak 准确率 92.24±0.30%，常数与余弦为 90.25±0.10%、88.05±0.23%。定理 3.1 在光滑强凸及半径约束下给确定性线性收敛。
- **适用条件 / 局限** · 证明主要针对光滑凸 USAM；随机非插值时保证到邻域。归一化 SAM 和深度网络主要由实验支撑。

**可复用机制** · 计算 Polyak 步长时，用扰动方向与扰动点梯度的内积修正损失余量，使步长与实际用于更新的梯度对应。

## 3502 · Safeguarded Stochastic Polyak Step Sizes for Non-smooth Optimization: Robust Performance Without Small (Sub)Gradients

[原文](https://proceedings.mlr.press/v306/oikonomou26c.html)

<a id="oikonomou26c-optimization"></a>

**技术主题** · 次梯度分母保护

- **问题 / 瓶颈** · 非光滑随机优化中，Polyak 步长可因小子梯度变得过大，而固定学习率上限往往主导整个训练。
- **核心创新 / 方法** · SPSsafe 用正阈值为分母中的子梯度范数平方设下界，以已知样本损失下界计算余量，扩展到带迭代平均动量的 IMA。
- **Baseline** · 改进来源为随机 Polyak、子梯度裁剪和 IMA。实验对照为 SPSmax、平滑 SPS、常数等步长及多种阈值。
- **Benchmark** · 合成 SVM hinge、非凸相位检索与 ResNet-20 的 CIFAR-10/100，测损失差、学习率、子梯度范数和测试准确率。
- **关键结果 / 消融** · 定理 3.1 在随机凸 Lipschitz 目标给 O(T⁻¹ᐟ²) 至噪声邻域，且无需插值或知道最优点的样本损失。定理 3.6 对 IMA 的末次迭代给同阶界。
- **适用条件 / 局限** · 理论依赖凸和 Lipschitz 条件，噪声邻域一般仍在，降低阈值无法消去噪声项。非凸网络结果为经验观察。

- **适用条件 / 局限** · 使用简化的短期记忆和交互结构，理论以离散决策为主。开放式多轮辩论和带专家分工的群体未充分覆盖。

## 3505 · Finite and Corruption-Robust Regret Bounds in Online Inverse Linear Optimization under M-Convex Action Sets

[原文](https://proceedings.mlr.press/v306/oki26a.html)

<a id="oki26a-theory-statistics"></a>

**技术主题** · 用交换约束和有向环诊断逆优化反馈

- **问题 / 瓶颈** · 在线逆线性优化要从不同可行集中的专家行动推断隐藏目标，在时间不设上限且反馈可能被篡改时控制累计遗憾。
- **核心创新 / 方法** · 用 M-凸单元交换刻画每条观测施加的坐标顺序约束，在候选多面体重心提出目标向量；用有向图的环检测冲突并重启。
- **Baseline** · 改进来源：将交换约束、体积收缩与可检测的顺序冲突结合。实验对照：未报告；表1比较已有按时间增长或维度指数的理论界。
- **Benchmark** · 随轮次变化的整数 M-凸动作集、线性隐藏目标和至多 C 轮对抗反馈，度量推荐行为的目标价值累计缺口。
- **关键结果 / 消融** · 定理4.2 给出不随时域增长的 O(d log d)，定理5.3 在未知 C 时给出 O((C+1)d log d)；定理6.1 给出 Ω(d) 下界。
- **适用条件 / 局限** · 依赖 M-凸交换结构和单轮遗憾有界；上下界相差对数因子，污染依赖能否进一步收紧仍未知。

## 3506 · Distortion of AI Alignment Revisited: RLHF is a Decent Utilitarian Aligner

[原文](https://proceedings.mlr.press/v306/oko26a.html)

<a id="oko26a-theory-statistics"></a>

**技术主题** · 用偏好采样与参考策略的错配解释效用失真

- **问题 / 瓶颈** · 用户偏好异质时，RLHF 学得的策略平均效用可能低于在相同参考约束下直接求最优的策略。
- **核心创新 / 方法** · 用 Bradley–Terry 混合偏好分析带奖励裁剪的 KL 约束 RLHF，分别追踪温度和偏好采样分布相对参考策略的对数密度比上界 B。
- **Baseline** · 改进来源：把偏好非线性与分布错配分解到失真界。实验对照：已有失真界、算法无关下界、合成同分布/异分布实验。
- **Benchmark** · 在理论中度量平均效用乘性缺口，实证含 RewardBench 上 Skywork/UltraRM 的奖励尺度检查及合成分布配对。
- **关键结果 / 消融** · 定理4.1 中匹配分布时上界为 O(β)，与算法无关下界同阶；代表性 KL 区间错配贡献可达 O(Bβ)，下界在对数因子内匹配。合成对照同分布逼近失真 1。
- **适用条件 / 局限** · 理论依赖 BT 偏好及密度比约束；主上界使用特定奖励裁剪，实际全规模 RLHF 的效用失真未直接测量。

## 3507 · Amortizing Maximum Inner Product Search with Learned Support Functions

[原文](https://proceedings.mlr.press/v306/olausson26a.html)

<a id="olausson26a-inference"></a>

**技术主题** · 用凸支持函数学习向量检索路由

- **问题 / 瓶颈** · 大向量库的最大内积搜索需重复扫描或索引路由，很多查询来自可学习的分布。
- **核心创新 / 方法** · 用凸支持函数表示最大内积分数；SupportNet 学分数和梯度，KeyNet 直接预测最大匹配向量并约束分数一致性，可用预测结果重路由索引。
- **Baseline** · 改进来源：用凸性和一次齐次性约束摊销搜索。实验对照：簇质心路由、直接 FAISS-IVF 查询和不同容量网络。
- **Benchmark** · BEIR 的 FIQA、Quora、NQ、HotpotQA 等，评价最优键命中、Recall@0.1%、计算量及定位延迟；比较查询分布偏移。
- **关键结果 / 消融** · NQ 128 簇时，学得路由选 1 簇约 72% 正确，质心法约 56%；选 4 簇约 95%，质心法约需 16 簇。HotpotQA 用 KeyNet 改写查询亦改善 IVF 的检索前沿。
- **适用条件 / 局限** · 训练需预先计算精确最大内积监督，收益依赖查询和库分布；SupportNet 如直接取键需反向计算。

## 3508 · Computational Arbitrage in AI Model Markets

[原文](https://proceedings.mlr.press/v306/olmedo26a.html)

<a id="olmedo26a-evaluation"></a>

**技术主题** · 用可验证成功率估算多模型级联成本

- **问题 / 瓶颈** · 当模型提供商的单位推理成本与求解效果不同，可验证请求的服务方是否能通过跨提供方分配预算降低成本尚未量化。
- **核心创新 / 方法** · 用重复抽样估计每家每题的成功—花费曲线；先查询一个模型，失败时将剩余预算转给下一个，并模拟价格竞争与蒸馏带来的变化。
- **Baseline** · 改进来源：按可验证成功率安排不同能力与成本的模型。实验对照：单独 GPT-5 mini、单独 DeepSeek v3.2 Thinking，以及同策略的多套利方。
- **Benchmark** · SWE-bench Verified 的 500 个问题，以测试通过率、预算、单位服务成本和利润率衡量；Django 与其他库对拆测试。
- **关键结果 / 消融** · 在 1 美元预算的示例，最优分配先给 GPT-5 mini 0.08 美元、其余给 DeepSeek；达到 68% 以上解题率时级联更便宜，论文设定的峰值利润率约 40%。
- **适用条件 / 局限** · 利润依赖实验时的价格、可自动验证的任务和成本假设；竞争模拟中利润随相互压价缩小。

## 3509 · Opportunistic Expert Activation: Batch-Aware Expert Routing for Faster Decode Without Retraining

[原文](https://proceedings.mlr.press/v306/oncescu26a.html)

<a id="oncescu26a-inference"></a>

**技术主题** · 在解码批内共享已激活专家

- **问题 / 瓶颈** · 自回归 MoE 解码在中等批量常受显存带宽限制，整批加载的专家数比每个 token 的名义 top-k 更影响延迟。
- **核心创新 / 方法** · OEA 先保留各 token 的 top-k₀ 专家，取批并集；再按各 token 原评分从已激活并集中补充低优先专家，避免加载额外权重。
- **Baseline** · 改进来源：用批内已加载专家替代部分次要路由，无需重训。实验对照：标准 top-8、仅剪到 top-k₀ 和带批复用的 OEA。
- **Benchmark** · Qwen3-30B-A3B 与 235B-A22B 在 8 张 H100 上以 SGLang 解码，AIME24、GPQA、MATH 500、LiveCodeBench，记录延迟和答案准确率。
- **关键结果 / 消融** · 论文报告批上限 16 时，MoE 层延迟在 30B 上降 39%，在 235B 上降 15%；表3的 235B AIME24 基线 118.4 μs，k₀=5 时 98.8 μs。
- **适用条件 / 局限** · 结果是层级解码延迟，整体加速还受注意力等开销影响；大模型有轻微质量折损，实测配置受 KV 缓存限制。

**可复用机制** · 先为各 token 保留最重要的专家，再从同一批必加载的专家中按原分数填充剩余名额。对带宽受限的解码，这能减少读取权重数，同时保留关键计算。

## 3510 · OmniSapiens: A Foundation Model for Social Behavior Processing via Heterogeneity-Aware Relative Policy Optimization

[原文](https://proceedings.mlr.press/v306/ong26a.html)

<a id="ong26a-reinforcement-learning"></a>

[原文](https://proceedings.mlr.press/v306/paes-leme26a.html)
