## 3701 · ParisKV: Fast and Drift-Robust KV-Cache Retrieval for Long-Context LLMs

[原文](https://proceedings.mlr.press/v306/qi26b.html)

<a id="qi26b-inference"></a>

**技术主题** · 用解析码本抗 KV 检索漂移

- **问题 / 瓶颈** · 长生成时 KV 分布随步骤漂移，训练得到的索引质心会过时。百万 token 全缓存牵涉显存和传输延迟。
- **核心创新 / 方法** · ParisKV 用无数据依赖质心的子空间碰撞选候选，再基于校准 4 bit 表示做内积重排。以 UVA 从 CPU 按需读取最终 top-k。
- **Baseline** · 改进来源：碰撞近邻检索、量化内积与 UVA。实验对照：全注意力、PQCache、MagicPIG、Quest、ShadowKV、RetroInfer、SOCKET 等。
- **Benchmark** · Qwen3 和 Llama/DeepSeek-R1 在 MATH500、GPQA-Diamond、AIME25、LongBench-V2、RULER。测正确率、吞吐、每步解码延迟，从 64K 至 1024K 的效率。
- **关键结果 / 消融** · 可运行范围内峰值解码吞吐较全注意力最高 2.8 倍。Llama3.1-8B 1024K、批 1 时 49 ms/步，PQCache 为 2,179 ms、MagicPIG 为 830 ms。
- **适用条件 / 局限** · 系统收益依赖 GPU、CPU 主存连通与融合核，固定 top-100 为测试设定。候选截断之后保留的是近似全注意力。

## 3702 · Delving into Muon and Beyond: Deep Analysis and Extensions

[原文](https://proceedings.mlr.press/v306/qi26c.html)

<a id="qi26c-optimization"></a>

**技术主题** · 分开比较谱压缩强度和输入归一

- **问题 / 瓶颈** · Muon 的正交化矩阵更新经验高效，但与动量 SGD、Adam 的关系及稳定性来自哪种谱调节尚不明晰。
- **核心创新 / 方法** · 将矩阵更新统一为 UΣ^pVᵀ，p 取 0、1/4、1/2、1，比较一阶动量与 RMS 输入，两类用一致的矩阵/向量学习率协议，并近似 Newton–Schulz。
- **Baseline** · 改进来源：Muon 极分解、动量 SGD、Adam 和谱矩阵函数。实验对照：8 个输入/谱指数消融、不同学习率和附加稳定化设置。
- **Benchmark** · nanoGPT 124M、OpenWebText、上下文 1024、200K 步，主实验向量 Adam 固定并去权重衰减，比较训练稳定、验证损失及八 A800 耗时。
- **关键结果 / 消融** · p=0 的 Muon 对原始动量较稳，稳定时 p=1/4 变体可更优。RMS 输入完全展平反而降表现。Adam 谱版五步迭代额外耗时 3.2%–3.8%。
- **适用条件 / 局限** · 作者指出集中在受控小规模 nanoGPT，排名未验证于更大模型和生产配方。分数谱函数的算力及显存也需进一步优化。

## 3703 · Detecting Contextual Hallucinations in Large Language Models with Frequency-Aware Attention

[原文](https://proceedings.mlr.press/v306/qi26d.html)

<a id="qi26d-evaluation"></a>

**技术主题** · 在注意力位置序列上提取高频

- **问题 / 瓶颈** · 上下文生成的幻觉检测常汇总注意力质量，容易丢失沿 token 位置快速变化的失稳信号。
- **核心创新 / 方法** · 把每层每头指向上下文、指向既有生成文本的两段注意力视为离散信号，用 Fourier 或小波提取高频能量，交给逻辑回归检测。
- **Baseline** · 改进来源：用注意力质量比例、方差或熵的检测。实验对照：Lookback-Lens、SelfCheckGPT、RefChecker、EigenScore、ReDeEP 及低频和全频消融。
- **Benchmark** · RAGTruth 的问答、数据到文本、摘要及 HalluRAG 问答；测 LLaMA-7B/13B、Mistral-7B 的 token 和片段检测 AUROC、F1。
- **关键结果 / 消融** · 八 token 窗口下，LLaMA-7B 的 Fourier-high 在 RAGTruth 平均 AUROC 0.8412、HalluRAG 0.8100，Lookback-Lens 分别为 0.7884、0.7856；图4中高频优于低频和全频。
- **适用条件 / 局限** · 主要实验需能读出生成器的分头注意力并用有标注数据校准；测的是相对提供上下文的幻觉。

**原文定位** · [§3.3 信号定义（PDF 第 3 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/qi26d/qi26d.pdf#page=3) · [图3 与 §3.4 高频能量（PDF 第 4 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/qi26d/qi26d.pdf#page=4) · [§4.1 对照（PDF 第 5 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/qi26d/qi26d.pdf#page=5) · [表2 与检测协议（PDF 第 6 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/qi26d/qi26d.pdf#page=6) · [图4 频带消融（PDF 第 7 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/qi26d/qi26d.pdf#page=7)

**可复用机制** · 上下文幻觉可能出现在注意质量看似正常的 token 上。把一个生成步中各头的上下文注意和历史生成注意分别按位置做高通，用能量衡量局部跳变，就能补足只看两段注意力总量的检测器。

## 3704 · Auto-regressive In-context Demonstration Selection

[原文](https://proceedings.mlr.press/v306/qi26e.html)

<a id="qi26e-inference"></a>

**技术主题** · 按现有示例顺序选下一个

- **问题 / 瓶颈** · 少样本提示的效果与示例内容、相对顺序及组合有关，枚举所有排列的成本随示例数急升。
- **核心创新 / 方法** · AutoSelect 编码查询和已有示例矩阵，自回归选择下一个示例或 EOS。将 KL 正则的轨迹收益转换为采样集合上的软标签，以策略交叉熵拟合 Plackett–Luce 排序。
- **Baseline** · 改进来源：近邻等顺序无关示例检索及固定重排。实验对照：random、max-entropy、re-ordering、greedy-oracle、ActRL、CEIL、EASE。
- **Benchmark** · Qwen2.5-3B 在 AGNews、Amazon、SST-2、Trec、四个推理任务与 AQuA 的少样本任务表现，三种子报告。
- **关键结果 / 消融** · Winowhy 从最强对照 CEIL 的 0.591±0.037 升至 0.657±0.012，相对增益 11.2%。定理4.2以有限轨迹集合上的超额交叉熵控制最坏的排序概率差。
- **适用条件 / 局限** · 训练需用任务模型的带监督回报评估采样轨迹；定理针对固定查询和有限集合，AGNews 略落后于逐步穷举对照。

**可复用机制** · 少样本示例有组合效应时，可以把已有的有序提示纳入选择状态，让策略逐个添加示例并决定停止。用少量有测量回报的轨迹拟合软排序，能在训练时避免枚举所有排列。

## 3705 · Towards the Training of Deeper Predictive Coding Neural Networks

[原文](https://proceedings.mlr.press/v306/qi26f.html)

<a id="qi26f-optimization"></a>

**技术主题** · 对齐局部误差信号的到达时刻

- **问题 / 瓶颈** · 预测编码网络增深时，误差信号逐层衰减，迭代后的潜变量偏离前向状态，残差路径还会提前到达高层。
- **核心创新 / 方法** · 误差信号首次到达某层时使用脉冲精度，权重更新对照松弛后的活动和初始前向预测，残差支路插入辅助神经元对齐信号到达时间。
- **Baseline** · 改进来源：经典 PC、增量 PC 的局部松弛及权重更新。实验对照：反向传播、PC、iPC、精度或前向更新变体。
- **Benchmark** · VGG5/7/10 与 ResNet-10/18 上的 CIFAR-10、CIFAR-100、TinyImageNet 五次测试准确率；另有 Galaxy10 DECaLS、ImageNet32。
- **关键结果 / 消融** · CIFAR-10 ResNet-18 的 iPC+S 达 91.96±0.07%，iPC 为 21.90±1.5%，反向传播为 93.13±0.16%；CIFAR-100 同结构的 PC+S+F 为 70.90±0.18%，反向传播为 71.69±0.21%。
- **适用条件 / 局限** · 前向更新需要保存初始预测，削弱时间局部性；残差路径要做结构适配，且表2中深网仍有小幅准确率差距。

**可复用机制** · 深层预测编码可在误差第一次到层时调整活动更新，在残差捷径加延迟单元，让捷径和主路同时起作用。层间能量曲线和深度对照能区分信号过弱与路径不同步两类故障。

## 3706 · CACR: Reinforcing Temporal Answer Grounding in Instructional Video via Candidate-Aware Causal Reasoning

[原文](https://proceedings.mlr.press/v306/qi26g.html)

<a id="qi26g-reinforcement-learning"></a>

**技术主题** · 给视频候选明确的拒绝动作

- **问题 / 瓶颈** · 教程长视频中的答案往往只是短片段，干扰画面与冗余字幕会妨碍边界定位。
- **核心创新 / 方法** · CACR 先以视觉语言预训练分数提出 Top-K 片段，再用含字幕摘要与预答案信息的 GRPO 学习时间推理；对无重叠候选正确输出空边界才给拒绝奖励。
- **Baseline** · 改进来源：直接扫描长视频的时间定位，以及按视觉语言匹配召回片段。实验对照：MutualSL、TimeZero、Time-R1、VTG-R1、Qwen2.5-VL、GPT-3.5 及分组件变体。
- **Benchmark** · VehicleVQA、TutorialVQA、MedVidQA、CMIVQA、COIN、CrossTask 六组教程视频；报告 mIoU 和不同 IoU 阈值的召回，基座 Qwen2.5-VL-7B-Instruct。
- **关键结果 / 消融** · TutorialVQA mIoU 43.65%，CMIVQA 为 45.37%，后者高于 MutualSL 的 33.42%。表3中 CMIVQA 仅用 Top-K 为 39.01%。
- **适用条件 / 局限** · 精定位依赖候选阶段召回答案、以及字幕和预答案的质量；原文消融发现过细画面描述可增加噪声。

**原文定位** · [§3.1–3.2 候选与 GRPO（PDF 第 4 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/qi26g/qi26g.pdf#page=4) · [拒绝奖励与推理（PDF 第 5 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/qi26g/qi26g.pdf#page=5) · [表1 数据（PDF 第 6 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/qi26g/qi26g.pdf#page=6) · [§4.2 指标比较（PDF 第 7 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/qi26g/qi26g.pdf#page=7) · [表2–3 与 §4.4（PDF 第 8 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/qi26g/qi26g.pdf#page=8)

**可复用机制** · 长视频定位可先召回少量相关片段，再让策略为每段预测边界或返回空答案。训练时对与真值完全不重叠的候选给予正确拒绝奖励，减少策略把粗筛候选一律当真。

## 3707 · Towards Universal Gene Regulatory Network Inference: Unlocking Generalizable Regulatory Knowledge in Single-cell Foundation Models

[原文](https://proceedings.mlr.press/v306/qi26h.html)

<a id="qi26h-representation-learning"></a>

**技术主题** · 统一虚拟表达以比较调控响应

- **问题 / 瓶颈** · 单细胞模型的重建目标未直接监督基因调控，模型在未见基因、细胞类型或参考网络上需要可迁移的边特征。
- **核心创新 / 方法** · 冻结 scGPT 或 scBenchmark。VVP 把源基因从统一虚拟表达改到多个取值并测目标响应；GDT 取多个虚拟状态上的局部梯度；拼接双向特征并用训练集边标签学习投影。
- **Baseline** · 改进来源：以真实表达作敲除对照、用注意力或嵌入作基因关系。实验对照：Origin-Pert、Origin-Attn、Pert、Emb，以及 VVP、GDT 和集成。
- **Benchmark** · UGRN 以 STRING hESC 训练投影，在其他数据上测试 STRING、ChIP-seq、文献及敲低网络标注，使用 AUPRC，并检查跨数据、物种和网络。
- **关键结果 / 消融** · scBenchmark 在 STRING HHEP 的集成 AUPRC 0.927，Emb 为 0.738；在 ChIP-seq 的细胞类型特异 MESC 上，VVP 与集成均为 0.673，GDT 为 0.643。
- **适用条件 / 局限** · 虚拟干预是模型探针，不能当做湿实验因果验证；参考边和组织等生物背景会影响外部泛化。

## 3708 · Cert-LAS: Toward Certified Model Ownership Verification for Text-to-Image Diffusion Models via Layer-Adaptive Smoothing

[原文](https://proceedings.mlr.press/v306/qi26i.html)

<a id="qi26i-theory-statistics"></a>

**技术主题** · 按层平坦度分配水印认证噪声

- **问题 / 瓶颈** · 文生图扩散模型的水印验证在生成模型被微调或参数被蓄意扰动时可能失效。
- **核心创新 / 方法** · Cert-LAS 用私有扩散分类器嵌入签名，按层平坦度分配高斯平滑噪声，以相对无水印模型的响应做显著性检验，并计算可证扰动半径。
- **Baseline** · 改进来源：后门型扩散水印和各向同性参数平滑。实验对照：WatermarkDM、SleeperMark、Vanilla 平滑及去掉推理平滑的 Cert-LAS。
- **Benchmark** · Stable Diffusion v1.4 和 COCO2014 验证字幕，50,000 张图的 FID、CLIP、DreamSim；测 TPR@FPR=10⁻⁶、验证成功率、证书半径及参数攻击。
