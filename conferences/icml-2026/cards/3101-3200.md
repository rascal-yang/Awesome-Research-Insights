## 3101 · Plan for Speed: Dilated Scheduling for Masked Diffusion Language Models

[原文](https://proceedings.mlr.press/v306/luxembourg26a.html)

<a id="luxembourg26a-inference"></a>

**技术主题** · 掩码解码空洞调度

- **问题 / 瓶颈** · 在掩码扩散语言模型块内并行解码时，缓解同一步预测邻近位置的相互依赖。
- **核心创新 / 方法** · DUS 预先规定逐轮揭示的位置，先填间距大的锚点，再按几何尺度缩小间隔填空；也可把最小间隔作为自适应置信排序的后过滤器。
- **Baseline** · 改进来源：自置信 top-k 的半自回归掩码解码。实验对照：置信或随机规划、逐 token 生成及 EB/CB 自适应采样。
- **Benchmark** · LLaDA、Dream、DiffuCoder 五变体，块长 8/16/32/64；GSM8K、MATH500、HumanEval、MBPP、BBH、MMLU-Pro 等测正确性和去噪函数次数。
- **关键结果 / 消融** · LLaDA-Instruct 在 GSM8K、B=32 时 DUS 得 65.73%，同预算置信规划 38.74%，对应约 6.4 倍函数调用缩减；逐 token 得 80.29%。
- **适用条件 / 局限** · 固定位置日程缺输出自适应，较高并行度仍比逐 token 损失准确率；NFE 改善与端到端时延取决于服务实现。

**可复用机制** · 同一轮优先揭示彼此相隔的 token，再在已有锚点之间并行细化，可减少同时决策相邻位置时的局部依赖冲突。

## 3102 · The Hidden Link between RLHF and Contrastive Learning

[原文](https://proceedings.mlr.press/v306/lv26a.html)

<a id="lv26a-loss-functions"></a>

**技术主题** · 偏好优化的对比互信息

- **问题 / 瓶颈** · 解释偏好优化何时因拒绝回答概率接近零而失去学习信号，并改善被选回答的概率更新。
- **核心创新 / 方法** · 将 RLHF/DPO 与对比互信息联系，以 Jensen–Shannon 型估计替代 Donsker–Varadhan 上的比率目标，MIO 对偏好项和拒绝项分别构造平滑贡献。
- **Baseline** · 改进来源：DPO/RLHF、DV/MINE 与 JSD 互信息估计。实验对照：DPO、IPO、KTO、ORPO、SimPO、NCA 等及在线 DPO/IPO。
- **Benchmark** · UltraFeedback-Binarized 约 64K 偏好对，比较 Mistral-7B、LLaMA3-8B、Qwen2.5-7B 的八个数学/推理指标；Qwen3.5-9B 在线 TL;DR 测胜率和评分。
- **关键结果 / 消融** · 在线 TL;DR 的 MIO 胜率/质量 35.5/4.01，DPO 为 30.1/3.92，IPO 为 28.9/3.86；Mistral-7B 的 Arena-Hard 相对 DPO 提高 7.3 个绝对点。
- **适用条件 / 局限** · 互信息联系为近似解释，主要梯度结论针对成对偏好；摘要实验只检验在线偏好环，完整 clipped-PPO 动力学与其他估计器未验证。

**原文定位** · [§3.1 JSD 目标（PDF 第 4 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/lv26a/lv26a.pdf#page=4) · [§3.2–3.3（PDF 第 5 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/lv26a/lv26a.pdf#page=5) · [§4.2（PDF 第 7 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/lv26a/lv26a.pdf#page=7) · [表 5、§4.4–5（PDF 第 9 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/lv26a/lv26a.pdf#page=9)

**可复用机制** · 在拒绝样本概率已几乎为零时，改用分别计入正负响应的估计目标，可保留推动优选响应的梯度。

## 3103 · AtomWorld: A Benchmark for Evaluating Spatial Reasoning in Large Language Models on Material Structures

[原文](https://proceedings.mlr.press/v306/lv26b.html)

<a id="lv26b-evaluation"></a>

**技术主题** · 晶体结构操作评测

- **问题 / 瓶颈** · 量化语言模型能否直接构建和编辑晶体结构文件，并定位空间操作、格式与组成错误。
- **核心创新 / 方法** · AtomWorld 对初始 CIF 施加可计算的结构编辑以生成真值，模型根据文字动作返回 CIF；解析、组成和结构匹配分层验收，并用纯坐标与 CIF 专项探针分离误差。
- **Baseline** · 改进来源：材料知识或性质预测基准。实验对照：Gemini、GPT-o3/o4-mini、DeepSeek、Qwen、Llama，及坐标简化和少量工具实验。
- **Benchmark** · AtomMotor-2K 为 2,500 例、10 操作；CIF-Repair 22 例、CIF-Gen 20 例，另有 StructProp、CCS；测经结构匹配的成功比例、对齐后最大位移等。
- **关键结果 / 消融** · CIF-Repair Gemini 2.5 Pro 成功率 100%、o3 为 95.5%；CIF-Gen 分别 95%/100%。纯坐标 rotate around 的平均最大距离为 16.17/14.06（Gemini/DeepSeek），两模型 move 均为 0。
- **适用条件 / 局限** · 以文本 CIF 操作为主，工具循环测试初步，未覆盖统一多模态渲染；性质探针样本较少。

**原文定位** · [§3.1 输入与验证（PDF 第 2 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/lv26b/lv26b.pdf#page=2) · [§3.3–3.4（PDF 第 3 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/lv26b/lv26b.pdf#page=3) · [§4.4、表 2（PDF 第 6 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/lv26b/lv26b.pdf#page=6) · [表 3（PDF 第 7 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/lv26b/lv26b.pdf#page=7) · [局限（PDF 第 9 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/lv26b/lv26b.pdf#page=9)

## 3104 · SCalDA: Semantics-Calibrated and Diffusion-Enhanced Data Augmentation

[原文](https://proceedings.mlr.press/v306/lv26c.html)

<a id="lv26c-data-strategies"></a>

**技术主题** · 语义校准局部扩散增强

- **问题 / 瓶颈** · 改善合成训练图像的视觉语义、软标签与分类特征不一致，特别是少样本细粒度分类。
- **核心创新 / 方法** · SCalDA 用 Grounded-SAM 获得语义区域、Grad-CAM 积分定出显著区域和软标签占比；扩散修补只替换该区域，训练分类器时使特征相似度匹配门控标签相似性。
- **Baseline** · 改进来源：按面积混合标签的 CutMix、扩散样本增强及度量学习。实验对照：Mixup、AugMix、PuzzleMix、DiffMix、DiffuseMix、SaSPA、SGD-Mix 和随机掩膜消融。
- **Benchmark** · CUB 2/10/20-shot 用约五倍合成样本；常规评测含 CUB、Aircraft、Cars、Dogs、CIFAR-100、Tiny-ImageNet，报 Top-1。
- **关键结果 / 消融** · CUB 2-shot 为 40.21%，DiffMix 为 36.19%、原始训练为 28.18%；20-shot 为 84.16% 对 DiffMix 80.96%。常规 CUB 为 88.17%，仅无约束随机掩膜扩散为 86.92%。
- **适用条件 / 局限** · 区域模板和预训检测、掩膜及显著性影响可用性；多模块增加生成成本，论文离线合成。

## 3105 · FLAC: Maximum Entropy RL via Kinetic Energy Regularized Bridge Matching

[原文](https://proceedings.mlr.press/v306/lv26d.html)

<a id="lv26d-reinforcement-learning"></a>

**技术主题** · 控制隐式策略的生成路径

- **问题 / 瓶颈** · 隐式连续动作策略可以表达多峰分布，但动作对数概率难求，妨碍最大熵强化学习直接使用。
- **核心创新 / 方法** · FLAC 从高熵参考过程构造广义 Schrödinger 桥，以速度场动能控制路径偏离，对终端分布偏离给出上界，再将自适应拉格朗日约束用于离策略 actor–critic。
- **Baseline** · 改进来源：以路径上的动能正则替代难计算的动作熵项。实验对照：SAC、DIME、SAC-Flow、FlowRL；TD-MPC2 用作有模型参考。
- **Benchmark** · DMC Dog 与 HumanoidBench Unitree H1 连续控制，评估训练回报与每动作函数求值数；正则预算消融另行比较。
- **关键结果 / 消融** · 主实验的学习曲线中 FLAC 匹配或超过所测强无模型对照；每动作 2 次函数求值，DIME 和 SAC-Flow 分别为 16 次与 4 次。消融中 C=0 或 0.1 的过紧约束会降低表现。
- **适用条件 / 局限** · 结果依赖参考过程、动能预算和连续流的离散化；论文的上界约束终端分布偏离，未建立每项任务上的性能保证。

**原文定位** · [§3 广义桥（PDF 第 4 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/lv26d/lv26d.pdf#page=4) · [§4.2–4.3 动能及约束（PDF 第 5 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/lv26d/lv26d.pdf#page=5) · [图2 控制任务（PDF 第 6 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/lv26d/lv26d.pdf#page=6) · [图3与§5.1 对照及消融（PDF 第 7 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/lv26d/lv26d.pdf#page=7)

**可复用机制** · 若连续策略能采样却难求密度，可以约束生成路径偏离高熵参考过程的动能，间接保留探索所需的分布宽度，再由预算调节约束强度。

## 3106 · Spatial-Aware Reduction Framework: Towards Efficient and Faithful Visual State Space Models

[原文](https://proceedings.mlr.press/v306/lv26e.html)

<a id="lv26e-inference"></a>

**技术主题** · 扫描兼容的视觉 token 压缩

- **问题 / 瓶颈** · 视觉 Mamba 的二维选择性扫描依赖规则网格，无结构删减 token 会破坏扫描拓扑。
- **核心创新 / 方法** · STORM 沿行列组织候选裁减单元，并将合并限制在局部邻域，生成尺寸变小且可供扫描的规则特征网格；可接入现有剪枝或合并策略且无需重训练。
- **Baseline** · 改进来源：保留规则网格和邻域连续性。实验对照：原版 VMamba、PlainMamba，以及 EViT、ToMe 等裁减策略。
- **Benchmark** · ImageNet-1K 分类 Top-1 与 GFLOPs；另在 COCO 上评估目标检测和实例分割。
- **关键结果 / 消融** · VMamba-T 上，EViT 在 3.00 GFLOPs 得 15.2% Top-1，接入 STORM 后为 78.5%；原版 4.91 GFLOPs、82.6%。同预算的 STORM+ToMe 为 78.8%。
- **适用条件 / 局限** · 结构化裁减的自由度受扫描网格与邻域限制，表中的高压缩设置仍低于未裁减骨干。

## 3107 · Beyond Rational Illusion: Behaviorally Realistic Strategic Classification

[原文](https://proceedings.mlr.press/v306/lv26f.html)

<a id="lv26f-theory-statistics"></a>

**技术主题** · 基于参照点的策略分类

- **问题 / 瓶颈** · 经典策略分类假设人按客观收益和成本作最优反应，可能造成防御过度或不足。
- **核心创新 / 方法** · Pro-SF 将参照点、主观概率权重和损失厌恶写入 Stackelberg 博弈的个体响应，并考察分类器的两类防御错误。
- **Baseline** · 改进来源：用前景理论刻画特征操纵的主观收益。实验对照：完全理性响应下训练的分类器及去除各行为因素的版本。
- **Benchmark** · Adult、Diabetes、German、Spam 等表格数据及合成数据，模拟完全理性、非完全理性与混合响应；度量准确率和两类防御错误。
- **关键结果 / 消融** · 行为消融中完整模型为 78.92% 准确率、5.17% 过度防御、3.22% 防御不足；移除损失因素后分别为 77.72%、6.24%、5.29%。
- **适用条件 / 局限** · 结论基于论文定义的操纵成本和仿真响应，现场个体概率权重与参照点的可辨识性未报告。

## 3109 · Hierarchical ODE: Learning Continuous-Time Physical Prototypes for Early Link Failure Detection

[原文](https://proceedings.mlr.press/v306/lv26h.html)

<a id="lv26h-representation-learning"></a>

**技术主题** · 稀疏故障前兆的连续时间原型

- **问题 / 瓶颈** · 无线链路的失效前兆样本稀少且时刻不规则，跨物理场景的退化模式也不同。
- **核心创新 / 方法** · 用带 GRU 观测修正的 ODE 自编码器重建稀疏时序；以 Ward 层次聚类自动选原型簇，再局部细分和估计覆盖半径，按到原型的距离触发预警。
- **Baseline** · 改进来源：连续时间状态演化和两级原型发现。实验对照：LSTM、GRU、ResNet 与 ModernTCN 等离散编码器。
- **Benchmark** · 高密度办公楼混合 WiFi/蜂窝轨迹覆盖办公室、走廊、楼梯、会议室、卫生间、茶水间六场景，每场景约 20–30 条；评估 FAR 与 FRR。

- **核心创新 / 方法** · VFM 将观测条件转到初始噪声分布，用变分目标联合训练噪声适配器与流映射，以一次或少数前向映射生成条件样本。
- **Baseline** · 改进来源：让流和条件噪声共同对齐数据后验。实验对照：冻结映射的适配器、Latent DPS、Latent DAPS、PSLD、MPGD、FlowChef 与 FlowDPS。

## 3200 · Turbo4DGen: Ultra-Fast Acceleration for 4D Generation

[原文](https://proceedings.mlr.press/v306/man26a.html)

<a id="man26a-inference"></a>

**技术主题** · 按链稳定性复用多视角去噪计算

- **问题 / 瓶颈** · 动态三维视频的空间、相机和运动注意力链成本高，逐块独立删 token 又会破坏跨视角一致性。
- **核心创新 / 方法** · Turbo4DGen 跨去噪步滚动缓存块输出，用空间语义注意力为相机与运动块选 token 并用缓存回填；链级相似度过阈值则旁路整链。
- **Baseline** · 改进来源：结合块级复用、语义裁减和链级旁路。实验对照：SV4D、L4GM、Consistent4D、STAG4D 及随机裁剪等消融。
- **Benchmark** · ObjaverseDy 微调及 Consistent4D 零样本测试；主设定 576×576、5 帧、8 视角和 20 去噪步；评价延迟、峰值显存、LPIPS、PSNR 和 FVD。
- **关键结果 / 消融** · 论文报相对 SV4D 平均加速 9.7 倍。ObjaverseDy 的 LPIPS 为 0.113 对 0.122；Consistent4D 零样本为 0.119 对 0.118，FVD-F 为 708.51 对 732.40。
- **适用条件 / 局限** · 过度裁剪和提前旁路会损害时序与细节；零样本对照部分指标略低，所报延迟依赖模型、分辨率及帧视角设置。
