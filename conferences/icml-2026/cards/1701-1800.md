## 1701 · ALAS: Additive Learnable Alpha-Stable Kernels for Flexible Bayesian Optimization

[原文](https://proceedings.mlr.press/v306/huang26o.html)

<a id="huang26o-optimization"></a>

**技术主题** · 学习谱尾以适配目标函数粗糙度

- **问题 / 瓶颈** · 如何给贝叶斯优化选核，使其能随有限观测适配未知目标的粗糙程度？
- **核心创新 / 方法** · ALAS 用对称 α 稳定谱构造平稳 GP 核，以边际似然估计稳定度 α。ALAS-Sep 对各维一维核求和并分别学习 α。
- **Baseline** · 改进来源为平稳谱核与可学习谱尾。实验对照为 RBF、Matérn-5/2、RQ、Sinc 和 SDK，共用采集函数和优化设置。
- **Benchmark** · 一维 Weierstrass 和 RBF 先验模拟测拟合，多维合成、机器人推物和组合投资测 EI 最优差距，图 3 按 10 个种子汇总。
- **关键结果 / 消融** · 表 1 中学习到的最终 α 在指数基准为 1.96±0.03，Weierstrass 为 1.56±0.34；定理 4.2 给出一维 0<α<2 下信息增益 Õ(T^(1/(1+α)))。
- **适用条件 / 局限** · 作者指出精确 GP 的立方代价仍在。可加核适用于近似可加目标；稀疏交互或变量分组留待后续。

## 1702 · E2Former-V2: On-the-Fly Equivariant Attention with Linear Activation Memory

[原文](https://proceedings.mlr.press/v306/huang26p.html)

<a id="huang26p-architecture"></a>

**技术主题** · 基于局部轴对齐流式计算等变注意力

- **问题 / 瓶颈** · 如何让高阶旋转等变原子模型处理大型分子系统，避免边张量成为显存瓶颈？
- **核心创新 / 方法** · E2Former-V2 以轴对齐将 SO(3) 稠密收缩改写成有宇称稀疏性的 SO(2) 重索引，用 Triton 融合邻域收集、在线 softmax 和节点归约。
- **Baseline** · 改进来源为 E2Former-V1 与轴对齐的等变张量积。实验对照包括 MACE、eSEN、UMA，以及 e3nn、OpenEquivariance 和朴素 PyTorch 核。
- **Benchmark** · SPICE、OMol25 评能量/力 MAE；另测核 TFLOPS、激活显存、单 H20 的 1k 至 100k 原子吞吐及分子动力学。
- **关键结果 / 消融** · SPICE 二聚体能量 MAE 较 MACE-Large 低 48%；融合核相对朴素实现约 20 倍。在 10 万原子保守推理设置达 0.12 步/秒。
- **适用条件 / 局限** · 规模和加速测量限于报告的分子系统、GPU 与两种推理模式；独立局限小节未报告。

## 1705 · Semantic Tube Prediction: Beating LLM Data Efficiency with JEPA

[原文](https://proceedings.mlr.press/v306/huang26s.html)

<a id="huang26s-loss-functions"></a>

**技术主题** · 以局部方向一致性约束隐状态轨迹

- **问题 / 瓶颈** · 怎样提高语言模型在有限文本上的学习效率，并在生成时保留合理答案的多样性？
- **核心创新 / 方法** · STP 在下一个词元损失外，对相近序列位置的两个隐状态差分施加余弦方向一致性，结合 RoPE 位置处理。仅训练时应用该约束。
- **Baseline** · 改进来源为语言 JEPA 与局部线性测地假设。实验对照为常规 NTP 训练、两视图 JEPA 及掩码、曲率等变体。
- **Benchmark** · 以 Llama 系列测 NL-RX-SYNTH 正则表达式准确率及功能等价输出多样性，另用小型从头训练模型测试 HellaSwag 数据子集。
- **关键结果 / 消融** · NL-RX-SYNTH 用 1/16 数据并相应增加 16 倍轮数时，可达到全数据普通微调的准确率。HellaSwag 的 STP 1/16 数据为 30.39%，全数据 NTP 为 27.93%。
- **适用条件 / 局限** · 测地性是建模假设；主要节省独特样本，等计算比较增加小样本重复。作者将更大规模预训练和与推理时方法结合列为后续。

## 1706 · SAD-Flower: Flow Matching for Safe, Admissible, and Dynamically Consistent Planning

[原文](https://proceedings.mlr.press/v306/huang26t.html)

<a id="huang26t-inference"></a>

**技术主题** · 在生成时间加入轨迹约束控制

- **问题 / 瓶颈** · 怎样让流匹配在推理时满足新安全约束、动作可行性和动力学一致性，避免重新训练规划器？
- **核心创新 / 方法** · SAD-Flower 给生成 ODE 加虚拟控制，用规定时间的控制障碍函数和 Lyapunov 条件构造二次规划，联合减少三类轨迹约束违规。
- **Baseline** · 改进来源为流匹配规划和 CBF/CLF 控制。实验对照含 FM、Diffuser、SafeDiffuser、Decision Diffuser、梯度引导及拒绝采样。
- **Benchmark** · Maze2D、Hopper 等导航/运动、Kuka 堆叠及灵巧操作，记录安全、可接受性、动力学残差、奖励和计算开销。
- **关键结果 / 消融** · Maze2D Large 的安全和动作违规均为 0，动力学误差 0.01±0.01、奖励 1.69±0.26；FM 分别为 0.37、0.13、0.02 和 1.43。
- **适用条件 / 局限** · 定理要求二次规划在控制时间段可行并分析连续解；实际积分有小动力学偏差。作者讨论模型失配，并将随机动力学留待后续。

**原文定位** · [§5.1–5.2 控制增广（PDF 第 4 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/huang26t/huang26t.pdf#page=4) · [定理 5.1、§6.1（PDF 第 5 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/huang26t/huang26t.pdf#page=5) · [表 2（PDF 第 6 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/huang26t/huang26t.pdf#page=6) · [§6.2–6.3 数值偏差（PDF 第 7 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/huang26t/huang26t.pdf#page=7) · [结论（PDF 第 9 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/huang26t/huang26t.pdf#page=9) · [影响说明（PDF 第 10 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/huang26t/huang26t.pdf#page=10)

**可复用机制** · 流匹配生成轨迹时，可把采样演化写成受控系统，在每步解小型二次规划来纠正状态、动作和动力学残差。约束可推理时替换，前提是知道动力学且规划问题可行。

## 1707 · Robust Learning via Nested Distributionally Robust Optimization

[原文](https://proceedings.mlr.press/v306/huang26u.html)

<a id="huang26u-optimization"></a>

**技术主题** · 分离离群清洗与几何鲁棒化

- **问题 / 瓶颈** · 训练数据同时发生输入扰动和统计污染时，怎样保护有信息的远端样本，同时抑制近处的异常样本？
- **核心创新 / 方法** · 嵌套 DRO 以内层悲观最优传输稳健化局部损失、外层乐观 φ 散度清洗权重；推导强对偶、闭式权重及 χ² 情形的方差正则形式。
- **Baseline** · 改进来源为最优传输 DRO 与散度鲁棒估计。实验对照含标准 DRO、OR-WDRO、UOT-DRO、污染 ERM 及纯统计或顺序清洗。
- **Benchmark** · 混合合成回归测干净分布上的 MAE 超额风险；CIFAR-10 ResNet-18 在硬旋转、错标及重叠污染下测最佳干净测试准确率。
- **关键结果 / 消融** · CIFAR-10 嵌套方法为 78.78%，污染 ERM 为 75.00%，最佳所列耦合基线 UOT-DRO 为 74.10%，干净 ERM 参考为 88.17%。
- **适用条件 / 局限** · 对偶与闭式重加权依赖相应正则和半径条件。实验污染由设计注入，作者将更广散度约束与序列决策作为后续。

## 1709 · Alignment-Sensitive Minimax Rates for Spectral Algorithms with Learned Kernels

[原文](https://proceedings.mlr.press/v306/huang26w.html)

<a id="huang26w-theory-statistics"></a>

**技术主题** · 在噪声尺度上评估谱排序与信号的对齐

- **问题 / 瓶颈** · 当核由学习产生时，如何刻画目标信号与核谱排序的对齐对谱估计风险的影响？
- **核心创新 / 方法** · 以信号相对核排序的尾能量和噪声定义有效跨度维数 ESD 与跨度剖面，证明相应最小最大风险，并分析固定特征基的过参数化梯度流。
- **Baseline** · 改进来源为谱截断、核回归与最小最大分析。理论对照含最优调参的主成分估计和固定核谱理论，数值对照固定谱与学习谱。
- **Benchmark** · 有限、无限序列模型及扩展的线性/RKHS 回归；数值合成改变信号在谱序中的错位，度量 ESD 和估计风险。
- **关键结果 / 消融** · ESD 至多 K 的有限序列类最小最大风险为 Θ(Kσ²)。无限序列在配额条件下为 Θ(σ₀²Kₙ/n)；固定特征基梯度流在条件下可弱降 ESD。
- **适用条件 / 局限** · 作者指出 ESD 是总体量，梯度流的保证要求固定特征基、信号间隔与初始谱序条件。特征函数随训练改变的情形仍待理论证明。

## 1710 · Breaking the Computational Barrier: Provably Efficient Actor–Critic for Low-Rank MDPs

[原文](https://proceedings.mlr.press/v306/huang26x.html)

**技术主题** · 把探索与策略更新降到评估 oracle

- **问题 / 瓶颈** · 低秩转移的未知特征 RL 能否在保留样本效率的同时避免使用规划或约束规划 oracle？
- **核心创新 / 方法** · Opt-AC 用最大似然学转移、Gram 矩阵构造乐观奖励，调用策略评估获得 critic 后更新策略；用条件随机 Fourier 特征构造近似低秩扩展。
- **Baseline** · 改进来源为低秩 MDP 乐观探索和 actor–critic。理论对照比较 PE、PP、CP 的监督学习 oracle 复杂度及 RAFFLE 等样本界；实验对照含 SAC 与探索奖励消融。

- **关键结果 / 消融** · 定理 5.2 的轨迹上界为 Õ(H⁵d³∣A∣² log∣Θ∣/ε²)。K 轮的监督学习复杂度至多 SL_{2K}(1/K)；MuJoCo 实现多数环境可比或优于 SAC。
- **适用条件 / 局限** · 计算界以监督学习 oracle 代价为代理，并依赖模型类和覆盖条件。连续控制实现用神经 critic 近似理论结构。

## 1711 · Formalizing the Binding Problem

[原文](https://proceedings.mlr.press/v306/huang26y.html)

<a id="huang26y-evaluation"></a>

**技术主题** · 从特征存在性中扣除对象绑定信息

- **问题 / 瓶颈** · 如何定量判断视觉模型把颜色、形状等特征绑定到了正确对象，而非仅表示有哪些特征？
- **核心创新 / 方法** · 定义对象代码与特征代码的绑定互信息和条件量，以数据集先验熵、对象与特征探针的自回归交叉熵估计。
- **Baseline** · 改进来源为对象—特征绑定与信息论探针。实验对照比较线性、二次、DNN 和注意力探针，及 [CLS] 与空间词元。
- **Benchmark** · 在 ColorShape 等合成场景和自然数据上改变物体数、特征或遮挡，报告绑定比特数、归一化解析比例和条件绑定。

## 1798 · Gradient Preconditioning for Efficient and Reliable Reward-Guided Generation

[原文](https://proceedings.mlr.press/v306/hwang26h.html)

<a id="hwang26h-optimization"></a>

**技术主题** · 把奖励梯度投影成保持噪声统计的方向

- **问题 / 瓶颈** · 怎样提高单步文生图的测试时噪声优化效率，并减轻为提高代理奖励而产生的异常图像？
- **核心创新 / 方法** · 以紧凑 Fourier 域的分块范数构造白高斯可行集，用闭式投影预处理每步奖励梯度，再用 Adam 更新噪声。
- **Baseline** · 改进来源为初始噪声优化与频谱先验。实验对照为无优化、ReNO、PRNO、MPGR 与附录 best-of-K。
- **Benchmark** · 用 FLUX 的单步生成，四种偏好奖励轮换为优化或留出指标，比较美学分、PickScore、用时和图像多样性。
- **关键结果 / 消融** · 60 次迭代达美学分 7.120、耗时 69.7 秒；MPGR 200 次为 7.133、235.5 秒。该方法 200 次为 8.908，留出 PickScore 0.220。
- **适用条件 / 局限** · 投影对象是梯度，实际潜变量无需留在可行集。作者指出依赖奖励模型，仍可能放大其偏见或盲点。

**原文定位** · [算法 1、§4 白噪声约束（PDF 第 3 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/hwang26h/hwang26h.pdf#page=3) · [§4.3 闭式投影（PDF 第 4 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/hwang26h/hwang26h.pdf#page=4) · [§5 实验设置（PDF 第 6 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/hwang26h/hwang26h.pdf#page=6) · [表 1、结论（PDF 第 8 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/hwang26h/hwang26h.pdf#page=8) · [影响说明（PDF 第 9 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/hwang26h/hwang26h.pdf#page=9)

**可复用机制** · 在固定生成器上调初始噪声以追求奖励时，可先约束每次梯度的局部频谱能量，再拿投影后的方向更新。这样让单步更新与训练时噪声统计更一致，同时保留直接优化奖励的能力。
