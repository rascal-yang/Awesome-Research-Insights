## 5101 · Spectral Bridge Variational Inference: Dynamic LoRA via Bures-Wasserstein Gradient Flows

[原文](https://proceedings.mlr.press/v306/xi26g.html)

<a id="xi26g-optimization"></a>

**技术主题** · 逆列能量的自适应LoRA收缩

- **问题 / 瓶颈** · 固定rank依赖手动选择，而统一权重衰减不能分别压制弱因子列。
- **核心创新 / 方法** · 初始rank64；每列能量为A/B对应列范数平方和，以截顶逆能量系数的EMA作加权L2，再用AdamW更新。仅按缓存算法描述实际操作，不将其自动等同精确BW流或变分后验。
- **Baseline** · ARD/组稀疏与LoRA为来源；实际表格含LoRA/DoRA/PiSSA/MiLoRA/AdaLoRA/GOAT/LoRA-One，部分结果直接引既有论文；最近自适应收缩原作及独立新增待核实。
- **Benchmark** · Llama2-7B NF4、Mistral7B/Llama3-8B；Commonsense170k及GSM8K/HumanEval/MMLU；准确率、按奇异值阈值1e−4计算的平均effective rank。
- **关键结果 / 消融** · Llama2平均45.63对LoRA-One45.45；GSM8K60.85对60.44，而HumanEval28.54低28.66。报告effective rank6.8并不直接证明实际adapter张量或训练显存缩为该rank。
- **适用条件 / 局限** · 主文更新未明确给出物理裁剪步骤；近零列、谱分量与实际参数预算须分开。几何/全局收敛/指数裁剪主张和因子参数化的对应、引用基线预算及消融待统一核实。

## 5102 · Do Neural Operators Forget Geometry? The Forgetting Hypothesis in Deep Operator Learning

[原文](https://proceedings.mlr.press/v306/xia26a.html)

<a id="xia26a-evaluation"></a>

**技术主题** · 几何探针指导算子重注入

- **问题 / 瓶颈** · 几何只在输入提供时，深层特征可能难以恢复边界或整体区域。
- **核心创新 / 方法** · 训练辅助mask decoder并看频谱，比较FNO/Transolver/LNO；用FiLM、加法或拼接在不同层注入mask/SDF/坐标。新增暂限有条件失效诊断与注入位置选择，非新FiLM。
- **Baseline** · DPI、FiLM、特征拼接和已有几何算子为来源；实际同骨干无注入及位置/encoder/融合消融；最近geometry-conditioning原作待核实。
- **Benchmark** · FlowBench LDC-NS/NSHT跨几何、AirfRANS、Darcy五边形训练六/八边形测试；relative L2及逐层mask MSE，单5090。
- **关键结果 / 消融** · FNO LDC-NS .361→.121（相对66.6%降），NSHT .411→.239；LNO NSHT仅.236→.229，部分注入会退化。LNO AirfRANS仍降26.3%，不能概括LNO永远无需注入。
- **适用条件 / 局限** · DPI只保证信息不增加，不保证严格丢失或趋于独立；可逆层是边界。探针容量/频谱只是代理，最佳位置逐数据挑选与额外参数控制待核实。

## 5103 · Factored Classifier-Free Guidance

[原文](https://proceedings.mlr.press/v306/xia26b.html)

<a id="xia26b-inference"></a>

**技术主题** · 分属性组的classifier-free guidance

- **问题 / 瓶颈** · 单一CFG权重会强化目标属性同时改变应保持的属性与身份。
- **核心创新 / 方法** · 属性独立MLP编码后拼接，按组mask条件，分别计算条件减无条件score并按组权重求和；在假定图下划分受影响/保持组，接入DDIM编辑。
- **Baseline** · CFG、组合score、DDIM编辑和给定因果图为来源；实比全局CFG不同权重及不引导参考。独立增量暂限组权重与编辑协议，最近compositional guidance先例待核实。
- **Benchmark** · CelebA-HQ64×64，Smiling/Male/Young简化独立属性；目标/非目标分类器AUROC相对ω1变化，反向编辑MAE/LPIPS；其他图像设置细节待核实。
- **关键结果 / 消融** · 第6–7页曲线中提高目标权重可保留相近目标AUROC变化，同时减小非目标放大与反向重建误差；精确数值与多seed待核实，不按图猜测。
- **适用条件 / 局限** · 因子proxy posterior要求给定噪声潜变量的组条件独立，现实属性通常相关；给定图不等于已识别真实因果。组数增加需额外denoiser调用，DDIM离散反演不是无条件精确逆。

## 5104 · EchoAttention: Exploiting Token-Pair Redundancy and Frame-Block Similarity for Efficient Video Generation

[原文](https://proceedings.mlr.press/v306/xia26c.html)

<a id="xia26c-modules"></a>

**技术主题** · 非稀疏视频head的帧块原型复用

- **问题 / 瓶颈** · 部分head权重分散，统一token剪枝遇到质量下限。
- **核心创新 / 方法** · 一帧作原型，低维投影预测逐token校准并全局归一化，先汇聚value再一次原型乘积；soft→straight-through→固定路由三阶段蒸馏，另训练LoRA128。
- **Baseline** · 稀疏attention、时间冗余、原型近似和蒸馏为来源；实比VSA/SLA/SpargeAttn及sparse-only/echo-only/manual-route/echo-full，最近原作待核实。
- **Benchmark** · Wan2.1-1.3B480p、CogVideoX1.5-5B720p，5秒50步；3000蒸馏step batch64；VBench、相对dense PSNR/SSIM/LPIPS与端到端秒数。
- **关键结果 / 消融** · Wan181→92秒，1.97倍，VBench83.2持平；同92秒sparse-only81.5，manual-route93秒82.9。Cog770→318秒2.42倍，VBench81.9→82.0，但LPIPS .2391略差SpargeDense .2317。
- **适用条件 / 局限** · 原型校准为近似且需额外训练和三分支早期成本；LoRA与路由收益须分开。帧块相似性不保证任意视频时序，更多模型/长视频与硬件适配待核实。

## 5107 · LazyAttention: Efficient Retrieval-Augmented Generation with Deferred Positional Encoding

[原文](https://proceedings.mlr.press/v306/xia26f.html)

<a id="xia26f-inference"></a>

**技术主题** · 内核延迟旋转的单副本文档KV

- **问题 / 瓶颈** · 预先为位置修正物化KV会复制缓存或产生带宽开销。
- **核心创新 / 方法** · 把相对RoPE变换移到tile计算；prefill选择较小tile旋转，decode仅相对文档offset变化时旋转query，元数据打包并与FlashAttention/vLLM融合。
- **Baseline** · RoPE相对旋转、PromptCache/CacheBlend/Block-Attention为来源及实比；新增暂限单副本共享和低开销kernel，最近位置无关cache先例待核实。
- **Benchmark** · Tulu3-Block-FT8B、H10096GB vLLM0.8.5；2WikiMQA/HotpotQA/TriviaQA/NarrativeQA，TTFT/ITL/QA质量；Zipf文档池10万、每query10文档的trace模拟hit ratio。
- **关键结果 / 消融** · 1GB高偏度cache命中13.57%对Block-Attn7.27%，低偏度3.47%对1.84%；10GB中偏23.89%对21.13%，优势随预算缩小。约.2%额外核开销为作者概括，具体端到端数字待核实。
- **适用条件 / 局限** · 命中表为trace模拟而非全部真实在线流量；位置对齐只对相同cached K/V精确，独立块产生的隐藏态不等于完整上下文重算。线性attention不在范围；质量和跨硬件表待核实。

## 5108 · DIVER: Diving Deeper into Distilled Data via Expressive Semantic Recovery

[原文](https://proceedings.mlr.press/v306/xia26g.html)

**技术主题** · 蒸馏图像的扩散后恢复

- **问题 / 瓶颈** · 像素蒸馏数据常过拟合蒸馏骨干，新骨干难利用其信息。
- **核心创新 / 方法** · VAE编码蒸馏图，加适度噪声初始化；类条件CFG贯穿采样，仅语义阶段加向原潜码平方距离梯度，后处理不重做原始双层蒸馏。

- **关键结果 / 消融** · MTT ImageFruit IPC10 18.9±1.4→29.8±2.0；SRe2L IPC50 RN18 46.8→54.0，但RN10160.8→61.3收益缩小。SI和SG组合有饱和，强MGD3 IPC10仅45.8→46.4。
- **适用条件 / 局限** · 扩散模型本身引入外部训练数据与计算，非仅从小数据恢复被证明存在的信息。VAE不保证滤掉架构专属噪声；附录phase范围、成本与各组等生成预算待核实。
