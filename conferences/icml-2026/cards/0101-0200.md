## 101 · Flow-Based Density Ratio Estimation for Intractable Distributions with Applications in Genomics

[原文](https://proceedings.mlr.press/v306/antipov26a.html) · [关联 Insight](../../../papers/scientific-ml.md#antipov26a-theory-statistics)

- **问题 / 瓶颈** · 直接用两个条件生成模型分别积分似然，再取比值，会增加计算并传播两次离散化误差。
- **核心创新 / 方法** · 通过条件流匹配在一条生成动力学上跟踪对数密度比，并用不同噪声和调度处理估计难度。
- **Baseline** · 改进来源为条件流匹配。互信息对照有分类器、TSM 和 CTSM 的 Schrödinger bridge 版本。单细胞丰度对照有 MrVI、MELD。
- **Benchmark** · 用模拟高斯任务测解析互信息与估计值的 MAE。单细胞差异丰度比较 AUC、NAR、CSP 与已知变化强度的 Spearman 相关，三次训练求均值。另在 NeurIPS 2021 和 C. elegans 数据上测批次校正。
- **关键结果 / 消融** · 高差异丰度段，噪声下限 0.1 的 scRatio 的 AUC 为 0.96、NAR 为 11.39。MrVI 为 0.89、7.33，MELD 为 0.93、6.45。该设定的 CSP 为 0.98，低于 MELD 的 0.99。
- **适用条件 / 局限** · 估计需要各条件的训练样本，并受流路径和调度选择影响。丰度变化的真值对照来自论文构造的半合成设置。

## 102 · Protein Language Model Embeddings Improve Generalization of Implicit Transfer Operators

[原文](https://proceedings.mlr.press/v306/antoniadis26a.html) · [关联 Insight](../../../papers/scientific-ml.md#antoniadis26a-representation-learning)

- **问题 / 瓶颈** · 训练可跨蛋白迁移的分子动力学生成代理，需要大量长时间 MD 轨迹，遇到未见蛋白仍可能泛化不足。
- **核心创新 / 方法** · 在学习隐式转移算子的粗粒度模型中加入预训练蛋白语言模型嵌入，使序列提供外部结构和演化线索。
- **Baseline** · 改进来源为粗粒度 TITO。实验比较原 TITO、只加结构条件的模型、PLaTITO 系列及 Boltzmann Emulator/BioEmu。
- **Benchmark** · 在未见快折叠蛋白体系上用参考 MD 衡量平衡分布特性，报 MAE、RMSE 和覆盖率，并列出训练轨迹时长、GPU 小时及参数。
- **关键结果 / 消融** · 相同 56 ms MD 训练数据下，原 TITO 为 MAE 1.068 和覆盖率 0.590，3M PLaTITO 为 0.949 和 0.651，19M 版本为 0.824 和 0.666。另一种结构与语言特征组合的覆盖率为 0.570，加入特征并非总有收益。
- **适用条件 / 局限** · 结果基于粗粒度蛋白与所测平衡采样分布，依赖序列嵌入及参考 MD，尚不能由这些指标断定迁移到任意蛋白体系。

## 103 · Certificates for Complex-Compatible Learned Cochain Laplacians

[原文](https://proceedings.mlr.press/v306/anwer26a.html) · [关联 Insight](../../../papers/scientific-ml.md#anwer26a-loss-functions)

- **问题 / 瓶颈** · 网格学习算子的小预测误差可能掩盖链复形不相容，引发谱低端偏移与网格加密时的病态。
- **核心创新 / 方法** · 计算算子对到链相容集合的距离证书，并用闭式 Frobenius 最近相容投影控制线性求解与谱偏差。训练中可用软缺陷惩罚或硬约束。
- **Baseline** · 比较来源为满足链约束的经典离散化。实验对照含无约束训练、软缺陷惩罚和硬链相容参数化。
- **Benchmark** · 在常系数 Poisson 等椭圆方程上变更网格分辨率和测试拓扑，比较 MSE、条件数、归一化缺陷、谱隙和证书状态。表 1 用五个种子。
- **关键结果 / 消融** · 表 1 的 N=32 时，无约束与软惩罚的条件数分别约为 1.73×10⁴ 和 2.47×10²，MSE 从约 2.18×10² 降至 2.91×10⁻⁷。硬相容模型将链缺陷保持为零。
- **适用条件 / 局限** · 低谱扰动保证依赖核空间和正谱之间有隙，且边界处理良定。软惩罚仅在实测缺陷足够小的证书区间内提供保障。

## 104 · ORLoopBench: Solver-in-the-Loop Benchmarks for Self-Correction and Behavioral Rationality in Operations Research

[原文](https://proceedings.mlr.press/v306/ao26a.html) · [关联 Insight](../../../papers/llm.md#ao26a-evaluation)

- **问题 / 瓶颈** · 一次性生成优化代码忽视不可行模型的诊断和修复过程。整段重写即使恢复可行，也可能改掉原问题语义。
- **核心创新 / 方法** · 将不可行修复建为可执行的多步过程。每次局部编辑后由求解器重新返回不可约不可行约束组，使用可验证反馈训练修复策略。
- **Baseline** · 改进来源为基于 IIS 的人工优化诊断及可验证奖励强化学习。对照含 Qwen3-8B 的 SFT 版本、多家 API 智能体和整段代码重生成。
- **Benchmark** · ORDebug 提供 5,362 个 LP/MILP 例子，Gurobi 11.0 复算 IIS。固定 LP 测试含 450 例，测 RR@5、诊断准确率和步数。ORBias 测库存决策在等价表述下的稳定性。
- **关键结果 / 消融** · Qwen3-8B-GRPO 在固定 LP 比较中的 RR@5 为 95.3%，最强 API 对照 Claude Sonnet 4.6 为 92.4%。论文另报告诊断准确率由 47.8% 到 62.4%，平均步数由 3.15 到 2.25。
- **适用条件 / 局限** · 实验以 Gurobi 的 IIS 为反馈，主要覆盖构造的 LP/MILP 故障和库存题。模型改到可行仍需核查是否保留原目标与约束语义。

## 105 · The Sign Estimator: Preference Modeling for LLM Alignment under Heterogeneity

[原文](https://proceedings.mlr.press/v306/aouad26a.html) · [关联 Insight](../../../papers/llm.md#aouad26a-loss-functions)

- **问题 / 瓶颈** · 将异质标注者的偏好都拟合为同一个 Bradley–Terry 奖励，可能扭曲总体平均效用的排序。
- **核心创新 / 方法** · 在汇总偏好对上，用二分类损失替换标准交叉熵，直接估计与总体平均效用顺序一致的偏好方向。
- **Baseline** · 改进来源为 RLHF 的偏好奖励建模。对照包括标准交叉熵 RLHF，以及用 EM 显式拟合多个同质群的混合奖励。
- **Benchmark** · 用 SHP、HH-Anthropic 和 CoVal 评测偏好预测准确率，另做 HH 训练到 CoVal 的跨分布评测。数字孪生实验检查真实平均效用排序的准确率和方向角误差。
- **关键结果 / 消融** · CoVal 上标准 RLHF 和 Sign Estimator 为 78.09% 和 80.72%。理论在对称性及特征分布正则条件下给出 O(n⁻¹ᐟ³) 收敛率。
- **适用条件 / 局限** · 估计目标是总体平均效用的序关系，需要论文的偏好异质性对称假设。不能从该保证推出个体偏好都能被恢复。

## 106 · Off-Policy Learning in Large Action Spaces: Optimization Matters More Than Estimation

[原文](https://proceedings.mlr.press/v306/aouali26a.html) · [关联 Insight](../../../papers/reinforcement-learning.md#aouali26a-reinforcement-learning)

- **问题 / 瓶颈** · 大动作空间的离策略策略优化中，估计器 MSE 小也可能伴随难优化的目标，最终策略收益不高。
- **核心创新 / 方法** · 对使用线性 softmax 的策略，以日志回报和倾向概率加权对数似然，简化目标几何，同时检验依估计器设计的参数化能缓解多少优化难题。
- **Baseline** · 改进来源为 IPS 型离线策略优化和加权行为克隆。对照含 IPS、ES、DR、MIPS、OffCEM、POTEC、PC，以及 LPI、cLPI、RegKL、BPR。
- **Benchmark** · 用 MovieLens 等三个推荐基准测试，GoodReads 的动作数达 100 万。比较不同批量大小和学习率的验证收益，并与估计器 MSE、目标几何对照。
- **关键结果 / 消融** · MovieLens 上，PWLL 一类的 cLPI 即使估计 MSE 高于 MIPS，也得到更高验证收益。批量和学习率变化下，对数似然目标通常比 IPS 类目标的收益更稳定。
- **适用条件 / 局限** · 实证使用内积 softmax 策略与已知日志倾向，理论和实验不直接覆盖一般深度策略或多步离线强化学习。

- **问题 / 瓶颈** · 归纳头的出现曾在语言模型中被观察到，但何时形成、数据中哪些统计结构足以触发形成仍不清楚。

- **Baseline** · 分析来源为归纳头的前缀匹配和上下文复制诊断。对照调整同系列模型的规模、批量、上下文及不同重复分布，另用 Pythia 检查拟合。
- **Benchmark** · 在自然语料、半自然和合成序列上训练或分析 GPT-2 与 Pythia。测前缀匹配、关联回忆等指标，以及相变出现时的训练词元数。
- **关键结果 / 消融** · 按式 7 用正比于 B^0.63·C^0.38 的训练词元数预测出现点，报告与观察值的相关 r=0.986。合成实验显示高频且可靠的局部重复已足够诱发归纳头。
- **适用条件 / 局限** · 预测式来自论文的训练配置和检测判据，接近数据门槛时还受类别结构与边际分布影响。跨架构或训练目标的普适性未报告。

## 108 · Taming Stochastic Gradient Descent: Almost Sure Convergence and Saddle-Point Avoidance under $(L_0,L_1)$-Smoothness

[原文](https://proceedings.mlr.press/v306/apidopoulos26a.html) · [关联 Insight](../../../papers/ml-foundations.md#apidopoulos26a-optimization)

- **问题 / 瓶颈** · 广义 (L₀,L₁) 光滑允许梯度超线性增长，传统全局 Lipschitz 假设下的 SGD 收敛结论无法直接套用。
- **核心创新 / 方法** · 用状态相关尺度压制随机更新。耗散版本进一步用目标梯度的耗散性质限制轨迹，放松对梯度噪声矩的要求。
- **Baseline** · 改进来源为 SGD 的驯化及经典鞍点逃逸分析。理论对照是普通 SGD 和不同噪声矩条件，无经验算法对照。
- **Benchmark** · 理论设定为广义光滑非凸目标、递减步长和随机梯度，考查几乎必然收敛及收敛到严格鞍流形的概率。应用示例包括带正则的经验风险。
- **关键结果 / 消融** · 定理 1–2 给出两种驯化迭代的几乎必然收敛。定理 3 在鞍附近有足够激励噪声且步长符合条件时，收敛到严格鞍流形的概率为零。
- **适用条件 / 局限** · 结论依赖目标函数与噪声的正则性、步长序列和鞍点附近激励条件。理论避免严格鞍点，不保证达到全局极小。

## 109 · Optimal Learning from Label Proportions with General Loss Functions

[原文](https://proceedings.mlr.press/v306/applebaum26a.html) · [关联 Insight](../../../papers/ml-foundations.md#applebaum26a-loss-functions)

- **问题 / 瓶颈** · 训练时只能看到每袋的类别比例，却要优化单样本损失。既有无偏估计在大袋条件下的方差会变大。
- **核心创新 / 方法** · GeneralUPM 以预测概率和袋内标签比例构造去偏损失，通过中心化降低方差，并扩展到二分类和多分类估计。
- **Baseline** · 改进来源为比例匹配和 EasyLLP 的无偏损失。实验对照为这两种方法。
- **Benchmark** · MNIST 奇偶、CIFAR-10 二值化、Higgs 和 Adult 做批训练，Criteo Display Advertising Challenge 做在线点击预测。主要指标为单样本对数损失。
- **关键结果 / 消融** · 理论估计方差可做到不随袋大小增长。Criteo 在线实验中，大袋时 GeneralUPM 的对数损失明显优于对照，袋大小为 2¹¹ 时各时段也保持优势。
- **适用条件 / 局限** · 作者指出实验仅做二分类，多类全直方图尚无快速率分析，多类界对类别数的紧性与类别总量场景的仿射条件必要性仍未知。

- **问题 / 瓶颈** · 超图神经网络已有攻击多需掌握模型参数或只修改一种输入，需要在参数未知时同时评估结构和特征攻击。
- **核心创新 / 方法** · MeLA 通过代理模型和超图拉普拉斯构造元目标，在显式预算下用 FGSM 或 PGD 修改关联矩阵和节点特征。MeLA-D 交替生成扰动和训练分类器。

- **Benchmark** · 理论考虑可实现类型预测，在线衡量累计领导者遗憾，分布设定衡量 PAC 阈值误差和样本复杂度。实验数据集未报告。
- **关键结果 / 消融** · 实例最优在线遗憾等于所提维数。分布式样本下界为 Ω((SNdim+log(1/δ))/ε)，上界为 O((SGdim·log(1/ε)+log(1/δ))/ε)。
- **适用条件 / 局限** · 作者指出主要统计保证要求可实现假设，计算高效且实例最优的算法和不可实现情形仍待研究。

## 200 · Is One Layer Enough? Understanding Inference Dynamics in Tabular Foundation Models

[原文](https://proceedings.mlr.press/v306/balef26a.html) · [关联 Insight](../../../papers/ml-foundations.md#balef26a-evaluation)

- **问题 / 瓶颈** · 表格基础模型依靠多层 Transformer 推断，但各层是否提供不同计算、能否共享参数尚不清楚。
- **核心创新 / 方法** · 用逐层表格 Logit Lens、表示相似性、层消融和顺序扰动比较推断阶段，据此训练重复同一层的循环 nanoTabPFN。
