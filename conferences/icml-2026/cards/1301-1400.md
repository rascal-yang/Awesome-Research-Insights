## 1301 · Identifying Common Hubs in Multiple Gaussian Graphical Models

[原文](https://proceedings.mlr.press/v306/gomez26a.html) · [关联 Insight](../../../papers/ml-foundations.md#gomez26a-theory-statistics)

- **问题 / 瓶颈** · 多群体的高斯图可能共享枢纽也可能有群体特有强节点，单独估每张精度矩阵再交集容易累积误差。
- **核心创新 / 方法** · JIC-HD 直接求联合最小最大特征子空间，用投影矩阵对角值度量共同影响，再阈值筛选，无须完整估每群体条件图。
- **Baseline** · 改进来源为 Gaussian graphical model、公共因子和 hub 检测。对照 GLASSO、HWGLASSO 等以及加法共享特征空间。
- **Benchmark** · 合成 3 群 GGM、p=100/200/400、5–15 个共同 hub，扫特有和共有强度报 F-score；TCGA LUAD/LUSC 分析 426 基因。
- **关键结果 / 消融** · 在共同概率 0.4、个体强度 0.5 的难组，图 4 的平均 F-score 高于对照。实数据 JIC-HD 与 HWGLASSO 同时识别 SFTPA1/2。
- **适用条件 / 局限** · 高概率排错需结构假设、适当特征空间维度和阈值，实数据条件关联不能确定因果或临床效果。

## 1302 · AdaSplash-2: Faster Differentiable Sparse Attention

[原文](https://proceedings.mlr.press/v306/goncalves26a.html) · [关联 Insight](../../../papers/llm.md#goncalves26a-modules)

- **问题 / 瓶颈** · entmax 可使注意力块精确为零，但迭代计算归一化阈值导致可微稀疏注意难超过 softmax 内核。
- **核心创新 / 方法** · AdaSplash-2 在 SRAM 内按块构造近似分数直方图，以更紧初始值将阈值求解减至通常 1–2 次，再让 Triton 前向/反向跳过零块。
- **Baseline** · 改进来源为 AdaSplash 和 α-entmax。对照 FlashAttention-2 的 CUDA/Triton、原 AdaSplash、softmax/entmax 配 RoPE 或 NAPE。
- **Benchmark** · 单 A6000 测 bf16 的 4K–128K 前反向，扫块稀疏度；350M/1B 模型用 OLMES、RULER、HELMET 测困惑度、精度和上下文能力。
- **关键结果 / 消融** · 零块很高的算子极限超过 FlashAttention-2 的 2×，且在测试稀疏度上都快于 AdaSplash。1B RoPE softmax 的 RULER 平均由 4K 51.4 到 32K 27.3，文中比较了 NAPE 稀疏模型对退化的缓解。
- **适用条件 / 局限** · 速度取决于真块稀疏度和硬件，长序列计时用代表层而非端到端吞吐。未在 Hopper 的 FlashAttention-3 同设比较。

## 1303 · VenusBench-Mobile: A Challenging and User-Centric Benchmark for Mobile GUI Agents with Capability Diagnostics

[原文](https://proceedings.mlr.press/v306/gong26a.html) · [关联 Insight](../../../papers/multimodal.md#gong26a-evaluation)

- **问题 / 瓶颈** · 手机 GUI 基准按应用功能出题，常漏掉意图模糊、多轮、冲突与布局变化，无法定位代理是哪种能力失效。
- **核心创新 / 方法** · VenusBench-Mobile 用用户意图设计任务并按 PUDAM 的感知、理解、决策、行动、记忆分能力分层标注，在线执行并加入稳定性变体。
- **Baseline** · 基准来源为在线手机 GUI 代理评测。实测 UI-Venus、GUI-Owl、Qwen3-VL、Kimi K2.5、Gemini-3-Pro、GPT-5.1 等。
- **Benchmark** · 真实移动界面任务与中文、措辞、暗色、平板变体，报任务成功率、分能力等级准确率及要求五变体全成功的 SPR。
- **关键结果 / 消融** · 总成功率 Gemini-3-Pro+UI-Venus-72B 为 36.9%，Kimi K2.5 为 24.8%，UI-Venus-72B 单独 15.4%；最高 SPR 15%，多数模型为 0。
- **适用条件 / 局限** · 在线评估会受真实界面与执行配置波动，闭源配置借用 UI-Venus 落地执行。变体稳定性仍局限于基准设置。

## 1304 · Twins: Learn to Predict Unified Representations with Focal Loss

[原文](https://proceedings.mlr.press/v306/gong26b.html) · [关联 Insight](../../../papers/multimodal.md#gong26b-loss-functions)

- **问题 / 瓶颈** · 语义 ViT 适合理解，VAE 像素细节利于生成。在同 DiT 上联合拟合时，简单 MSE 偏向容易的语义通道。
- **核心创新 / 方法** · Twins 在同空间网格沿通道拼接 SigLIP/ViT 与 VAE latent，保持 token 序列长不变；为难预测 VAE 通道按误差加权做 focal 回归。
- **Baseline** · 改进来源为表示自编码与 latent DiT flow matching。对照 Flux.2 VAE、SigLIP2、RAE、联合 latent MSE 与 focal，并比较多种理解/生成模型。
- **Benchmark** · ImageNet-1K 256² 重建报 PSNR、SSIM、rFID，类条件生成报 gFID、IS、Precision/Recall；多模态报 POPE、GQA、TextVQA、MMBench、MME。
- **关键结果 / 消融** · 80 epoch 无引导 ImageNet gFID，联合 MSE 6.80，focal 3.78，Flux.2 VAE 4.57；focal 加引导为 1.79。
- **适用条件 / 局限** · 虽不加 token 数，通道空间仍扩大，收益依赖同栅格和语义/细节编码器的匹配，focal 权重在实证中选定。
