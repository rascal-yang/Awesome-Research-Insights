## 1302 · AdaSplash-2: Faster Differentiable Sparse Attention

[原文](https://proceedings.mlr.press/v306/goncalves26a.html)

<a id="goncalves26a-modules"></a>

**技术主题** · 稀疏 entmax 的直方图阈值初始化

- **问题 / 瓶颈** · entmax 可使注意力块精确为零，但迭代计算归一化阈值导致可微稀疏注意难超过 softmax 内核。
- **核心创新 / 方法** · AdaSplash-2 在 SRAM 内按块构造近似分数直方图，以更紧初始值将阈值求解减至通常 1–2 次，再让 Triton 前向/反向跳过零块。
- **Baseline** · 改进来源为 AdaSplash 和 α-entmax。对照 FlashAttention-2 的 CUDA/Triton、原 AdaSplash、softmax/entmax 配 RoPE 或 NAPE。
- **Benchmark** · 单 A6000 测 bf16 的 4K–128K 前反向，扫块稀疏度；350M/1B 模型用 OLMES、RULER、HELMET 测困惑度、精度和上下文能力。
- **关键结果 / 消融** · 零块很高的算子极限超过 FlashAttention-2 的 2×，且在测试稀疏度上都快于 AdaSplash。1B RoPE softmax 的 RULER 平均由 4K 51.4 到 32K 27.3，文中比较了 NAPE 稀疏模型对退化的缓解。
- **适用条件 / 局限** · 速度取决于真块稀疏度和硬件，长序列计时用代表层而非端到端吞吐。未在 Hopper 的 FlashAttention-3 同设比较。

## 1305 · Scaling Transformers for End-to-End Discrete Audio Tokenization

[原文](https://proceedings.mlr.press/v306/gong26c.html)

<a id="gong26c-architecture"></a>

**技术主题** · 纯因果 Transformer 的音频分词

- **问题 / 瓶颈** · 能否从头联合训练能跨语音、环境声和音乐扩展的通用离散音频分词器？
- **核心创新 / 方法** · TAC 用同质因果 Transformer 和分层分块做编解码，以 32 层残差向量量化和量化器随机丢弃支持可变码率，重建、对抗与语音转文本辅助目标共同训练。
- **Baseline** · 改进来源为神经音频编解码与残差向量量化。实验对照含 StableCodec 等开源音频分词器，TTS 对比 MaskGCT、VoxCPM、HiggsAudio-v2 等。
- **Benchmark** · 约 309 万小时语音、声音和音乐训练。LibriSpeech、AISHELL-2、AudioSet、MUSDB 测不同码率重建，Seed-TTS-Eval 测中英文错误率与说话人相似度。
- **关键结果 / 消融** · TAC-TTS 在 Seed-EN 的 WER 和相似度为 1.89% 和 73.1，Seed-ZH 的 CER 和相似度为 1.23% 和 78.5。VoxCPM 对应 1.85%、72.9、0.93%、77.2。
- **适用条件 / 局限** · 作者指出各音频领域及训练配方的全面研究仍待开展。训练结果来自大规模数据及所测码率。

## 1307 · LLM-Guided Loop Bound Generation for Program Termination Verification

[原文](https://proceedings.mlr.press/v306/gong26e.html)

<a id="gong26e-inference"></a>

**技术主题** · 语言模型猜测与形式验证的循环上界

- **问题 / 瓶颈** · 如何用 LLM 提议程序循环的迭代上界，并对终止结论提供形式化保证？
- **核心创新 / 方法** · LIFT 先生成常数或符号循环界，将验证转为安全性或不变量义务，利用违例分析区分无效上界与不变量不足，再把诊断反馈给模型迭代。
- **Baseline** · 改进来源为循环上界终止证明与反例驱动生成验证。实验对照包括 PROTON 2.1、LOOPY、ddlTerm、UAutomizer、FreqTerm 和加诊断反馈的 LOOPY。
- **Benchmark** · 采用现有 171 个可终止程序的套件，记录验证成功数、求解时间与不同生成模型和不变量验证后端表现。
- **关键结果 / 消融** · Gemini 版 LIFT 验证 152 个，已求解样例平均 189.4 秒。LOOPY 验证 125 个，迭代反馈后 139 个且平均 336.2 秒。
- **适用条件 / 局限** · 作者指出 LLM 多轮交互增加开销，部分候选边界产生现有 SMT 与不变量后端难解的非线性算术。实验范围为可终止程序套件。

**原文定位** · [§3 上界生成（PDF 第 3 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/gong26e/gong26e.pdf#page=3) · [§4.1–4.3 形式化验证（PDF 第 4 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/gong26e/gong26e.pdf#page=4) · [§5.1 基准（PDF 第 5 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/gong26e/gong26e.pdf#page=5) · [表 1（PDF 第 6 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/gong26e/gong26e.pdf#page=6) · [表 2–3（PDF 第 7 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/gong26e/gong26e.pdf#page=7) · [§7 局限（PDF 第 9 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/gong26e/gong26e.pdf#page=9)

**可复用机制** · 先生成符号循环上界，把终止转成验证义务，再按反例区分上界不成立还是不变量不够，定向修复证明。

## 1309 · EchoingPixels: Aliasing-Resistant Joint Token Reduction for Audio-Visual LLMs

[原文](https://proceedings.mlr.press/v306/gong26g.html)

<a id="gong26g-modules"></a>

**技术主题** · 视听稀疏采样的 RoPE 抗混叠

- **问题 / 瓶颈** · 联合压缩音视频令牌时，怎样保留与提示相关的信息并减少稀疏采样引起的位置混叠？
- **核心创新 / 方法** · EchoingPixels 用跨模态语义筛在共享流上对音视频联合评分和选择，不预分配两模态配额。Sync-RoPE 根据稀疏间隔限制旋转编码高频相位。
- **Baseline** · 改进来源为模态内令牌剪枝和 RoPE 空间频率解释。实验对照含完整 Qwen2.5-Omni、IntraModal 和多种视频压缩策略及位置编码消融。
- **Benchmark** · Qwen2.5-Omni 3B/7B，Daily-Omni、WorldSense、Video-MME 和 MLVU-dev，保留 5%–20% 令牌，测相对任务分数、前向延迟及 CUDA 峰值内存。
- **关键结果 / 消融** · 3B 用 20% 令牌保留平均 99.0% 性能，前向 231.7 ms 对原始 517.1 ms，显存 14.15 GB 对 32.03 GB。7B 用 10% 令牌保留 94.1%。
- **适用条件 / 局限** · 作者指出 Sync-RoPE 依赖旋转相位频域，学习型绝对位置或相对偏置的抗混叠扩展仍待研究。

**原文定位** · [§3.1 联合筛选（PDF 第 3 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/gong26g/gong26g.pdf#page=3) · [§3.2 Sync-RoPE（PDF 第 4 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/gong26g/gong26g.pdf#page=4) · [§4.1–4.2（PDF 第 6 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/gong26g/gong26g.pdf#page=6) · [表 1–3（PDF 第 7 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/gong26g/gong26g.pdf#page=7) · [局限（PDF 第 9 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/gong26g/gong26g.pdf#page=9)

**可复用机制** · 对音视频词元联合竞争预算，并按稀疏保留间距限制旋转位置高频相位，减少压缩后的时序混叠。

## 1311 · The Cost of Information: Phase Transitions in Contextual Bandits with Paid Observations

[原文](https://proceedings.mlr.press/v306/gong26i.html)

<a id="gong26i-theory-statistics"></a>

**技术主题** · 付费观测的免费预算相变

- **问题 / 瓶颈** · 上下文老虎机需为观察反馈支付成本时，总遗憾随时域和免费观察预算怎样变化？
- **核心创新 / 方法** · 设计付费反馈下的加权探索及估计，按免费预算切换策略，并在随机可实现环境下以在线平方损失预言机替代枚举策略。
- **Baseline** · 改进来源为对抗上下文老虎机、付费观察与 SquareCB 式函数逼近。实验对照包括 linUCB、Tucker 方法，并扫描观测预算及问题规模。
- **Benchmark** · 合成高斯上下文，轮数 2,000–40,000、维度 2/4/8、动作数 3/5/10，设置重复 50 次，衡量损失与观察成本之和及运行用时。
- **关键结果 / 消融** · 均一成本 c 的对抗设定有 Ω(max{√(T log|Π|),(c|A|log|Π|)^(1/3)T^(2/3)}) 下界。免费预算的阈值量级为 c^(−2/3)(|A|log|Π|)^(1/3)T^(2/3)，阈值以上上界改善为 O(T√(|A|log|Π|/B))。
- **适用条件 / 局限** · 有限策略类的相变分析依赖一致观察成本，预言机算法另依赖随机函数逼近条件。作者单列局限未报告。

## 1315 · Decoupling The "What" and "Where" With Polar Coordinate Positional Embedding

[原文](https://proceedings.mlr.press/v306/gopalakrishnan26a.html)

<a id="gopalakrishnan26a-modules"></a>

**技术主题** · 位置与内容分离的极坐标编码

- **问题 / 瓶颈** · Transformer 的注意力怎样分别按内容或相对位置寻址，减轻其中一个因素干扰另一个？
- **核心创新 / 方法** · PoPE 把键与查询表示成复向量，以 softplus 非负幅度编码内容，位置相位独立由索引和频率给出。注意力分数是内容幅度积加权的相对位置余弦。
- **Baseline** · 改进来源为 RoPE 的复数旋转表示。实验对照含标准 RoPE、YaRN 长度外推、PoPE 去 softplus 或相位偏置及长序列微调。
- **Benchmark** · 间接索引诊断、JSB/MAESTRO 音乐、人参考基因组、OpenWebText 124M–774M 自回归模型和最长 10,240 词元的 PG-19 长度外推。测准确率、NLL 和困惑度。
- **关键结果 / 消融** · 间接索引 94.82±2.91%，RoPE 为 11.16±2.45%。774M 英文验证困惑度 15.45 对 15.85，在最长十倍序列的所测区间零样本外推优于 YaRN。
- **适用条件 / 局限** · 证据限所测自回归任务、模型规模及 PG-19 上下文跨度。其他作者明示局限未报告。

## 1317 · Towards Spectroscopy: Susceptibility Clusters in Language Models

[原文](https://proceedings.mlr.press/v306/gordon26a.html)

<a id="gordon26a-evaluation"></a>

**技术主题** · 词元扰动的成分响应分析

- **问题 / 瓶颈** · 能否通过语言模型对训练分布中局部词元权重扰动的响应发现模型学到的结构？
- **核心创新 / 方法** · 在检查点附近用预条件 SGLD 采样局部 Gibbs 后验，以组件可观测量和词元损失的协方差估计敏感度，构造词元上下文图并按导通率聚类。
- **Baseline** · 改进来源为统计物理的线性响应和几何聚类。实验对照使用 Pythia-70M 稀疏自编码器激活、随机顶点集与更大 Pythia 模型。
- **Benchmark** · The Pile 的 13 个子集各采 60,000 段，得到 78 万上下文与续词对。评估 Pythia-14M 聚类、结构导通率和稀疏特征匹配。
- **关键结果 / 消融** · 得到 510 个簇，259 个与稀疏自编码器特征匹配，占 50.8%。簇在 31M–1.4B Pythia 上保持低于随机集的导通率。
- **适用条件 / 局限** · 作者指出直接在更大模型上聚出更少的簇，可能受高维后验采样等影响。用响应反推训练干预仍待验证。

## 1319 · TabPack: Efficient Hyperparameter Ensembles for Tabular Deep Learning

[原文](https://proceedings.mlr.press/v306/gorishniy26a.html)

<a id="gorishniy26a-training-strategies"></a>

**技术主题** · 表格 MLP 超参数并行集成

- **问题 / 瓶颈** · 怎样在表格深度学习中以一次训练得到有竞争力的模型集成并减少单独调参？
- **核心创新 / 方法** · TabPack 在预设区间为多组 MLP 随机采样不同超参，将计算与优化器打包并行训练，以验证结果在运行中贪心选入成员。
- **Baseline** · 改进来源为 Packed Ensembles 和超参数集成。实验对照有 XGBoost、MLP、ModernNCA、RealMLP、TabM、TabPFN-3 和 TabICLv2，以及离线/同超参 TabPack。
- **Benchmark** · 主要比较 17 个中大型表格数据集，最大约 1,360 万条样本，跨分类/回归按各任务指标排序，报告相对排名、总运行时间及时间预算曲线。
- **关键结果 / 消融** · 带特征嵌入的 TabPack 在三种自身变体中平均排名 1.6±0.6、单轮合计 2.4 小时，同超参调优版本为 1.4±0.7、65.5 小时。

## 1396 · Fine-Tune Once, Reuse Across Models: Bayesian Task-Update Factors and Approximations

[原文](https://proceedings.mlr.press/v306/guo26y.html)

<a id="guo26y-training-strategies"></a>

**技术主题** · 在指数族中迁移微调因子

- **问题 / 瓶颈** · 从旧基模得到的微调参数差分在新基模上可能失效，因为参数附近的损失曲率随基模而变。
- **核心创新 / 方法** · BTransfer 把基模看作先验，微调前后模型用对角 Fisher 的 Laplace 高斯近似，取旧后验与旧先验的自然参数差作为任务因子，加到新先验后取峰值还原参数。
- **Baseline** · 改进来源为贝叶斯参数更新及指数族的自然参数表示。实验对照为直接加参数差分 ParamΔ、新基模、旧微调模型，以及视觉实验中的 TransFusion。
- **Benchmark** · 测试从 RoBERTa 到同系列其他文本模型、Gemma 到衍生模型，以及视觉网络，比较任务准确率。Gemma 实验涵盖编程、安全、数学、多语和指令。
- **关键结果 / 消融** · Gemma-2-2B-IT 转移到 TiTU-2B 的数学准确率为 31.84%，ParamΔ 为 15.85%，未经转移的新基模为 12.43%。定理 3.1 在给定矩条件下导出可复用指数因子及其半空间族的凸极大性。
- **适用条件 / 局限** · 理论因子依赖变分族条件。神经网络中的对角 Fisher 忽略参数相关及非局部曲率，算法还依赖新旧兼容参数与估计 Fisher 的数据。
