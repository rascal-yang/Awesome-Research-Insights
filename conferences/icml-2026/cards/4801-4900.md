## 4801 · Target-Oriented Pretraining Data Selection via Neuron-Activated Graph

[原文](https://proceedings.mlr.press/v306/wang26hk.html)

<a id="wang26hk-data-strategies"></a>

**技术主题** · 目标神经元激活集合筛选数据

- **问题 / 瓶颈** · 输出embedding相似度未必反映目标任务所用计算。
- **核心创新 / 方法** · 沿用PLND局部投影影响近似，每层取top-K神经元ID；目标集合统计频次，以候选ID命中频次均值排序，无需训练筛选器。
- **Baseline** · 神经元影响源于PLND，集合聚合为显式计算；比较BETR、FineWebEdu与随机，新增是激活集合驱动目标数据排序。
- **Benchmark** · 150B RefinedWeb池选30B，同训练tokens；六个目标任务及多目标，Qwen/Llama/SmolLM提取信号。
- **关键结果 / 消融** · 表1 Qwen单目标平均49.8%对BETR48.8、随机44.9；多目标48.5对44.4；UP神经元HellaSwag60.55高于DOWN57.99。
- **适用条件 / 局限** · 所谓graph实际为跨层索引集，不含学习边；局部幅值是影响代理而非端到端因果效应；筛选需全候选前向，目标数据代表性影响结果。

## 4802 · d2: Improving Reasoning in Diffusion Language Models via Trajectory Likelihood Estimation

[原文](https://proceedings.mlr.press/v306/wang26hl.html)

<a id="wang26hl-reinforcement-learning"></a>

**技术主题** · 扩散揭示轨迹的似然估计

- **问题 / 瓶颈** · 直接套AR概率比可能与扩散采样路径不一致。
- **核心创新 / 方法** · AnyOrder把clean与mask拷贝打包并按揭示因果mask评估；普通masked模型StepMerge把路径切N段，计算各段新揭示token条件概率。
- **Baseline** · 最近DDPO、diffu-GRPO(d1)、wd1；新增轨迹似然估计器，非GRPO目标本身；按FLOPs对照。
- **Benchmark** · Qwen3-1.7B AO、LLaDA8B、Dream7B；GSM8K、MATH500、Sudoku、Countdown。
- **关键结果 / 消融** · 同计算Qwen AO的GSM8K67%对diffuGRPO63%；LLaDA表6 Sudoku91.9%、GSM8K85.0%，但不同基线训练需按图7的匹配FLOPs判断。
- **适用条件 / 局限** · one-pass精确只在采样mask与packing一致成立：逐token揭示或并行组内禁止互看；不能将Alg1顺序编号推广为同批token可互看。StepMerge是近似，误差界含未测块内变化常数；多次旧轨迹更新梯度仅近似。 附录B.3（PDF23）仍按全token顺序packing；PDF26明确实际两token并行后人为左右排序，未证明同批第二token条件与采样一致，因此该实验不能宣称似然严格精确。

## 4804 · SparseInfer: Accelerating Large Language Model Inference with Semantics-Inspired Adaptive Sparse Activation

[原文](https://proceedings.mlr.press/v306/wang26hn.html)

<a id="wang26hn-inference"></a>

**技术主题** · 句级固定核心神经元

- **问题 / 瓶颈** · token级稀疏预测器成本抵消计算节省。
- **核心创新 / 方法** · 先按token正激活幅值选集合，再按句内频次挑核心；稳定前缀复用自身集合，短不稳定输入使用语义近邻簇集合。

- **适用条件 / 局限** · 10.33×含从CPU搬运转为GPU驻留的收益，非通用算子速度；语义切换可破坏固定集合，任务精度非无损；CoreInfer是同稿早期名称不作新增先例。

## 4805 · Generalized Discrete Diffusion with Self-Correction

[原文](https://proceedings.mlr.press/v306/wang26ho.html)

<a id="wang26ho-loss-functions"></a>

**技术主题** · 替换与吸收独立调度的离散纠错

- **问题 / 瓶颈** · 已有GIDD自纠错目标和噪声权重耦合难调。
- **核心创新 / 方法** · 构造离散时间转移矩阵及解析后验/ELBO，uniform普通token变化与absorbing概率分别调度；反向普通token可改写但不重mask。
- **Baseline** · 最近GIDD连续插值uniform-absorbing、MDLM及ReMDM；SCDD改变转移分解与训练，而非单纯推理改采样。
- **Benchmark** · GPT2规模DiT SMALL，LM1B33B/OWT131B训练tokens；同边际噪声重训GIDD+，生成PPL和熵/裁判。
- **关键结果 / 消融** · OWT32步SCDD pu0.2 GenPPL67.1，对GIDD+ pu0.2为79.0、最佳GIDD+ pu0.1为71.4；ValPPL32.49较MDLM24.72更差。
- **适用条件 / 局限** · 纠错次数不等于正确性，生成PPL需结合熵；删一remask并非测得端到端2×加速；仅小模型语言实验，噪声量/likelihood存在权衡。

## 4806 · How Few-Shot Examples Add Up: A Causal Decomposition of Function Vectors in In-Context Learning

[原文](https://proceedings.mlr.press/v306/wang26hp.html)

<a id="wang26hp-evaluation"></a>

**技术主题** · 功能向量的路由与内容分解

- **问题 / 瓶颈** · function vector如何汇聚示例与上下文作用不清楚。
- **核心创新 / 方法** · 用注意力边屏蔽构造无跨示例上下文对照，OLS拟合示例sub-FV；对QK和V做二因子patch及对称Shapley分解。
- **Baseline** · 沿用已有FV、activation patching与Bakalova上下文化/聚合区分；新增是FV示例线性重构及QK/V因子分解证据。
- **Benchmark** · Gemma2多尺寸、Llama系列，3/5/10-shot任务与歧义示例；位置交换控制，0shot FV注入。
- **关键结果 / 消融** · 主实验OLS重构余弦≥0.925、R²≥0.875；QK上下文化贡献通常更稳定为正，V贡献更异质；歧义prompt注意力偏向无歧义示例。
- **适用条件 / 局限** · ctx sub-FV仍可携带别的示例经上下文化传入信息，不能证明示例独立；最大注入准确率含层/scale扫描，不是固定ICL实际收益；近似线性仅所测任务。

## 4813 · Scaling by Diversified Experience for Vision-Language-Action Models

[原文](https://proceedings.mlr.press/v306/wang26hw.html)

<a id="wang26hw-training-strategies"></a>

**技术主题** · 动作梯度筛选意图状态

- **问题 / 瓶颈** · VLA的推理query可能向动作专家传入任务无关状态。
- **核心创新 / 方法** · 第一次动作前向求各query状态的动作损失梯度范数，删除最低5%状态，再做第二次动作前向更新；推理时保留完整query。
- **Baseline** · 梯度显著性及token剪枝已有先例；独立选择是把动作梯度用于训练期意图状态掩码。相似示范检索、BC和RL不单独构成新机制。 实验比较OpenVLA-oft、GR00T、Wall-Oss、ChatVLA与pi0；pi0区分官方预训练和同数据从头训练版本。
- **Benchmark** · Cobot Magic实机：折Polo衫14次、计算后选方块并包毛巾28次、装零食14次，报告ID/OOD成功率；OOD分别改变衣物位置或指令。另测DocVQA、AI2D、MMMU、MME、HallBench以检查VLM能力保留；Task1组件消融。
- **关键结果 / 消融** · Task1完整成功率0.86，去意图解耦0.43；去RL0.71；额外动作专家前向约增加10%训练成本。 整体ID/OOD成功率0.73/0.64，pi0预训练版0.63/0.48；但折衣ID任务pi0为0.93，高于完整模型0.86，不能称所有任务均优。
- **适用条件 / 局限** · 消融范围有限，梯度小可能源于饱和或抵消，不保证因果无关；梯度剪枝一般原理已有，机器人外迁移未验证。

- **适用条件 / 局限** · 允许为全部文档/查询任意构造向量，不保证神经编码器可学、语义泛化或ANN索引恢复；鲁棒结论依归一化与m/k范围，常数及对数项影响实际维度。
