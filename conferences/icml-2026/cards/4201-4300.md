## 4201 · Can Microcanonical Langevin Dynamics Leverage Mini-Batch Gradient Noise?

[原文](https://proceedings.mlr.press/v306/sommer26a.html)

<a id="sommer26a-inference"></a>

**技术主题** · 微正则采样噪声纠偏

- **问题 / 瓶颈** · 全梯度MCLMC直接改小批会产生噪声诱导漂移与数值不稳定。
- **核心创新 / 方法** · pSMILE用局部协方差白化思想并以EMA对角噪声标准差近似；能量变化绝对值的EMA拟合Gamma分布，极端分位数拒绝并清零动量，其余按上下分位数乘性调步长；可多链集成。
- **Baseline** · 来源：MCLMC/MILE、SGMCMC、RMS式预条件；比较naive SMILE、pSMILE、SGLD、scale-adapted SGHMC、cSGLD与deep ensemble。
- **Benchmark** · 10维解析ICG/Rosenbrock/Funnel，显式各向同性/对角/相关/空间变噪声，10链归一化二阶矩偏差；CIFAR-10 ResNet18、Imagenette ViT及nanoGPT。
- **关键结果 / 消融** · 表1 ICG相关噪声偏差平方naive0.502±0.194→pSMILE0.055±0.007；表3 CIFAR-10 pSMILE准确率0.9135、NLL0.3900，对cSGLD0.9140/0.4059，并非全部指标最佳。
- **适用条件 / 局限** · 局部常数对角预条件忽略Riemannian校正，不保证精确后验；护栏不是MH接受规则，存在偏差。需优化warmstart，Gamma误差分布经验拟合；对角化不能完全消除相关噪声。

**可复用机制** · 用小批梯度驱动微正则Langevin前先检验噪声各向异性；EMA标准差预条件可降偏，能量误差分位数调步长及拒绝护栏避免崩溃。

## 4202 · Judging What We Cannot Solve: A Consequence-Based Approach for Oracle-Free Evaluation of Research-Level Math

[原文](https://proceedings.mlr.press/v306/son26a.html)

<a id="son26a-evaluation"></a>

**技术主题** · 以可迁移后果验证推理

- **问题 / 瓶颈** · 研究级证明外观可信但难核验，LLM judge易奖励省略与权威引用。
- **核心创新 / 方法** · CBU对每个候选(Q,C)，在可验证邻域题上生成多次解答，平均二元verifier结果作为分数；以候选的上下文可迁移性间接排序。
- **Baseline** · 来源：in-context demonstration valuation；比较同骨干LLM judges、Qwen2.5-Math-RM/AceMath-RM及Qwen3/Llama GenRM；judges和CBU均64 rollout。
- **Benchmark** · EXPERTMATH：70原题、122变体、630人工核验LLM候选与专家解；Acc@1、Recall@5、AUC、HumanWin/MeanWin。
- **关键结果 / 消融** · GPT-OSS-120B Acc@1由judge67.21%到CBU76.27%，AUC71.42%→79.63%；20B AUC69.03%→79.18%。112个judge高分/CBU低分错例中80例含不当省略。
- **适用条件 / 局限** · 目标题无oracle，但依赖高质量可验证邻域、参考答案和构造成本；上下文效用不构成证明正确性保证。RM经RoPE扩展并使用dummy配对，非完全原生最优配置；64次预算有token比较但非所有工程成本相等。

## 4203 · Decoupling Variance and Scale-Invariant Updates in Adaptive Gradient Descent for Unified Vector and Matrix Optimization

[原文](https://proceedings.mlr.press/v306/song26a.html)

<a id="song26a-optimization"></a>

**技术主题** · 解耦谱方向与方差适应

- **问题 / 瓶颈** · Muon矩阵符号更新缺少方差自适应，SOAP的矩分解与完整谱方差项不同。
- **核心创新 / 方法** · DeVA将白化写为E[H]^−1/2 H^1/2和H^−1/2g两部分；向量版二阶矩用动量平方EMA。矩阵版旋转梯度后积累未平方行列范数外积，预条件并以Newton-Schulz近似matrix sign；RMS对齐。
- **Baseline** · 来源：AdaGrad/Adam、Shampoo/SOAP、Muon与SNR解释；比较Adam、Lion、Muon、SOAP、Adamuon及SignSGD。
- **Benchmark** · 异质Hessian二次迹函数；约274M modded-nanoGPT、FineWeb-Edu约1.4B token；ViT-L/16 ImageNet1K、ResNet20 CIFAR10，loss及时间。
- **关键结果 / 消融** · 表2最终Loss：DeVA3.271、Muon3.305、SOAP3.304；表列Time16.49秒/10.72秒/15.79秒，对Muon+54%。表标题称perplexity而行标Loss，按原行指标保守报告。
- **适用条件 / 局限** · token/步数收益不能推成wall-clock提速；统一学习率轨迹不代表各优化器最优预算。理论需光滑、权重可预测且有界及随T增大的batch，不直接覆盖常规动量实现。

## 4204 · EnerGS: Energy-Based Gaussian Splatting with Partial Geometric Priors

[原文](https://proceedings.mlr.press/v306/song26b.html)

<a id="song26b-optimization"></a>

**技术主题** · 部分几何能量场与梯度隔离

- **问题 / 瓶颈** · 部分可见几何的统一强约束会把未观测区域当错误几何，光度梯度又会把高斯位置拉入自由空间。
- **核心创新 / 方法** · EnerGS建立局部占据吸引势、自由空间softplus屏障和未知区域弱势；阻断光度对均值的位置更新，保留外观/协方差更新及光度驱动增密；定期裁剪自由空间违规高斯，体素预计算梯度。
- **Baseline** · 来源：LiDAR引导3DGS及几何正则；比较3DGS、2DGS、Taming-3DGS、GeoGaussian、Mip-Splatting、Scaffold-GS，另有SplatAD。
- **Benchmark** · KITTI/Waymo静态场景、剔除动态物体；30k迭代，适用时同点云初始化，每四帧留一测试；PSNR/SSIM、Leak/OccCov/Margin/Thick及高斯数。
- **关键结果 / 消融** · 表1 KITTI EnerGS PSNR16.80对3DGS15.01，Leak9.2对12.5、OccCov25.8对16.1；但SSIM0.841弱于0.938，Thick1.47弱于1.39，不能声称全部几何指标提升。
- **适用条件 / 局限** · 已知自由空间必须可信，缺失不等于自由；未知区均值更新趋零，结构恢复依赖光度增密，并非任意移动。只评静态、体素网格有分辨率/内存成本，未证动态控制闭环改善。

**原文定位** · [方法/实验/适用边界（PDF第4页）（PDF 第 4 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/song26b/song26b.pdf#page=4) · [方法/实验/适用边界（PDF第6页）（PDF 第 6 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/song26b/song26b.pdf#page=6) · [方法/实验/适用边界（PDF第7页）（PDF 第 7 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/song26b/song26b.pdf#page=7)

**可复用机制** · 稀疏LiDAR先验可按占据/已知自由/未知空间定义不同能量，只让位置随几何梯度动，让颜色协方差随光度梯度动，未知区域依靠densification。

## 4205 · Expanding the Capabilities of Reinforcement Learning via Text Feedback

[原文](https://proceedings.mlr.press/v306/song26c.html)

<a id="song26c-reinforcement-learning"></a>

**技术主题** · 反馈蒸馏的首轮奖励基线

- **问题 / 瓶颈** · 奖励只有一比特，反馈条件策略的改进不自动转为测试时单轮能力，二轮GRPO基线会抹去信号。
- **核心创新 / 方法** · RLTF-SD以反馈后二轮轨迹更新单轮概率，采用首轮均值基线与低方差无重要性加权AWR；RLTF-FM联合RL与给定问题/回答的反馈预测。反馈仅训练可用。
- **Baseline** · 来源：GRPO、self-distillation/AWR与辅助语言建模；比单轮/多轮GRPO、Feedback Descent；消融二轮基线、拒绝采样及PPO/CISPO clipping。
- **Benchmark** · Llama3.1-8B学习器，Qwen3-235B模拟反馈；Knights/Knaves、Binary Matrix、Shortest Path、DAPO/DeepMath→MATH500/AIME24、LitBench/WritingBench；主评单轮。
- **关键结果 / 消融** · 表1 Knights准确率GRPO单轮0.373、多轮0.352、SD0.802、FM0.880；DeepMath→MATH500分别0.558/0.578/0.598/0.636。二轮同奖励时归零概率p1^N+(1−p1)^N。
- **适用条件 / 局限** · 无重要性加权降低方差但有偏；理论含冻结rollout早期近似及反馈coverage条件。强外部教师与额外训练监督成本需计入，不能理解为同信息预算胜reward-only；未验证真实人反馈或动作策略。

**可复用机制** · 将反馈后成功回答蒸馏回无反馈策略时，用首轮平均奖励作优势基线，避免第二轮全成功导致优势归零；另可预测文本反馈提供辅助表征监督。

## 4206 · When Diffusion Language Models Hesitate: Detecting and Correcting Visual Hallucinations via Confidence Fluctuation

[原文](https://proceedings.mlr.press/v306/song26d.html)

<a id="song26d-inference"></a>

**技术主题** · 去噪置信波动定位幻觉

- **问题 / 瓶颈** · 扩散文本最终高置信可能掩盖语言先验与视觉证据竞争，低终态置信常挑到功能词。
- **核心创新 / 方法** · VGR先用约37k RefCOCO+衍生样本训练双视图；CF=相邻置信绝对差之和减净增长，定位高CF语法span，检测器检索局部框并门控，重掩码该span与上下文，拼接全局和局部视觉tokens迭代修正。
- **Baseline** · 来源：LLaDA-V、remasking与局部视觉refinement；比较MMaDA、FUDOKI、LaViDa、LLaDA-V及AR VLM；同SFT骨干对低置信/high-CF/混合、全局/局部与重掩码策略。

- **关键结果 / 消融** · AMBER-g CHAIR原始8.2→SFT6.2→完整6.0，Hal44.9→38.5→37.2；high-CF与low-confidence同为CHAIR6.0，CapArena−52.17对−57.83；不将全部提升归CF。
- **适用条件 / 局限** · 专有模型合成/标注、检测器及多轮额外推理有成本；CF为经验代理不是因果证明。low-confidence的Hal36.9略优于CF37.2，混合36.0更好，CF非各指标全面优越；仅一个主骨干，机器人感知迁移未证。

## 4207 · EnsembleVLA: Ensemble Learning for Vision-Language Action Models

[原文](https://proceedings.mlr.press/v306/song26e.html)

<a id="song26e-inference"></a>

**技术主题** · 生成策略场组合与有界修正

- **问题 / 瓶颈** · 多模态动作分布的样本均值可能落在无效动作间隙，异构diffusion/flow策略需要共同组合接口。
- **核心创新 / 方法** · EnsembleVLA冻结基策略，对齐时间/位移空间后线性组合score或velocity，联合学softmax权重；两层谱归一Delta-Net用0.001 tanh限幅，Gate-Net以残差是否降低示范MSE的detach标签训练，另直接监督裁剪残差。
- **Baseline** · 来源：EBM product-of-experts与compositional generation；实际DP、DP3、π0、π0.5，比较动作直接平均、等权场组合、learned weights、Delta与Gate逐级消融。
- **Benchmark** · RoboTwin2.0八任务，每任务100示范/100评测episode，三seed；Mobile ALOHA六任务20次实机试验；成功率。
- **关键结果 / 消融** · 表1 DP+DP3平均82.8±1.6%，对DP3 68.4±2.1%提高14.4个百分点；DP+π0.5 70.1%对65.1%，π0+π0.5 74.6%对65.1%。Handover固定场组合42%、动作均值12%、完整70%。
- **适用条件 / 局限** · 能量解释对一般flow仅在保守场近似下成立，Helmholtz残差未消除，不能当任意velocity严格乘积分布采样保证。组合与残差需额外示范训练，多模型推理成本；动作归一化尺度与时间对齐关键，缺同算力单策略完整控制。

## 4210 · LoBCD-GW: A Fast and Data-Dependent Algorithm for Computing Gromov-Wasserstein Distance via Localized Block Coordinate Descent

[原文](https://proceedings.mlr.press/v306/song26h.html)

<a id="song26h-optimization"></a>

[原文](https://proceedings.mlr.press/v306/song26t.html)

<a id="song26t-loss-functions"></a>

**技术主题** · chunk价值引导单步critic

- **问题 / 瓶颈** · chunk多步备份减自举累积，却因开环策略限制拼接与反应控制。
- **核心创新 / 方法** · 同时训练chunk策略/critic与单步FQL策略/critic；单步TD外加chunk值减单步值的上expectile平方损失，β控制指导，部署单步策略。
- **Baseline** · 来源：FQL、QC-FQL及expectile；比较FQL、NFQL、QC-FQL、DEAS、DQC，区别DQC的长短chunk蒸馏。
- **Benchmark** · OGBench六类操纵与三类导航，每类5目标；4种子，每目标150评估episode，成功率。
- **关键结果 / 消融** · 表1操纵均值76±2，FQL38、QC-FQL57、DEAS71；cube-double69±3对DEAS48。导航35±4逊FQL49及DQC58±3。
- **适用条件 / 局限** · 理论凸组合是分析代理，不等于实际expectile目标；导航负结果支持chunk critic可靠性边界，不能宣传全面SOTA；训练多一套辅助策略critic。

## 4224 · ANCHOR: Automated Alignment Auditing for CLI Agents on Real-World Harm

**技术主题** · 拒答率与执行后果分离

- **问题 / 瓶颈** · 长程CLI代理只用拒答率评估会漏掉执行框架及环境真实性对后果的改变。
- **核心创新 / 方法** · 固定模型对照不同执行框架，分别统计拒答、执行真实性与风险/后果；另在任务真实性对照中检查指标是否同向。
- **Baseline** · 来源：长期代理安全审计；实际比较同模型不同框架及真实性设置，不将审计器训练或具体任务生成视为本卡机制。

- **适用条件 / 局限** · 风险与harm为论文评判指标，不能当实际现实伤害发生率；有限模型/框架/样本，不证明所有框架相同方向。此卡保留部署评测的指标选择与失效边界。

## 4227 · Causal Attention with Lookahead Keys

[原文](https://proceedings.mlr.press/v306/song26y.html)

<a id="song26y-architecture"></a>

**技术主题** · 保持因果性的动态旧key

- **问题 / 瓶颈** · 标准因果注意力旧key静止，不能随已生成后续信息更新其可检索含义。
- **核心创新 / 方法** · 并用普通key与额外lookahead key；后者只汇总位置s之后、当前t之前的表示，以sigmoid门控，注意力logit减SiLU修正；低秩结构专用Flash式核实现并行，推理缓存U、Q及普通KV。
- **Baseline** · 来源：因果注意力、KV cache及FlashAttention；实际比较相同其余组件的Transformer与滑窗CASTLE-SWL。
- **Benchmark** · FineWeb-Edu 50B tokens，从头训练160M/350M/750M/1.3B；验证loss/PPL与下游任务。
- **关键结果 / 消融** · XL验证PPL基线11.309，CASTLE10.922，SWL10.900；参数1.310B/1.304B。定理专用核训练O(L²d)、空间O(Ld)，解码O(td+ddmodel)。
- **适用条件 / 局限** · 不是读取尚未生成token；直接矩阵公式仍可能三次复杂度，需专用核；额外缓存和常数开销，不能把同阶复杂度等同标准注意力同速度。
