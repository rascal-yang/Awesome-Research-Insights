## 1101 · WorldCache: Accelerating World Models for Free via Heterogeneous Token Caching

[原文](https://proceedings.mlr.press/v306/feng26d.html) · [关联 Insight](../../../papers/multimodal.md#feng26d-inference)

- **问题 / 瓶颈** · 扩散世界模型的视频与深度词元随去噪步变化不均。对所有位置使用同一缓存和跳过频率，少数剧烈变化位置就可能积累漂移。
- **核心创新 / 方法** · WorldCache 用最近全计算结果估计局部轨迹曲率，按可预测性选择复用、外推或 Hermite 阻尼预测。累积最难预测词元的曲率归一化漂移，过阈值再全计算。
- **Baseline** · 改进来源为扩散特征缓存和按层缓存/合并。实验对照含不缓存原模型、EasyCache、TeaCache、DuCa、TaylorSeer、HiCache 和 HERO。
- **Benchmark** · 单张 NVIDIA A800 上用 HunyuanVoyager-13B 与 Aether-5B 生成 RGB 和深度，测 WorldScore、与原输出感知一致性、3D 重建、延迟及显存。
- **关键结果 / 消融** · Voyager 49 帧 512×768 下，从 1053.7 秒降至 288.6 秒（3.65×），动态 WorldScore 为 45.43，未缓存 46.40。EasyCache 为 294.5 秒、44.91，PSNR 21.76，WorldCache 为 23.49。
- **适用条件 / 局限** · 阈值和预测有效性取决于去噪特征曲率能否预警漂移。两种骨干的加速倍数不同，长程或其他模态组合需另测。

## 1102 · What Characterizes Effective Reasoning? Revisiting Length, Review, and Structure of CoT

[原文](https://proceedings.mlr.press/v306/feng26e.html) · [关联 Insight](../../../papers/llm.md#feng26e-evaluation)

- **问题 / 瓶颈** · 更长的思维链或更多复查会增加推理算力，却可能混入重复和弃用的分支。论文比较文字量和结构统计量对最终正确率的解释。
- **核心创新 / 方法** · 让模型把自然语言推理抽为图，将被弃用或失败的节点数占比定义为 FSF。控制题目因素比较相关性，并以 FSF 筛候选、删改失败分支再续写做干预。
- **Baseline** · 改进来源为按长度、复查比例选推理轨迹。实验对照为各指标选样、含失败分支前缀、删除分支和用短摘要替换。
- **Benchmark** · 十种推理模型，HARP 六档各 50 题与 GPQA-Diamond 198 题，报告正确率、筛选增益与部分思维链续写结果。
- **关键结果 / 消融** · DeepSeek R1 在 HARP 已错轨迹中去掉最后失败分支后，续写正确率由 9.72±0.98% 升至 23.75±1.36%，换成摘要为 22.57±1.37%。各设置每条前缀续写 8 次。
- **适用条件 / 局限** · FSF 是模型从可见文本抽出的测量，分段和分支边界有歧义。删改实证用有限错误轨迹和两个续写模型。

## 1103 · Leveraging Machine Unlearning for Cost-Efficient Preference Alignment

[原文](https://proceedings.mlr.press/v306/feng26f.html) · [关联 Insight](../../../papers/llm.md#feng26f-training-strategies)

- **问题 / 瓶颈** · 偏好对齐常需优质正样本，按同样权重遗忘所有负样本又可能损伤能力，负样本之间的对齐贡献并不相同。
- **核心创新 / 方法** · U2A 用双层优化把遗忘模型作为内层，再在外层最大化偏好奖励并限制样本权重的支持。用边际增益选负样本、熵镜像下降更新单纯形权重，可接入既有遗忘损失。
- **Baseline** · 改进来源为梯度上升、GradDiff 和 NPO 等不加选择的遗忘。实验对照含重训、原模型、GA、GradDiff、NPO、PPO 与 DPO。
- **Benchmark** · SafeRLHF、UltraFeedback、HaluEval 上用 Llama-2、Llama-3.1、Qwen2.5 比较奖励、攻击成功率、遗忘测试和困惑度。
- **关键结果 / 消融** · SafeRLHF 的 Llama-2 中，GradDiff 接 U2A 后评估奖励由 −19.545 到 −15.843，ASR-A 从 0.815 到 0.089，困惑度从 5.982 到 14.573。
- **适用条件 / 局限** · 样本重权依赖偏好评价和边际近似。安全或奖励改善可伴随通用效用下降，源数据的负样本一致性会影响收益。

## 1104 · Explainable Forensics of Manipulated Segments in Untrimmed Long Videos

[原文](https://proceedings.mlr.press/v306/feng26g.html) · [关联 Insight](../../../papers/computer-vision.md#feng26g-inference)

- **问题 / 瓶颈** · 未剪辑长视频可能仅少量片段由 AI 操纵。整片段真假分类难找到时间边界，也无法说明疑点。
- **核心创新 / 方法** · TASLE 标注长视频的篡改区间与理由。MSLoc 先用滑窗区分纯真、纯假及两类转场以产生候选，再用多模态模型细化边界并解释。
- **Baseline** · 改进来源为短视频真假检测和时间定位。实验对照含 D3、DeMamba、BusterX++、Qwen3-VL、Trace 及只做候选阶段。
- **Benchmark** · TASLE 12,472 条长视频，区分已见、未见和混合的生成手法。用窗口检测 F1、多个 IoU 阈值平均定位 F1 及 GPT-5.1 理由评分。
- **关键结果 / 消融** · 见过手法时 MSLoc 检测/定位 F1 为 70.1/72.2，Trace 加相同提案模块为 69.0/70.9。混合手法时为 55.0/56.3 与 52.7/54.0。
- **适用条件 / 局限** · 定位依赖前级候选覆盖，解释质量用模型评分。人工加入的混合操纵和所测工具只覆盖部分真实传播情形。

## 1105 · Learning in the Fisher Subspace: A Guided Initialization for LoRA Fine-Tuning

[原文](https://proceedings.mlr.press/v306/feng26h.html) · [关联 Insight](../../../papers/ml-foundations.md#feng26h-optimization)

- **问题 / 瓶颈** · LoRA 的初始化决定有限秩更新沿哪些方向展开。只依据预训练权重大小或谱，未必能判断下游数据对参数扰动的敏感性。
- **核心创新 / 方法** · FILet 用小批下游样本估计激活、输出梯度二阶矩，以 K-FAC 分解 Fisher，再将因子投影到预训练权重的 SVD 基。选 Fisher 响应最强的秩方向并加权初始化 LoRA。
- **Baseline** · 改进来源为标准 LoRA、权重谱初始化和数据驱动的适配。实验对照含 DoRA、PiSSA、NEAT、KaSA、LoRA-Dash 等，匹配可训练参数。
- **Benchmark** · BF16 下比较 Llama 自然语言推理、ViT-B/32 图像分类和自然语言生成。主推理表汇报五次运行中位数。
- **关键结果 / 消融** · Llama2-7B 八项自然语言推理均分，FILet 为 83.1，KaSA 与 LoRA-Dash 均为 81.7，普通 LoRA 为 77.6。FILet 的 PIQA 为 86.6，KaSA 为 85.2。
- **适用条件 / 局限** · Fisher 是小批近似并使用因子独立假设，方向只在候选谱基中选。额外的初始化时间和样本代表性会影响实践收益。

## 1106 · ExpWeaver: LLM Agents Learn from Experience via Latent RAG

[原文](https://proceedings.mlr.press/v306/feng26i.html) · [关联 Insight](../../../papers/llm.md#feng26i-modules)

- **问题 / 瓶颈** · 文本经验检索把历史操作拼进上下文，增加词元且检索器与回答器分别优化，难随解码变化调用经验。
- **核心创新 / 方法** · ExpWeaver 用同一语言模型隐藏态编码经验，按当前解码态逐步检索潜向量，再交叉注意力聚合、门控残差注入。用强化学习联合优化生成或排序任务。
- **Baseline** · 改进来源为文本拼接式经验学习与外部检索。实验对照含 CoT、HRPO、R1、ReasoningBank、ExpeL、LLM-R、IRCoT、Search-o1、Search-R1。
- **Benchmark** · ExpBench-Generic 十项问答、推理和编码，以及 Sci、Rec，总计 13 项。各套分别训练，同设置对照指标和生成词元量，并考察迁移。
- **关键结果 / 消融** · Generic 十项均分 78.25，HRPO 74.04，Search-R1 73.27。GPQA 为 35.00，Search-R1 为 23.33。论文汇总 13 项中 12 项达到其比较最高。
- **适用条件 / 局限** · 需要访问和调节骨干隐状态、建立经验库及按任务设置奖励。每步检索和注意力有额外运行成本，词元量不能概括全部延迟。

## 1107 · CriticalKV: Optimizing KV Cache Eviction from an Output Perturbation Perspective

[原文](https://proceedings.mlr.press/v306/feng26j.html) · [关联 Insight](../../../papers/llm.md#feng26j-inference)

- **问题 / 瓶颈** · KV 压缩按注意力分数逐出词元时，未计入值向量和输出投影，可能删除对注意力输出扰动显著的条目。
- **核心创新 / 方法** · CriticalKV 推导打掩码后的输出扰动上界，将保留预算分两段。先保高注意力条目，再结合注意力和投影值范数选剩余条目以约束最坏扰动。
- **Baseline** · 改进来源为 SnapKV、AdaKV、HeadKV 的逐出打分和预算分配。实验对照含完整缓存以及三方法分别接入前后。
- **Benchmark** · 三个 LLM 骨干上的 RULER 与 LongBench 长上下文任务，主设置在看到问题前单独压缩上下文，比较得分、相对损失和扰动。
- **关键结果 / 消融** · Llama-3.1-8B 保留 40% 缓存的 RULER，完整缓存均分 91.05。AdaKV 从 78.38 提升到 86.28，损失从 13.9% 降到 5.2%。SnapKV 从 67.93 到 76.89。
- **适用条件 / 局限** · 理论围绕注意力输出及两阶段选择假设，最终任务误差靠实证核验。比例参数和各头预算会影响保留结果。

## 1108 · Understanding Dynamics of Adam in Zero-Sum Games: An ODE Approach

[原文](https://proceedings.mlr.press/v306/feng26k.html) · [关联 Insight](../../../papers/ml-foundations.md#feng26k-theory-statistics)

- **问题 / 瓶颈** · Adam 下降–上升用于零和博弈，但最小化中的动量经验不能直接说明旋转耦合局部动态与隐式梯度正则。
- **核心创新 / 方法** · 以反向误差分析推导连续 Adam-DA 的修正常微分方程，在均衡点线性化，给出步长的局部指数收敛条件，并分析动量导致的梯度范数项。
- **Baseline** · 改进来源为最小化 Adam 的连续分析和符号 GDA 流。实验对照含离散 Adam-DA、连续近似、SignGDA-flow 和不同一二阶动量。
- **Benchmark** · 三个解析测试函数和 CIFAR-10、STL-10 的 CNN/ResNet GAN，用轨迹、局部稳定区及累计梯度范数检验理论。
- **关键结果 / 消融** · 定理 3.1 在有限时域和四阶有界导数等条件下给动量初始过渡后 O(h³) 的局部逼近误差。强耦合及指定特征谱条件下，降低 β 会扩大局部稳定步长区间。GAN 用学习率 2×10⁻⁴ 比较，较小 β、较大 ρ 得到较小梯度范数。
- **适用条件 / 局限** · 主要证明针对确定性动力学，局部收敛依赖均衡点谱的假设。随机 GAN 观察只提供所测设置的验证。

## 1109 · Convex Optimization for Alignment and Preference Learning on a Single GPU

[原文](https://proceedings.mlr.press/v306/feng26l.html) · [关联 Insight](../../../papers/llm.md#feng26l-optimization)

- **问题 / 瓶颈** · 偏好对齐的策略与参考模型训练需大量显存和计算，非凸优化也增加调参成本。COALA 探索只在冻结语言特征上训练可全局求解的模块。
- **核心创新 / 方法** · 在预训练骨干之上放置两层凸化 ReLU 偏好头，先用基于 ADMM 的 CRONOS 求初始策略，再固定首层，以带偏移的 Bradley–Terry 损失优化第二层，无需参考模型。
- **Baseline** · 改进来源为 DPO 偏好目标与凸神经网络重写。实验对照含 DPO、ORPO、SFT，有无 SFT 初始化，以及相同骨干的算力和人类偏好。
- **Benchmark** · 六种语言模型、四个偏好数据集，含 26,621 条 EduFeedback。评估自动胜率、奖励差、实际人类评选和训练 TFLOPs。
- **关键结果 / 消融** · EduFeedback 的 Llama-8B 配置中 COALA 为 1,805.39 TFLOPs，DPO 为 10,253.37，约 17.6%。教育数据盲评胜率为 39.1%，DPO 为 28.8%。
- **适用条件 / 局限** · 全局最优是冻结表征上的凸子问题。若骨干缺少任务相关信息，偏好头的表达能力仍受限，算力与人评收益按所测任务衡量。

## 1110 · Multimodal Nested Learning for Decoupled and Coordinated Optimization

- **问题 / 瓶颈** · 视频问答即使答对也可能定位错片段，均匀抽帧会浪费算力并遗漏短时关键事件。
- **核心创新 / 方法** · LINGUA 用事件驱动感知，维护情景、语义和程序三类语言记忆；以信念—行动—验证循环核对时序与后置条件，再用反思和贝叶斯可靠度更新选择。
- **Baseline** · 改进来源为 Gemma3-4B 量化视觉语言模型和记忆式 VideoQA。对照 VITA-1.5、LLaVA-NeXT-Video、M3-Agent，以及均匀抽帧和无记忆版本。
- **Benchmark** · NExT-QA/GQA、以自我中心视频为主的 Ego 系测试及无字幕 Video-MME。报正确率、定位 IoU/IoP、Acc@GQA、帧和调用量、耗时。
- **关键结果 / 消融** · NExT-GQA 完整 42.3%，去程序记忆 34.1%，去所有记忆 31.0%。同准确率下均匀 315 帧/22.1 秒，LINGUA 99 帧/7.1 秒。
- **适用条件 / 局限** · 依赖事件检测和显式文本化保留关键证据，抽帧可能错过短时事件，积累的记忆与脚本也可受初始错误影响。

## 1149 · Temporal Difference Calibration in Sequential Tasks: Application to Vision-Language-Action Models

[原文](https://proceedings.mlr.press/v306/francis-meretzki26a.html) · [关联 Insight](../../../papers/robotics.md#francis-meretzki26a-theory-statistics)

- **问题 / 瓶颈** · 机器人 VLA 每步看到的轨迹不完整、过很久才知道成败，静态 token 置信度很难沿整个回合校准。
- **核心创新 / 方法** · 将 Brier 损失扩展到轨迹前缀，证明最优二元成功预测是策略价值；用时间差分及最终奖励约束训练 TDQC，并把置信度用于提前停机或动作搜索。
- **Baseline** · 来源为 Brier score 与 TD value prediction。比较静态 token 置信/熵、监督 BCE 预测器、安全 RNN、其他 TD 损失，并测白盒和黑盒。
- **Benchmark** · OpenVLA、UniVLA、π0-FAST、π0 在 LIBERO 模拟和 WidowX/Franka 实机，21 划分种子报已见/未见顺序 Brier、ROC-AUC 及测试时搜索成功率。
- **关键结果 / 消融** · 表 1 中 TDQC 在各组报最小顺序 Brier，未见任务的 ROC-AUC 在六组中四组最佳。RNN 黑盒及阈值搜索对算量有不同取舍。
- **适用条件 / 局限** · 需以固定策略的成功定义和轨迹为监督，分布偏移会改变价值函数。部分模型方法得分无法归一为概率，Brier 缺项有明确标记。

## 1150 · Singular Vectors of Attention Heads Align with Features

[原文](https://proceedings.mlr.press/v306/franco26a.html) · [关联 Insight](../../../papers/llm.md#franco26a-evaluation)

- **问题 / 瓶颈** · 注意力权重 SVD 有时能找到语义方向，缺少说明何种特征分布和训练目标会让奇异向量可解释。
- **核心创新 / 方法** · 在特征可观测的 toy model 构造注意头目标，证明单对目标的最优秩一头的左右向量是白化特征，并用稀疏注意分解把这一现象迁到真实模型检验。
- **Baseline** · 来源为对注意矩阵做 SVD 的可解释性工作。对照 toy model 的真特征和不同各向异性，比较原始分解与旋转分解等诊断。
- **Benchmark** · 可控注意头模型跟踪训练中奇异向量与已知特征的余弦和分解稀疏性；真实语言模型用成对 token 的相对注意和激活证据。
- **关键结果 / 消融** · 单目标特征条件下主向量为 Σ_X⁻¹x₁、Σ_Y⁻¹y₁，特征不独立时可呈白化差异。真实模型发现若干稀疏贡献，支持但不能直接证明逐向量语义。
- **适用条件 / 局限** · 真实模型真特征不可观测，特征各向异性时向量可能混入共同主方向；理论依赖 toy 设定，适用范围受头功能约束。

## 1151 · Complexity Bounds for Dirichlet Process Slice Samplers

[原文](https://proceedings.mlr.press/v306/franzolini26a.html) · [关联 Insight](../../../papers/ml-foundations.md#franzolini26a-theory-statistics)

- **问题 / 瓶颈** · Dirichlet 过程 slice sampler 每轮需动态实例化额外组件，其随机计算成本可能无界，难知随数据量和后验簇数怎样增长。
- **核心创新 / 方法** · 将活动簇数量与随机截断分开，按给定后验分区界定 stick-breaking 尾部，从而给额外组件数统一高概率界及相应复杂度。
- **Baseline** · 理论来源为 Walker/Kalli 型 DP slice MCMC。实验对照 blocked Gibbs（固定深度）和 CRP 边际型采样器，区分显式与积分原子。
- **Benchmark** · 三高斯模拟，样本 150–12,000，每方法 10,000 次迭代；报每千步墙钟和 log-likelihood ESS/秒、聚类 ARI。
- **关键结果 / 消融** · 条件于任意分区，额外截断 K_n−H_n=O_P(log n)，最坏 H_n=O(n) 时总截断 O_P(n)。实验中边际 CRP 时间增长最陡。
- **适用条件 / 局限** · 分析针对 DP 先验和所述 sampler，复杂度依赖每组件似然执行成本；惯常 ESS/秒会随混合性和模型变化。

## 1152 · Nonparametric LLM Evaluation from Preference Data

[原文](https://proceedings.mlr.press/v306/frauen26a.html) · [关联 Insight](../../../papers/llm.md#frauen26a-theory-statistics)

- **问题 / 瓶颈** · 用人类偏好做 LLM 排名时，固定 Bradley–Terry 假设可能错设，黑盒估计的普通 plug-in 又难给可靠置信区间。
- **核心创新 / 方法** · DMLRank 定义可包含平局的 GARS 统一 Borda、BT、Rank Centrality，基于上下文与倾向的影响函数用双重机器学习去偏，并推导 A-optimal 标注分配。
- **Baseline** · 来源为偏好排名泛函及 debiased ML。比较相同泛函的直接 plug-in、去偏，主动采集对照随机标签策略。
- **Benchmark** · 模拟偏好，比较 n=1K/2K/3K 的估计误差和 95% 置信覆盖，另测 2K 标签预算排名 MSE，并在 Chatbot Arena 排名。
- **关键结果 / 消融** · 模拟 n=2,000 的 Borda 误差由 0.16 到 0.08，覆盖率由 0.20 到 0.95；A-optimal 在三泛函上的平均 MSE 小于随机。
- **适用条件 / 局限** · 依赖选择概率重叠及缺失随机假设，极小倾向会使加权不稳；长任务、外部工具等复杂系统的偏好没有纳入。
