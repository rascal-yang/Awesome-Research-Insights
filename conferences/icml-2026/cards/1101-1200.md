## 1101 · WorldCache: Accelerating World Models for Free via Heterogeneous Token Caching

[原文](https://proceedings.mlr.press/v306/feng26d.html)

<a id="feng26d-inference"></a>

**技术主题** · 世界模型缓存的曲率漂移判据

- **问题 / 瓶颈** · 扩散世界模型的视频与深度词元随去噪步变化不均。对所有位置使用同一缓存和跳过频率，少数剧烈变化位置就可能积累漂移。
- **核心创新 / 方法** · WorldCache 用最近全计算结果估计局部轨迹曲率，按可预测性选择复用、外推或 Hermite 阻尼预测。累积最难预测词元的曲率归一化漂移，过阈值再全计算。
- **Baseline** · 改进来源为扩散特征缓存和按层缓存/合并。实验对照含不缓存原模型、EasyCache、TeaCache、DuCa、TaylorSeer、HiCache 和 HERO。
- **Benchmark** · 单张 NVIDIA A800 上用 HunyuanVoyager-13B 与 Aether-5B 生成 RGB 和深度，测 WorldScore、与原输出感知一致性、3D 重建、延迟及显存。
- **关键结果 / 消融** · Voyager 49 帧 512×768 下，从 1053.7 秒降至 288.6 秒（3.65×），动态 WorldScore 为 45.43，未缓存 46.40。EasyCache 为 294.5 秒、44.91，PSNR 21.76，WorldCache 为 23.49。
- **适用条件 / 局限** · 阈值和预测有效性取决于去噪特征曲率能否预警漂移。两种骨干的加速倍数不同，长程或其他模态组合需另测。

## 1102 · What Characterizes Effective Reasoning? Revisiting Length, Review, and Structure of CoT

[原文](https://proceedings.mlr.press/v306/feng26e.html)

<a id="feng26e-evaluation"></a>

**技术主题** · 推理链的失败步骤比例

- **问题 / 瓶颈** · 更长的思维链或更多复查会增加推理算力，却可能混入重复和弃用的分支。论文比较文字量和结构统计量对最终正确率的解释。
- **核心创新 / 方法** · 让模型把自然语言推理抽为图，将被弃用或失败的节点数占比定义为 FSF。控制题目因素比较相关性，并以 FSF 筛候选、删改失败分支再续写做干预。
- **Baseline** · 改进来源为按长度、复查比例选推理轨迹。实验对照为各指标选样、含失败分支前缀、删除分支和用短摘要替换。
- **Benchmark** · 十种推理模型，HARP 六档各 50 题与 GPQA-Diamond 198 题，报告正确率、筛选增益与部分思维链续写结果。
- **关键结果 / 消融** · DeepSeek R1 在 HARP 已错轨迹中去掉最后失败分支后，续写正确率由 9.72±0.98% 升至 23.75±1.36%，换成摘要为 22.57±1.37%。各设置每条前缀续写 8 次。
- **适用条件 / 局限** · FSF 是模型从可见文本抽出的测量，分段和分支边界有歧义。删改实证用有限错误轨迹和两个续写模型。

## 1103 · Leveraging Machine Unlearning for Cost-Efficient Preference Alignment

[原文](https://proceedings.mlr.press/v306/feng26f.html)

<a id="feng26f-training-strategies"></a>

**技术主题** · 偏好对齐中的负例遗忘权重

- **问题 / 瓶颈** · 偏好对齐常需优质正样本，按同样权重遗忘所有负样本又可能损伤能力，负样本之间的对齐贡献并不相同。
- **核心创新 / 方法** · U2A 用双层优化把遗忘模型作为内层，再在外层最大化偏好奖励并限制样本权重的支持。用边际增益选负样本、熵镜像下降更新单纯形权重，可接入既有遗忘损失。
- **Baseline** · 改进来源为梯度上升、GradDiff 和 NPO 等不加选择的遗忘。实验对照含重训、原模型、GA、GradDiff、NPO、PPO 与 DPO。
- **Benchmark** · SafeRLHF、UltraFeedback、HaluEval 上用 Llama-2、Llama-3.1、Qwen2.5 比较奖励、攻击成功率、遗忘测试和困惑度。
- **关键结果 / 消融** · SafeRLHF 的 Llama-2 中，GradDiff 接 U2A 后评估奖励由 −19.545 到 −15.843，ASR-A 从 0.815 到 0.089，困惑度从 5.982 到 14.573。
- **适用条件 / 局限** · 样本重权依赖偏好评价和边际近似。安全或奖励改善可伴随通用效用下降，源数据的负样本一致性会影响收益。

## 1105 · Learning in the Fisher Subspace: A Guided Initialization for LoRA Fine-Tuning

[原文](https://proceedings.mlr.press/v306/feng26h.html)

<a id="feng26h-optimization"></a>

**技术主题** · 下游 Fisher 子空间初始化 LoRA

- **问题 / 瓶颈** · LoRA 的初始化决定有限秩更新沿哪些方向展开。只依据预训练权重大小或谱，未必能判断下游数据对参数扰动的敏感性。
- **核心创新 / 方法** · FILet 用小批下游样本估计激活、输出梯度二阶矩，以 K-FAC 分解 Fisher，再将因子投影到预训练权重的 SVD 基。选 Fisher 响应最强的秩方向并加权初始化 LoRA。
- **Baseline** · 改进来源为标准 LoRA、权重谱初始化和数据驱动的适配。实验对照含 DoRA、PiSSA、NEAT、KaSA、LoRA-Dash 等，匹配可训练参数。
- **Benchmark** · BF16 下比较 Llama 自然语言推理、ViT-B/32 图像分类和自然语言生成。主推理表汇报五次运行中位数。
- **关键结果 / 消融** · Llama2-7B 八项自然语言推理均分，FILet 为 83.1，KaSA 与 LoRA-Dash 均为 81.7，普通 LoRA 为 77.6。FILet 的 PIQA 为 86.6，KaSA 为 85.2。
- **适用条件 / 局限** · Fisher 是小批近似并使用因子独立假设，方向只在候选谱基中选。额外的初始化时间和样本代表性会影响实践收益。

## 1106 · ExpWeaver: LLM Agents Learn from Experience via Latent RAG

[原文](https://proceedings.mlr.press/v306/feng26i.html)

<a id="feng26i-modules"></a>

**技术主题** · 逐解码步的潜空间经验检索

- **问题 / 瓶颈** · 文本经验检索把历史操作拼进上下文，增加词元且检索器与回答器分别优化，难随解码变化调用经验。
- **核心创新 / 方法** · ExpWeaver 用同一语言模型隐藏态编码经验，按当前解码态逐步检索潜向量，再交叉注意力聚合、门控残差注入。用强化学习联合优化生成或排序任务。
- **Baseline** · 改进来源为文本拼接式经验学习与外部检索。实验对照含 CoT、HRPO、R1、ReasoningBank、ExpeL、LLM-R、IRCoT、Search-o1、Search-R1。
- **Benchmark** · ExpBench-Generic 十项问答、推理和编码，以及 Sci、Rec，总计 13 项。各套分别训练，同设置对照指标和生成词元量，并考察迁移。
- **关键结果 / 消融** · Generic 十项均分 78.25，HRPO 74.04，Search-R1 73.27。GPQA 为 35.00，Search-R1 为 23.33。论文汇总 13 项中 12 项达到其比较最高。
- **适用条件 / 局限** · 需要访问和调节骨干隐状态、建立经验库及按任务设置奖励。每步检索和注意力有额外运行成本，词元量不能概括全部延迟。

## 1107 · CriticalKV: Optimizing KV Cache Eviction from an Output Perturbation Perspective

[原文](https://proceedings.mlr.press/v306/feng26j.html)

<a id="feng26j-inference"></a>

**技术主题** · 按输出扰动分配 KV 缓存预算

- **问题 / 瓶颈** · KV 压缩按注意力分数逐出词元时，未计入值向量和输出投影，可能删除对注意力输出扰动显著的条目。
- **核心创新 / 方法** · CriticalKV 推导打掩码后的输出扰动上界，将保留预算分两段。先保高注意力条目，再结合注意力和投影值范数选剩余条目以约束最坏扰动。
- **Baseline** · 改进来源为 SnapKV、AdaKV、HeadKV 的逐出打分和预算分配。实验对照含完整缓存以及三方法分别接入前后。
- **Benchmark** · 三个 LLM 骨干上的 RULER 与 LongBench 长上下文任务，主设置在看到问题前单独压缩上下文，比较得分、相对损失和扰动。
- **关键结果 / 消融** · Llama-3.1-8B 保留 40% 缓存的 RULER，完整缓存均分 91.05。AdaKV 从 78.38 提升到 86.28，损失从 13.9% 降到 5.2%。SnapKV 从 67.93 到 76.89。
- **适用条件 / 局限** · 理论围绕注意力输出及两阶段选择假设，最终任务误差靠实证核验。比例参数和各头预算会影响保留结果。

## 1108 · Understanding Dynamics of Adam in Zero-Sum Games: An ODE Approach

[原文](https://proceedings.mlr.press/v306/feng26k.html)

<a id="feng26k-theory-statistics"></a>

**技术主题** · 零和博弈中 Adam 一阶动量的稳定区间

- **问题 / 瓶颈** · Adam 下降–上升用于零和博弈，但最小化中的动量经验不能直接说明旋转耦合局部动态与隐式梯度正则。
- **核心创新 / 方法** · 以反向误差分析推导连续 Adam-DA 的修正常微分方程，在均衡点线性化，给出步长的局部指数收敛条件，并分析动量导致的梯度范数项。
- **Baseline** · 改进来源为最小化 Adam 的连续分析和符号 GDA 流。实验对照含离散 Adam-DA、连续近似、SignGDA-flow 和不同一二阶动量。
- **Benchmark** · 三个解析测试函数和 CIFAR-10、STL-10 的 CNN/ResNet GAN，用轨迹、局部稳定区及累计梯度范数检验理论。
- **关键结果 / 消融** · 定理 3.1 在有限时域和四阶有界导数等条件下给动量初始过渡后 O(h³) 的局部逼近误差。强耦合及指定特征谱条件下，降低 β 会扩大局部稳定步长区间。GAN 用学习率 2×10⁻⁴ 比较，较小 β、较大 ρ 得到较小梯度范数。
- **适用条件 / 局限** · 主要证明针对确定性动力学，局部收敛依赖均衡点谱的假设。随机 GAN 观察只提供所测设置的验证。
