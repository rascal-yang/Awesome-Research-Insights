## 301 · Autoregressive Language Models are Secretly Energy-Based Models: Insights into the Lookahead Capabilities of Next-Token Prediction

[原文](https://proceedings.mlr.press/v306/blondel26a.html) · [关联 Insight](../../../papers/llm.md#blondel26a-theory-statistics)

- **问题 / 瓶颈** · 只做下一 token 预测的自回归模型，怎样对应给整条序列打分的能量模型及其前瞻行为？
- **核心创新 / 方法** · 从概率链式法则构造能量函数到 logit 的双射，用后缀的对数配分和软 Bellman 递推解释每步看前方的信息，再分析监督训练和蒸馏误差。
- **Baseline** · 改进来源：自回归因子分解、能量模型与最大熵强化学习。实验对照：因果 Transformer ARM 与非因果 Transformer EBM，以及变换前后 logit 误差。
- **Benchmark** · 小词表、短最大长度的合成语言模型，精确枚举配分函数；比较训练风险最优差及 logit 的 L∞ 距离。
- **关键结果 / 消融** · 命题 1 在函数空间建立条件分布双射，命题 3 给出 KL ≤ 2T 乘以最大 logit 近似误差；小模型中两种训练收敛到相同最小风险。
- **适用条件 / 局限** · 精确对应针对函数空间；有限参数架构未必能实现精确转换，枚举验证只适用于极小模型。

## 302 · Benchmarking Dense and Indiscernible Object Counting with Blueberries

[原文](https://proceedings.mlr.press/v306/bo26a.html) · [关联 Insight](../../../papers/computer-vision.md#bo26a-loss-functions)

- **问题 / 瓶颈** · 密集、微小且与背景相似的蓝莓在野外图像中难以区分，怎样设计计数基准并降低漏计？
- **核心创新 / 方法** · MaskCount 先用 CLIP 产生背景抑制伪掩码，结合对比训练估计密度图，并重叠裁切与拼接有效中心区域，减少边界截断。
- **Baseline** · 改进来源：CLIP 语义对齐及 LOCA 类少样本密度估计。实验对照：CounTR、LOCA、SAFECount、多种人群计数方法和逐项去除掩码、对比损失、裁切的变体。
- **Benchmark** · DIOCblueberry 含 6,265 张图、约 67.9 万实例、每图平均 108 颗；还测杏仁和番茄，少样本计数使用三示例，指标为 MAE 和 RMSE。
- **关键结果 / 消融** · 蓝莓全模型 MAE/RMSE 为 3.63/4.26，普通 LOCA 为 7.14/14.44；仅加掩码和对比损失但未加边缘裁切时为 6.94/10.44。
- **适用条件 / 局限** · 评估以农业单类和已提供的计数示例为主；掩码由模型生成，外部作物与背景的迁移仍依赖所测数据。

## 303 · Efficient Multi-modal Dataset Distillation via Analytic Parameter Matching

[原文](https://proceedings.mlr.press/v306/bo26b.html) · [关联 Insight](../../../papers/multimodal.md#bo26b-data-strategies)

- **问题 / 瓶颈** · 如何用少量合成配对样本蒸馏大型多模态数据集，同时省去反复训练内层模型的开销？
- **核心创新 / 方法** · APM 固定模态编码器，以闭式投影参数为匹配目标，把目标拆成两种模态的统计和跨模态项，分别归一化并用相似度挖掘稳定训练。
- **Baseline** · 改进来源：多模态轨迹和分布匹配蒸馏。实验对照：随机、Herd、K-Center、Forget 子集及 MTT-VL、TESLA、LoRS、CovMatch、RepBlend。
- **Benchmark** · Flickr30k、MS-COCO 图文及 AudioCaps 音频文本检索，固定 CLIP 式编码器，报告双向 Recall@K，另做跨骨干和零样本分类。
- **关键结果 / 消融** · Flickr30k 的 100 对样本下 IR@1/TR@1 为 12.8±0.4/17.8±0.5，RepBlend 为 11.5±0.4/16.2±0.8；全量同骨干为 21.3/31.1。
- **适用条件 / 局限** · 闭式匹配依赖冻结编码器和线性投影假设；少量样本仍有秩和全量精度差距。

## 304 · Counterfactual Bootstrap for Robust Meta-Reinforcement Learning

[原文](https://proceedings.mlr.press/v306/bo26c.html) · [关联 Insight](../../../papers/reinforcement-learning.md#bo26c-reinforcement-learning)

- **问题 / 瓶颈** · 跨环境元强化学习的演示受隐藏混杂影响时，如何避免把有偏行为直接学成策略初始化？
- **核心创新 / 方法** · 利用部分识别找与观测相容的候选环境，从其后验执行反事实轨迹自举，并把增强轨迹交给 Causal MAML 优化快速适配的初始化。
- **Baseline** · 改进来源：MAML、PPO 和部分识别的反事实推断。实验对照：从头 PPO、演示预训练 PPO、普通 MAML 和 RL²。
- **Benchmark** · 带隐藏风向的 Windy Gridworld，拾钥匙、走到门、走到目标三个任务族，各含四个源任务和两个目标任务；测目标适配时累积奖励。
- **关键结果 / 消融** · 定理 1 在学习率及正则条件下给出达到一阶驻点的梯度误差界，所列设置的随机梯度计算量为 O(ε^{-4})；控制网格实验中反事实增强提升适配回报。
- **适用条件 / 局限** · 理论结论是一阶驻点及有限轨迹误差；依赖候选因果环境与后验设定，实证限于受控离散导航。

## 305 · VFMF: Dense Forecasting by Generating Vision Foundation Model Features

[原文](https://proceedings.mlr.press/v306/boduljak26a.html) · [关联 Insight](../../../papers/computer-vision.md#boduljak26a-representation-learning)

- **问题 / 瓶颈** · 历史场景仅部分可见且未来多解时，怎样预测可供分割和深度等下游用的视觉特征？
- **核心创新 / 方法** · VFMF 用 VAE 将视觉基础模型特征压到紧凑潜空间，再以条件 rectified flow 生成多个未来，将预测特征解码为语义、深度、法线及 RGB。
- **Baseline** · 改进来源：确定性 DINO-Foresight 和条件流匹配。实验对照：DINO-Foresight、长度可变回归、Generalist Forecasting、直接扩散与 PCA 压缩。
- **Benchmark** · Cityscapes 和 Kubric，改变输入帧数并自回归多步；评估分割 IoU、深度、法线和 RGB，另外用 ImageNet 256×256 检验生成。
- **关键结果 / 消融** · Cityscapes 单帧输入第 18 帧预测时，全类别分割指标 VFMF 样本均值 34.85，DINO-Foresight 为 31.67，择优样本 41.69；ImageNet 上 VAE/PCA 方案 FID 为 11.76/18.49。
- **适用条件 / 局限** · 择优样本使用真值选择，部署时不可直接获得；多步表现取决于基础特征、压缩和下游解码器。

## 306 · Verified SHAP: Provable Bounds for Exact Shapley Values of Neural Networks

[原文](https://proceedings.mlr.press/v306/boetius26a.html) · [关联 Insight](../../../papers/ml-foundations.md#boetius26a-evaluation)

- **问题 / 瓶颈** · 在输入特征数造成指数级子集空间时，怎样为神经网络的边际 SHAP 值提供可证的界或精确值？
- **核心创新 / 方法** · VERISHAP 将特征子集分块，用网络验证器界定每块的贡献，按照分裂策略逐步收紧全局区间，必要时细分到上下界一致。
- **Baseline** · 改进来源：SHAP 分解和神经网络验证。实验对照：EXACTSHAP 精确枚举、KernelSHAP、TreeMSR、LeverageSHAP 等统计估计。
- **Benchmark** · Obesity、German、Mushroom、Default、Auto、Sonar 等表格任务及不同网络结构；测精确求解或给定半区间宽度的耗时、估计 MSE，限 600 秒和 GPU 内存。
- **关键结果 / 消融** · Auto 的 2^25 子集空间中，VERISHAP 的 1% 半区间耗时 213 秒、精确 316 秒，EXACTSHAP 未在预算内完成；Sonar 的 2^60 空间在 13 秒给出表中 10% 半区间。
- **适用条件 / 局限** · 精确 SHAP 仍是 #P-hard，网络验证松紧和计算预算决定能否定精确值；例如 Sonar 未计算精确结果。

## 307 · Statistically Undetectable Backdoors in Deep Neural Networks

[原文](https://proceedings.mlr.press/v306/bogdanov26a.html) · [关联 Insight](../../../papers/ml-foundations.md#bogdanov26a-theory-statistics)

- **问题 / 瓶颈** · 持有完整权重的用户，能否识别训练者在深层网络埋入、可生成远输入近输出碰撞的后门？
- **核心创新 / 方法** · 理论构造在指定的冻结随机压缩层中嵌入近零方向，再以总变差和密码学计算难度分别分析模型可区分性和无密钥碰撞。
- **Baseline** · 改进来源：随机线性特征和密码学不可检测后门。实验对照：无后门训练分布及三种未知植入方向的碰撞搜索方法。
- **Benchmark** · 在 Fashion-MNIST 做概念演示，随机压缩矩阵 n=100、m=10/20/30 比较剩余范数；理论指标是权重分布总变差及有效碰撞强度。
- **关键结果 / 消融** · n=100、m=10 时，植入方向经矩阵变换后的范数约 1.6×10⁻¹⁰，三个搜索对照中最小为 0.03；定理 7 在给定架构约束与密码学假设下界定可区分性和碰撞优势。
- **适用条件 / 局限** · 结果要求特定冻结压缩层、后续网络的条件及高效攻击者；小规模图像和矩阵实验仅验证构造行为。

## 308 · Uncovering Competency Gaps in Large Language Models and Their Benchmarks

[原文](https://proceedings.mlr.press/v306/bohacek26a.html) · [关联 Insight](../../../papers/llm.md#bohacek26a-evaluation)

- **问题 / 瓶颈** · 语言模型总体分数掩盖了哪些概念的能力或覆盖差距，能否用内部激活分解？
- **核心创新 / 方法** · 以稀疏自编码器或 transcoder 的概念激活作为权重，分别计算各概念在基准中的相对覆盖及激活样例的任务分数，再查看低分及跨基准差距。
- **Baseline** · 改进来源：稀疏特征解释与标准基准平均分。实验对照：比较多基准、多模型及不同稀疏特征模型的诊断；独立诊断算法对照未报告。
- **Benchmark** · 五种开放权重语言模型；主分析十个事实、数学、推理和偏见静态基准，附 Chatbot Arena 及能力基准；用归一覆盖和激活加权正确性评估。
- **关键结果 / 消融** · 十个静态基准的概念覆盖右偏，多数概念覆盖低；表 1 在 AGI Eval、LogicBench、Social IQA 给出缺失样例，模型分析还辨出了迎合与恰当拒答的差距。
- **适用条件 / 局限** · 只能识别稀疏表示已经编码的概念；激活本身不能确证能力，题目难度可能混淆诊断，独立量化准确率未报告。

## 309 · Token Sample Complexity of Attention

[原文](https://proceedings.mlr.press/v306/bohbot26a.html) · [关联 Insight](../../../papers/ml-foundations.md#bohbot26a-theory-statistics)

- **问题 / 瓶颈** · 上下文很长时，有限 token 的自注意力以什么速率接近无限 token 极限？
- **核心创新 / 方法** · 将注意力写成对经验分布的归一指数加权，分别分析映射在查询域上的一致偏差、输出分布的矩及温度趋近硬最大时的极限。
- **Baseline** · 改进来源：自注意力的均场分布视角和集中不等式。实验对照：有限样本与高斯理论/高样本参考、短 key 采样与完整注意力，并对比 BigBird 和 BERT。
- **Benchmark** · 合成高斯及维基百科英、德、中和 CC-News 共七个文本数据设置，BigBird 经位置插值可至约 50 万 token；测拟合收敛率、logit 偏差和下游准确率。
- **关键结果 / 消融** · 定理 4.4 给出有界查询域内 n^{-1/2}、但区域相关前因子指数增长的界；定理 5.1 的 Lipschitz 矩界为 n^{-β} 乘对数项，β 受注意力跨度影响，一维高斯硬最大情形可慢至对数速率。
- **适用条件 / 局限** · 理论的 token 独立次高斯假设与真实语言相关性不同；实证的有限长参考和位置插值近似极限。

## 344 · Flatness-Aware Stochastic Gradient Langevin Dynamics

[原文](https://proceedings.mlr.press/v306/bruno26a.html) · [关联 Insight](../../../papers/ml-foundations.md#bruno26a-optimization)

- **问题 / 瓶颈** · 寻找较平坦损失谷通常需要重复梯度、Hessian 或额外状态，希望保留 SGLD 的单梯度与内存规模。
- **核心创新 / 方法** · fSGLD 在高斯扰动参数处取一次随机梯度，再加 Langevin 噪声。把扰动尺度设为 σ=β^(-(1+η)/4)，诱导平坦偏置的 Gibbs 分布。
- **Baseline** · 改进来源为 SGLD 和对平滑损失的局部熵分析。实验对照有 SGD、SAM、ASAM、Entropy-SGD、Entropy-SGLD、Entropy-MCMC。
- **Benchmark** · 在 CIFAR-10/100 与 ResNet、ViT 微调等测分类 ACC、NLL，并用 CIFAR–SVHN 测分布外 AUROC/AUPR。另消融 β–σ 耦合。
- **关键结果 / 消融** · ResNet-18 的 CIFAR-10 准确率 95.73±0.07%，NLL 0.144±0.001，SGLD 为 95.47±0.11%、0.167±0.011。理论给出非渐近误差与超额风险界。
- **适用条件 / 局限** · 作者指出理论需要所列正则假设，推广到仅半凸目标和扩散生成任务仍待验证。
