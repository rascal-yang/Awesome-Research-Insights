## 5304 · Path-Coupled Bellman Flows for Distributional Reinforcement Learning

[原文](https://proceedings.mlr.press/v306/xu26ct.html)

<a id="xu26ct-loss-functions"></a>

**技术主题** · 保持源边界的Bellman路径耦合

- **问题 / 瓶颈** · 直接全路径Bellman仿射会改坏源噪声分布，独立采样又增方差。
- **核心创新 / 方法** · 当前路径=(1−t)X0+t(R+gammaXnext)，后继用同X0；其关系含(1−t)(1−gamma)X0修正，再构造lambda控制变量训练目标。
- **Baseline** · Value Flows、IQN/CODAC、FloQ/FQL等；共享噪声/控制变量已有基础，候选为源边界修正和条件偏差分解。
- **Benchmark** · 解析MRP、OGBench30任务及D4RL Adroit8任务；分布Wasserstein/CDF、离线归一化表现；8种子，视觉4种子。
- **关键结果 / 消融** · cube-double PCBF70±3、ValueFlows69±4；cube-triple6±2对14±3，visual-cube-double3±0对13±2，非全面更好。
- **适用条件 / 局限** · 控制变量在后继条件均值零，不保证在当前插值条件仍零；lambda目标可偏，原稿也明确此条件。基准任务均值不是每任务胜出，完整预算待核实。

## 5307 · Advantage Weighted Matching: Aligning RL with Pretraining in Diffusion Models

[原文](https://proceedings.mlr.press/v306/xue26c.html)

<a id="xue26c-loss-functions"></a>

**技术主题** · 有符号优势加权的匹配后训练

- **问题 / 瓶颈** · 逐去噪转移RL与clean目标匹配的估计方差及计算不一致。
- **核心创新 / 方法** · 采样终图、评奖励与组优势，再用source前向噪声构造score/flow匹配损失乘优势；旧rollout在局部梯度推导中停止。
- **Baseline** · DDPO/Flow-GRPO/TempFlow-GRPO及reward-weighted匹配为直接来源；独立新增量相对已有优势匹配需核，不能称首次奖励加权回归。
- **Benchmark** · SD3.5 Medium/FLUX；GenEval、OCR、PickScore，GPU小时/速度及生成指标。
- **关键结果 / 消融** · GenEval表Flow-GRPO总体0.95，AWM0.985、标记16.54倍；摘要最高34倍跨任务口径，不当每项速度。
- **适用条件 / 局限** · DDPO梯度等价只在当前参数等于冻结rollout且满足过程条件的局部位置；多步更新和负优势不保证全局同目标/有界损失，同计算控制待核实。

## 5312 · R2-Router: A New Paradigm for LLM Routing with Reasoning

[原文](https://proceedings.mlr.press/v306/xue26h.html)

<a id="xue26h-inference"></a>

**技术主题** · 模型与输出长度预算联合路由

- **问题 / 瓶颈** · 每模型每查询单一成本点会漏掉短回答仍高质量的配置。
- **核心创新 / 方法** · 每模型采多个输出预算构质量—成本曲线，编码查询后用按成本分头的MLP预测质量，按质量/成本权衡选模型与预算。
- **Baseline** · MIRT/CARROT/UniRouter等模型选择为基础；候选是把输出预算纳入路由动作，最近budget-aware路由待核实。
- **Benchmark** · R2-Bench多模型多长度；MMLU-Pro STEM训/non-STEM测及未见模型扩池；AUDC/QNC、peak accuracy及成本。
- **关键结果 / 消融** · OOD表R2 AUDC0.71±0.05、QNC0.26±0.09，CARROT-L0.67±0.04/0.56±0.06；摘要4–5倍低成本是比较口径待核，不当所有质量阈值。
- **适用条件 / 局限** · 长度提示是软约束，不保证实际token不超；曲线采集/裁判成本及预算遵循、质量预测外推待核，强模型短答优势依任务。

## 5313 · FourTune: Towards Fully 4-Bit Efficient Post-Training for Diffusion Models

[原文](https://proceedings.mlr.press/v306/xue26i.html)

<a id="xue26i-optimization"></a>

**技术主题** · 冻结稳定分支支持4位反传

- **问题 / 瓶颈** · 只量化权重无法充分降训练带宽，全4位主路径容易被异常值破坏。
- **核心创新 / 方法** · SVD拆冻结稳定分支与4位残差主干，再加可训练LoRA；块量化/融合kernel实现W/A/G4主矩阵乘，稳定器和adapter仍走高精度。
- **Baseline** · BF16/FP8 LoRA、NF4 QLoRA及SVD异常值隔离为来源；候选是反传三分支与转置块量化的训练实现，最近4位训练待核。
- **Benchmark** · FLUX1-dev12B及Qwen-Image，身份/风格/主体定制、RL、4步蒸馏；质量/相似度/多样性/指令遵循、显存/吞吐。
- **关键结果 / 消融** · FLUX身份定制相似度BF16 0.771、本法0.783，但prompt following0.941→0.913；摘要显存降2.25倍、吞吐2.27倍，硬件条件待核。
- **适用条件 / 局限** · 不是所有张量/分支都4位；额外稳定分支及硬件kernel影响收益，主路径量化尺度、梯度误差和同rank预算控制待核。

## 5315 · Any-Order GPT as Masked Diffusion Model: Decoupling Formulation and Architecture

[原文](https://proceedings.mlr.press/v306/xue26k.html)

<a id="xue26k-architecture"></a>

**技术主题** · 同decoder骨干的任意顺序建模

- **问题 / 瓶颈** · 架构和生成范式同时改变会混淆效率/质量结论。
- **核心创新 / 方法** · decoder-only训练任意顺序条件概率，按置换因果上下文预测；固定生成顺序支持标准cache，温度退火和多顺序集成改善质量。
- **Baseline** · GPT式AR、XLNet和encoder-only SEDD；任意顺序本身已有历史，候选是架构匹配控制及顺序相关条件的成本边界。
- **Benchmark** · LAMBADA/WikiText2/PTB/WikiText103/1BW困惑度；小/中模型同架构训练曲线，多顺序ensemble；长1024、batch32生成时间。
- **关键结果 / 消融** · 同decoder下AO-GPT早期收敛更慢；特定cache配置相对SEDD约25倍加速，不等相对同架构AR25倍。Ensemble增加可改善困惑度但也增计算。
- **适用条件 / 局限** · cache需每次生成顺序固定，动态重排不能直接套用；排列顺序依赖条件数量增加不自动证明更强实践表达力，训练/总FLOPs待核。

## 5330 · Spurious Rewards Paradox: Mechanistically Understanding How RLVR Activates Memorization Shortcuts in LLMs

[原文](https://proceedings.mlr.press/v306/yan26f.html)

<a id="yan26f-evaluation"></a>

**技术主题** · 伪奖励下污染捷径的分层审计

- **问题 / 瓶颈** · 污染记忆可使无意义奖励训练后评测分数上升。
- **核心创新 / 方法** · 比较真/伪奖励及模型家族，定位中层检索样式表征与后层适配，使用patch/reset和稳定样本对照检查污染特异性。
- **Baseline** · 部分提示污染评测、logit lens和path patching为来源；候选为伪奖励触发污染快捷路径的干预经验，不称首次发现记忆子空间。
- **Benchmark** · Qwen2.5-Math7B/1.5B及LLaMA/OLMo/Qwen3对照，MATH500与LiveMathBench；答案/提示perplexity、泄漏/稳定子集准确率和patch recovery。
