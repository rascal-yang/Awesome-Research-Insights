## 5302 · Gradient Flow Sampler-based Distributionally Robust Optimization

[原文](https://proceedings.mlr.press/v306/xu26cr.html)

<a id="xu26cr-optimization"></a>

**技术主题** · 条件最坏分布的输运与反应采样

- **问题 / 瓶颈** · 非凸损失下最坏分布采样和对偶优化难稳定实现。
- **核心创新 / 方法** · 先取经验源点，再从其条件最坏分布用WGF/WFR/SVGD采样，外层SGD；WFR用生灭重分配权重而不只移动粒子。
- **Baseline** · WRM、Dual Sinkhorn DRO及经典梯度流/粒子采样为来源；候选是内层条件采样框架和几何选择，非首次使用WFR/SVGD。
- **Benchmark** · MNIST LeNet5端到端及CIFAR10特征/ResNet18设置；PGD L2/Linf强度，测试错误率、采样/外层复杂度。
- **关键结果 / 消融** · MNIST L2强度0.075：WRM29.22%、Dual24.20%、WGF21.57%、WFR20.81%；CIFAR10无扰WFR11.10%差于SAA6.35%，保留鲁棒—clean权衡。
- **适用条件 / 局限** · WFR粒子混合与有限采样误差影响梯度；总体PDE收敛不是实际混合时间保证，CIFAR特征提取/端到端口径及等计算控制待核实。

## 5303 · On Learnability and Disambiguation of Multiclass Partial Concept Classes

[原文](https://proceedings.mlr.press/v306/xu26cs.html)

<a id="xu26cs-theory-statistics"></a>

**技术主题** · 部分标签补全的可学习性边界

- **问题 / 瓶颈** · 无界类别下有限Natarajan维不能完整判断部分概念可学习。
- **核心创新 / 方法** · 用DS维刻画部分多类类的PAC可学习性；构造不同off-support补全标签方案并分析其DS维和样本压缩。
- **Baseline** · 有限标签Natarajan理论及总类DS维结果为来源；候选是部分定义标签补全的反例/标签复杂度权衡。
- **Benchmark** · 抽象可实现/不可实现PAC、可无界标签空间与部分定义支持；样本复杂度、DS维及补全反例，未据此验证具体神经网络。
- **关键结果 / 消融** · 构造存在类，任何仅0/1补全导致DS维发散，而较丰富、携带假设信息的标签可保留可学习性；是存在性反例而非所有细标签均好。
- **适用条件 / 局限** · 实用标签补全需可实现且不泄漏假设身份；抽象压缩算法不自动高效，有限固定类别和冻结特征情形的直接收益待核实。

## 5304 · Path-Coupled Bellman Flows for Distributional Reinforcement Learning

[原文](https://proceedings.mlr.press/v306/xu26ct.html)

<a id="xu26ct-loss-functions"></a>

**技术主题** · 保持源边界的Bellman路径耦合

- **问题 / 瓶颈** · 直接全路径Bellman仿射会改坏源噪声分布，独立采样又增方差。
- **核心创新 / 方法** · 当前路径=(1−t)X0+t(R+gammaXnext)，后继用同X0；其关系含(1−t)(1−gamma)X0修正，再构造lambda控制变量训练目标。
- **Baseline** · Value Flows、IQN/CODAC、FloQ/FQL等；共享噪声/控制变量已有基础，候选为源边界修正和条件偏差分解。
- **Benchmark** · 解析MRP、OGBench30任务及D4RL Adroit8任务；分布Wasserstein/CDF、离线归一化表现；8种子，视觉4种子。
- **关键结果 / 消融** · cube-double PCBF70±3、ValueFlows69±4；cube-triple6±2对14±3，visual-cube-double3±0对13±2，非全面更好。
- **适用条件 / 局限** · 控制变量在后继条件均值零，不保证在当前插值条件仍零；lambda目标可偏，原稿也明确此条件。基准任务均值不是每任务胜出，完整预算待核实。

## 5307 · Advantage Weighted Matching: Aligning RL with Pretraining in Diffusion Models

[原文](https://proceedings.mlr.press/v306/xue26c.html)

<a id="xue26c-loss-functions"></a>

**技术主题** · 有符号优势加权的匹配后训练

- **问题 / 瓶颈** · 逐去噪转移RL与clean目标匹配的估计方差及计算不一致。
- **核心创新 / 方法** · 采样终图、评奖励与组优势，再用source前向噪声构造score/flow匹配损失乘优势；旧rollout在局部梯度推导中停止。
- **Baseline** · DDPO/Flow-GRPO/TempFlow-GRPO及reward-weighted匹配为直接来源；独立新增量相对已有优势匹配需核，不能称首次奖励加权回归。
- **Benchmark** · SD3.5 Medium/FLUX；GenEval、OCR、PickScore，GPU小时/速度及生成指标。
- **关键结果 / 消融** · GenEval表Flow-GRPO总体0.95，AWM0.985、标记16.54倍；摘要最高34倍跨任务口径，不当每项速度。
- **适用条件 / 局限** · DDPO梯度等价只在当前参数等于冻结rollout且满足过程条件的局部位置；多步更新和负优势不保证全局同目标/有界损失，同计算控制待核实。

## 5308 · Physics-Guided Motion Loss for Video Generation Model

[原文](https://proceedings.mlr.press/v306/xue26d.html)

<a id="xue26d-loss-functions"></a>

**技术主题** · SIM2频谱运动残差正则

- **问题 / 瓶颈** · 生成视频视觉清晰但局部运动容易扭曲。
- **核心创新 / 方法** · 短窗FFT，平移用能量加权ridge平面拟合，旋转/缩放经相应频谱坐标建约束；按各损失softmax负值加权成组合项。
- **Baseline** · 经典运动频谱/SIM2与视频扩散为来源；候选是可微频谱拟合辅助目标，不称新物理定律或保证守恒。

## 5315 · Any-Order GPT as Masked Diffusion Model: Decoupling Formulation and Architecture

[原文](https://proceedings.mlr.press/v306/xue26k.html)

<a id="xue26k-architecture"></a>

**技术主题** · 同decoder骨干的任意顺序建模

- **问题 / 瓶颈** · 架构和生成范式同时改变会混淆效率/质量结论。
- **核心创新 / 方法** · decoder-only训练任意顺序条件概率，按置换因果上下文预测；固定生成顺序支持标准cache，温度退火和多顺序集成改善质量。
- **Baseline** · GPT式AR、XLNet和encoder-only SEDD；任意顺序本身已有历史，候选是架构匹配控制及顺序相关条件的成本边界。
- **Benchmark** · LAMBADA/WikiText2/PTB/WikiText103/1BW困惑度；小/中模型同架构训练曲线，多顺序ensemble；长1024、batch32生成时间。

**技术主题** · 用上下文重建提取步骤增量特征

- **问题 / 瓶颈** · token级SAE粒度难分离整步推理增量和背景。
