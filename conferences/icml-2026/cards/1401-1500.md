## 1401 · WildActor: Unconstrained Identity-Preserving Video Generation

[原文](https://proceedings.mlr.press/v306/guo26ad.html)

<a id="guo26ad-modules"></a>

**技术主题** · 人体视频的非对称身份注意力

- **问题 / 瓶颈** · 有参考的人物视频在转身、镜头切换及大动作中容易保持脸部却改变体型和服饰，或因过强参考约束而锁姿。
- **核心创新 / 方法** · WildActor 将静态脸部/身体参考与运动 token 作非对称注意力，用只作用于参考的 LoRA、隔开的 I-RoPE 坐标保持身份和运动分离。训练时按视角覆盖的边际效用对候选参考动态重加权。
- **Baseline** · 改进来源为预训练视频 DiT 和多视角身份条件。实验对照为 Qwen-Image-Edit 加 I2V、无参考的连续生成、VACE、Stand-In、Vidu Q2 和 Kling 1.6。
- **Benchmark** · Actor-18M 训练资源含 160 万视频与 1,800 万对应人物图。Actor-Bench 用 75 个主体评估连续叙事及跨场景泛化，报告 ArcFace、视角匹配的身体一致性与语义对齐。
- **关键结果 / 消融** · 跨场景泛化中，WildActor 的身体一致性为 0.952、VLM 语义对齐 0.920，Vidu Q2 为 0.905、0.880，其脸部身份 0.565 高于 WildActor 的 0.559。视角自适应比随机参考抽样的平均身体一致性 0.865 更高。
- **适用条件 / 局限** · 评测对象较少，身体与部分语义评价依赖 Gemini-3-Pro，脸部相似度依赖可检测的脸及可比视角。参考覆盖弱的场景仍受输入条件限制。

**可复用机制** · 将身份参考和运动词元隔开位置坐标并用非对称注意力交互，根据边际视角覆盖选参考，减少动作与身份改写的耦合。

## 1402 · CorrectionPlanner: Self-Correction Planner with Reinforcement Learning in Autonomous Driving

[原文](https://proceedings.mlr.press/v306/guo26ae.html)

<a id="guo26ae-reinforcement-learning"></a>

**技术主题** · 碰撞预测驱动的驾驶动作自纠正

- **问题 / 瓶颈** · 闭环驾驶策略即使能提议合理轨迹，仍可能生成局部不安全的运动 token。需要在执行前评估提议并重新生成。
- **核心创新 / 方法** · CorrectionPlanner 自回归提议运动 token，用短程碰撞 critic 筛查，把拒绝的动作累积成纠错历史，条件化下一次重提，直至通过或达到次数上限。用模仿预训练及学习世界模型生成的反应式 rollout 微调。
- **Baseline** · 改进来源为运动 token 驱动规划及模型式强化学习。实验对照为 SMART、PlanT、LatentDrive、EasyChauffeur-PPO、nuPlan 规划器及不读纠错历史的重试策略。
- **Benchmark** · 在 Waymax 与 nuPlan 作反应式和非反应式闭环评估，报告碰撞、驶离道路、进展与 nuPlan 规划综合分。另比较纠错次数与时延。
- **关键结果 / 消融** · Waymax 反应式碰撞指标 1.68，SMART 为 2.36，下降约 28.8%。不读纠错历史的重试为 2.01，含历史为 1.68。nuPlan Val14 非反应规划分为 91.22，SMART 为 90.03。
- **适用条件 / 局限** · 安全性依赖碰撞 critic 的预测和世界模型的仿真反应。触发重试会增加推理开销，正文报告的是闭环仿真结果。

**原文定位** · [§4、提议与纠错（PDF 第 4 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/guo26ae/guo26ae.pdf#page=4) · [§4.2–4.3、强化学习与 critic（PDF 第 5 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/guo26ae/guo26ae.pdf#page=5) · [表 1–2（PDF 第 7 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/guo26ae/guo26ae.pdf#page=7) · [表 3–4（PDF 第 8 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/guo26ae/guo26ae.pdf#page=8) · [时延与结论（PDF 第 9 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/guo26ae/guo26ae.pdf#page=9)

**可复用机制** · 用碰撞 critic 验收短时运动轨迹，并把被拒动作作为下一次提案条件，使驾驶策略能从具体失败修正。

## 1403 · DreamID-Omni: Unified Framework for Controllable Human-Centric Audio-Video Generation

[原文](https://proceedings.mlr.press/v306/guo26af.html)

<a id="guo26af-modules"></a>

**技术主题** · 用位置编码绑定人物与音色

- **问题 / 瓶颈** · 参考图音视频生成、身份/音色编辑及音频驱动动画通常分开训练，多人场景中角色与说话音色还容易绑错。
- **核心创新 / 方法** · DreamID-Omni 用对称条件 DiT 统一注入图像、音频和视频条件，通过同步 RoPE 及分角色结构字幕在信号与语义两层绑定身份和音色。先同配对重建、再跨配对解耦、最后按任务混合微调。
- **Baseline** · 改进来源为 Ovi 联合音视频底座和扩散条件注入。实验对照为 Wan2.6、Qwen-Image 搭配 Ovi/LTX-2，以及各子任务专用系统，另移除结构字幕、同步 RoPE 或渐进训练。
- **Benchmark** · IDBench-Omni 有 200 个案例，分别为 100 项参考生成、50 项遮罩编辑和 50 项驱动动画。测身份与音色相似度、WER、唇音同步和说话人混淆。
- **关键结果 / 消融** · 参考生成的多人身份/音色相似度为 0.603/0.402，Wan2.6 为 0.455/0.217，说话人混淆率 0.080 对 0.380，WER 0.052 对 0.534。
- **适用条件 / 局限** · 基准规模有限，训练约 128 H20 GPU 天。渐进次序消融显示，过早混入强约束任务会降低弱约束生成表现。

## 1404 · OmniAID: Decoupling Semantics and Artifacts for Universal AI-Generated Image Detection in the Wild

[原文](https://proceedings.mlr.press/v306/guo26ag.html)

<a id="guo26ag-architecture"></a>

**技术主题** · 内容伪迹分离的生成图像鉴别

- **问题 / 瓶颈** · 生成图像检测需要同时跨生成器和内容域泛化。单一特征空间容易把面部等内容相关异常与生成过程的通用伪影混在一起。
- **核心创新 / 方法** · OmniAID 在冻结 CLIP-ViT 主子空间的正交残差中建立专家。语义专家经域内困难样本专门化，通用专家以同语义真实/重构对学习伪影并始终启用，冻结专家后用轻量全局门控选择语义专家。
- **Baseline** · 改进来源为 CLIP 正交残差适配和 MoE 稀疏路由。实验对照为 DIRE、NPR、DRCT、AIDE、Effort 等，并区分 GenImage-SD v1.4 共同训练与 Mirage 训练。
- **Benchmark** · 在 GenImage 和新建 Mirage-Test 上评估。Mirage-Test 约有 2.2 万张真实、2.8 万张生成图像，覆盖人、动物、物体、场景及动漫五域，报告准确率和平均精确率。
- **关键结果 / 消融** · 同用 GenImage-SD v1.4 训练时，OmniAID 在 Mirage-Test 的类别平均准确率为 51.10%，Effort 为 43.03%。用 Mirage-Train 后 OmniAID 为 88.39%。
- **适用条件 / 局限** · Mirage-Test 的动漫类因版权只含生成样本，无法据此评估真人绘制动漫的误报率。只用 SD v1.4 训练时，现代生成器评测仍有明显差距。

## 1406 · Remove the Ambiguity: Few-shot Multimodal Anomaly Detection Using Crossmodal Feature Replacer

[原文](https://proceedings.mlr.press/v306/guo26ai.html)

<a id="guo26ai-inference"></a>

**技术主题** · 异常检测的跨模态重建替换

- **问题 / 瓶颈** · RGB 与 3D 特征间可一对多，形状相同的正常物体可能有不同颜色。用确定型跨模态回归容易把正常变化平均掉，造成重建式异常误报。
- **核心创新 / 方法** · CFR 用双向循环映射粗重建各模态，以正常特征库筛出低置信 RGB 重建，在点云键空间用注意力辅助近邻检索，对这些位置选择性替换。
- **Baseline** · 改进来源为循环式跨模态映射 CFM 及特征记忆库。实验对照为 M3DM、CFM 等方法，并比较纯重建和移除检索模块。
- **Benchmark** · 在 10 类工业物品 MVTec 3D-AD 和 10 类合成糖果 Eyecandies 的像素对齐 RGB/点云上测 1、2、4-shot。指标为图像 AUROC 与固定 FPR 上限的区域 AUPRO。
- **关键结果 / 消融** · 在 MVTec 3D-AD 的 1-shot，CFR 的图像 AUROC/30% AUPRO 为 74.0%/92.3%，M3DM 为 73.9%/90.2%，CFM 为 67.5%/91.4%。Eyecandies 的 1-shot 为 75.9%/82.7%。
- **适用条件 / 局限** · 候选替换依赖配准的 3D 与 RGB 及正常记忆库的覆盖。固定阈值 0.4 来自 MVTec Bagel 的相似度统计，文中检验了邻近阈值的敏感性。

## 1407 · ImpText: A Benchmark and Tool-Augmented Framework for Implicit Text Reasoning

[原文](https://proceedings.mlr.press/v306/guo26aj.html)

<a id="guo26aj-training-strategies"></a>

**技术主题** · 隐蔽文字识别的能力边界训练

- **问题 / 瓶颈** · 物理形变、视觉伪装和语境暗示会让隐藏文字难以通过常规 OCR 读出，需要先发现文字存在并恢复含义。
- **核心创新 / 方法** · ImpText-Reader 分为调用图像处理工具的增强器和识别文字的推理器，依次做知识热身、oracle 工具引导协同训练、以能力边界样本和多维 GRPO 进行强化训练。
- **Baseline** · 改进来源为 Qwen3-VL 8B、图像增强调用及 GRPO。实验对照为传统 OCR、开源及闭源多模态模型、单独 SFT 或 GRPO、各阶段增量消融。
- **Benchmark** · ImpText-Bench 含 1,630 个重构样本，其中 1,141 个正常图像，余下覆盖形变、纹理干扰、融合、排版和语境遮掩。报告 F1 与基于归一化编辑距离阈值的 TMS。
- **关键结果 / 消融** · 完整模型总体 F1 87.97%、TMS 48.26%，Qwen3-VL 8B 为 26.09%/10.22%。仅增加工具为 28.62%/10.63%，加入 oracle 工具阶段后为 78.49%/46.83%。
- **适用条件 / 局限** · 基准主要源于中文社交媒体场景，经重构后发布，其他语言和平台的隐藏形式仍需验证。

## 1408 · SSL4RL: Revisiting Self-supervised Learning as Intrinsic Reward for Visual-Language Reasoning

[原文](https://proceedings.mlr.press/v306/guo26ak.html)

<a id="guo26ak-reinforcement-learning"></a>

**技术主题** · 以自监督扰动构造视觉强化奖励

- **问题 / 瓶颈** · 视觉语言模型可能通过文字捷径回答问题。需要可规模化的训练奖励，促使推理时更多使用图像证据。
- **核心创新 / 方法** · SSL4RL 由原图自动构造旋转、拼图、增强配对与图块位置任务，使用预测与已知扰动标签是否一致作为可验证奖励，以带参考策略 KL 项的 GRPO 微调。
- **Baseline** · 改进来源为经典视觉自监督预任务和 GRPO。实验对照为原始 Qwen2.5-VL-3B、不同奖励任务、简单混合及任务难度等消融。
- **Benchmark** · 对 MMBench、SEED-Bench、V*、RealWorldQA、BLINK、MME 报告 VQA 测试性能，另测 ImageNet 下游任务、图像描述与视觉损坏。
- **关键结果 / 消融** · 位置预测训练在六项 VQA 上平均 60.39%，原模型为 53.36%，提升 7.03 个百分点。旋转奖励在 MMBench 为 80.38%，基线为 72.99%。
- **适用条件 / 局限** · 收益随任务难度和模型能力的匹配程度变化。简单混合不同自监督任务并不稳定提升分数，开放式图像描述的验证范围较窄。

## 1409 · Discrete Adjoint Schrödinger Bridge Sampler

[原文](https://proceedings.mlr.press/v306/guo26al.html)

<a id="guo26al-optimization"></a>

**技术主题** · 离散 Schrödinger 桥的伴随匹配

- **问题 / 瓶颈** · 离散组合分布缺少连续状态梯度，连续域常用的伴随匹配难以直接用于已知能量、未知归一化常数的神经采样。
- **核心创新 / 方法** · DASBS 以连续时间马尔可夫链统一离散 Schrödinger 桥和随机最优控制，用循环群上的加性噪声表达跳转，以最优控制固定点迭代学习速率及校正。
- **Baseline** · 改进来源为连续伴随匹配与 ASBS，扩展到离散状态。实验对照为 LEAPS、UDNS、DFNS、MDNS、Metropolis–Hastings 与去噪匹配消融。
- **Benchmark** · 在 24×24 Ising 与 16×16 四态 Potts 格点，以磁化、两点相关及能量分布 Wasserstein-2 误差评价，DASBS 表 2 汇总 3 种子，训练计时使用 2 张 RTX A6000。
- **关键结果 / 消融** · 24×24 Ising 的低温 β=0.6，DASBS 的能量 W₂ 为 2.5，LEAPS 为 176.6。表 2 的训练计时为 0.2 小时、3 千步，相较 LEAPS 的 8.4 小时、3 万步。
- **适用条件 / 局限** · 循环群结构约束了所用加性噪声构造。评测限于合成格点，强模态壁垒可造成训练不稳，单步能量求值很贵时成本可能显著。

- **问题 / 瓶颈** · 推理分割需要由复杂指令找出隐含目标，但长推理可能让多模态模型的注意力分散，使目标定位变差。
- **核心创新 / 方法** · DR²Seg 第一轮生成独立指代及空间答案，训练时用指代替换原复杂问题再跑一轮。按第二轮定位准确性给描述奖励，并用两轮相对长度及绝对锚点约束推理。推理只运行第一轮。
- **Baseline** · 改进来源为 VisionReasoner 的 GRPO 奖励和 SAM 分割接口。实验对照包括 LISA、Seg-Zero、SAM-R1、PixelThink、VisionReasoner 及描述和长度奖励消融。
- **Benchmark** · 使用 Qwen2.5-VL 3B/7B 和 SAM2/SAM3，在 ReasonSeg 验证/测试、refCOCO 系列测 gIoU、cIoU 和推理 token。
- **关键结果 / 消融** · ReasonSeg 零样本测试中，7B 的 DR²Seg 为 64.8 gIoU、62.8 cIoU、55.4 推理 token，VisionReasoner 为 63.6、58.2、84.8。用 ReasonSeg 训练后本法为 66.1、63.6 和 27.2 token。
- **适用条件 / 局限** · 第二轮自奖励仍依赖训练空间真值，训练比单轮多一次 rollout。主要由短指代组成的零样本训练数据不采用长度奖励。

## 1500 · Self-Prophetic Decoding to Unlock Visual Search in LVLMs

[原文](https://proceedings.mlr.press/v306/he26g.html)

<a id="he26g-inference"></a>

**技术主题** · 以双模型概率一致性接入单步视觉草稿

- **问题 / 瓶颈** · 后训练提高了视觉搜索模型的多轮规划能力，但长上下文会干扰单步视觉定位和回答，直接把基模输出追加为文本也会改变推理分布。
- **核心创新 / 方法** · SeProD 让预训练模型依据当前视图产生定位或答案草稿，搜索模型并行评估。以两个模型的 token 概率构造一致性分数，接受到首个低于阈值的 token 之前，再由搜索模型续写。
- **Baseline** · 改进来源为同族预训练和搜索模型的互补能力，以及草稿并行验证。实验对照为 Mini-o3、DeepEyes、其他视觉搜索方法和直接提示、强制替换消融。
- **Benchmark** · 在 VisualProbe、V* Bench 和 HR-Bench 4K/8K 的 12 个划分及 MME-RW、ScienceQA、OCRBench、CVBench 上评估。VisualProbe 用 H20、batch=4 测接受率和速度。
- **关键结果 / 消融** · 相对 Mini-o3，SeProD 的 MME-RW 从 65.5 到 67.7，CVBench 从 74.4 到 78.4。VisualProbe 难档接受 74.6% 草稿 token，速度为 1.06 倍。
- **适用条件 / 局限** · 需要同时运行预训练和搜索模型，速度结果取决于设备安排与草稿接受率。一致性阈值和概率权重改变对基模建议的采纳程度。
