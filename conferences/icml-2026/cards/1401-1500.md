## 1402 · CorrectionPlanner: Self-Correction Planner with Reinforcement Learning in Autonomous Driving

[原文](https://proceedings.mlr.press/v306/guo26ae.html)

<a id="guo26ae-reinforcement-learning"></a>

**技术主题** · 碰撞预测驱动的驾驶动作自纠正

- **问题 / 瓶颈** · 闭环驾驶策略即使能提议合理轨迹，仍可能生成局部不安全的运动 token。需要在执行前评估提议并重新生成。
- **核心创新 / 方法** · CorrectionPlanner 自回归提议运动 token，用短程碰撞 critic 筛查，把拒绝的动作累积成纠错历史，条件化下一次重提，直至通过或达到次数上限。用模仿预训练及学习世界模型生成的反应式 rollout 微调。
- **Baseline** · 改进来源为运动 token 驱动规划及模型式强化学习。实验对照为 SMART、PlanT、LatentDrive、EasyChauffeur-PPO、nuPlan 规划器及不读纠错历史的重试策略。
- **Benchmark** · 在 Waymax 与 nuPlan 作反应式和非反应式闭环评估，报告碰撞、驶离道路、进展与 nuPlan 规划综合分。另比较纠错次数与时延。
- **关键结果 / 消融** · Waymax 反应式碰撞指标 1.68，SMART 为 2.36，下降约 28.8%。不读纠错历史的重试为 2.01，含历史为 1.68。nuPlan Val14 非反应规划分为 91.22，SMART 为 90.03。
- **适用条件 / 局限** · 安全性依赖碰撞 critic 的预测和世界模型的仿真反应。触发重试会增加推理开销，正文报告的是闭环仿真结果。

**可复用机制** · 用碰撞 critic 验收短时运动轨迹，并把被拒动作作为下一次提案条件，使驾驶策略能从具体失败修正。

## 1409 · Discrete Adjoint Schrödinger Bridge Sampler

[原文](https://proceedings.mlr.press/v306/guo26al.html)

<a id="guo26al-optimization"></a>

**技术主题** · 离散 Schrödinger 桥的伴随匹配

- **问题 / 瓶颈** · 离散组合分布缺少连续状态梯度，连续域常用的伴随匹配难以直接用于已知能量、未知归一化常数的神经采样。
- **核心创新 / 方法** · DASBS 以连续时间马尔可夫链统一离散 Schrödinger 桥和随机最优控制，用循环群上的加性噪声表达跳转，以最优控制固定点迭代学习速率及校正。
- **Baseline** · 改进来源为连续伴随匹配与 ASBS，扩展到离散状态。实验对照为 LEAPS、UDNS、DFNS、MDNS、Metropolis–Hastings 与去噪匹配消融。
- **Benchmark** · 在 24×24 Ising 与 16×16 四态 Potts 格点，以磁化、两点相关及能量分布 Wasserstein-2 误差评价，DASBS 表 2 汇总 3 种子，训练计时使用 2 张 RTX A6000。
- **关键结果 / 消融** · 24×24 Ising 的低温 β=0.6，DASBS 的能量 W₂ 为 2.5，LEAPS 为 176.6。表 2 的训练计时为 0.2 小时、3 千步，相较 LEAPS 的 8.4 小时、3 万步。
- **适用条件 / 局限** · 循环群结构约束了所用加性噪声构造。评测限于合成格点，强模态壁垒可造成训练不稳，单步能量求值很贵时成本可能显著。

## 1412 · Geometry-Aware Neural Optimizer for Shape Optimization and Inversion

[原文](https://proceedings.mlr.press/v306/guoze26a.html)

<a id="guoze26a-optimization"></a>

**技术主题** · 几何潜变量到 PDE 场的可微优化

- **问题 / 瓶颈** · PDE 驱动的形状设计需反复做前向模拟与几何处理，普通神经代理即使能快速预测场，也难以给出稳定且可控制的几何更新。
- **核心创新 / 方法** · GANO 用去噪训练的 STABLESDF 自动解码器表示形状，以注入几何信息的代理模型获得目标到潜变量梯度，通过无重网格投影更新，并用零空间投影保护局部结构。
- **Baseline** · 改进来源为 DeepSDF 潜几何及神经 PDE 代理，加入潜去噪和可微闭环。实验对照为 AEROGTO、Transolver、DeepONet、U-Net 及车辆优化的 PhysGen。
- **Benchmark** · 在二维 Helmholtz 散射、AirFoil 9k 和 DrivAerNet++ 评估相对场误差、传感器反演和形状目标。翼型用 COMSOL、车辆用 OpenFOAM 验证优化结果。
- **关键结果 / 消融** · 100 次翼型迭代在软阻力约束 C_D<0.02 下得到升阻比 83.4，初始 53.6，U-Net 75.0。车辆 fastback 阻力系数由 0.299 降到 0.278，降幅 7.02%。
- **适用条件 / 局限** · 目前限于稳态 PDE，时变动力学的形状优化未覆盖。车辆结果展示两个代表性案例，表现取决于代理和潜几何对具体形状族的覆盖。

## 1413 · Divide-and-Denoise: A Game-Theoretic Method for Fairly Composing Diffusion Models

[原文](https://proceedings.mlr.press/v306/gupta26a.html)

<a id="gupta26a-inference"></a>

**技术主题** · 多扩散模型的公平区域分工

- **问题 / 瓶颈** · 多个预训练扩散模型联合采样时可能争抢同一区域，也可能忽略其中一个条件，导致物体遗漏和属性错配。
- **核心创新 / 方法** · Divide-and-Denoise 每步以各模型的分数或注意力为区域效用，求满足比例或无嫉妒约束的分配，并对分配加时间 KL 平滑。随后用分配加权的单模型去噪提案与效用梯度更新潜变量。
- **Baseline** · 改进来源为公平分割与预训练扩散模型的采样组合。实验对照为得分平均、Composable Diffusion、Multi-Concept Diffusion、MultiDiffusion 和移除公平约束的消融。
- **Benchmark** · 用 Stable Diffusion 组合 2/3 个物体、描述及属性条件，用 DiT 验证类别组合。报告图像和提示级 GenEval、CLIP、奖励模型及 VQA，另测时间步公平约束违反率。
- **关键结果 / 消融** · Stable Diffusion 的三物体组合中，图像级 GenEval 为 59.50%±2.99%，去公平约束为 51.75%±3.08%，MultiDiffusion 为 14.00%±2.08%。
- **适用条件 / 局限** · 去噪核的闭式结果依赖特征因子化与效用线性条件，实践用局部线性近似。效用质量和每步分配优化的成本限制进一步扩展。

## 1414 · Adapting to Evolving Graphs: A Scalable Framework for Dynamic Coarsening

[原文](https://proceedings.mlr.press/v306/gupta26b.html)

<a id="gupta26b-optimization"></a>

**技术主题** · 演化图的粗化映射增量更新

- **问题 / 瓶颈** · 每次节点或边变化后从头粗化图会重复消耗大量时间与内存。需要在保留拓扑和特征的同时增量维护粗图。
- **核心创新 / 方法** · 从任意静态粗化映射初始化。DIGC 在增长时固定既有分配、优化新节点的映射，ACNR 允许重新分配部分已有节点以处理删除和边变化，并用 ε-相似性界控制粗化误差。
- **Baseline** · 改进来源为静态图粗化的映射矩阵递推。实验对照为每个时间步全量重跑 FGC、LVN 或 LHE，并比较两种增量算法。
- **Benchmark** · 在 ACM、DBLP 等离散时间演化图上测结构误差、节点分类均值与标准差、粗化计算耗时和峰值 GPU 内存，另测合成变化场景。
- **关键结果 / 消融** · FGC 初始化时，ACNR 在 ACM/DBLP 的分类准确率为 86.49±1.28%/79.93±1.13%，从头 FGC 为 86.74±1.25%/80.07±1.43%，表中保留率为 99.8%，DIGC 为 98.1%。
- **适用条件 / 局限** · DIGC 固定已有映射，对差初始化和非单调拓扑变化较敏感，长期会积累误差。ACNR 通过重分配改善恢复，但开销高于 DIGC。

## 1417 · FLIPS: Instance-Fingerprinting for LLMs via Pseudo-random Sequences

[原文](https://proceedings.mlr.press/v306/gurvan26a.html)

<a id="gurvan26a-evaluation"></a>

**技术主题** · 部署实例的伪随机指纹

- **问题 / 瓶颈** · 同一语言模型部署时改变系统提示、解码温度或量化会改变行为。为识别来源设计的指纹对这类实例参数通常不够敏感。
- **核心创新 / 方法** · FLIPS 逐一给模型两 token 伪随机生成指令，将输出映射为比特串并提取 NIST 随机性统计。用 XGBoost 学实例类别，汇总多组 token 对的预测并用置信阈值判定未知实例。
- **Baseline** · 改进来源为黑箱输出指纹和随机性检验。实验对照为适配实例识别的 LLMmap，另比较不同 token 对、验证查询数及开集阈值。
- **Benchmark** · 基准由 25 个开权重基模的温度、系统提示、量化与部分拒答改写组合出 237 实例。每实例 40 次注册查询，开集每折保留 10% 实例为未知，指标为识别准确率与未知精确率、召回率。
- **关键结果 / 消融** · 8 次验证查询后闭集准确率为 96%，开集为 90%，未知精确率/召回率为 54%/83%。适配 LLMmap 在闭集最高 35%。
- **适用条件 / 局限** · 结论针对能按请求返回序列的诚实实例。主动查询重路由可绕开检测，且有生成不足 100 比特而被重试或丢弃的情况。

## 1419 · Constrained Flow Optimization via Sequential Fine-Tuning for Molecular Design

[原文](https://proceedings.mlr.press/v306/gutjahr26a.html)

<a id="gutjahr26a-optimization"></a>

**技术主题** · 约束分子生成的顺序微调

- **问题 / 瓶颈** · 分子生成模型的奖励微调可能以违反性质约束为代价。固定惩罚权重很难提前保证满足约束并维持高收益。
- **核心创新 / 方法** · CFO 通过增广拉格朗日自适应更新乘子与惩罚，将期望成本约束转成一系列无约束、熵正则奖励微调，并可调用 Adjoint Matching 或 DiffusionNFT 作为内层求解器。
- **Baseline** · 改进来源为增广拉格朗日和现有奖励微调，并与固定惩罚权重比较。实验对照为原始 FlowMol、直接用同等更新预算的 Adjoint Matching、直接 DiffusionNFT 及固定惩罚 Pareto 扫描。
- **Benchmark** · 在合成分布与 GEOM Drugs 的 FlowMol 微调上测期望奖励和可行性。分子任务最大化偶极矩且规定期望 xTB 能量≤−80 Ha，优化用 GNN 预测性质。
- **关键结果 / 消融** · CFO 的 AM 版本以 6 轮各 10 步使偶极矩由 6.55 增至 8.39 D、能量 −82.28 Ha，直接 AM 60 步为 8.37 D、−78.31 Ha。定理 5.4 在内层误差趋零且可行时给出极限策略全局最优。
- **适用条件 / 局限** · 期望约束允许个别样本超标，能量只是稳定性代理。按严格有效性标准，分子有效率从预训练 34% 降到 CFO 的 9%，全局最优条件在实践中较难确保。

## 1421 · Front-Loaded Robust Conformal Prediction: Heavy Calibration, Minimal Test-Time Cost

[原文](https://proceedings.mlr.press/v306/h-zargarbashi26a.html)

<a id="h-zargarbashi26a-theory-statistics"></a>

**技术主题** · 前置校准的鲁棒保形预测

- **问题 / 瓶颈** · 鲁棒共形预测可在输入受到最坏扰动时控制失覆盖率，但较小预测集往往依赖部署时重复运行模型。
- **核心创新 / 方法** · FLoR 在校准阶段增加平滑蒙特卡洛采样，用 Clopper–Pearson 下界与共形风险控制选阈值，预算分为独立的调参与认证样本。FLoR(1) 测试只采一次噪声，FLoR(k) 以少量多次采样降低集合随机性。
- **Baseline** · 改进来源：随机平滑、共形风险控制与二项置信界。实验对照：单次采样的 RCP1 和校准、测试均多次采样的 BinCP。
- **Benchmark** · CIFAR-10 和 ImageNet，噪声增广 ResNet 或扩散去噪加 ViT，以不同扰动半径下的认证及攻击覆盖率、平均集合大小和采样预算评估。
- **关键结果 / 消融** · 命题3.1 在校准和测试的可交换条件及给定扰动集合下保证边缘最坏情形覆盖率至少 1−α。较大半径时 FLoR(1) 的平均预测集比 RCP1 小。
- **适用条件 / 局限** · 证明针对边缘覆盖；单次预测集仍随机。很小半径下，有限样本修正可使 RCP1 的预测集更小，校准开销也需一次性承担。
