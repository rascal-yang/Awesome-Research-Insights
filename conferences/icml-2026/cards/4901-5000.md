## 4901 · UniSVQ: 2-bit Unified Scalar-Vector Quantization

[原文](https://proceedings.mlr.press/v306/wang26lg.html)

<a id="wang26lg-inference"></a>

**技术主题** · 仿射整数格的结构化向量量化

- **问题 / 瓶颈** · 自由向量码本解码较复杂，单纯标量2bit量化误差大。
- **核心创新 / 方法** · 四维整数向量经4×4矩阵A与4维偏置B映射为码字，每权重矩阵20个浮点参数；沿用RHT/LDLQ补偿，逐块重建微调A/B；推理把A移到激活端再整数矩阵乘及偏置校正。
- **Baseline** · QuIP#的RHT/LDLQ与E8码本、SpinQuant/OSTQuant旋转标量量化、AQLM自由码本为先例；新增是允许剪切的共享仿射整数格及其可折叠计算结构。
- **Benchmark** · Qwen3-4B/8B/32B与Llama3-8B-Instruct的2bit权重量化；1024条长度2048的RedPajama序列校准。测WikiText2/C4 PPL及ARC-E/C、BoolQ、HellaSwag、PIQA、WinoGrande六项0-shot准确率，另有量化器MSE/SNR控制；单A100、batch1、生成1024 tokens测吞吐和峰值显存，三次平均。
- **关键结果 / 消融** · Qwen3-4B量化器MSE SpinQuant1.06e−3、UniSVQ7.40e−5；Qwen3-8B微调前后QA66.99→67.95，D4初始化61.00；Llama3-8B-Instruct QA67.62低于QuIP#69.72，优于SpinQuant44.48。 PDF9单A100 throughput FP16 60.38、QuIP#79.60、UniSVQ101.65 tok/s，peak显存15.72/4.13/3.87GB。
- **适用条件 / 局限** · 不是全整数流水线；A变换/校正及校准有成本；仅单A100 batch1测过吞吐，activation/KV量化未涉及，优化GEMM交互尚待验证。有限截断仿射网格不等同自由VQ；原文1/64存储比与所列20参数/码本口径不完全一致，不沿用该比。

## 4903 · ReCoG: Relational and Compact Context Graph Learning for Few-shot Molecular Property Prediction

[原文](https://proceedings.mlr.press/v306/wang26li.html)

<a id="wang26li-loss-functions"></a>

**技术主题** · 实例条件的任务标签关系监督

- **问题 / 瓶颈** · 少样本任务图只用目标标签容易忽略辅助任务之间的监督关系。
- **核心创新 / 方法** · 以样本与两任务节点的表示构造关系预测器，用已知二元标签差平方作为MSE目标；与目标分类共同训练，未知查询标签不用于辅助监督；可搭配任务条件图瓶颈。
- **Baseline** · KRGTS原作2405.15544 PDF5–6以标签为sample–task边类型、target CE及同任务两子图NT-Xent；GS-Meta沿episode对比，Pin-Tuning已有context graph。新增是逐样本两任务标签XOR的三元辅助MSE，图IB为成熟构件。 最近KRGTS的标签用于sample-task边类型与目标CE，另有任务/子图NT-Xent；本项新增限同一样本两任务标签差平方的三元监督，不将上下文图或信息瓶颈称为新机制。
- **Benchmark** · Tox21/SIDER/MUV/ToxCast/PCBA的预训练图少样本分类，1-shot及10-shot，ROC-AUC%；Tox21/SIDER单独移除关系损失与瓶颈。
- **关键结果 / 消融** · Tox21 1-shot完整91.01±2.03、去关系损失88.18±1.04；SIDER 1-shot90.06±1.17→87.57±0.86；两个模块全去则86.91与86.93。
- **适用条件 / 局限** · 验证仅上述任务图；辅助任务需可用标签，迁移其他任务关系尚未验证。信息瓶颈式19丢弃项是工作近似，不能称精确条件互信息最优或不变性保证。

## 4904 · Learning High-Frequency Continuous Action Chunks in Latent Space

[原文](https://proceedings.mlr.press/v306/wang26lj.html)

<a id="wang26lj-inference"></a>

**技术主题** · 动作空间拼块后重编码细化

- **问题 / 瓶颈** · 高频latent策略独立解码相邻动作块，异步切换仍会回退和突跳。
- **核心创新 / 方法** · 时间对齐后重用最近实际执行动作前缀，拼接新预测有效后缀，通过预训练动作VAE的encoder-decoder整段重建，再提交未来动作；保留连续低维latent预测。
- **Baseline** · ACT/latent动作先验、DP/OFT/pi0.5为先例；RTC（2506.07339，§4）已有异步执行前缀固定、overlap soft-mask梯度引导。新增仅生成后action空间拼接→VAE重编码解码RTR，非异步/重叠/latent chunk本身。
- **Benchmark** · 60Hz真实接触操作：擦花瓶、白板书写及削皮任务；DP/OFT/pi0.5同步/异步，成功率、jerk、速度超阈次数；示范相邻块Overlap Diff与Boundary Gap。
- **关键结果 / 消融** · pi0.5白板异步Latent→Latent+RTR jerk3.904→1.754，成功100%均不变；重叠位置差1.778→0.331mm，边界6.842→4.069mm；latent+RT-C边界8.478mm反退。DP整任务书写耗时19.09→15.11秒。
- **适用条件 / 局限** · 重建可能改变已执行前缀，不能保证严格连续或硬约束安全；速度超阈为经验指标。约2ms重建有时延，依赖足够重叠与VAE重建质量；整体latent+RTR与原策略比较不能全部归于RTR。 RT-C控制限所测PI0.5配置，不能据此推断所有latent inpainting均退化。

## 4910 · Optimization, Generalization and Differential Privacy Bounds for Gradient Descent on Kolmogorov–Arnold Networks

[原文](https://proceedings.mlr.press/v306/wang26lp.html)

<a id="wang26lp-theory-statistics"></a>

**技术主题** · 私有KAN的宽度与训练时长联选

- **问题 / 瓶颈** · 私有KAN训练仅按非私有过参数化直觉加宽，可能增加噪声代价。
- **核心创新 / 方法** · 对固定基函数数p、受界输入及光滑有界基函数的两层KAN，投影参数到初始化中心R1/R2球；分别向mdp和mp维参数梯度加Gaussian噪声，投影与基函数界控制敏感度，无逐例梯度裁剪；分析自由R,m下宽度相关噪声与时长的权衡。
- **Baseline** · Gao/Tan2025已有KAN NTK回归收敛，Nitanda/Taheri等已有可分神经网络GD分析，标准Gaussian DP-GD为先例；新增为此KAN参数化的私有宽度/时长可行界及控制，非全新GD。
- **Benchmark** · Synthetic logistic：d10、20K训练/8K测试，50 seeds；MNIST0/1二分类，20 seeds；ε2、δ1/n，扫宽度与全批迭代数，test accuracy/private utility；定理NTK marginγ与固定p。
- **关键结果 / 消融** · 图2 MNIST私有效用约m8、T64后转降；非私有加宽后趋平台。自由R,m条件界含mηTd/(n²ε²)噪声项，说明取宽度/时长需同时考虑噪声；经验拐点不能由risk上界自动推出，也不能取作统一阈值。
- **适用条件 / 局限** · 仅两层、有界光滑、固定p、局部参考点/宽度/步长条件；参数噪声实际维度mp(d+1)，d是输入维度。理论是迭代平均risk，图2评末迭代；所谓必要宽度非KAN minimax下界。附录E15的R≈sqrt(log n)/γ与所引τ≈logT/γ不一致，故不沿用精确polylog宽度/最优率承诺。

## 4914 · NaRA: Noise-Aware LoRA for Parameter-Efficient Fine-Tuning of Diffusion LLMs

[原文](https://proceedings.mlr.press/v306/wang26lt.html)

<a id="wang26lt-modules"></a>

**技术主题** · 跨层共享噪声条件低秩核心

- **问题 / 瓶颈** · 掩码扩散LLM的各噪声阶段输入难度不同，静态权重更新可能难兼顾。
- **核心创新 / 方法** · 每模块ΔWλ=B Cλ A，Cλ=I+ηMLP(Fourier(λ))；A/B各模块独立、核心网络全局共享；零初始化超网络输出与B，保留LoRA初始行为。
- **Baseline** · Terra2024已有B K(t) A连续核心，用t表示域/任务插值；本篇改为扩散噪声、全局共享非线性超网络并测试共享粒度，非首个时变LoRA；实比LoRA、HiRA、四区间MultiLoRA与r40 LoRA。
- **Benchmark** · LLaDA8B Base/Instruct，Commonsense170k、Math14k、CodeFeedback；8常识/4数学/HumanEval-MBPP；同r32、3次NaRA运行；附录r40预算控制。
