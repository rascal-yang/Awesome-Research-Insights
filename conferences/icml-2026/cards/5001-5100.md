## 5001 · Query Circuits: Explaining How Language Models Answer User Prompts

[原文](https://proceedings.mlr.press/v306/wu26a.html)

<a id="wu26a-evaluation"></a>

**技术主题** · 用改写候选搜索单题电路

- **问题 / 瓶颈** · 跨题平均稳定的能力电路打分在单题会受梯度噪声与边组合影响；传统归一faithfulness还奖励过冲。
- **核心创新 / 方法** · BoN对原题及p个改写分别作EAP-IG、各取N条边，按原题上的NDF择优。NDF=1−min(模型/电路输出差绝对值除原题/污染题模型差绝对值,1)；可缓存多预算电路插值或分层排序。
- **Baseline** · EAP-IG、activation patching及MIB的circuit-model distance已有；新增候选改写电路搜索与对称截断指标。对照single-query与改写分数先平均；最邻近电路搜索原作待查。
- **Benchmark** · IOI用GPT2-small，算术加/乘、ARC-Challenge与9类MMLU用Llama3.2-1B-Instruct；EAP-IG m20、9改写，边预算与逐题平均NDF。IOI所谓改写是随机另取同任务题，非严格同义。
- **关键结果 / 消融** · MMLU约5k边（1.3%）可达平均NDF .6，single-query约200k；这是归一输出差指标，不是60%答题准确率或60%完整因果机制。改写分数平均并未优于single-query。
- **适用条件 / 局限** · 在同一原题输出指标上选优会偏向该标量，不能证明机制唯一/因果完整；分母近0仍需数值处理且未在已读页核实。成本含改写生成、10组边评分及每N最多10次电路forward，非无额外计算。

## 5002 · Optimal Stopping in Latent Diffusion Models

[原文](https://proceedings.mlr.press/v306/wu26b.html)

<a id="wu26b-theory-statistics"></a>

**技术主题** · 联合选择潜维度与停止时刻

- **问题 / 瓶颈** · 更低AE重建误差不直接决定某停止时刻下的生成分布误差。
- **核心创新 / 方法** · 在线性投影/高斯VP-SDE中写出解码协方差，比较目标W2²/Fréchet距离；推导估计方差下非单调条件和最优维度时间区间。另以受限线性score系数C分析维度阈值，并测试带噪AE作为比较不同latent的代理。
- **Baseline** · 已有数值稳定性early-stop与AE/LDM研究；候选增量是潜维度×停止时刻及score容量条件下的显式决策。最近理论原作未追溯。
- **Benchmark** · 高斯/低秩合成、exact-score GMM，MNIST线性AE潜64/256/400配U-Net，ImageNet256非线性AE+LDM总500M参数匹配；FID、sliced Wasserstein、MMD与带噪AE轨迹。
- **关键结果 / 消融** · Prop4.1：trueΣ的高斯过程距离随反向时间不增；plug-in估计Σ满足指定符号和条件时可非单调。Prop5.3指数谱λ>16时容量C对应最佳维度落在阈值d或d+1。GMM及实图曲线给经验支持，数值最佳点待核。
- **适用条件 / 局限** · 高斯精确score不能支持“降维必使最后几步恶化”；非线性AE代理只是经验排序，不是无需训练LDM的性能保证。ImageNet曲线、超参公平及全附录尚未统一核查。

## 5013 · VLANeXt: Recipes for Building Strong VLA Models

[原文](https://proceedings.mlr.press/v306/wu26m.html)

<a id="wu26m-training-strategies"></a>

**技术主题** · VLA的本体感知路由与频域动作监督

- **问题 / 瓶颈** · 强VLA配方混合架构、感知及训练成本，整套系统分数难定位设计收益。
- **核心创新 / 方法** · 比较本体感知接入VLM或策略头；DCT动作回归提高低频项权重，以较小附加成本替代辅助未来图像预测。
- **Baseline** · RT-2/OpenVLA式动作token基线；MetaQuery、独立策略头、紧耦合策略及未来图像辅助头均属比较对象，组件来源与最近配方尚待统一核查。
- **Benchmark** · LIBERO及LIBERO-plus；主要配方在Spatial探索，统一10000步、batch256，成功率；Franka/Aloha真实任务为补充。
- **关键结果 / 消融** · 缓存报告VLM侧本体感知较好，策略侧可能不如不输入；未来图像辅助训练接近三倍耗时，DCT略优且附加开销小。最终LIBERO均值97.4%，不能归因于单个组件。
- **适用条件 / 局限** · 统一步数不等于统一FLOPs；本体感知位置和DCT的逐项数值、跨任务控制待核实，最终配方并非所有组件均新。

## 5015 · EasyBalance: Cross-Layer Load Balancing in Distributed MoE Inference

[原文](https://proceedings.mlr.press/v306/wu26o.html)

<a id="wu26o-inference"></a>

**技术主题** · 跨层微批次MoE调度

- **问题 / 瓶颈** · 专家并行推理中单层路由不均会令部分设备等待。
- **核心创新 / 方法** · 在多个独立微批次之间跨层选择待执行工作；CumUtil按利用率增益加入，DiffPeak按新增峰值设备选择，避免枚举全部子集。
- **Baseline** · 与常规逐层调度及EPLB专家放置比较；专家放置与跨层排程可叠加，最近流水线调度先例待核实。
- **Benchmark** · LongBench共13任务；Qwen3与Moonlight MoE，多种专家并行度/批量；利用率、调度耗时及端到端时间。
- **关键结果 / 消融** · Qwen3-30B、2WikiMQA、batch128：MaxUtil/CumUtil/DiffPeak调度约0.277/0.267/0.130ms，端到端8.21/8.27/8.24s；调度更快不等于整体大幅更快。
- **适用条件 / 局限** · 依赖可并行微批次及缓存资源；保持每条序列层顺序，不是跨层替换专家权重。显存与低延迟场景代价待核实。

## 5017 · SGMD: Score Gradient Matching Distillation for Few-Step Video Diffusion Distillation

[原文](https://proceedings.mlr.press/v306/wu26q.html)

<a id="wu26q-loss-functions"></a>

**技术主题** · 假分数残差的反向目标

- **问题 / 瓶颈** · 少步视频蒸馏中假分数跟踪和教师输入梯度可能限制稳定性。
- **核心创新 / 方法** · 生成器使用教师停止输入梯度的分数差平方项，并减去加权假网络重建残差平方；假网络仍最小化该残差，交替更新。
- **Baseline** · DMD2、SIM及停止教师梯度的Fisher/SIM变体；新增候选是残差的相反符号目标，而非首次使用假分数网络。
- **Benchmark** · Wan2.1-T2V-14B蒸馏至4步；20万私有提示、480×832、81帧，32张H100；VBench质量/语义/动态、FVD及光流。
- **关键结果 / 消融** · 缓存表中DMD2、假更新比5时FVD115.1/语义77.46，SGMD、比1时100.3/75.64；动态80.56→93.06，质量85.05→84.77，不能称所有指标提高或该比较预算完全相同。
- **适用条件 / 局限** · 反向KL解释依赖理想跟踪等条件，残差梯度方向依赖局部Jacobian近似；假更新比、计算量及最近蒸馏目标需统一核实。

## 5033 · Diversity-Preserved Distribution Matching Distillation for Fast Visual Synthesis

[原文](https://proceedings.mlr.press/v306/wu26ag.html)

<a id="wu26ag-loss-functions"></a>

**技术主题** · 首步监督与后续分布蒸馏

- **问题 / 瓶颈** · 少步DMD可能把不同初始噪声映到较窄生成模式。
- **核心创新 / 方法** · 教师由同噪声运行若干步，构造首步速度回归目标；后N−1步用标准DMD，首步状态stop-gradient；共享学生参数仍同时接受两种损失更新。
- **Baseline** · DMD/DMD2、轨迹蒸馏和早晚去噪分工为来源；实际同预算比较DMD、DMD-LPIPS、DMD-GAN，另比Hyper-SD、Flash、TDM但后者训练配置不严格匹配。最近原作与重复性待核实。
- **Benchmark** · SD3.5-M/SDXL，1024²，DiffusionDB提示6000迭代、8A800；Pick-a-Pic/COCO10K2014每提示9seed，4NFE；DINO/CLIP条件内多样性、VQ-R1/MANIQA、ImageReward/PickScore。
- **关键结果 / 消融** · SD3.5-M Pick-a-Pic DINO多样性.137→.179，CLIP.133→.182，VQ4.649→4.646基本持平，但ImageReward1.189→1.142下降。SDXL Pick-a-Pic VQ4.667→4.591下降。首步不截梯度的曲线更易丢多样性，精确差值待核实。
- **适用条件 / 局限** · 特征多样性不等于真实模式覆盖，质量/偏好不全面占优；没有存储教师完整图并不等于没有教师在线rollout成本。首步截图不意味着共享参数完全角色独立；教师anchor/权重仍需选择。

## 5034 · Large Language Models Develop Novel Social Biases Through Adaptive Exploration

[原文](https://proceedings.mlr.press/v306/wu26ah.html)

**技术主题** · 序贯探索产生新分配偏差

- **核心创新 / 方法** · 在四人工群体、同成功率的contextual-bandit式分配中跟踪群体分配熵、群间JSD及跨run随机性；比较CoT、温度、压缩历史、成功率和显式多样性目标干预。

- **Benchmark** · 20种工作、四类别、40轮、成功率各.9；每模型/提示30run，打乱工作顺序；GPT/Claude/Gemini/Llama/Qwen及推理模型；SI、BGD、GASI，含额外分配场景。

## 5035 · Native Parallel Reasoner: Reasoning in Parallelism via Self-Distilled Reinforcement Learning

[原文](https://proceedings.mlr.press/v306/wu26ai.html)

<a id="wu26ai-reinforcement-learning"></a>

**技术主题** · 保持分支语义的并行轨迹训练

- **问题 / 瓶颈** · 串行监督或仅文本格式检查可能无法稳定产生真正独立执行的推理分支。
- **核心创新 / 方法** · 先格式奖励RL、自生成正确格式轨迹拒绝采样，再用继承Multiverse的mask/位置编码SFT；并行engine rollout后按batch尺度归一化优势，去importance reweighting/clip-masking以保留控制标记梯度。
- **Baseline** · Multiverse提供并行schema、attention和引擎，DAPO/Lite-PPO等提供已有训练部件；新增暂定为图语义一致的on-policy训练选择与工程控制。实际比MV4B/32B、同基模SR-BETA/SR；先例优先权待核实。
- **Benchmark** · Qwen3-4B及4B-Instruct2507，固定ORZ8k贯穿三阶段，最大3万token；AIME24/25、HMMT25、AMC23报告avg@8，另四任务avg@1；avg@k为样本正确率而非pass@k。

- **Benchmark** · LongCat13B 480p5秒约38k token、HYWorldPlay8B；INT2/4 KV，PSNR/SSIM/LPIPS相对BF16、VBench分项、KV压缩比。
- **关键结果 / 消融** · LongCat INT2 QVG KV6.94倍压缩、PSNR28.716/LPIPS.065，对RTN PSNR20.872；Pro4.97倍、PSNR30.376。主体一致性94.11仍低BF16 95.51；INT4并非所有分项优于RTN。
- **适用条件 / 局限** · 压缩倍数只针对KV，不是总显存；聚类、多级中心与索引有额外成本。质量相对BF16偏差不等于真实视频分布保真，完整延迟/控制待核实。
