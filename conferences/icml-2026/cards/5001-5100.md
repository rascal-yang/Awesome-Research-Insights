## 5001 · Query Circuits: Explaining How Language Models Answer User Prompts

[原文](https://proceedings.mlr.press/v306/wu26a.html)

<a id="wu26a-evaluation"></a>

**技术主题** · 用改写候选搜索单题电路

- **问题 / 瓶颈** · 跨题平均稳定的能力电路打分在单题会受梯度噪声与边组合影响；传统归一faithfulness还奖励过冲。
- **核心创新 / 方法** · BoN对原题及p个改写分别作EAP-IG、各取N条边，按原题上的NDF择优。NDF=1−min(模型/电路输出差绝对值除原题/污染题模型差绝对值,1)；可缓存多预算电路插值或分层排序。
- **Baseline** · EAP-IG、activation patching及MIB的circuit-model distance已有；新增候选改写电路搜索与对称截断指标。对照single-query与改写分数先平均；最邻近电路搜索原作待查。
- **Benchmark** · IOI用GPT2-small，算术加/乘、ARC-Challenge与9类MMLU用Llama3.2-1B-Instruct；EAP-IG m20、9改写，边预算与逐题平均NDF。IOI所谓改写是随机另取同任务题，非严格同义。
- **关键结果 / 消融** · MMLU约5k边（1.3%）可达平均NDF .6，single-query约200k；这是归一输出差指标，不是60%答题准确率或60%完整因果机制。改写分数平均并未优于single-query。
- **适用条件 / 局限** · 在同一原题输出指标上选优会偏向该标量，不能证明机制唯一/因果完整；分母近0仍需数值处理且未在已读页核实。成本含改写生成、10组边评分及每N最多10次电路forward，非无额外计算。

## 5002 · Optimal Stopping in Latent Diffusion Models

[原文](https://proceedings.mlr.press/v306/wu26b.html)

<a id="wu26b-theory-statistics"></a>

**技术主题** · 联合选择潜维度与停止时刻

- **问题 / 瓶颈** · 更低AE重建误差不直接决定某停止时刻下的生成分布误差。
- **核心创新 / 方法** · 在线性投影/高斯VP-SDE中写出解码协方差，比较目标W2²/Fréchet距离；推导估计方差下非单调条件和最优维度时间区间。另以受限线性score系数C分析维度阈值，并测试带噪AE作为比较不同latent的代理。
- **Baseline** · 已有数值稳定性early-stop与AE/LDM研究；候选增量是潜维度×停止时刻及score容量条件下的显式决策。最近理论原作未追溯。
- **Benchmark** · 高斯/低秩合成、exact-score GMM，MNIST线性AE潜64/256/400配U-Net，ImageNet256非线性AE+LDM总500M参数匹配；FID、sliced Wasserstein、MMD与带噪AE轨迹。
- **关键结果 / 消融** · Prop4.1：trueΣ的高斯过程距离随反向时间不增；plug-in估计Σ满足指定符号和条件时可非单调。Prop5.3指数谱λ>16时容量C对应最佳维度落在阈值d或d+1。GMM及实图曲线给经验支持，数值最佳点待核。
- **适用条件 / 局限** · 高斯精确score不能支持“降维必使最后几步恶化”；非线性AE代理只是经验排序，不是无需训练LDM的性能保证。ImageNet曲线、超参公平及全附录尚未统一核查。

## 5003 · Diffusion Models Are Statistically Optimal for Learning Low-Dimensional Multi-Modal Distributions

[原文](https://proceedings.mlr.press/v306/wu26c.html)

<a id="wu26c-theory-statistics"></a>

**技术主题** · 子空间混合score的条件样本率

- **问题 / 瓶颈** · ambient维度的核score估计率忽略数据实际落在低维多模态子空间。
- **核心创新 / 方法** · 分样本做子空间恢复与score估计；每簇用Gaussian KDE比值、低密度门控和范数clip估计切向score，法向用−(x−Projx)/t；再按平滑混合密度比组合，供连续OU反向SDE使用。
- **Baseline** · 单子空间法向/切向分解、核score与子空间聚类已有；候选增量是在无score光滑假设的多子空间下给近最优W1样本率。相邻理论原作未精读。
- **Benchmark** · 纯理论无噪声union of M linear subspaces，最大维k、每簇质量下界、簇内subgaussian；核估计score L2误差及连续SDE期望W1误差，无神经训练benchmark。
- **关键结果 / 消融** · 在exact recovery事件下给W1误差≤C·d·M^(3/2)·n^(−1/(k∨2))polylog n；指数依k，前因子仍含ambient d及M。不是训练迭代/离散采样复杂度保证。
- **适用条件 / 局限** · 附录19的(31b)把任意真子空间质量为0当作Assumption1结论，但原假设仅排给定不同子空间交集，需另核非集中/一般位置条件。Alg2枚举组合非一般多项式；最稳妥仅采用条件于exact recovery的率。

## 5004 · Single-Rollout Hidden-State Dynamics for Training-Free RLVR Data Selection

[原文](https://proceedings.mlr.press/v306/wu26d.html)

<a id="wu26d-data-strategies"></a>

**技术主题** · 单轨迹首尾状态差筛样

- **问题 / 瓶颈** · 无标签候选池无法便宜地获取RL训练准确率方差等选择信号。
- **核心创新 / 方法** · 各层平均think起止hidden states，Δ=end−start，quality=log(1+||Δ||)；归一[start;Δ]作覆盖特征，首取最高quality，再取quality×到已有集合最小距离最大者。
- **Baseline** · CoreSet/quality-diversity与hidden-state delta已有，CLUE原作已缓存未精读；候选增量是将差范数作为单轨迹RLVR效用信号并提供分离消融，最近相关选择先例仍待查。
- **Benchmark** · Qwen2.5-Math1.5B，MATH500取350池/150测试，预算7/14题，另AMC Pass@1；Qwen3-1.7B的QA任务用于通用筛样消融，本文不涉及回答内容。
- **关键结果 / 消融** · 7题时MATH测试62.67%/AMC38.55%，Random53.73%/25.78%；14题AMC36.14%低于Cluster40.96%。单例RLVR的top5/bottom5十题pilot rank与增益ρ=.818，选择极值样本的相关不代表全池。
- **适用条件 / 局限** · 需全候选池各跑一条CoT且读取全部层，label-free仅选择阶段，训练仍需可验证奖励。固定位置block的权重更新上界不是RIRS效用保证；模型/模板依赖与RL运行预算细节待核。

## 5005 · Improved Scaling Laws via Weak-to-Strong Generalization in Random Feature Ridge Regression

<a id="wu26e-theory-statistics"></a>

**技术主题** · 随机特征蒸馏的谱预测

- **问题 / 瓶颈** · teacher误差的总量未区分学生能滤除的方向及可继承的目标方向。
- **核心创新 / 方法** · teacher用带噪真标签RFRR，student在独立新输入上拟合teacher无额外噪声伪标签，随机特征独立重抽；以population特征谱、目标系数、样本数/宽度/λ求有效ridge固定点，代入学生test-error确定性等价式。
- **Baseline** · Defilippis2024已有单模型RFRR确定性等价；此处候选增量是teacher→student误差传播的dimension-free表达。最近weak-to-strong理论及条件范围尚待精读。
- **Benchmark** · L2随机特征ridge回归理论；teacher(nt,pt,λt)与student(ns,ps,λs)，同输入分布、fresh student输入；excess squared test error，实验具体设置待核实。
- **关键结果 / 消融** · 已读PDF5 Eq14把student误差分为teacher目标偏差项与teacher标签噪声经student滤波后的项。作者称某些谱条件可改善scaling exponent甚至teacher不衰减时student达minimax；具体指数/区间尚待核实，暂不写作已证实结论。
- **适用条件 / 局限** · 需特征本征函数二次型集中、有效正则及独立抽样；population谱与目标投影实际未必已知。不能推广到共享训练输入、任意深网络全参更新或无条件越强越好；非渐近误差余项需继续核实。

## 5010 · Multi-scale Explainer for Graph Neural Networks

[原文](https://proceedings.mlr.press/v306/wu26j.html)

<a id="wu26j-loss-functions"></a>

**技术主题** · 跨稀疏率监督解释边

- **问题 / 瓶颈** · 单尺度子图优化可能初始化敏感，无法同时表达粗细不同的证据。
- **核心创新 / 方法** · GCN+MLP产生共享边score；各scale取top-ratio关键子图和补图。若关键图argmax保持原预测，其所含边以+1为目标，否则−1；跨scale平均L1，再用关键/补图与原输出相似度的对比目标。训练用soft mask，推理hard TopK。
- **Baseline** · PGExplainer已有共享参数边mask，保留/补图与contrastive解释亦已有；候选增量为跨保留率的统一预测一致性边监督。最近multi-scale解释先例尚未查。
- **Benchmark** · 图分类GNN的post-hoc explanation，六项benchmark的名称、GNN训练和ground-truth motif设置待核实；目标为解释accuracy/fidelity及稳定性。
- **关键结果 / 消融** · 已读Eq16–18仅给固定scale数M时同阶复杂度，不能称相同运行时间。摘要报告解释效果提升，数值表和稳定性消融待核实，暂不填猜测结果。

## 5011 · HumanLM: Simulating Users with State Alignment Beats Response Imitation

[原文](https://proceedings.mlr.press/v306/wu26k.html)

<a id="wu26k-reinforcement-learning"></a>

**技术主题** · 先对齐显式状态再合成响应

- **问题 / 瓶颈** · 只模仿响应措辞可能遗漏立场或沟通方式，整响应奖励混合多个属性。
- **核心创新 / 方法** · HumanLM规定belief/goal/emotion/value/stance/communication维度，每batch随机一个维度，生成多个自然语言状态并由同批比较式judge按真实响应打分；再用状态生成最终响应。完整RL目标与两阶段连接待核实。
- **Baseline** · UserLM/响应SFT、persona RL与状态prompting已有；候选新增为状态维度分开对齐与比较式奖励后合成。最近状态监督/用户模拟原作尚未核查。
- **Benchmark** · Humanual六领域：News、Book、Opinion、Politics、Email、Chat，LLM judge alignment；另37参与者即时响应模拟研究。训练/测试用户划分、规模与judge协议待核实，摘要与正文规模表述不一。
- **关键结果 / 消融** · 已读正文PDF3报告overall similarity win rate41.4%，55.9%响应获mostly similar/nearly identical对最佳基线45.0%；76.6%获quite natural以上。摘要平均相对alignment+16.3%尚待逐表核实。
- **适用条件 / 局限** · 状态标签来自响应推断，不是真实隐状态因果观测；受judging偏差与用户历史泄漏影响，单题一个ground truth不覆盖人类响应分布。与直接响应RL等预算控制、合成模块和用户研究统计待核。
