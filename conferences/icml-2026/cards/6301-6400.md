## 6303 · Phase-Type Variational Autoencoders for Heavy-Tailed Data

[原文](https://proceedings.mlr.press/v306/ziani26a.html)

<a id="ziani26a-architecture"></a>

**技术主题** · latent条件Phase-Type decoder的有限尾部拟合

- **问题 / 瓶颈** · 固定Gaussian/单一parametric tail难兼顾主体与极值，decoder均值采样又掩盖随机尾部。
- **核心创新 / 方法** · decoder输出初始prob softmax与递增softplus累计rates，series acyclic subgenerator；density=α exp(Ax)(−A1)，uniformization算likelihood，标准βELBO，跨维依shared z。
- **Baseline** · PH/CTMC吸收时间、canonical form和VAE为来源；实际Gaussian/t/xVAE及LogNormal/Gamma decoders，matched架构/optimization、phase/β控制。暂定增量是可训PH条件likelihood接口，最近原作待核。
- **Benchmark** · 10K synthetic Weibull/Pareto/LogNormal/Burr，real DanishFire/wordfreq、multivariate/financial；conditional tailKS above95%、Q99 relative error、CVaR/quantile error与tail co-exceedance。
- **关键结果 / 消融** · Pareto tailKS .051对Gaussian .259，Q99 .023对.336；但Burr Q99 .599劣Gamma .166/LogNormal .379，不能称所有tail metrics最优。Danish q.995 CVaR error .192对Gaussian .854仍非零。
- **适用条件 / 局限** · 每个有限PH conditional是轻尾，shared latent混合可能更丰富但不自动有正确渐近正则变化；结论限观测范围。正值support与transform需匹配，matrix exp/截断precision、极端rate和phase数优化不稳；全混合tail dependence非仅conditional独立即可保证。

## 6304 · Affine-Equivariant Kernel Space Encoding for NeRF Editing

[原文](https://proceedings.mlr.press/v306/zielinski26a.html)

<a id="zielinski26a-representation-learning"></a>

**技术主题** · Mahalanobis核邻域的可编辑feature场

- **问题 / 瓶颈** · Euclidean KNN在形变后换邻居会产生feature不连续，hashgrid较难局部操纵。
- **核心创新 / 方法** · anisotropic Gaussian核加权feature，RT-GPS对confidence ellipsoid作ray-based候选和topK Mahalanobis选择；联合优化hashgrid/centers后缓存中心feature，edit更新mean/cov、以局部axes还原viewdirection。
- **Baseline** · Gaussian RBF/Mahalanobis invariance、RT-kNNS、Point-NeRF/Neuraleditor/LagHash为来源；实际上述及GaMeS/SuGaR/INGP，邻域和蒸馏组件。暂定增量是kernel search与grid-free部署接口，先例待核。
- **Benchmark** · NeRF-Synthetic8scenes、MipNeRF3609scenes，posedimages训练，PSNR/static fidelity、deformation可视化与neighbor选择；训练/渲染time和硬件完整设置待核。
- **关键结果 / 消融** · Synthetic Lego EKS35.59对PointNeRF35.04，但Ficus33.82低36.13；Mip360Bicycle22.93低GaMeS24.99，Room30.60低31.52，编辑性有fidelity代价。未把编辑可视化当物理准确度。
- **适用条件 / 局限** · Mahalanobis不变需query/所有kernels同可逆affine及covariance一致变换，单独不同局部变形无同一全局保证；完整radianceMLP非自动affine-equivariant。icosahedra近似/固定topK边界仍可能换邻居，hashgrid联合sampling不等固定teacher蒸馏，内存/搜索成本待核。

## 6305 · Can local learning match self-supervised backpropagation?

[原文](https://proceedings.mlr.press/v306/zihan26a.html)

<a id="zihan26a-optimization"></a>

**技术主题** · 以末层反馈与空间依赖逼近局部SSL梯度

- **问题 / 瓶颈** · 层间reference不一致与空间共享反馈限制local loss传递全局信息。
- **核心创新 / 方法** · 线性网络条件证明局部contrastive loss梯度等BP；shrinking widths改用末层reference DFB，convnet反馈矩阵加入2D位置依赖，形成CLAPP++/DFB/both variants，反馈以局部loss学习。
- **Baseline** · ForwardForward/CLAPP、directfeedbackalignment和CPC/InfoNCE为来源；实际sameVGG BP-CLAPP++/InfoNCE、去spatial/DFB，理想BP-gradient拟合仅分析upper comparator。暂定增量是空间反馈参数化和条件等价诊断，最近原作待核。

- **关键结果 / 消融** · CIFAR both81.18对BPCLAPP80.49；STL both79.62低80.36，ImageNet DFB44.16低BPCLAPP48.52/BPInfoNCE55.19。去空间CLAPP38.31→spatial42.55 ImageNet，有独立组件作用但非全尺度match。
- **适用条件 / 局限** · 严格条件需square orthonormal W及最优B/时间尺度分离，ReLU/normalization/一般conv破等价。理想Δ°训练本身用BP不是部署local规则；DFB有跨层通信，2D反馈可能高成本，生物locality与硬件优势未认证。

## 6307 · Learning Normalized Energy Models for Linear Inverse Problems

[原文](https://proceedings.mlr.press/v306/zilberstein26b.html)

<a id="zilberstein26b-loss-functions"></a>

**技术主题** · covariance score约束的跨退化能量归一

- **问题 / 瓶颈** · 普通score只给空间梯度，任意随covariance变化的energy常数妨碍跨观测比较。
- **核心创新 / 方法** · generalized anisotropic DSM外加Σ梯度匹配CSM，以矩残差监督并两侧Σ^1/2加权；UNet用spatial/spectral covariance branches，highnoise Gaussian边界校准energy，支持posterior sampling/MH和operator估计。
- **Baseline** · Tweedie、dual/time score normalization(Guth/Yu/Plainer)、DPS/DAPS/RED-Diff为来源；实际上述及Palette，covariance loss组件与adaptive sampler。暂定增量为matrix-covariance score及跨退化对齐，最近原作待核。
- **Benchmark** · CelebA/ImageNet64 inpaint/Gaussian deblur、AFHQ，PSNR/LPIPS/FID/DISTS；MNIST随机pixel观测分类与adaptive sampling，spatial mask/spectral blur等训练退化。
- **关键结果 / 消融** · ImageNet inpaint FID47.54对DAPS54.07但PSNR22.90低23.87；CelebA deblur PSNR32.27低DPS32.98而LPIPS.002优.004，存在perceptual/distortion取舍。
- **适用条件 / 局限** · H⁻¹转colored-noise只对可逆operator直接成立，inpainting/superres需极限/广义逆处理；finite covariance/training range与数值energy误差使normalized posterior仅近似。MH至多纠正到学习目标而非真实posterior，证据自评不能独立认证校准；CSM高阶autodiff和采样成本待核。

## 6308 · PAC-Bayesian Reinforcement Learning Trains Generalizable Policies

[原文](https://proceedings.mlr.press/v306/zitouni26a.html)

<a id="zitouni26a-loss-functions"></a>

**技术主题** · mixing与参数KL驱动的posterior RL正则

- **问题 / 瓶颈** · RL轨迹依赖破IID证书，确定点policy难直接利用PACBayes参数posterior。
- **核心创新 / 方法** · Gaussian参数posterior与prior KL，Markov dependent concentration引入τmix；以√x的λ变分式交替调正则和posterior，policy级REINFORCE fresh-rollout估梯度，结合SAC critic与adaptive sampling。
- **Baseline** · PACBayes change-of-measure/Paulin Markov concentration、PACBayesλ与SAC/PBAC为来源；实际SAC/PBAC及prior/posterior sampling/mixing组件。暂定增量是Markov复杂度进入posterior探索接口，完整证明及先例待核。
- **Benchmark** · MuJoCo HalfCheetah/Ant/Hopper/Walker v5 continuous control，约1Msteps rolloutreturn，empirical discounted return与作者bound曲线；dense/sparse reward协议分开，统计种子/点值待核。
- **关键结果 / 消融** · 缓存曲线报告competitive SAC，HalfCheetah约100ksteps后计算lowerbound变informative；没有补猜图中return数。作者也指出posterior更新会 destabilize critic，adaptive sampling减轻，不能称无代价证书。
- **适用条件 / 局限** · weighted reward有界、data-independent/合法处理prior、正确mixing上界是理论条件；clip对非负return可给保守loss但改target，负reward需另处理。reward/state自相关不证明全chain总变差mixing上界；动态moving prior与adaptive数据、trajectory权重随transition变化的bounded difference需核，暂不认证formal performance guarantee。

## 6309 · One-Step Gradient Delay is Not a Barrier for Large-Scale Asynchronous Pipeline Parallel LLM Pretraining

[原文](https://proceedings.mlr.press/v306/zmushko26a.html)

**技术主题** · 一拍延迟的update级外推纠正

- **问题 / 瓶颈** · AdamW在一拍stale下易掉loss，schedule/Taylor gradient补偿并非稳定修复。
- **核心创新 / 方法** · 沿用PipeDream2BW恒定一拍，比较optimizer及momentum；x_next=x−2u_prev+u_prevprev，u是完整optimizer update非rawgradient。理论另对delayed LMO/Muon给条件error bound。
- **Baseline** · PipeDream2BW、error-feedback/extrapolation与DCASGD为来源；实际10optimizers、syncstart/cooldown、Taylor、EF以及135/360M至10B规模。暂定增量是update差补偿与optimizer条件失败经验，最近先例待核。

- **关键结果 / 消融** · 360M AdamW sync2.612→delay2.890→EF2.640，Muon2.578→2.590→2.583；但Adan2.651delay→2.653EF、NAdam2.694→2.703变坏。EF非全optimizer有效。
- **适用条件 / 局限** · 一拍delay与sync模拟实验不等实cluster无通信瓶颈；变delay/pipeline depth需另证。理论smooth/noise/decay条件不认证神经非凸到globaloptimum，外推可放大噪声且多存model-sized buffer；Muon理论与实际数值NS近似、全部tokens/hardware吞吐匹配待核。

## 6311 · Conflict-Aware Adaptive Alignment for LLM Hallucination Mitigation

[原文](https://proceedings.mlr.press/v306/zong26a.html)

<a id="zong26a-loss-functions"></a>

**技术主题** · 真诚与有用冲突的pair自适应DPO margin

- **问题 / 瓶颈** · 统一truth优化可能拒答过多，统一加权又忽略仅部分pair冲突。
- **核心创新 / 方法** · DPO logit减α∆；help差≥0取∆truth，否则取max(∆truth+λ∆help,0)。margin非负，冲突严重时回标准truth-pair DPO，非逆转truth排序；按pair评分调强弱。
- **Baseline** · DPO/margin preference、MODPO/CPO与FLAME/F-DPO/AlignHonesty为来源；实际overall DPO/KTO和truth-pair α0、去conflict/adaptive组件。暂定增量是piecewise score差margin，最近目标待核。
- **Benchmark** · UltraFeedback去TruthfulQA来源后9:.5:.5 split，外测TruthfulQA/HaluEval；judge helpful/truth scores及accuracy/uncertain/hallucinationrate，具体basebackbone/judge和matched训练预算待核。
- **关键结果 / 消融** · TruthfulQA CAMP accuracy85.92/Hallu9.79对DPO80.66/11.26，help3.97对3.92；Halu helpful4.70低FLAME4.72。λ过大1.0时help也降，tradeoff非单调。
