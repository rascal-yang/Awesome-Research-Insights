## 5804 · UniFast-HGR: Scalable and Efficient Maximal Correlation for Multimodal Models

[原文](https://proceedings.mlr.press/v306/zhang26bp.html)

<a id="zhang26bp-loss-functions"></a>

**技术主题** · 用去对角Gram surrogate替代高维协方差正则

- **问题 / 瓶颈** · 高feature维度使covariance交互/whitening内存昂贵。
- **核心创新 / 方法** · UniFast-HGR先batch standardize、row normalize，最大化paired cosine减offdiagonal Gram-row structural cosine；TSS去单位自相似，OptFast以F(FᵀR)−diag(FFᵀ)R免显式Gram。
- **Baseline** · Soft-HGR、Gram trace identities、normalization及random projections已有；候选为明确normalized/offdiagonal auxiliary objective与sketched实现，最近原作待核。
- **Benchmark** · ImageNet1K top1、COCO R1、InternVid/ViCLIP MSRVTT/LSMDC/DiDeMo T2V R1，另情感/分割；K至10⁵ microbenchmark。
- **关键结果 / 消融** · PDF7 CLIP COCO38.9→42.1、SoftHGR40.3，OptFast42.0；PDF6 full cost O(m²K)、sketch O(mKr)，m为local per-device batch，非global batch无代价。
- **适用条件 / 局限** · 作者明确非exact finite-sample HGR reparameterization；row normalization改目标、cosine structural penalty不能当whitened maximal correlation。m²成本在大localbatch仍大，sketch低offdiagonal energy误差及εnorm效应、同优化budget待核。

## 5806 · T-measure: A Topology-Consistent Metric for Binary Segmentation

[原文](https://proceedings.mlr.press/v306/zhang26br.html)

<a id="zhang26br-evaluation"></a>

**技术主题** · 把连通碎裂显式接入分割评分

- **问题 / 瓶颈** · 相同像素错误面积可能破坏不同程度的对象连通结构，background统计可掩空预测。
- **核心创新 / 方法** · T-measure以Spix×[.8Itopo+.2Abdy]，Itopo在P>.5与每GT component交集中算最大片/总交面积，再按GT面积加权；boundary以双向gradient匹配补充。
- **Baseline** · fuzzy Jaccard、connected-components与boundary metrics已有；候选为具体可计算的碎裂惩罚/组合评估与meta-measure失败经验，最近拓扑metric先例待核。
- **Benchmark** · binary segmentation；ISIC2017前景<5%的153samples空预测，结构切裂stress tests及human perception比较；IoU/Dice/Smeasure/95HD/ASD，完整数据与相关系数待核。
- **关键结果 / 消融** · PDF6空预测Smeasure均值.482而Tmeasure0；PDF4同pixel-error案例区分破坏结构/边界。该零分也由fuzzyIoU给出，不能归因新增topology项独有。
- **适用条件 / 局限** · 固定.5 threshold、4/8connectivity待核；只看GT内交集可漏跨对象bridge/孔洞和GT外ghost，组合其他项补但无完整同胚保证。面积加权可能弱化小组件，α/human-study协议与空GT边界待核。

## 5810 · MA$^3$S: Model-Agnostic Active Annotation Strategy for Crowdsourcing

[原文](https://proceedings.mlr.press/v306/zhang26bv.html)

<a id="zhang26bv-data-strategies"></a>

**技术主题** · 用票数margin后验分配重复标注预算

- **问题 / 瓶颈** · 相同投票比例但不同票数证据强度应区别，重复近邻也耗预算。
- **核心创新 / 方法** · MA3S把majority/rest计数成α=Nm+1、β=Ns+1，取Beta CDF(.4)为uncertainty；对称kNN graph上U+neighbor mean，收到一label后在线更新，不依赖训练模型反馈。
- **Baseline** · Beta vote posterior、active repeated labeling与graph smoothing已有；候选为margin-tail uncertainty及model-free邻域budget规则，最近原作待核。
- **Benchmark** · Income/Leaves/Music/LabelMe多噪声labels，另synthetic票数/比例控制；GRR/ENTROPY/LU/MU/LMU/ALFC/DPP，model-centric用同10tree RF，最终指标/accuracy曲线待核。
- **关键结果 / 消融** · PDF4能区分{+,−}与3:3票数的tie，θ=.4而非.5；PDF6 K3默认。batch版topk减少更新次数但可能较弱，精确收益/方差待核。
- **适用条件 / 局限** · 票被当交换同质量证据，系统偏差/相关workers可自信错，majority-vs-rest多类压缩丢信息。较小variance不单独证明CDF单调，原定理证明细节待核；全pair distances N²成本和神经feature距离迁移尚未验证。

## 5811 · Reinforcement-aware Knowledge Distillation for LLM Reasoning

[原文](https://proceedings.mlr.press/v306/zhang26bw.html)

<a id="zhang26bw-reinforcement-learning"></a>

**技术主题** · 让teacher进入advantage加权概率比

- **问题 / 瓶颈** · 无条件teacher KL可能与reward-driven student更新竞争。
- **核心创新 / 方法** · RLAD/TRRD使用πstudent/(πold^απteacher^(1−α))替换GRPO ratio，在student rollouts上按advantage clipping，另保reference KL；α=1回到GRPO，非teacher sampling。
- **Baseline** · onpolicy KD、GRPO与advantage-aware imitation已有；候选为teacher-old几何anchor和clipping阈值的明确新目标，最近原作及控制待核。
- **Benchmark** · Qwen3-0.6/1.7B student、Qwen3-8B teacher；K&K Logistics PPL2–8，2K/8K contexts，accuracy；另math datasets/splits待核，对GRPO/KDRL/offline distill。
- **关键结果 / 消融** · PDF6 0.6B8K平均RLAD.94 vsKDRL.92/GRPO.76，1.7B8K .99 vs.96/.95；某subsets不总胜KDRL。摘要所谓+18对应.94−.76=18pp，非18%相对。
- **适用条件 / 局限** · 分母几何乘积总和一般非1，初始ratio不一定1；PPO min-clip非硬约束整个policy移动，不能保证不会降低teacher高概率token。非零梯度含ratio权重，不能仅用log-derivative省略它；teacher查询成本/α与fixed reward控制待核。

## 5813 · Prescriptive Scaling Reveals the Evolution of Language Model Capabilities

[原文](https://proceedings.mlr.press/v306/zhang26by.html)

<a id="zhang26by-evaluation"></a>

**技术主题** · 时间外验证的条件分位能力边界

- **问题 / 瓶颈** · 模型家族、后训练和发布时期混杂，使平均分数的compute回归掩盖可达到的经验高分区域。
- **核心创新 / 方法** · 按log FLOPs建条件高分位sigmoid，四时间段依次拟合和外推验证；用局部Jacobian的I-optimal预测方差加分箱balance目标，按gain/cost贪心选择待评模型。
- **Baseline** · 经验scaling、quantile regression与I-optimal experimental design是来源；实际比较函数形状、跨时期/新旧家族和不同评测预算。独立增量暂限经时间外检验的上沿规律及预算选择，最近scaling原作差异待核。
- **Benchmark** · Open LLM Leaderboard约5000模型及另评约2400 Proteus模型；IFEval、MMLU-Pro、MUSR、MATH Lvl5、BBH、GPQA，accuracy、quantile coverage/误差及预算比例；相邻时期只比较重合compute区间。
- **关键结果 / 消融** · 作者报告约20%预算可恢复接近全量的边界，GPQA/MUSR低至5%；高分边界较原始pretrained点更单调。最早时间切分有undercoverage，MATH Lvl5高compute新模型显著上移，非所有时期稳定。
- **适用条件 / 局限** · 边界条件于数据、家族、后训练与benchmark实践，是观测分位数而非可达性或因果compute定律。FLOPs估计、重复finetune依赖和污染影响结果；I-optimal依赖初始拟合与metadata，未来新recipe跃迁不能由曲线保证。

## 5817 · FedRot-LoRA: Mitigating Rotational Misalignment in Federated LoRA

[原文](https://proceedings.mlr.press/v306/zhang26cc.html)

<a id="zhang26cc-training-strategies"></a>

**技术主题** · 联邦LoRA的正交规范对齐

- **问题 / 瓶颈** · 相同BA可有不同因子坐标，直接平均A/B产生交叉项，冻结单因子又限制表达。
- **核心创新 / 方法** · 奇偶轮交替对齐A或B，rank×rank相关矩阵SVD求SO(r)旋转；将I与旋转线性插值后再SVD投影，同步变换B与A以保留本地BA，再服务器因子平均。
- **Baseline** · Procrustes、LoRA规范自由度和factor-wise FedAvg为来源；实际比较FedIT、FlexLoRA、FFA-LoRA、RoLoRA。暂定增量为交替软旋转的聚合接口，最近factor alignment先例待核。
- **Benchmark** · GLUE SST-2/QNLI/QQP/RTE/MNLI，r=4、Dirichlet h=.5、客户端3/10/50；accuracy均值/方差与BA聚合误差；模型、轮数及总训练预算待统一核实。
- **关键结果 / 消融** · 50客户端平均accuracy .8734对RoLoRA .8244、FedIT .7680；10客户端RTE .798低RoLoRA .805，不是逐项胜。SST-2聚合误差4.72e-4对FedIT 7.49e-3，属于该实验条件。
- **适用条件 / 局限** · 正交规范变换不改变A行空间/B列空间，不能修复任意真实子空间差。第4页soft投影写作R′=UΣVᵀ后取VdiagUᵀ，λ=1端点按字面存在逆向疑问，公式/实现待核，卡不保证精确定义一致；收敛改善还假设dispersion随λ收缩、小步长及有界因子，非任意数据保证。

## 5819 · Exploring More to Solve More: Boosting Diversity in Text Diffusion Models via Entropy-Based Guidance

[原文](https://proceedings.mlr.press/v306/zhang26ce.html)

<a id="zhang26ce-inference"></a>

**技术主题** · 局部语义核排斥的文本扩散引导

- **问题 / 瓶颈** · 单纯升温提高表面变化却损害正确性，固定锐化不保证语义探索。

- **Baseline** · entropy guidance、kernel entropy与embedding-space linearization为来源；实际比较unguided温度搜索及D-CFG。暂定新增是位置局部语义核梯度的离散扩散接口，最近原作待核。

- **关键结果 / 消融** · HumanEval Pass@32 55.8对base41.1、D-CFG41.2；MBPP56.1对48.2；GSM8K strict75.1对71.5。平均44.09 tokens/s对base47.41、D-CFG31.83，保约93%吞吐而非零开销。
- **适用条件 / 局限** · token内排斥是代理，不等于跨回答语义多样或推理正确；带宽/强度过大仍可能损害质量。熵协方差公式只给局部导数，符号不固定；逐token O(L)不等整序列线性，Alg1全对核有L²及词表投影成本。相同sample数不是相同总计算预算。
