## 1201 · PPT-Eval: A Benchmark for Computer-Use Agents on PowerPoint Tasks

[原文](https://proceedings.mlr.press/v306/gandhi26a.html) · [关联 Insight](../../../papers/llm.md#gandhi26a-evaluation)

- **问题 / 瓶颈** · PowerPoint 任务可能只完成一部分，也可能在达成目标时误改幻灯片，单一成功标签难以反映代理对真实文件的编辑质量。
- **核心创新 / 方法** · PPT-Eval 设定 120 道分难度的创作与编辑任务，并以可核查的任务细则给完成进度打分，对非预期改动扣分，同时以人评检查自动评分。
- **Baseline** · 改进来源：通用计算机使用代理基准以及 PowerPoint 文件级检查。实验对照：人类、GUI 操作代理及具备 PowerPoint 操作工具的 API 代理。
- **Benchmark** · 覆盖 12 个演示文件，比较任务成功率、平均得分、操作步数及评分与人类判断的 Spearman 和 Kendall 相关性。
- **关键结果 / 消融** · Claude Opus 4.5 GUI 的成功率和平均分为 0.45、0.57，API 为 0.62、0.81，人类为 0.80、0.90。自动评分与人评的 Spearman 为 0.84、Kendall 为 0.77。
- **适用条件 / 局限** · 评估限于给定的 PowerPoint 任务与文件。自动评分对“部分进展”一类的准确率只有 44.44%。

## 1202 · Gateways to Tractability for Satisfiability in Pearl’s Causal Hierarchy

[原文](https://proceedings.mlr.press/v306/ganian26a.html) · [关联 Insight](../../../papers/ml-foundations.md#ganian26a-theory-statistics)

- **问题 / 瓶颈** · Pearl 因果层级中，概率、干预和反事实陈述的可满足性通常难解，需要确定公式和依赖结构在何种限制下可以高效求解。
- **核心创新 / 方法** · 对线性概率公式用原始图的树分解构建局部边际一致性的线性规划。反事实片段则利用结构因果模型的变量排序和有限域表示，分析参数赋值的搜索复杂度。
- **Baseline** · 改进来源：Pearl 因果层级的可满足性复杂度与树宽参数化算法。实验对照：未报告，为理论论文。
- **Benchmark** · 理论设定为不同因果层级的可满足性，区分基本、线性和多项式公式，以原始树宽、变量数和域大小作为参数。数据集或实测指标未报告。
- **关键结果 / 消融** · 线性概率片段以域大小和树宽联合参数化是固定参数可解的，仅以树宽参数化属于 XP。线性反事实片段以变量数和域大小联合参数化是固定参数可解的。
- **适用条件 / 局限** · 条件不能直接推广到多项式概率片段，后者即使只有一个变量或二值域且原始图无边也为 ∃R 完全。

## 1203 · SuperHype: Hypergraph Generation via Graph-Superposition Decomposition

[原文](https://proceedings.mlr.press/v306/gantes26a.html) · [关联 Insight](../../../papers/graph-and-recommendation.md#gantes26a-architecture)

- **问题 / 瓶颈** · 超图生成要保留高阶邻接结构，直接建模关联矩阵成本较高，常见简化又会丢掉结构或生成无效样本。
- **核心创新 / 方法** · SuperHype 用共享节点集上的多层图无损表示超图，对图层叠加结构扩散去噪，并用 Graph-Superposition Transformer 的三元关系聚合在图层内外传递信息。
- **Baseline** · 改进来源：超图分解、图扩散和图 Transformer。实验对照：HyperPA、HyGene、HyperPLR，以及关联矩阵上的 VAE、GAN 和扩散。
- **Benchmark** · 在 SBM、Ego、Tree、Erdős–Rényi 和 ModelNet40 Bookshelf 超图上，以节点数、节点度、超边大小、谱统计和数据集有效率等评估。
- **关键结果 / 消融** · SBM、Tree 有效率分别为 88.3%、90%，HyGene 为 63%、79.2%。Ego 上有效率为 50.6%，低于 HyGene 的 95.6%。
- **适用条件 / 局限** · HyperPLR 在 Tree 上复现训练例，分布差异为零不能据此视为新样本质量高。SuperHype 的有效率增益也未覆盖所有结构。

## 1204 · EntroKV: Entropy-Guided Dynamic Budget Allocation for KV-Cache Compression

[原文](https://proceedings.mlr.press/v306/gao26a.html) · [关联 Insight](../../../papers/llm.md#gao26a-inference)

- **问题 / 瓶颈** · 长上下文的 KV 缓存对显存要求高，按头均分压缩预算忽略了注意力分布的可压缩程度。
- **核心创新 / 方法** · EntroKV 在线计算注意力熵，通过层和注意力头的熵差异动态分配缓存额度，从而将更多预算分到注意力较分散的头，并与已有丢弃或合并机制组合。
- **Baseline** · 改进来源：固定缓存预算与现有淘汰、合并策略。实验对照：全缓存、固定预算的 SnapKV、CaM、D2O，以及 PyramidKV、AdaKV 等预算分配方案。
- **Benchmark** · 在 Llama-3.1-8B、Qwen2.5-7B 和 Qwen3-8B 上测 RULER、LongBench 和短上下文任务，并考察准确率、显存和延迟。
- **关键结果 / 消融** · Llama-3.1-8B 上 RULER-16K 的 CaM 得分由固定预算 67.18 升为 91.57，全缓存为 91.73。SnapKV 相同对照为 90.88 升至 91.63。
- **适用条件 / 局限** · 注意力保留率是压缩质量的代理信号，降低代理损失不保证保持任意下游性能。

## 1205 · The First Drop of Ink: Nonlinear Impact of Distracting Information in Long-Context Reasoning

[原文](https://proceedings.mlr.press/v306/gao26b.html) · [关联 Insight](../../../papers/llm.md#gao26b-evaluation)

- **问题 / 瓶颈** · 长上下文问答会受相关但会误导的检索文档影响，总长度与困难干扰比例若同时变化，难以辨别各自影响。
- **核心创新 / 方法** · 固定上下文长度和答案证据，对困难干扰文档与简单或随机无关文档的混合比例做受控扫描，再用注意力头对不同文档的 logit 间隔解释初段的非线性下跌。
- **Baseline** · 改进来源：多文档检索问答的噪声分析。实验对照：0% 困难干扰、只混合简单或随机文档的两种设定，以及准确率线性衰减的参照。
- **Benchmark** · Natural Questions、TriviaQA、PopQA、HotpotQA，覆盖 4K–128K 的多种 Qwen 和 Llama 指令模型，使用问答准确率与前 10% 干扰所占总损失比例。
- **关键结果 / 消融** · Qwen2.5-7B-Instruct 在 128K 的 Natural Questions 简单文档混合设置中，前 10% 困难干扰造成全量干扰总损失的 58%，线性模型预期为 10%。图3也有接近线性或初段无损失的组合。
- **适用条件 / 局限** · 实验限多文档问答。按比例过滤并不保证成比例恢复准确率，文中未验证可通用的消除手段。

## 1206 · Salus: Strategic Diagnostic Testing for Complex Diagnosis via Multi-Agent Reinforcement Learning

[原文](https://proceedings.mlr.press/v306/gao26c.html) · [关联 Insight](../../../papers/scientific-ml.md#gao26c-reinforcement-learning)

- **问题 / 瓶颈** · 复杂疾病鉴别需要分轮请求检查，语言模型易在关键信息不足时停止并给出诊断。
- **核心创新 / 方法** · Salus 将鉴别推理和停止决定分给两个代理，以包含推理轨迹的监督微调初始化，再通过多代理 GRPO 和过程评估奖励训练检查决策与诊断。
- **Baseline** · 改进来源：交互式诊断代理、监督微调和过程奖励。实验对照：GPT-5.2、Gemini 3 Flash 等通用模型，以及只做监督微调、停止代理不做强化学习的变体。
- **Benchmark** · CompDiag-Bench 模拟检查环境，评估 269 个高复杂病例与 483 个常规病例，记录 Top-1/2/3 诊断准确率及信息充分率，交互设轮数上限。
- **关键结果 / 消融** · 高复杂集 Salus-7B 的 Top-1 为 83.64%，GPT-5.2 为 80.30%。只做监督微调为 55.02%，保留鉴别代理 RL 但停止代理不做 RL 为 61.71%。
- **适用条件 / 局限** · 检查响应、诊断和信息充分性由模拟环境与评估模型处理。前瞻临床验证未报告。

## 1207 · One-shot Entropy Minimization for Language Model Reasoning

[原文](https://proceedings.mlr.press/v306/gao26d.html) · [关联 Insight](../../../papers/llm.md#gao26d-training-strategies)

- **问题 / 瓶颈** · 常见推理后训练需要带答案反馈或多条提示。研究考察仅一条未标注提示能否激发预训练时已形成的推理能力。
- **核心创新 / 方法** · One-shot EM 根据候选提示的输出方差选取一条，采样模型响应并约十步最小化生成熵。对从去污染数据预训练的 Deconta-7B 和多个已有模型验证。
- **Baseline** · 改进来源：无监督熵最小化和提示选择。实验对照：原始模型、已有基于可验证奖励的强化学习方法，以及去掉基于方差的提示选择。
- **Benchmark** · MATH500、Minerva Math、OlympiadBench、AMC23 等数学推理，另有逻辑与 MBPP 代码任务。主表用多次生成 AVG@8 衡量。
- **关键结果 / 消融** · Qwen2.5-Math-7B 四个主数学任务的平均得分增幅为 24.9 点，AMC23 得分为 70.3、增幅 26.2 点。
- **适用条件 / 局限** · 效果受模型已有能力与提示选择影响，训练持续加长不一定继续改善。严格排除数据污染的设置针对作者单独预训练的模型。

## 1208 · Taming I2V models for Image HOI Editing: A Cognitive Benchmark and Agentic Self-Correcting Framework

[原文](https://proceedings.mlr.press/v306/gao26e.html) · [关联 Insight](../../../papers/computer-vision.md#gao26e-inference)

- **问题 / 瓶颈** · 现有图像编辑方法对复杂人–物交互易失效，整图分数又难以区分动作语义错误和原有主体外观被改坏。
- **核心创新 / 方法** · HOI-Edit 按三个认知等级组织人–物编辑。HOI-Eval 先定位人和物，再集中评估交互有效性与身份一致性。SCPE 借助 I2V 中间过程诊断失败，并用经验手册迭代修订提示。
- **Baseline** · 改进来源：图生视频中间序列与区域定位式评估。实验对照：Wan2.2、Nano Banana 等图像编辑器，以及不含经验手册或仅单次改写提示的消融。
- **Benchmark** · 在 HOI-Edit 三等级任务上，以交互 I、人 H、物 O 一致性及人工评分相关性评估。
- **关键结果 / 消融** · Wan2.2 上加入 SCPE 后，交互分由 0.6804 升至 0.8199，身份一致性汇总分由 0.8494 升至 0.8954。
- **适用条件 / 局限** · 迭代推理需要额外时间，背景保持仍可能波动，数据规模有限。

## 1209 · Unleashing Implicit Rewards: Prefix-Value Learning for Distribution-Level Optimization

[原文](https://proceedings.mlr.press/v306/gao26f.html) · [关联 Insight](../../../papers/llm.md#gao26f-reinforcement-learning)

- **问题 / 瓶颈** · 隐式过程奖励用整条推理轨迹的成败监督训练，却在使用时给各前缀评分，信号未必能准确定位错误。
- **核心创新 / 方法** · IPVRM 直接从结局标签学习每个前缀的最终正确概率，用相邻前缀的时序差分估计步骤奖励。DistRL 进一步在每一步对高概率候选 token 的分布进行更新。
- **Baseline** · 改进来源：隐式过程奖励模型与轨迹级策略优化。实验对照：Q-RM、EndoRM、DPO-RM、隐式 PRM，RL 对照含 PRIME、SPRO、GRPO 等。
- **Benchmark** · 使用 Eurus-2 数据，Qwen3 和 Llama-3.2 小至中型骨干。比较 MATH-500、Minerva-Math 的 best-of-N，PROCESSBENCH 的首错步 F1，以及数学策略的 AVG@8。
- **关键结果 / 消融** · Qwen3-0.6B 奖励模型 best-of-N 汇总分为 28.1，隐式 PRM 为 25.1，PROCESSBENCH F1 为 39.1 对 25.4。策略 DistRL 为 16.7，GRPO 加 IPVRM 为 16.3。
- **适用条件 / 局限** · 训练仍需要可获得的终局正确标签，线上 RL 使用可验证任务。实验只覆盖两个模型家族的 0.6B–8B 模型。

## 1210 · FakeWorld 1.0: An Omni-modal Benchmark for Fake Media and Content

[原文](https://proceedings.mlr.press/v306/gao26g.html) · [关联 Insight](../../../papers/multimodal.md#gao26g-evaluation)

- **问题 / 瓶颈** · 在线虚假内容可同时包含合成媒体、跨模态不一致和事实错误，单个真假标签难覆盖这些成因。
- **核心创新 / 方法** · FakeWorld 以网页和移动社交布局呈现真假组合，提供媒体与事实两轴及诊断解释。OmniCheck 将验证拆成媒体检测、检索式事实核查和跨模态一致性判断。
