## 3401 · Data Selection for Fine-tuning Vision Language Models via Cross Modal Alignment Trajectories

[原文](https://proceedings.mlr.press/v306/naharas26a.html)

<a id="naharas26a-data-strategies"></a>

**技术主题** · 用跨模态对齐轨迹选择指令样本

- **问题 / 瓶颈** · 用损失或图像文本相似度等单次标量筛选 LVLM 指令，可能在紧预算下保留冗余且不如随机选择。
- **核心创新 / 方法** · XMAS 以小 LVLM 微调检查点提取跨模态注意力轨迹，聚类近似具有类似梯度的样本，在簇间均衡选对齐轨迹稳定的点。
- **Baseline** · 改进来源：梯度相似性和视觉指令数据代表性抽样。实验对照：Random、MP、HL、EL2N、D2 Pruning、SemDeDup、CLIP-Score、Self-Sup、Self-Filter、COINCIDE。
- **Benchmark** · 从 LLaVA-665K 与 Vision-Flan 选子集，用 0.5B/2B TinyLLaVA 代理、四种目标 LVLM，测 POPE、TextVQA、MME-Perception、ScienceQA、GQA 等 10 任务相对全量平均表现 ARP。
- **关键结果 / 消融** · LLaVA-1.5-7B 用 LLaVA-665K 的 50% 或 Vision-Flan 的 15% 可达全量表现。检查点消融中 7 个得 ARP 95.4%，增至 11 个降为 94.1%。
- **适用条件 / 局限** · 理论梯度相似界依赖所分析的一层 Transformer 等假设，跨骨干迁移由实验支持。筛选需付代理微调和轨迹提取成本，单列作者局限未报告。

## 3402 · Less Diverse, Less Safe: The Indirect But Pervasive Risk of Test-Time Scaling in Large Language Models

[原文](https://proceedings.mlr.press/v306/nahin26a.html)

<a id="nahin26a-evaluation"></a>

**技术主题** · 压低候选多样性的推理安全压力测试

- **问题 / 瓶颈** · 测试时扩展依赖多样候选，候选池被压缩后，奖励排序或树搜索可能在近似同类的有害回答中作选择。
- **核心创新 / 方法** · RefDiv 用参考引导的低多样性情境暴露 TTS 的安全弱点。实验追踪 token 级熵与有害输出的关联，并分别在 Best-of-N 和 MCTS 下做诊断。
- **Baseline** · 改进来源：测试时扩展与候选熵分析。实验对照：GCG、AutoDAN、AutoDAN-Turbo，另比较不同奖励模型与分支预算。
- **Benchmark** · AdvBench 含 520 个安全测试查询，主要针对 Mistral、Llama3.1、Qwen3、Gemma3 等，并测闭源模型迁移。Best-of-N 取 N=2、8、16，另用 MCTS，指标 ASR 与 Shannon 熵。
- **关键结果 / 消融** · N=8 的 Gemma3-27B 上 RefDiv ASR 为 92.6%，AutoDAN 为 74.9%。MCTS 的 Llama3.1-8B 上为 96.7% 和 83.1%。同一张表的 Qwen3 Best-of-N 中 AutoDAN 略高。
- **适用条件 / 局限** · 作者指出诊断优化随种群、迭代数和 TTS 开销增长，主要只验证 Best-of-N 与 MCTS，对其他扩展方式仍需测试。

## 3403 · Interpreting Genomic Language Models using Sparse Autoencoders

[原文](https://proceedings.mlr.press/v306/nair26a.html)

<a id="nair26a-representation-learning"></a>

**技术主题** · 基因组模型的稀疏特征探针

- **问题 / 瓶颈** · 基因组语言模型预测有效，但隐藏层哪些单元对应已知的剪接、转录和调控结构缺少系统评测。
- **核心创新 / 方法** · 在 Evo2 与 Nucleotide Transformer v3 多层训练稀疏自编码器，用单维稀疏探针比较激活和序列注释。另用长片段激活的 Tanimoto 近邻构造特征图。
- **Baseline** · 改进来源：稀疏自编码器解释与单维探针。实验对照：同层原嵌入单神经元，比较不同层、来源基因组、上下文、字典和稀疏度。
- **Benchmark** · 留出人 22 号染色体的 10 kb 片段，涵盖基因结构、调控、重复和保守区等 55 种概念。用修正版核苷酸精度/区域召回 F1、AUPRC 与稀疏事件激活等指标。
- **关键结果 / 消融** · Evo2 有 42/55 概念最优探针来自 SAE，26 项修正 F1 大于 0.7。NT 对应 30/55。优势集中在中间层，早晚层原嵌入有时略占优。
- **适用条件 / 局限** · 作者指出依赖不完整且异质的注释，细胞类型与条件会影响配对。训练 SAE 以及很宽字典的长程激活近邻开销高。

## 3404 · Removing Noise, not Finding Gold: Quality Filtering for Large-Scale Pretraining

[原文](https://proceedings.mlr.press/v306/nait-saada26a.html)

<a id="nait-saada26a-data-strategies"></a>

**技术主题** · 区分预训练过滤收益与高质量分布匹配

- **问题 / 瓶颈** · 基于二分类器的预训练筛选提高任务效果，但通常被解释为模仿高质量样本分布，缺少对分布距离和可学习性的拆解。
- **核心创新 / 方法** · CQF 用文档嵌入在高质参考与原始文档之间二分类并截取高分，论文从密度比和条件化角度分析，并用不同过滤强度、词序扰动构造交叉训练测试矩阵。
- **Baseline** · 改进来源：分类器质量过滤、密度比与优化数据条件性。实验对照：未过滤语料、CRISP 重要性采样、在足量高质量参考集直接训练、半合成打乱。
- **Benchmark** · RedPajama-V2 作待筛母集，参考涉及 OpenOrca、KnowledgePile、OH+ELI5、OpenWebMath 和 ARC-Easy。比较下游准确率与参考集下一 token 损失，代理缩放覆盖 125M–1.3B。
- **关键结果 / 消融** · OpenOrca 扩出的足量参考直接训练准确率 50.1%，再经 CQF 取前 1% 为 53.8%。多数参考上，下游分数提高可伴随参考集损失出现 U 形或恶化。
- **适用条件 / 局限** · 贝叶斯最优分类器和无限模型容量是密度解释的理想假设，数据条件性依赖训练算法及步数。过严筛选可能损伤如 OpenWebMath 的效果。

## 3405 · Aitchison Embeddings for Learning Compositional Graph Representations

[原文](https://proceedings.mlr.press/v306/nakis26a.html)

<a id="nakis26a-representation-learning"></a>

**技术主题** · 图角色比例嵌入

- **问题 / 瓶颈** · 图嵌入可做链路预测，却常难从向量解释节点是如何混合不同潜在角色的。
- **核心创新 / 方法** · AICoG 将节点表示为单纯形内部的成分向量，以等距对数比 ILR 映射到无约束空间，对 Aitchison 距离建模，并按 Bernoulli 边似然拟合。
- **Baseline** · 改进来源为混合成员模型和潜在距离模型。实验对照为 Node2Vec、Role2Vec、NetMF、MMSBM 及直接用欧氏距离的单纯形基线。
- **Benchmark** · 无节点特征的引用、合著及社交图，报告链路 ROC-AUC、分类 Micro-F1。用合成混合角色考察成员恢复，报告 L1、余弦相似度和 JS 散度。
- **关键结果 / 消融** · 合成的 bilinear-continuous 设置中，AICoG 的 L1、余弦、JS 分别为 0.922、0.624、0.161，MMSBM 分别为 1.456、0.423、0.360。定理 3.2 证明相同距离链接下的表达等价。
- **适用条件 / 局限** · 解释依赖节点角色适合混合建模，分量解释也受所选 ILR 基底影响。实验主要基于连通图或以大连通分量为主的图。

## 3406 · FOAM: Frequency and Operator-Error Based Adaptive Damping Method for Reducing Staleness-Oriented Error for Shampoo

[原文](https://proceedings.mlr.press/v306/nam26a.html)

<a id="nam26a-optimization"></a>

**技术主题** · 陈旧预条件器阻尼

- **问题 / 瓶颈** · Shampoo 若隔固定步数更新逆根，能节省特征分解，但旧预条件器随曲率漂移会累积误差。
- **核心创新 / 方法** · FOAM 按因子周期性计算算子误差代理，以控制阈值调整特征值阻尼并复用已有谱基。候选阻尼越过上限才触发特征分解并重置阻尼。
- **Baseline** · 改进来源为固定刷新 Shampoo 及逆根扰动误差分析。实验对照为固定间隔刷新、去掉适应阻尼或去掉自适应刷新。
- **Benchmark** · AlgoPerf 上用 ViT-small 做 ImageNet-1K、Conformer 做 LibriSpeech，另测 GPT-2 在 WikiText-103-v1。记录固定训练预算下耗时、EVD 频率和准确率、WER 或 PPL。
- **关键结果 / 消融** · 在 ViT 的分析设置中，每 20 步感知一次，左右因子的特征分解调用量约为固定刷新基线的 10% 和 5%。消融显示同时保留阻尼与刷新可兼顾训练损失和总耗时。
- **适用条件 / 局限** · 控制器需要感知频率、误差容忍度和阻尼上限，实测来自所列架构和硬件。更新策略调整的效果随谱变化而异。

## 3407 · Maximizing Mutual Information Between Prompt and Response Improves LLM Performance With No Additional Data

[原文](https://proceedings.mlr.press/v306/nam26b.html)

<a id="nam26b-data-strategies"></a>

**技术主题** · 提示响应互信息

- **问题 / 瓶颈** · 缺少人工偏好或可验证奖励时，模型自生成数据可能强化泛化答案，忽略请求内容及用户上下文。
- **核心创新 / 方法** · MIPO 把正确提示或用户上下文生成的回复作正样本，把重排、缺失上下文或错配上下文的回复作负样本，用标准 DPO 学习。由一负样本 InfoNCE 联系参考模型的点互信息。
- **Baseline** · 改进来源为 DPO 和 InfoNCE。实验对照为同数据 SFT、修改后 SFT、RLAIF、RLVR 及不同负例构造。
- **Benchmark** · 考查个性化人群数据，以及 GSM8K 和 SVAMP 的 8-shot、ARC Easy 和 Challenge 的零样本，推理表按三个种子统计。
- **关键结果 / 消融** · Llama-3.2-1B-Instruct 四项推理均值由 37.72 升至 45.25，同数据普通 SFT 为 35.48，利用真值的 RLVR 为 47.55。
- **适用条件 / 局限** · 个性化用 LLM 评判，部分用户上下文由 GPT-4o 从已有数据提取。偏好信号由模型自产，负样本也只是边缘分布的近似。

## 3408 · Causal-JEPA: Learning World Models through Object-Level Latent Masking

[原文](https://proceedings.mlr.press/v306/nam26c.html)

<a id="nam26c-representation-learning"></a>

**技术主题** · 对象级掩码世界模型

- **问题 / 瓶颈** · 对象槽位能分解视频画面，但仅沿时间外推可忽略对象间的接触和相互作用。
- **核心创新 / 方法** · C-JEPA 用冻结对象编码器，训练时遮蔽历史中的选定对象潜变量，以可见对象、最小身份锚点和可用辅助量恢复缺失状态并预测未来，推断时用完整历史。
- **Baseline** · 改进来源为 JEPA 掩码预测和对象中心世界模型。实验对照为无掩码 OC-JEPA、SlotFormer、OCVP-Seq 和带图块或对象 token 的 DINO-WM。
- **Benchmark** · CLEVRER 用 ALOE 评估 128 帧到 160 帧滚动的 VQA，Push-T 以潜变量目标规划成功率衡量控制。
- **关键结果 / 消融** · CLEVRER 的 VideoSAUR 设置中遮蔽 4 个对象，反事实逐题准确率 68.81%，无掩码为 47.68%。Push-T 同为 6×128 token 预算，C-JEPA、OC-JEPA 与 OC-DINO-WM 成功率为 88.67%、76.00%、60.67%。
- **适用条件 / 局限** · 依赖对象对齐的槽位和历史窗口充分性，过多掩码可移除必要上下文。遮蔽改变可观测性，实验证据衡量预测依赖。
