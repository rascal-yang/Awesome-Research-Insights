## 6001 · iVGR: Internalizing Visually Grounded Reasoning for MLLMs with Reinforcement Learning

[原文](https://proceedings.mlr.press/v306/zhang26je.html)

<a id="zhang26je-reinforcement-learning"></a>

**技术主题** · 训练中定位而推理时不强制box

- **问题 / 瓶颈** · 强制每次推理输出定位框可能干扰最终答案，定位训练能力与显式推理格式需区分。
- **核心创新 / 方法** · 双stream GRPO：grounded流获格式/正确率/双向IoU奖励；archive保留格式正确、答案正确、定位过阈值的最高质量参考；text流用LLM语义一致性奖励对齐参考。
- **Baseline** · GRPO、teacher reasoning蒸馏、grounded CoT及一致性奖励为来源；候选是定位监督训练与box-free部署的受控选择，不称首次隐式视觉推理。
- **Benchmark** · Qwen2.5-VL-7B、Qwen3-VL-8B/32B；V*、HR4K/HR8K与POPE/RealWorldQA/CV-2D/3D、chart/math accuracy；文本/grounded输出与crop/union crop控制。
- **关键结果 / 消融** · Qwen2.5-7B V*/HR4K/HR8K平均70.9→80.1；8B CV-3D93.5→91.0。8B加crops平均84.1→83.7，说明额外局部视图不总增益。
- **适用条件 / 局限** · archive按GT筛选需定位标注及额外grounded rollouts/LLM judge成本；语义一致不能保证内部真的定位；reference陈旧/奖励偏差和teacher distillation最近先例待核，不能把移除box本身称新机制。

## 6006 · Transform Trained Transformer for Accelerating Native 4K Video Generation

[原文](https://proceedings.mlr.press/v306/zhang26jj.html)

<a id="zhang26jj-architecture"></a>

**技术主题** · 共享投影的多尺度窗口改造

- **问题 / 瓶颈** · 直接对4K长视频运行full attention昂贵，朴素各轴分块又产生空间接缝和时间跳跃。
- **核心创新 / 方法** · 所有尺度/窗口共享QKVO，用等大小窗口但不同采样stride覆盖局部与远程位置，归一加权输出；层组轮换blocking/overlap并保留完整轴；720p再4K适配。
- **Baseline** · Swin shifted windows、Neighborhood Attention、i2RMB和视频稀疏attention为来源；实际同5k步比较shifted window，候选是继承权重的多尺度并行/分层轴规则。
- **Benchmark** · Wan2.1 1.3B、81帧、2176×3840视频，4K-VBench VQA/VTC；720p同5k步attention变体；50-step CFG与8-step无CFG deployment分别计时。
- **关键结果 / 消融** · 720p同5k步shifted window VQA67.34/VTC.87，T3为69.37/.90。4K 50-step总时延79774.4→4165.8秒；deployment166.8秒还含步数/CFG蒸馏与eVAE，不能全归因attention。
- **适用条件 / 局限** · 仍需全参数/LoRA适配，直接改分辨率会失败；减MAC不等比例减walltime；remote稀疏窗不是单层任意token完整连接；速度表依赖硬件、batch和CFG口径，最近兼容预训练稀疏attention待核。

## 6008 · Unveiling And Addressing Dimensional Collapse In Vector Quantization Models Via Codebook Regularization

[原文](https://proceedings.mlr.press/v306/zhang26jl.html)

<a id="zhang26jl-evaluation"></a>

**技术主题** · 码本利用率不等于表征维数

- **问题 / 瓶颈** · codebook全利用仍可能有低有效维数，增大码本不一定恢复细节。
- **核心创新 / 方法** · 对连续AE与VQ的谱做D90/D99和effective-rank比较；连续AE逐步去除低方差主成分检查重建变化；另试码本维度Gram非对角平方惩罚并与谱阈值约束比较。
- **Baseline** · 码本利用、VICReg式去相关/Gram正交与谱正则均成熟；仅保留满利用仍塌维的控制经验，不把非对角惩罚本身当原创保证。
- **Benchmark** · ImageNet128/256、MSCOCO/FFHQ谱诊断；VQGAN/SimVQ/IBQ重建rFID/LPIPS/PSNR/SSIM、effective rank、utilization；ImageNet AR生成FID。
- **关键结果 / 消融** · SimVQ 128、65k码本利用均100%，加正则ER9.7→14.7、rFID2.24→1.99；262k码本ER9.3→16.4、rFID1.99→1.55。连续AE裁剪谱尾重建下降为间接控制。
- **适用条件 / 局限** · 原式称cov/correlation但算法CᵀC未显式中心化/标准化；去非对角也可缩小/旋转码本，不能数学保证恢复谱尾或rank；AE谱裁剪不是VQ真实生成过程因果识别；论文宣称1.50与表中1.55差异待核。

## 6009 · Geometry-Preserving Orthonormal Initialization for Low-Rank Adaptation in RLVR

[原文](https://proceedings.mlr.press/v306/zhang26jm.html)

<a id="zhang26jm-optimization"></a>

**技术主题** · RLVR下拆开奇异方向与幅度

- **问题 / 瓶颈** · SFT表现好的SVD初始化在RLVR可能梯度/KL膨胀，不能直接按SFT排名选adapter初始化。
- **核心创新 / 方法** · 用同top/tail方向的有/无奇异值缩放控制诊断，选择row-orthonormal A、零B保持初始函数，再比较geometry-preserving与model-agnostic正交方案。
- **Baseline** · LoRA、PiSSA、MiLoRA、OLoRA/OLoRA-tail、DCT/Wavelet-LoRA为来源；候选主要是RLVR受控适用边界，不把正交初始化本身称新。
- **Benchmark** · DeepSeek-R1-Distill-Qwen-1.5B，DAPO-Math-17k、rank16全linear；GSM8K、MATH500 mean@4、AIME22/23/24 mean@32；reward、梯度与KL轨迹。
- **关键结果 / 消融** · 相同方向去奇异值缩放后，tail配置几乎消除MiLoRA的collapse，top配置减缓PiSSA collapse但未必完全解决；LR衰减仅部分改善，支持拆开方向/幅度而非归因所有SVD方向。
- **适用条件 / 局限** · 有限时域小步长单层smooth模型的误差上界不等于实际全模型最优gap；r<n时||I−AᵀA||₂最小为1且许多奇异值≤1的A也达1，不能据此唯一选择正交或排除A=0；ratio clipping不自动约束KL/全梯度。

**原文定位** · 初筛整理，原文与先例尚未统一核查。现有缓存物理页定位，链接及证据对应待统一复核：[PDF第4页（PDF 第 4 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/zhang26jm/zhang26jm.pdf#page=4)；[PDF第5页（PDF 第 5 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/zhang26jm/zhang26jm.pdf#page=5)；[PDF第6页（PDF 第 6 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/zhang26jm/zhang26jm.pdf#page=6)；[PDF第7页（PDF 第 7 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/zhang26jm/zhang26jm.pdf#page=7)；[PDF第8页（PDF 第 8 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/zhang26jm/zhang26jm.pdf#page=8)

**可复用机制** · 从SFT迁移LoRA到RLVR时，分别对照奇异子空间、奇异值缩放和LR日程；保留方向但去掉奇异值幅度的正交初始化可比照直接PiSSA/MiLoRA。

## 6012 · Think in Latent, Explain in Language: Self-Explainable Latent Reasoning

[原文](https://proceedings.mlr.press/v306/zhao26a.html)

<a id="zhao26a-loss-functions"></a>

**技术主题** · 让同一latent-reasoning模型兼学文字解码

- **问题 / 瓶颈** · latent压缩节省generationtokens，却难读懂中间表示。
- **核心创新 / 方法** · SELR自回归反馈finalhidden作为下一latent；同参数解answer和fullCoT或单step文本，decodingprompt不含原question/image而只含latent，联合CE并分阶段训练。
- **Baseline** · Coconut latent feedback、Heima posthoc解码与multitask reconstruction已有；候选为shared-model latent-to-CoT辅助目标/stepwise对齐，最近原作和参数/teacher控制待核。
- **Benchmark** · Qwen2.5VL3B/Llama3.2-1B LoRA；LLaVACoT100k和GSM8kAug385k训练，VQA/math准确率、token数和CoTdecodequality，完整test数据和数值待核。
- **关键结果 / 消融** · PDF6VLM每例summary/caption/reasoning恰3stages，latent长度实际3，不能泛称可变长度。fullCoT用于第二stage质量下降是作者结果，完整loss对照待核。
- **适用条件 / 局限** · 重建teacherCoT不证明这些文字causally驱动answer；解释可后置合理化或存无用细节。训练auxdecode成本、latent迭代forward仍昂贵，节省token数不等walltime；不同CoT segmentation/order与faithfulness干预待核。

- **Baseline** · iterative visualservoing、cursorfeedback/coarsefinegrounding与GRPO已有；候选为相同baseGUI模型的feedback闭环训练/特定dense reward选择，最近原作及等推理预算待核。

## 6019 · Syntax vs. Semantics: How Transformers Learn Deep Dependencies

<a id="zhao26h-loss-functions"></a>

**技术主题** · 对已知依赖边直接加attentionmargin监督

- **问题 / 瓶颈** · 常见syntax线索可能让attention早饱和，稀疏dependency信号学得慢。
- **核心创新 / 方法** · 理论以syntax/semantic subspaces和alignmentratio描述starvation/phase；辅助loss max(0,η−(ssrc−mean sneg))给QK方向直接rank1监督，syntaxmask/densification另作诊断。
- **Baseline** · gradientstarvation/grokking、CoT中间监督及supervisedattention已有；候选为dependencytopology attentionmargin目标和阶段失败经验，最近原作及普通SupCon控制待核。

- **适用条件 / 局限** · 分解/curvature/threshold模型不证明所有LM语义必按相同阶段；syntax gradients大小不直接证明抑制因果。selectedheads/sourceannotation获取成本、训练标注外迁移、attentionmargin可能学捷径，不将CoT效用唯一归starvation。

## 6020 · Nonparametric Data Attribution for Diffusion Models

[原文](https://proceedings.mlr.press/v306/zhao26i.html)

<a id="zhao26i-evaluation"></a>

**技术主题** · 无modelaccess时以patchscoreproxy定位训练对应

- **问题 / 瓶颈** · 全图nearestneighbor忽略局部生成片段，gradientattribution又要模型访问。
- **核心创新 / 方法** · NDA以最优empiricalscore的patchposteriorweights为proxy，按每trainimage topkpatches和spatial/time/resolution聚合；convolution计算distances避免unfold大tensor。

- **Baseline** · NI merit function、penalty bilevel RL/PBRL与regularized Markov games为来源；实际META/DA/PBRL与精确DP+二阶oracle，λ1/4/10。暂定增量为NI双bestresponse的一阶bilevel接口/条件rate，最近原作待核。
- **Benchmark** · finiteS/A/B、strongconvex-concave policy-distribution regularizer、full-supportinitialρ及π(a|s)统一下界；5state/3actions incentive design tabularsoftmax，SentinelIntruder5²/20²grid；ULreward/loss、NI gap vs envsamples、3seeds。
- **关键结果 / 消融** · 作者平方gradient≤O(ε)的stationarity下tildeO(ε⁻1)iterations、ε⁻3samples，不能当gradientnorm ε同指数。图示较高ULreward、低NEgap，未猜曲线值；有限λ有O(1/λ)hypergradient偏差。
- **适用条件 / 局限** · 还需cf+NI对policy参数满足统一µPL，不是任意非凸游戏无条件保证；softmax虽正不自动有统一概率下界，常数随δπ/δρ和γ恶化。有限horizon/MC/bestresponse误差、penalty变大开销与实策略表达性待核，不保证global UL optimum。
