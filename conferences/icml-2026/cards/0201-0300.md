## 203 · Model-Based Diffusion Sampling for Predictive Control in Offline Decision Making

[原文](https://proceedings.mlr.press/v306/balim26a.html)

<a id="balim26a-inference"></a>

**技术主题** · 扩散预测控制

- **问题 / 瓶颈** · 离线扩散规划可能生成回报高、但真实动力学下执行不了的状态–动作轨迹，约束任务尤其受此影响。
- **核心创新 / 方法** · MPDiffuser 以扩散规划器生成任务条件下的状态和动作，用仅在状态上去噪、动作作为条件的动力学扩散器校正。采样时交替更新，另用排名器挑选符合回报和安全预算的候选。
- **Baseline** · 改进来源为在采样中直接交替施加动力学一致性与任务信号。实验对照含 D-MPC、规划器单独采样、将两种分数加权合并、使用或关闭排名。
- **Benchmark** · D4RL 无约束归一化回报、DSRL 约束回报和代价，Fetch PickandPlace 成功率，另有 Unitree Go2 实机。D4RL 标准结果为五次独立训练、每次 50 条轨迹。
- **关键结果 / 消融** · D4RL 三项 medium-replay 平均回报为交替 74.4、两种仅规划对照 69.3 与 68.8。Hopper 三种日志的交替更新均值 102.4、分数合并 98.2。Fetch 加 10,000 条随机轨迹后成功率 0.75→0.86，D-MPC 为 0.60→0.60。
- **适用条件 / 局限** · 规划器和动力学训练分布相差过大时，交替可能无法弥合偏移。排名效果也取决于可用任务目标和约束信号。

## 205 · Don’t Walk the Line: Boundary Guidance for Filtered Generation

[原文](https://proceedings.mlr.press/v306/ball26b.html)

<a id="ball26b-reinforcement-learning"></a>

**技术主题** · 生成安全对齐

- **问题 / 瓶颈** · 只奖生成器降低被安全过滤器拦截的概率，输出可能集中到阈值附近，使下游分类器更难区分该保留还是拒绝的回答。
- **核心创新 / 方法** · Boundary Guidance 将奖励写为帮助性估计加上过滤分数到阈值的距离，训练时用策略梯度使明晰安全和明晰不安全输出更易被部署过滤器分开。理论单调性依赖分类器分数的似然比条件。
- **Baseline** · 改进来源为直接避开过滤器边界。实验对照为原指令模型、带帮助性奖励、仅 guard 奖励、问题感知设计和不同安全分类器。
- **Benchmark** · Qwen2.5 0.5B/7B/14B 与 Gemma-2 9B，覆盖越狱、模糊和长上下文提示。Llama Guard 等作过滤器，以 LLM 裁判评价过滤后回答的 Helpful/Harmful 分数。
- **关键结果 / 消融** · 表 1 的 Qwen2.5-7B 中 Helpful 为 2.72→2.75，Harmful 为 0.19→0.04。14B 的 Harmful 为 0.14→0.03，但 Helpful 从 2.77 降至 2.71。
- **适用条件 / 局限** · 分数若明显不满足单调似然比，方法可强化分类器自信犯错的例子。收益也随提示组合和分类器实力变化。较弱的 guard 可能以帮助性损失换取更低危害。

## 207 · DOT-MoE: Differentiable Optimal Transport for MoEfication

[原文](https://proceedings.mlr.press/v306/bamba26a.html)

<a id="bamba26a-modules"></a>

**技术主题** · 稠密模型转 MoE

- **问题 / 瓶颈** · 密集语言模型改成稀疏 MoE 时，随机分组或按权重聚类易破坏 FFN 输出，需要同时解决专家容量与输入路由。
- **核心创新 / 方法** · DOT-MoE 对神经元到专家的分配做带容量的平衡最优传输，以可微 Sinkhorn–Knopp 生成软解、前向做硬分配，用直通估计联合学习离散分组和 token 路由，并对齐密集层输出。
- **Baseline** · 改进来源为以层输出重建直接监督平衡分组和路由。实验对照含启发式或随机 MoE 转换、CMoE、SliceGPT、DISP-LLM、SparseGPT 等。
- **Benchmark** · 多种 LLaMA/Qwen 模型族，测 WikiText-2 困惑度及 BoolQ、SciQ、PIQA、WinoGrande、ARC-C、HellaSwag 的协议准确率，另以不同微调 token 预算衡量恢复。
- **关键结果 / 消融** · LLaMA-2 7B 在约 50% 参数预算下，WikiText-2 困惑度 DOT-MoE 为 7.99、DISP-LLM 为 9.84。表 3 中同为 3.49B 激活参数，六项准确率均值为 61.5 对 CMoE 44.5。表 1 的 Pruner-Zero 在 HellaSwag 单项为 54.7，对 DOT-MoE 的 53.9。
- **适用条件 / 局限** · 激活参数量是预算指标，硬件推理效率会受专家分发和 kernel 实现影响。更大骨干和大规模部署的效果仍待验证。

## 209 · Riemannian Metric Matching for Scalable Geometric Modeling of Distributions

[原文](https://proceedings.mlr.press/v306/bamberger26a.html)

<a id="bamberger26a-representation-learning"></a>

**技术主题** · 数据流形几何

- **问题 / 瓶颈** · 图或核估计可提取高维数据的低维几何，但全局近邻构造在样本量和维数较大时昂贵，在图像上还可能失灵。
- **核心创新 / 方法** · 把扩散几何的 carré du champ 算子写成加噪后的条件二阶矩，训练低秩神经网络匹配局部度量，无须显式构图。推理可摊销地估计切空间、方向与几何梯度。
- **Baseline** · 改进来源为用去噪条件期望替代逐点图核。实验对照含 k-NN 扩散几何估计、Stein score、score Jacobian、欧氏和随机方向。
- **Benchmark** · 已知真值的合成流形与 MNIST、CIFAR-10、CelebA、FFHQ，比较度量或切空间误差、切向扰动后的 Inception 特征稳定性及 H100 推理开销。
- **关键结果 / 消融** · CIFAR-10 的表 1 计算量中，度量匹配为 16.6±3.7 ms、8.8 MB，score Jacobian 为 992.3±1.2 ms、27.4 GB，Stein score 为 17.0±0.4 ms、8.8 MB。后者速度接近，而在 CelebA、FFHQ 上 score Jacobian 耗尽显存。
- **适用条件 / 局限** · 需要为数据训练近似器，速度收益针对摊销查询。理论收敛受流形和正则性假设约束，估计度量得到的插值轨迹也不保证最短。

## 210 · EPSVec: Efficient and Private Synthetic Data Generation via Dataset Vectors

[原文](https://proceedings.mlr.press/v306/banayeeanzade26a.html)

<a id="banayeeanzade26a-data-strategies"></a>

**技术主题** · 差分隐私合成数据

- **问题 / 瓶颈** · 私有文本合成若每次采样都查询大量私有样本，会把隐私花费和计算量绑定到输出数量及长度。
- **核心创新 / 方法** · EPSVec 从私有与公开参考的隐藏激活差提取数据集方向，经剪裁和加噪后只发布一次，随后将方向注入生成。另以差分隐私直方图选固定示例，标准解码及筛选只做后处理。
- **Baseline** · 改进来源为将隐私开销集中到向量和固定示例提取，并用预训练底座提高多样性。实验对照为 AUG-PE、InvisibleInk、PP、PP++ 和去向量或去私有示例消融。
- **Benchmark** · IMDb、Yelp、bioRxiv、OpenReview 的文本分布。以 Llama-3.1-8B 生成每数据集目标 2,000 条，三随机种子，报告 MAUVE、合成数据训练 BERT 后的准确率与运行开销。
- **关键结果 / 消融** · ε=3 的 Yelp，预训练 EPSVec++ 的 MAUVE 为 67.3±3.6%，AUG-PE 为 0.4±0.0%、InvisibleInk 为 0.5±0.0%。同组 BERT 准确率 85.8±1.4%，InvisibleInk 为 87.1±0.3%，PP++ 在该预算未生成可用样本。
- **适用条件 / 局限** · 隐私在规定的提取机制及后处理下成立。质量取决于公开先验、模型和注入点，MAUVE 对特征与缩放设定敏感，长程、代理式数据仍需验证。

## 212 · Local-Minima-Preserving Polynomial Relaxation of Ising Problems

[原文](https://proceedings.mlr.press/v306/banerjee26a.html)

<a id="banerjee26a-optimization"></a>

**技术主题** · 组合优化松弛

- **问题 / 瓶颈** · Ising 问题直接在离散自旋上组合搜索，普通连续松弛可能产生不可取整的局部极小值。论文要求保留单比特翻转局部最优。
- **核心创新 / 方法** · MiP-CRIM 在超立方体内保留二次 Ising 能量并加逐坐标多项式吸引项，使满足参数条件的局部极点被推到顶点。实际采用四次吸引项配合 Adam，以符号读出离散解。
- **Baseline** · 改进来源为把连续局部极小同单翻转局部极小建立一一对应。实验对照含 GW-SDP、bSBM、SIA、D-Wave、NeuroSA、FEM 与不同吸引项。
- **Benchmark** · 1,000 自旋 SK、K2000 最大割、G-set 及 1,000 元数字划分。报告 100 次的最好和平均值、局部同步分数、求解时间，计时排除超参数搜索。
- **关键结果 / 消融** · 定理 3.13 在吸引项满足条件 (20)–(23) 时给出局部极小景观等价。K2000 最佳割值 34,137、0.24 秒，FEM 为 34,038、0.01 秒。SK 上论文方法最低能量 −16,689.49，FEM 为 −16,814.75。
- **适用条件 / 局限** · 景观保证仅涉及单翻转局部最优，Adam 仍需选择吸引项和参数，不能从证明推出全局解或所有实例上的领先。不同求解器计时取决于硬件。

## 213 · Efficient Continuous-Depth Modeling with GRU Equivalents

[原文](https://proceedings.mlr.press/v306/banerjee26b.html)

<a id="banerjee26b-modules"></a>

**技术主题** · 连续深度模型

- **问题 / 瓶颈** · 连续深度网络常为许多隐藏单元分别数值积分非线性 ODE，训练及推理的延迟和能耗随连续层数及隐藏宽度增长。
- **核心创新 / 方法** · CoDA 用 Mori–Zwanzig/Koopman 构造把 H 个原始单元替换为 P 个紧凑 GRU 单元、一个低维线性 ODE 和稠密读出。线性 ODE 用矩阵指数求解，端到端反传，并分析 PAC 可学性。
- **Baseline** · 改进来源为压缩连续状态并把大量非线性积分换成线性低维演化。实验对照为原 LTC-NN、GRUFlow、NODE、LSTM、模型降阶和变分 NODE。
- **Benchmark** · LFM2-1.2B 在 WildChat/AID 场景，另有六类时序任务及服务器 GPU、移动 GPU、FPGA 比较。测损失、训练和推理时延、电能。大模型把 H=1,024 的连续层替换为 P=16。
- **关键结果 / 消融** · LFM2-1.2B 训练加速 6.7±1.1×，测试加速 1.8±0.3×。表 2 中测试时间 LTC 为 34.65 秒、CoDA 为 19.24 秒，测试损失从 4.1308 降为 4.0191，论文判两者统计等效。
- **适用条件 / 局限** · 加速取决于 P、层结构、线性求解和硬件实现。大模型只展示指定液体骨干，与量化或额外模型降阶的组合尚未测试。

## 216 · Adversarially Robust Approximate Furthest Neighbor

[原文](https://proceedings.mlr.press/v306/banihashem26b.html)

<a id="banihashem26b-theory-statistics"></a>

**技术主题** · 自适应近似检索

- **问题 / 瓶颈** · 近似最远邻索引通常对固定查询给概率保证。查询者若根据先前答案挑选下一个点，随机投影索引可能不再正确。
- **核心创新 / 方法** · 先为单个查询的随机投影构造带余量的成功条件，用由数据直径决定的覆盖把保证延伸至查询空间，再从独立副本抽取小批候选，用精确或抗自适应的近似距离选择最远点。
- **Baseline** · 改进来源为由单点投影保证导出覆盖上的高概率同时保证。理论对照为 Indyk 的非自适应最远邻及稳健距离估计后全扫描。
- **Benchmark** · 固定 n 个 d 维欧氏点，评估对适应以往答案的查询序列的高概率近似、查询时间、预处理和空间，并构造旧索引失败的查询。
- **关键结果 / 消融** · 定理 1.1 的 c 近似查询时间为 Õ(d n^(1/c²))。允许 c(1+ε) 近似时是 Õ(n^(2/c²)+d)，对照稳健距离估计全扫为 Õ(n+d)。第二种改进在 c>√2、d=o(n) 时为次线性。
- **适用条件 / 局限** · 更快的方案牺牲 ε 近似余量，两种均需 Õ(d² n^(1+1/c)) 预处理且有额外空间成本。保证针对固定数据集上的查询自适应。

## 298 · Temper-Then-Tilt: Principled Unlearning for Generative Models through Tempering and Classifier Guidance

[原文](https://proceedings.mlr.press/v306/block26a.html)

<a id="block26a-inference"></a>

**技术主题** · 生成式模型遗忘

- **问题 / 瓶颈** · 遗忘样本集中于尖锐的小区域时，怎样防止有限样本分类器低估应去除的生成概率？
- **核心创新 / 方法** · T3-Unlearning 冻结原模型，在推断时先用温度压低分布尖峰，再以保留与遗忘样本训练的轻量分类器估计密度比并倾斜生成分布。
- **Baseline** · 改进来源：密度比估计和分类器引导。实验对照：GradAscent、GradDiff、RMU、ULD、NPO、SimNPO 等，并和原模型比较。
- **Benchmark** · TOFU 上使用 Llama 3.1 8B，测试不同遗忘比例及五次试验均值；指标含 Forget Quality、MU-ROUGE、Model Utility、训练参数量和耗时。
- **关键结果 / 消融** · 5% 遗忘集上，T3 的 FQ/MU-ROUGE/MU 为 0.914/0.900/0.612，SimNPO 为 0.745/0.786/0.653；理论在支持不交的构造下界定未调温法的遗忘误差。
- **适用条件 / 局限** · 温度过高可引入保留偏差；方法限制部署时生成，原模型权重中仍可能保存相关信息，实验主要基于 TOFU。
