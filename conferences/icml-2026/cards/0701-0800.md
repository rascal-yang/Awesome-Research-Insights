## 703 · Entropic Mirror Monte Carlo

[原文](https://proceedings.mlr.press/v306/cherradi26a.html)

<a id="cherradi26a-theory-statistics"></a>

**技术主题** · 重要性采样的熵镜像更新

- **问题 / 瓶颈** · 目标密度多模态时，重要性抽样提案易失配，局部 MCMC 又可能探索不足。
- **核心创新 / 方法** · EM²C 在概率测度上交替使用熵镜像更新和随机游走或 ULA 探索，再对采样云延迟加权和重采样。
- **Baseline** · 改进来源为序贯 Monte Carlo、镜像下降及局部 Markov 核。实验对照含 MALA、DiGS，以及 EM²C 的不同运动核。
- **Benchmark** · 10/20 维四峰高斯混合、Dual Moons、Two Rings 及贝叶斯神经网络；指标为切片 Wasserstein 距离、能量距离与预测 NLL。
- **关键结果 / 消融** · BNN 的 EM²C 预测 NLL 为 0.1294±0.0707，DiGS 为 0.2016±0.0128，MALA 为 0.2219±0.0170。理论分离理想更新收缩和 ULA 离散化误差。
- **适用条件 / 局限** · 作者指出实践中探索权重的调度仍需启发式设定，收缩证明以理想化更新为对象，高维适用性仍需验证。

**原文定位** · [算法（PDF 第 4 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/cherradi26a/cherradi26a.pdf#page=4) · [定理 3.3（PDF 第 5 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/cherradi26a/cherradi26a.pdf#page=5) · [表 2–3、局限（PDF 第 9 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/cherradi26a/cherradi26a.pdf#page=9)

**可复用机制** · 在概率测度中以熵镜像更新调权，并交错粒子探索和延迟重采样，可在利用权重信号时保持采样多样性。

## 704 · Unveiling the Potential of Quantization with MXFP4: Strategies for Quantization Error Reduction

[原文](https://proceedings.mlr.press/v306/chhugani26a.html)

<a id="chhugani26a-inference"></a>

**技术主题** · MXFP4 的溢出感知缩放

- **问题 / 瓶颈** · 面向推理的 OCP MXFP4 以共享低精度尺度压缩权重和激活，异常值会放大误差。
- **核心创新 / 方法** · OAS 按溢出代价选择二次幂尺度，MBS 用较粗粒度的高精度宏块尺度扩展范围；联合做软件量化和张量核设计。
- **Baseline** · 改进来源为 OCP MXFP4 的微缩放格式。实验对照为原版 MXFP4、NVFP4、BF16，并分解 OAS 和 MBS。
- **Benchmark** · 在 Llama-3.1-8B、Qwen3-8B、DeepSeek-R1 等模型上评估知识、数学和推理任务得分及 GEMM 开销，另估算张量核面积。
- **关键结果 / 消融** · 论文报告 MXFP4 对 NVFP4 的平均精度差从约 10% 缩至不足 1%，GEMM 平均开销 6.2%，并报告相对 NVFP4 约 12% 的张量核面积节省。
- **适用条件 / 局限** · 开销依赖张量核实现及宏块配置；精度结论来自论文的模型、任务与推理量化设定。

## 707 · Quadratically Regularized Optimal Transport: Localization Bounds and Affine Case Analysis

[原文](https://proceedings.mlr.press/v306/chi26c.html)

<a id="chi26c-theory-statistics"></a>

**技术主题** · 二次正则最优传输的支撑局部化

- **问题 / 瓶颈** · 二次正则最优传输的耦合随正则趋零时收敛到经典传输，但支撑集合靠近传输图的速率需要单独刻画。
- **核心创新 / 方法** · 从正则化目标差控制到 Brenier 图的平方距离，再由密度和支撑几何推导距离下界；仿射 Brenier 映射时约化为自传输给出上界。
- **Baseline** · 改进来源为二次正则 OT 与自传输支撑局部化分析。实验以仿射合成例的支撑偏差和理论幂律相比较。
- **Benchmark** · 有界边缘分布与满足相应正则条件的 Brenier 映射；考察到图的均方偏差和有向 Hausdorff 距离，补充二维等仿射数值例。
- **关键结果 / 消融** · 平方偏差量级上界为 O(ε^(2/(d+2)))，给出支撑有向 Hausdorff 偏差的 Ω(ε^(1/(d+2))) 下界；仿射情形取得同阶上界。
- **适用条件 / 局限** · 依赖边缘及映射的正则条件。作者指出一般非仿射映射下匹配的支撑上界仍未解决。

**原文定位** · [定理 3.3（PDF 第 4 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/chi26c/chi26c.pdf#page=4) · [定理 3.6–3.7（PDF 第 5 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/chi26c/chi26c.pdf#page=5) · [图 1 数值验证（PDF 第 8 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/chi26c/chi26c.pdf#page=8) · [结论（PDF 第 9 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/chi26c/chi26c.pdf#page=9)

**可复用机制** · 将二次正则目标差转成到最优传输图的距离，可在仅有边际密度与几何时判断正则计划扩散到哪里。

## 708 · Unifying and Optimizing Data Values for Selection via Sequential Decision-Making

[原文](https://proceedings.mlr.press/v306/chi26d.html)

<a id="chi26d-data-strategies"></a>

**技术主题** · 训练样本选择的二部图覆盖

- **问题 / 瓶颈** · 按单条样本的数据价值排序会忽略训练数据之间的冗余，尤其当选取预算与样本替代性变化时。
- **核心创新 / 方法** · 将选子集表为有限时域决策，解释若干半值为线性近似，再用二部图覆盖代理保留边际收益递减结构并做贪心选择。
- **Baseline** · 改进来源为 Data Shapley、Banzhaf、Beta Shapley 等估值代理。实验对照还含 DataOob、随机、RDS+ 及线性和 MLP 效用近似。
- **Benchmark** · 八个经典分类数据集考察所选子集的测试准确率与代理 MSE；DATE-LM 从 20 万条中取 1 万条 LoRA 微调 Llama-3.1-8B，测 MMLU、GSM8K、BBH。
- **关键结果 / 消融** · 二部图代理测试 MSE 0.019，线性回归 0.089；DATE-LM 平均准确率 63.89±0.34%，RDS+ 为 62.88±0.25%。理论给出半值排序的曲率依赖下界。
- **适用条件 / 局限** · 理论保证依赖归一化、单调次模及曲率。实验以替代性代理而非精确曲率分析退化，LLM 结果来自一个模型和基准。

**可复用机制** · 把数据子集价值建成有限时域决策，并用保留边际递减性的二部覆盖替代组合搜索，可据互补性而非孤立分数选择样本。

## 709 · Privacy Amplification in Differentially Private Zeroth-Order Optimization with Hidden States

[原文](https://proceedings.mlr.press/v306/chien26a.html)

<a id="chien26a-theory-statistics"></a>

**技术主题** · 零阶优化的迭代隐私放大

- **问题 / 瓶颈** · 只发布模型的最后一次迭代时，按全部迭代公开来做差分隐私会高估零阶优化的隐私支出。
- **核心创新 / 方法** · Noisy-ZOGD 沿随机正交方向估计有限差分，叠加方向噪声与小幅各向同性噪声；用辅助耦合拆开总变差失败概率和 Rényi 散度。
- **Baseline** · 改进来源为零阶 DP 梯度下降与迭代隐私放大。数值对照为标准组合和直接输出扰动。
- **Benchmark** · 有界域内光滑 Lipschitz 经验风险最小化，覆盖凸、强凸及非凸；绘制 ε 随步数、每步方向数等变化。
- **关键结果 / 消融** · 定理 3.2 给出包含耦合失败概率的 (ε,δ)-DP 界，强凸时推得闭式界；相比标准组合，隐藏状态的界可饱和，正交多方向在固定效用下改善界。
- **适用条件 / 局限** · 保证针对最终状态发布，依赖光滑、有界等条件；一般最优界需解约束优化，闭式结果要求强凸等额外假设。

**可复用机制** · 用辅助耦合分别界定隐状态分离概率和条件 Rényi 散度，可分析只发布末态的零阶优化隐私放大。

## 711 · Modeling Covariate Transition for Efficient Estimation of Longitudinal Treatment Effects in Randomized Experiments

[原文](https://proceedings.mlr.press/v306/chihara26a.html)

<a id="chihara26a-theory-statistics"></a>

**技术主题** · 协变量转移与纵向处理效应

- **问题 / 瓶颈** · 随机 A/B 试验重复测量同一用户时，如何利用随时间变化的协变量和中间结果，更精确地估计各日处理效应？
- **核心创新 / 方法** · 拟合随时间变化的结果与协变量转移核，用前向积分构造动态回归调整，再做正交矩与交叉拟合以控制干扰函数误差。
- **Baseline** · 改进来源为随机实验回归调整和正交化。实验对照含未经调整的经验估计、线性滞后调整及 RF-VAR。
- **Benchmark** · 模拟线性和非线性轨迹、样本量 500/1000/2000；另用流媒体 10 日推荐 A/B 试验，测逐日观看时长效应的 RMSE、标准误及置信区间。
- **关键结果 / 消融** · 适当正则条件下估计量渐近正态并达到半参数效率界。真实试验的逐日标准误比未调整估计低约 0.4%–20.4%。
- **适用条件 / 局限** · 作者假定完全依从和无干扰，指出时间变混杂、潜在状态及其他随机化设计需另行处理。

## 712 · Efficient and Minimax Optimal In-context Nonparametric Regression with Transformers

[原文](https://proceedings.mlr.press/v306/ching26a.html)

<a id="ching26a-theory-statistics"></a>

**技术主题** · Transformer 的局部多项式回归

- **问题 / 瓶颈** · Transformer 用有限上下文示例学习 Hölder 非参数回归时，能否以更小架构和预训练样本量达到极小极大速率？
- **核心创新 / 方法** · 用 Transformer 实现核加权局部多项式的特征计算和迭代最小二乘，再分析有限任务序列上的经验风险最小化。
- **Baseline** · 改进来源为局部多项式估计和线性注意力。理论比较 Shen 等与 Kim 等的 Transformer 构造，实验对照为局部多项式。
- **Benchmark** · 理论按平滑度 α、输入维数 d 和示例数 n 评估超额平方风险；模拟用随机 Fourier 任务、d=3、α=3、n=15–35。
- **关键结果 / 消融** · 达 O(n^−(2α/(2α+d))) 风险，模型参数 Θ(log n)，预训练序列取 Ω(n^(2α/(2α+d)) log³ n) 即足够。
- **适用条件 / 局限** · 速率针对论文的有界 Hölder 回归及设计分布条件，预训练结论基于经验风险最小化。数值验证为构造的回归任务。

- **核心创新 / 方法** · TAG 用中间样本估计径向和切向，把打分更新投影并放大切向分量，可附加到现成引导而无需额外模型求值。

- **适用条件 / 局限** · 作者指出理论只刻画局部一阶变化，径向/切向近似可能遗漏复杂流形结构，完整反向轨迹仍需研究。

- **核心创新 / 方法** · RESTORE 根据被删 token 的相对距离为保留 token 补偿注意力，并为合并筛选既有代表性又少冗余的锚点。

- **适用条件 / 局限** · 结论限于所测模型、注意力结构和 token 压缩设置；单项任务得分并非均有改善。

## 717 · GAAVI: Global Asymptotic Anytime Valid Inference for the Conditional Mean Function

[原文](https://proceedings.mlr.press/v306/cho26c.html)

<a id="cho26c-theory-statistics"></a>

- **Baseline** · 改进来源为带预测的 ski rental。理论参照已知真分布的最优策略；实验对照包括从预测分布抽点后使用点预测算法。
- **Benchmark** · 理论以购买价 b、Wasserstein-1 误差 η 和期望额外成本衡量；双峰合成例 b=100，20 万次 Monte Carlo。
- **关键结果 / 消融** · 额外成本 O(min{√b·max(η,1),b log b})，且 O(√b) 一致性迫使某些大误差具有 Ω(b log b) 额外成本。η=10 时成本 90.14，点预测为 132.59，最优为 80。
- **适用条件 / 局限** · 适用范围为论文的分布式租赁决策及其成本模型；实验是小型双峰模拟，作者用作理论的数值检验。

- **问题 / 瓶颈** · 采用平方损失的公平回归面对重尾噪声及群体条件分布差异时，如何使用稳健损失仍保证人口统计平等？
- **核心创新 / 方法** · 将各组预测值转成组内分位，再映射到风险最优的共享分位函数；用插值调节风险与不公平度，并按合法协变量分层处理条件平等。
- **Baseline** · 改进来源为分位变换和公平 Wasserstein 重心。实验对照为稳健深网 RDNN 与 FRWB。
- **Benchmark** · 模拟重尾回归及 1,994 个美国社区的 CRIME 数据，比较 Cauchy、Huber、LAD、分位数、Tukey 损失的经验风险和不公平度。
- **关键结果 / 消融** · CRIME 的 LAD 风险为 0.1294，不公平度为 0.0093；FRWB 为 0.1330、0.0615。理论给出秩保持预测器中的风险最优性与插值不公平度线性。
- **适用条件 / 局限** · 保证需要组内预测分布连续及相应风险条件；人口统计平等按所选敏感属性度量，条件扩展的实现按有限分层。

## 799 · Hard Labels In! Rethinking the Role of Hard Labels in Mitigating Local Semantic Drift

<a id="cui26g-training-strategies"></a>

**技术主题** · 稀疏软标签的硬标签校准

- **问题 / 瓶颈** · 预计算软标签时若每张图仅保留少数裁剪，教师可能把局部歧义的标签偏差反复传给学生，降低测试表现。
- **核心创新 / 方法** · HALD 先用有限软标签训练，在中间阶段重新采样裁剪与 CutMix，以图像级硬标签做重平滑的校准，最后回到原软标签细化。分析两类梯度一致性如何补足稀疏监督。
- **Baseline** · 改进来源为 SRe²L 与 LPLD 的存储式软标签数据蒸馏。实验对照含 RDED、FADRM、LPLD、仅软标签和等存储条件。
- **Benchmark** · 在 Tiny-ImageNet、ImageNet-1K、CIFAR-100 和 ImageWoof 评估分类准确率，对比每类样本量、每图软标签数、存储容量与裁剪策略。
- **关键结果 / 消融** · ImageNet-1K 每类 50 图、软标签存储 285M 时，HALD 为 42.7%，LPLD 为 33.7%，高 9.0 个百分点。95M 时为 36.9% 对 14.3%。
- **适用条件 / 局限** · 依赖可靠的全图类别标签和经过校准的平滑强度。理论方差下降依赖软硬梯度对齐，局部裁剪完全缺失类别语义时仍有歧义。
