## 4502 · Rethinking 1-bit Optimization Leveraging Pre-trained Large Language Models

[原文](https://proceedings.mlr.press/v306/tu26b.html)

<a id="tu26b-optimization"></a>

**技术主题** · analytic-plus-learned-binary-scaling

- **问题 / 瓶颈** · 预训练模型二值化时，将每步最小二乘解析幅度直接替换为可学习尺度可能破坏归一与稳定性。
- **核心创新 / 方法** · 仅保留dual-scale：每步按权重均值绝对值计算Sa，以W/Sa输入平滑二值函数，输出乘Sa及初始化为1的可学习同形Sl，即Wb=Sl×Sa×F(W/Sa,t)。Sa负责归一和近似幅度，Sl补偿任务误差；推理合并两尺度。
- **Baseline** · 平滑tanh前后向continuation已见Self-Binarizing Networks PDF2–4，不是本文首次；本文FBI-LLM式学习尺度Sl替换解析Sa为近对照。表5单独比较只Sa、只Sl、Sa×Sl；IR-Net梯度对照不能证明continuation新颖。
- **Benchmark** · 局部核心证据为Pythia70M相同二值训练下的Wiki2/C4/PTB PPL表5；大规模SmolLM/Pythia/Llama主表包含不同起点与预算，仅作适用范围。
- **关键结果 / 消融** · PDF8表5只Sa/只Sl/Sa×Sl的平均PPL75.5/77.0/70.9，Wiki2为73.1/76.2/68.7，C4为54.8/58.5/51.5，PTB98.7/96.4/92.5；证明局部参数化收益，不证明泛化理论或所有模型最优。
- **适用条件 / 局限** · 窄二值训练优化技巧，两尺度推理可合并但训练梯度参数化不同；完整表5证据限70M。tanh(t)归一可使近线性起步，但未与Self-Binarizing/adiabatic continuation直接消融；跨层初始化Eq8印作argmin sum logp有符号歧义且无独立控制，不作收录机制。主表非等总预训练预算。

## 4503 · DyCon: Dynamic Reasoning Control via Evolving Difficulty Modeling

[原文](https://proceedings.mlr.press/v306/tu26c.html)

<a id="tu26c-inference"></a>

**技术主题** · stepwise-difficulty-control

- **问题 / 瓶颈** · 静态难度估计无法追踪中途已解决问题后的冗余反思。
- **核心创新 / 方法** · 600道MATH轨迹记录步边界隐藏态与剩余长度；log归一化长度作代理标签拟合ridge线性探针；推理时按难度调整反思token logit惩罚。
- **Baseline** · 来源为关键词抑制/早停；增量是动态步骤难度信号；比较TrimR、FlashThink、ThinkPilot等，未开源者由作者重实现；有探针目标和动态控制消融。
- **Benchmark** · 4B–32B四个模型，数学/常识问答/代码共12基准；准确率、token长度与效率权衡。
- **关键结果 / 消融** · PDF7表2 R1-Distill-Qwen-7B在GPQA-D准确率38.4→47.0%，tokens7518→5304（-29.4%）；LiveCodeBench准确率57.5→57.0%，tokens8504→8061（-5.2%），并非各任务无损。PDF5说明基础模型冻结但需要拟合探针。
- **适用条件 / 局限** · 剩余长度是原模型行为代理，不是客观难度；依赖隐藏态与特定反思词表，超出模型/语言/解码设置须重校准；节省token不保证等比例墙钟收益。

## 4504 · Unifying Heterogeneous Degradations: Uncertainty-Aware Diffusion Bridge Model for All-in-One Image Restoration

[原文](https://proceedings.mlr.press/v306/tu26d.html)

<a id="tu26d-training-strategies"></a>

**技术主题** · uncertainty-modulated-bridge

- **问题 / 瓶颈** · 统一恢复不同退化时固定桥路径无法兼顾高低不确定区域。
- **核心创新 / 方法** · 冻结初步恢复器残差的一半绝对值作不确定性代理；放宽低质端为高斯分布，以像素不确定性联合调噪声幅度与传输路径，训练一步恢复。
- **Baseline** · 来源为扩散桥、熵正则OT；不同于固定终端/固定日程；比较其他恢复器及固定路径、固定终端松弛、BayesCap等不确定估计。

- **适用条件 / 局限** · 残差代理不是校准后验不确定性；HJB/熵屏障论证不等于学习轨迹达到OT最优，保留有消融支持的日程机制；初步恢复器有额外成本，单步不等于全流程只一次网络。

[原文](https://proceedings.mlr.press/v306/tuo26a.html)

<a id="tuo26a-optimization"></a>

**技术主题** · time-shared-ssm-pruning

- **问题 / 瓶颈** · 普通一次性剪枝忽视Alog时间共享与离散化敏感性。
- **核心创新 / 方法** · 仅提取近似显著性：用离散转移平方与隐状态平方的逐时统计、前缀偏置时间权重聚合选择mask。未结构化版先置零Alog；作者model/mamba.py在args.ppl路径另以(A!=-1)显式mask离散deltaA。结构化扩展实际删state列，并同步裁x_proj中的B/C行、修改d_state。

- **适用条件 / 局限** · PDF4 Eq2的Alog=-log(A)与标准A=-exp(Alog)不一致；Alog=0仅使A=-1，本身不删转移。代码显式deltaA mask受args.ppl条件，其他评估路径是否一致尚不明确。状态矩阵对角不推出共享参数输出Hessian无交叉项，显著性只作近似，不能宣称OBS无误差补偿为精确。结构化删列与未结构化评分有别，不等于全模型减半。
