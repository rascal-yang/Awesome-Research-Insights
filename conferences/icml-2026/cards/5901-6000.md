## 5901 · Interpreting and Enhancing Emotional Circuits in Large Vision-Language Models via Cross-Modal Information Flow

[原文](https://proceedings.mlr.press/v306/zhang26fi.html)

<a id="zhang26fi-evaluation"></a>

**技术主题** · 情绪头的中层选择性与深层共享性

- **问题 / 瓶颈** · 情绪输出分散、视觉counterfactual少，输出词概率难区分视觉聚合与语言表达。
- **核心创新 / 方法** · 用情绪/中性配对隐藏差筛成功样本得steering方向；逐层注入定位pivot，再对方向cosine作head patching并回溯neuron；按视觉routing加强及语义neuron激活做inference intervention。
- **Baseline** · activation steering、patching、saliency/logit lens为来源；实际比较random同规模head/neuron、VEE/ENA单组件及既有方法。暂定独立增量为中层情绪特异/深层共享的有干预失效规律及分离控制，先例待核。
- **Benchmark** · Qwen3-VL4B-Instruct为主，配对情绪/中性描述探针、四basic emotions；MER-UniBench九子集，hit rate、sentiment WAF、fine-grained Fs，3seeds；latency与selected-head规模消融。
- **关键结果 / 消融** · 作者pivot约l19、final l35的head交集不同；同规模随机干预效果较小。MER-UniBench混合metric平均58.1→64.8即6.7点，VEE/ENA约+3.7/+3.2；top10heads优于top30的MER2023，扩大干预非单调获益。
- **适用条件 / 局限** · 局部patch证明所测激活对输出有作用，不认证自然样本的唯一因果链或真实内在情绪。方向cosine/gradient和attention map均代理，hit-filter有选择偏差；九任务异质metric均值非同一accuracy，效应层/通路跨backbone和非情绪task副作用待核。

## 5903 · Functional building blocks of neural networks: from network motifs to collective dynamics

[原文](https://proceedings.mlr.press/v306/zhang26fk.html)

<a id="zhang26fk-loss-functions"></a>

**技术主题** · 三节点motif比例的任务相关正则

- **问题 / 瓶颈** · 单一谱约束难反映局部连接构型如何影响噪声抑制与动态适应。
- **核心创新 / 方法** · 13种有向三节点motif按局部线性化稳定条件分三层；以sigmoid(β(W²−θ))软邻接计数，训练时偏好指定motif类别分布，再比较噪声分类与连续控制表现。
- **Baseline** · network motifs、local Jacobian stability和低秩RNN为来源；实际比较vanilla RNN、LSTM、low-rank及spectral normalization，并比较三种motif层级。暂定增量为可微motif比例训练与任务依赖的抗噪/适应规律，最近先例待核。
- **Benchmark** · PDM/TIDIGITS/MNIST increasing Gaussian noise分类accuracy；InvertedPendulum-v2/Ant-v2 RL return和convergence时间，另低秩latent trajectories；初始化/参数量和训练budget控制待核。
- **关键结果 / 消融** · L1 MNIST平均噪声accuracy67.0±3.4%；L3 Ant在2Msteps2725±233.5对vanilla1961.1±133.8，5M4258±166.6对2882.1±243.9。InvertedPendulum LSTM与L3均ceiling，L3训练收敛158.61s对vanilla224.99s，非所有metric独占。
- **适用条件 / 局限** · 三节点平衡点局部Jacobian足够条件不推出任意大RNN全局稳定；motif拓扑忽略连接符号/尺度，W²软化与真实count有差。较多循环可能改变其他图统计，需匹配density/spectral radius/optimizer；模体统计开销和跨任务最优比例待核。

## 5907 · FlowPET: Physics-Informed Symplectic Flow Matching for Low-Count PET Reconstruction

[原文](https://proceedings.mlr.press/v306/zhang26fo.html)

<a id="zhang26fo-architecture"></a>

**技术主题** · 分离相空间流的逆问题重建

- **问题 / 瓶颈** · 高噪声图像逆问题中的细微结构易被重建模型平滑，常规flow可能缺显式观测算子偏置。
- **核心创新 / 方法** · 扩展z=(x,p)，位置速度只依p、动量速度只依x，用双网络回归边界直线路径速度，半kick/full drift/半kick积分；边界含Aᵀ数据残差和(I−A†A)投影noise，学习分离transport。
- **Baseline** · Hamiltonian/separable shear flow、flow matching与range-null inverse problems为来源；实际比较OSEM/CNN、IR-SDE、DREAM/FourierPET等及两种边界分量消融。暂定增量是分离phase-flow的边界训练接口，最近原作待核。
- **Benchmark** · PET BrainWeb20%count、In-House wholebody1%、UDPET brain1%；SSIM/PSNR/RMSE，boundary/scale消融和图像例。只取通用图像inverse-problem机制，无生物序列/实验设计操作。
- **关键结果 / 消融** · BrainWeb PSNR36.34对FourierPET35.36，但SSIM .9838低其.9859；UDPET PSNR28.88对DREAM28.49。双边界In-House PSNR36.35略低仅restoring36.36，SSIM .9811较高；无统一每指标最优。
- **适用条件 / 局限** · 扩展相空间divergence-free/单位det不能保证位置边缘不塌缩或弱信号保真；初始range/null并不约束后续速度严格Ax=y。第7页说直接U-Net近似两向量场梯度，若无curl-free约束未必Hamiltonian/symplectic，虽分离shear可保体积；FBP是否真A†、Poisson改L2及posterior校准待核。

## 5908 · HodgeFlow Policy Search by Topologically Dissecting Temporal-Difference Signals in Non-Markovian Environments

[原文](https://proceedings.mlr.press/v306/zhang26fp.html)

<a id="zhang26fp-loss-functions"></a>

**技术主题** · 辅助potential投影的TD更新

- **问题 / 瓶颈** · 观测混叠和隐含执行记忆使原始TD信号高方差，直接semi-gradient更新可能不稳。
- **核心创新 / 方法** · 用V构δ=r+γV(s′)−V(s)，U拟合δ≈U(s′)−γU(s)，批次loss为平方残差；以拟合量替代原δ更新value及可选policy，log残差为diagnostic，需同时训练额外U。
- **Baseline** · least-squares potential projection、Hilbert orthogonal projection及TD为来源；实际比较DQN/Double/Dueling、A2C/PPO、DRQN/ADRQN/R2D2。暂定增量为拟合分量替代TD的独立控制目标，最近residual-gradient先例待核。
- **Benchmark** · LunarLander/Acrobot/Pendulum/PointMass/BipedalWalker，隐藏actuation-memory Nonmarkov wrapper，另Clean/Noisy/Sticky待核；return AUC@T与Final@T、seed均值方差；synthetic ring的linear MSVE/投影残差。
- **关键结果 / 消融** · Nonmarkov LunarLander Final145.6±12.9低DRQN169.1±3.1，但AUC107.6±2.1高93.1±11.8（表单位×10^6）；Pendulum Final−106.2对DRQN−235.8。不是全任务最终return更高，Acrobot final低于部分DQN。
- **适用条件 / 局限** · dU=U(s′)−γU(s)与通常γU(s′)−U(s)方向不同，折扣图梯度不自动有无权cycle积分解释；Markov只给条件平均Bellman零，不保逐transition exact。LS投影稳定性需closed range/全局最优/固定π，经验replay与非平稳π未自动满足；不能称恢复隐藏状态或保证POMDP最优。

## 5909 · Scaling Laws for Precision in High-Dimensional Linear Regression

[原文](https://proceedings.mlr.press/v306/zhang26fq.html)

<a id="zhang26fq-theory-statistics"></a>

**技术主题** · 量化噪声几何改变模型与样本有效规模

- **问题 / 瓶颈** · 经验precision scaling把量化都当同一种容量收缩或误差地板，缺噪声几何条件。
- **核心创新 / 方法** · 在高维sketched linear regression与SGD下，对data/sketch/feature/parameter/activation/output梯度六处量化的二阶矩分别建模；谱幂律与协方差可交换条件下推导risk上下界，把误差组合为Neff、Meff及加性floor。
- **Baseline** · 高维线性SGD、sketch regression及empirical precision scaling为来源；实际比较是条件上/下界与合成谱数值，不是LLM量化SOTA。暂定增量为两类噪声的分解与尺度选择边界，最近quantized linear regression先例待核。
- **Benchmark** · 多项式协方差谱a=1.5/2，p=1000/10000，sketch model size M与sample N扫描；excess population risk vs effective M/N，γ=.1；可条件用于冻结神经特征凸输出层，非已验证深网端到端迁移。
- **关键结果 / 消融** · 合成拟合risk随Neff斜率约−.34/−.50、随Meff约−.50/−1，R²>.99。乘性上界Meff=M，加性上界有收缩因子；但加性lower theorem4.4仍用Meff=M，且upper/lower errorfloor不完全匹配，不能称严格证明同一有效容量律。
- **适用条件 / 局限** · 噪声须满足给定矩阵二阶矩上下界及无偏等假设；逐坐标float误差通常不等rank-one xxᵀ噪声，INT/FP标签只是启发。可交换谱、步长与两种M/N渐近区间限制，p/M可能放大量化参数；图中量化强度两类不同，不是同bit硬件公平比较，常数/适用边界待核。

## 5910 · TokenSwap: Backdoor Attack on the Compositional Understanding of Large Vision-Language Models

[原文](https://proceedings.mlr.press/v306/zhang26fr.html)

<a id="zhang26fr-evaluation"></a>

**技术主题** · 词汇相近时的关系完整性防御评测

- **问题 / 瓶颈** · 常规后门审查依赖固定输出模式或明显文字异常，关系错置可能保留大多数对象词。
- **核心创新 / 方法** · 把对象词保留但关系改变作为失效类别，分开测异常输入关系错误率与正常输入caption质量，跨数据/模型检查检测盲区，并比较增加clean数据与单纯延长finetuning的修复效果。卡仅整理防御评价规律，不提供注入或训练步骤。
- **Baseline** · backdoor/poisoning robustness与compositionality evaluation为来源；实际比较BadNet/Blended/SIG/TrojVLM等，具体threat capability不同；暂定增量为词汇近似下的组合语义失效证据，最近关系型后门先例待核。
- **Benchmark** · BLIP2/InstructBLIP/LLaVA7/13B/QwenVL2.5 7B；Flickr8k/30k/MSCOCO，in/cross-dataset；relation ASR与clean BLEU/ROUGE1/L、clean微调修复。ASR按主客体关系错误定义，非传统目标短语率。

## 5913 · Generative Online Reinforcement Learning

[原文](https://proceedings.mlr.press/v306/zhang26fu.html)

<a id="zhang26fu-training-strategies"></a>

**技术主题** · 交替优化latent policy并把改进蒸馏到固定prior decoder

- **问题 / 瓶颈** · 直接更新多步生成policy难算likelihood，持续改变latent输入也会使decoder目标漂移。
- **核心创新 / 方法** · GoRL identity-like decoder起步；phase1只latent PG，phase2冻结policy并用最近rollout的state/action分布做standard FM/diffusion训练，输入fresh Gaussian prior；每stage encoder reset。
- **Baseline** · latent-action policies、generative BC及交替蒸馏已有；候选为fixedprior consolidation/reset的可复用在线训练协议，最近原作与独立控制待核。
- **Benchmark** · DMControl CheetahRun/FingerSpin/FingerTurnHard/FishSwim/HopperStand/WalkerWalk，180Msteps/5seeds；HumanoidStand/Run21actions，对GaussianPPO/FPO/DPPO，return。
- **关键结果 / 消融** · PDF6相同main interaction budget，decoder边界60/120/150M；摘要HopperStand>870与3×优势，完整表/decoder额外rollout是否计预算待核。latent KL控制只对decoder固定阶段成立。

- **Benchmark** · lower及hρ均µPL、mean-square smooth、二阶导Lipschitz、upper梯度有界、固定symmetric doubly stochastic network；a9a/w8a/covtype/MNIST hyperparameter和model pruning；outerloss/gradient norm vs iteration，pruning指标待核。
- **关键结果 / 消融** · 作者复杂度O(κ^9/[K(1−λ)²ε^5])，K为workers，非多层数；第8页曲线支持较快降outerloss，未估数值。baseline completegraph、自己的通信图不同，调参ρ敏感，不能以iteration图直接证明等通信/时间优势。
- **适用条件 / 局限** · g PL不推出g+ρf PL，需共同满足；全DNN模型剪枝实验不认证全局PL。无Hessian计算不等无二阶正则性假设，ρ→0放大噪声/步长约束，κ^9与ε^−5可能高成本；optimistic solution selection及∇L存在的附加条件待核。
