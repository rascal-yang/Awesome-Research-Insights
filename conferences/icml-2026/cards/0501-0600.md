## 501 · Data-driven Mixed Integer Optimization through Probabilistic Multi-variable Branching

[原文](https://proceedings.mlr.press/v306/chen26ah.html)

<a id="chen26ah-optimization"></a>

**技术主题** · 混合整数规划分支

- **问题 / 瓶颈** · MIP 的二元预测即使单变量很准，逐一固定多个变量也可能很快排除最优解。需要把离线经验转成对分支定界有用的子区域。
- **核心创新 / 方法** · PMVB 对高置信为 0/1 的变量按组汇集概率，在和上施加一侧界，构造划分可行域的多个分支超平面。可作为原始启发式，也可用 LP 内点解做代理概率。
- **Baseline** · 改进来源为用组和聚合不确定预测。实验对照为原 Gurobi/COPT 求解、黑盒多分支、单独优先启发式及无训练 LP 版本。
- **Benchmark** · 集合覆盖 SCP、组合拍卖 CA、多重背包 MKP、MIPLIB 与真实实例。按移位几何平均求解时间和加速比比较，MIPLIB 设 3,600 秒限制。
- **关键结果 / 消融** · 表 1 中 MKP m=30、n=500 的原求解时间 1,283 秒，PMVB 为 979 秒（1.31×）。SCP-V 32.6→27.4 秒。57 个筛选后的 MIPLIB 实例上，δ=10⁻⁸、τ=0.9 的 SGM 加速比为 1.19。
- **适用条件 / 局限** · 概率集中受预测误差依赖及置信设定影响。若仅解首选子问题，仍可能不可行或排除最优解。MIPLIB 汇总排除了不可用实例。

## 503 · Normalizing Flows with Iterative Denoising

[原文](https://proceedings.mlr.press/v306/chen26aj.html)

<a id="chen26aj-inference"></a>

**技术主题** · 归一化流采样

- **问题 / 瓶颈** · 自回归流图像模型在小噪声下优化不稳，大噪声后单次去噪又会模糊。需要在保留似然训练的同时逐步细化样本。
- **核心创新 / 方法** · iTARFlow 用同一个 TARFlow 在连续噪声强度上学习条件似然。采样先自回归生成带噪中间图，再从粗到细利用似然梯度进行迭代去噪。
- **Baseline** · 改进来源为一个似然模型共享多噪声尺度的训练并在生成时逐级去噪。实验对照含 TARFlow、STARFLOW、扩散、相容性及潜自回归方法。
- **Benchmark** · ImageNet 64、128、256 像素测 FID 和参数量，区分像素生成与借助外部 VAE 的潜空间生成，另看去噪过程和伪影。
- **关键结果 / 消融** · ImageNet-64 iTARFlow-B 的 FID 1.68、770M 参数，TARFlow 为 2.66/880M，EDM-SDE 为 1.55/300M。ImageNet-256 潜空间 iTARFlow-B 为 2.32，STARFLOW 为 2.40。
- **适用条件 / 局限** · 去噪的自动微分增加显存，噪声上下界与步数需调，最高质量仍受不稳定或过平滑伪影影响。

**可复用机制** · 单一自回归流跨噪声强度学似然，生成后复用其分数渐次去噪，兼顾流的似然训练与从粗到细恢复。

## 507 · Beyond Two-Stage Training: Cooperative SFT and RL for LLM Reasoning

[原文](https://proceedings.mlr.press/v306/chen26an.html)

<a id="chen26an-training-strategies"></a>

**技术主题** · 监督微调与强化学习协同

- **问题 / 瓶颈** · SFT 和可验证奖励 RL 的方向并非总一致，固定先监督后 RL 或同时加权，可能把学生推向对最终奖励帮助不大的专家分布。
- **核心创新 / 方法** · BRIDGE 交替更新学生主模型和 LoRA 教师。学生用联合 SFT 与 RL 梯度，教师比较联合更新后的奖励与仅 RL 的对照收益，以元目标选择有利的监督。
- **Baseline** · 改进来源为用反事实 RL-only 步评价监督增益。实验对照为单独 SFT/RL、常规 SFT→RL、直接混合、LUFFY、SRFT、CHORD 及元目标消融。
- **Benchmark** · Qwen2.5-3B、Llama3.2-3B、Qwen3-8B 的 MATH-500、Minerva、OlympiadBench、AIME24、AMC23，另评逻辑、代码、科学及噪声奖励。
- **关键结果 / 消融** · Qwen2.5-3B 的五项平均 36.0%，SFT→RL 32.2%、CHORD 32.5%、简单混合 29.4%。AIME24 为 13.3%，两阶段 9.0%，CHORD 6.7%。
- **适用条件 / 局限** · 实验集中在答案可验证、带专家轨迹的数据。辅助学生迭代增加显存，在 70B 以上未直接检验，主观奖励任务也未覆盖。

**可复用机制** · 让监督教师依据联合 SFT/RL 更新相对仅 RL 的实际增益调整，筛选能改善可验证结果的监督。

## 510 · The Unlearnability Phenomenon in RLVR for Language Models

[原文](https://proceedings.mlr.press/v306/chen26aq.html)

<a id="chen26aq-evaluation"></a>

**技术主题** · RLVR 的难学样本

- **问题 / 瓶颈** · 可验证奖励强化学习中，为什么一些困难样本即使出现过正确轨迹，训练结束后仍没有学会？
- **核心创新 / 方法** · 定义训练前后低成功率但有正奖励的样本组，分别改变采样、梯度正则与数据增广，并用正确轨迹的 LoRA 梯度余弦及推理轨迹检查表征。
- **Baseline** · 改进来源：GRPO 与 RLVR 的正奖励采样及样本梯度分析。实验对照：可学习困难题、始终无正奖励题、重放增采、调整裁剪或 KL、增强数据及中期训练模型。
- **Benchmark** · MATH 的不同难度训练集，Qwen2.5-0.5B/3B、Llama3.2-3B-Instruct，三次独立训练；按每题 32 次输出估计 pass@1，另测跨样本梯度余弦。
- **关键结果 / 消融** · 初始成功率低于 10% 的样本中，三个模型不可学习组分别为 30.2%、16.7%、21.9%；该组梯度更不对齐，常规增采、正则变化或增广未消除现象。
- **适用条件 / 局限** · 定义依赖 10% 阈值、训练到何时停止及所测模型；中期训练提高梯度相似度的观察无法单独证明大规模可学习性改善。

**可复用机制** · 单独跟踪偶有正确采样却学不会的低成功率题，再比较成功轨迹的梯度方向，诊断 RLVR 中采到答案仍难学的问题。

## 514 · Do-Prompt: Causal Interventions Meet Variational Prompt Bottlenecks

[原文](https://proceedings.mlr.press/v306/chen26au.html)

<a id="chen26au-loss-functions"></a>

**技术主题** · 多模态提示泛化

- **问题 / 瓶颈** · 多模态提示学习怎样避免用训练环境的纹理或背景捷径，保住新类别和新数据集表现？
- **核心创新 / 方法** · Do-Prompt 把提示表示为随机潜变量，用变分瓶颈限制容量，再扰动环境相关提示成分，对干预前后预测施加一致性。
- **Baseline** · 改进来源：CLIP 多模态提示、变分信息瓶颈和 do 型干预。实验对照：CLIP、CoOp、PromptSRC、MaPLe、MMRL 等及加装 Do-Prompt 的同骨干。
- **Benchmark** · 每类 16 样本的 11 个图像分类集，做基类至新类、跨数据集和 ImageNet-V2/S/A/R 迁移；测分类准确率及基类、新类调和均值。
- **关键结果 / 消融** · MaPLe 加 Do-Prompt 后平均基类/新类/调和均值为 83.82/76.68/80.12，提高 1.79/1.65/1.75 分；ImageNet-A 从 48.80% 升至 50.30%。
- **适用条件 / 局限** · 提示干预是模型空间的构造，不直接识别现实因果关系；实证主要是少样本 CLIP 系图像分类。

**原文定位** · [§4.2–4.4 瓶颈与干预（PDF 第 5 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/chen26au/chen26au.pdf#page=5) · [§5.1 设置（PDF 第 6 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/chen26au/chen26au.pdf#page=6) · [表1（PDF 第 7 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/chen26au/chen26au.pdf#page=7) · [表2–3（PDF 第 8 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/chen26au/chen26au.pdf#page=8)

**可复用机制** · 用变分瓶颈限制提示依赖信息，再干预环境相关潜成分并约束预测一致性，降低跨环境迁移对背景捷径的依赖。

## 515 · Eyes-on-Me: Scalable RAG Poisoning through Transferable Attention-Steering Attractors

[原文](https://proceedings.mlr.press/v306/chen26av.html)

**技术主题** · 检索增强生成安全评测

- **问题 / 瓶颈** · 检索增强生成系统中，一个可复用的污染组件能否把检索器和生成器的注意力引向同一目标？
- **核心创新 / 方法** · Eyes-on-Me 将污染文档划分为可复用注意力引导和可替换目标区域，通过与输出强相关的少数头学习定位偏向，测跨组件转移。
- **Baseline** · 改进来源：RAG 数据投毒与注意力机制诊断。实验对照：GCG、AutoDAN、Phantom、基于 PoisonedRAG 的 LLM-Gen，以及重排器和迁移设置。

- **关键结果 / 消融** · 18 个设置汇总中Eyes-on-Me 与 LLM-Gen 组合的端到端成功率 57.8%，单用 LLM-Gen 为 21.9%，Phantom 为 14.6%；论文也报告跨未见检索器和生成器的迁移。
- **适用条件 / 局限** · 威胁模型需要写入检索语料，训练引导组件依赖可观测代理模型；黑盒转移限于受测目标。

- **适用条件 / 局限** · 实证仅 TRACE 的任务流，未覆盖更长序列和大型原生 MoE；理论解释局部敏感性，未刻画完整训练轨迹。

## 517 · IO-Adam: Rethinking Memory-Efficient Adaptive Optimizers from Gradient Computation

[原文](https://proceedings.mlr.press/v306/chen26ax.html)

**技术主题** · Adam 状态压缩

- **问题 / 瓶颈** · Adam 的逐权重矩估计占用大量内存，能否改用产生梯度的中间量并保持学习表现？
- **核心创新 / 方法** · IO-Adam 利用权重梯度由层输入与输出反传梯度相乘的结构，由两者统计近似二阶矩，将一阶动量更新与梯度计算融合；部分设置使用短缓冲。
- **Baseline** · 改进来源：Adam 自适应矩和反向传播的矩阵分解结构。实验对照：Adam/AdamW、Adafactor、GaLore、AdamSNSM、不同缓冲长度。

- **关键结果 / 消融** · CIFAR-10 的 ViT-Small 上缓冲 16 的 IO-Adam 准确率 77.63%，内存分配 68.40 MB，AdamW 为 76.06% 和 112.02 MB；LLaMA-60M 每步 0.3010 对 0.2817 秒。
- **适用条件 / 局限** · 二阶矩估计是近似，缓冲与追踪带来时间成本；内存与质量取舍随模型、实现以及训练设置变化。

## 521 · All Circuits Lead to Rome: Rethinking Functional Anisotropy in Circuit and Sheaf Discovery for LLMs

[原文](https://proceedings.mlr.press/v306/chen26bb.html)

<a id="chen26bb-evaluation"></a>

**技术主题** · 机制电路的非唯一性

- **问题 / 瓶颈** · 语言模型的一项功能是否只能由一套近唯一的可解释电路实现？
- **核心创新 / 方法** · OASR 在多次电路或 sheaf 搜索间显式惩罚结构重叠，同时控制任务忠实性、稀疏性与完整性，并用消融和叠加理论检验必要性。
- **Baseline** · 改进来源：DiscoGP 等稀疏电路发现和高维叠加。实验对照：随机初始化的重复搜索、ACDC、EP，以及三边核心的删边。
- **Benchmark** · 预训练语言模型的 IOI、BLiMP 等机制解释任务，报告边密度、边集合 IoU、任务准确率和补集准确率。
- **关键结果 / 消融** · IOI 的两套机制各得 100% 准确率，边 IoU 仅 4.1%；20 次 OASR 的共同 IoU 为 0.15%、平均准确率 99.59%。单独消融任一三边核心边，全模型仍达 99.8% 以上。
- **适用条件 / 局限** · 结果依赖选定任务、模型、边粒度和消融定义；理论给出局部线性叠加下的存在性，并不识别所有实际机制。
