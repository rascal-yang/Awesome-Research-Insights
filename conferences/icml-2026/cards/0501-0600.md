## 501 · Data-driven Mixed Integer Optimization through Probabilistic Multi-variable Branching

[原文](https://proceedings.mlr.press/v306/chen26ah.html) · [关联 Insight](../../../papers/ml-foundations.md#chen26ah-optimization)

- **问题 / 瓶颈** · MIP 的二元预测即使单变量很准，逐一固定多个变量也可能很快排除最优解。需要把离线经验转成对分支定界有用的子区域。
- **核心创新 / 方法** · PMVB 对高置信为 0/1 的变量按组汇集概率，在和上施加一侧界，构造划分可行域的多个分支超平面。可作为原始启发式，也可用 LP 内点解做代理概率。
- **Baseline** · 改进来源为用组和聚合不确定预测。实验对照为原 Gurobi/COPT 求解、黑盒多分支、单独优先启发式及无训练 LP 版本。
- **Benchmark** · 集合覆盖 SCP、组合拍卖 CA、多重背包 MKP、MIPLIB 与真实实例。按移位几何平均求解时间和加速比比较，MIPLIB 设 3,600 秒限制。
- **关键结果 / 消融** · 表 1 中 MKP m=30、n=500 的原求解时间 1,283 秒，PMVB 为 979 秒（1.31×）。SCP-V 32.6→27.4 秒。57 个筛选后的 MIPLIB 实例上，δ=10⁻⁸、τ=0.9 的 SGM 加速比为 1.19。
- **适用条件 / 局限** · 概率集中受预测误差依赖及置信设定影响。若仅解首选子问题，仍可能不可行或排除最优解。MIPLIB 汇总排除了不可用实例。

## 502 · From Holo Pockets to Electron Density: GPT-style Drug Design with Density

[原文](https://proceedings.mlr.press/v306/chen26ai.html) · [关联 Insight](../../../papers/scientific-ml.md#chen26ai-architecture)

- **问题 / 瓶颈** · 结构驱动设计通常用空的刚性结合口袋，错过原配体和邻近溶剂留下的形状与相互作用信息。
- **核心创新 / 方法** · EDMolGPT 用计算或实验低分辨率电子密度采样点云，并用近邻填充原子标注药效团。仅解码器 Transformer 自回归生成片段和三维几何，采样受键长、键角等约束。
- **Baseline** · 改进来源为以配体及填充物的密度软约束生成空间。实验对照有 ED2Mol、ECloudGen 及其他结构生成模型，并检查密度分辨率与温度。
- **Benchmark** · DUD-E 有 101 靶点，实验密度子集有 92 个，每靶点生成 1,000 个分子。测 ECFP4 活性配体覆盖、对接打分、构象及 QED/SAS。
- **关键结果 / 消融** · CalED 表 1 的 ECFP4 TS>0.5 覆盖为 41%，使用同一预有配体计算密度的 ECloudGen为 33%，EDMolGPT 的平均 Min-in-place 对接分为 −6.92、Redocking 为 −7.18。ExpED 子集表 3 的覆盖为 20%。
- **适用条件 / 局限** · 任务需已有配体或可用填充物电子密度，药效团标注也利用填充原子。检索恢复与对接分数是代理，不能证明生成物均有实验活性。

## 503 · Normalizing Flows with Iterative Denoising

[原文](https://proceedings.mlr.press/v306/chen26aj.html) · [关联 Insight](../../../papers/computer-vision.md#chen26aj-inference)

- **问题 / 瓶颈** · 自回归流图像模型在小噪声下优化不稳，大噪声后单次去噪又会模糊。需要在保留似然训练的同时逐步细化样本。
- **核心创新 / 方法** · iTARFlow 用同一个 TARFlow 在连续噪声强度上学习条件似然。采样先自回归生成带噪中间图，再从粗到细利用似然梯度进行迭代去噪。
- **Baseline** · 改进来源为一个似然模型共享多噪声尺度的训练并在生成时逐级去噪。实验对照含 TARFlow、STARFLOW、扩散、相容性及潜自回归方法。
- **Benchmark** · ImageNet 64、128、256 像素测 FID 和参数量，区分像素生成与借助外部 VAE 的潜空间生成，另看去噪过程和伪影。
- **关键结果 / 消融** · ImageNet-64 iTARFlow-B 的 FID 1.68、770M 参数，TARFlow 为 2.66/880M，EDM-SDE 为 1.55/300M。ImageNet-256 潜空间 iTARFlow-B 为 2.32，STARFLOW 为 2.40。
- **适用条件 / 局限** · 去噪的自动微分增加显存，噪声上下界与步数需调，最高质量仍受不稳定或过平滑伪影影响。

## 504 · SynGR: Unleashing the Potential of Cross-Modal Synergy for Generative Recommendation

[原文](https://proceedings.mlr.press/v306/chen26ak.html) · [关联 Insight](../../../papers/graph-and-recommendation.md#chen26ak-representation-learning)

- **问题 / 瓶颈** · 多模态生成推荐用图像和文本编码物品标识，训练时容易依赖单一强模态的捷径，忽略只有两者合看才出现的语义。
- **核心创新 / 方法** · SynGR 用残差量化得到两种模态的语义 token，按接收注意量识别主导模态，遮挡其中最显著 token，再用协同对比目标约束混合表征，并同生成损失联合训练。
- **Baseline** · 改进来源为在训练扰动主模态并让表征利用两者交互。实验对照含 SASRec、TIGER、MACRec 等序列/生成推荐方法及遮挡消融。
- **Benchmark** · Amazon Arts、Games、Instruments 三个物品序列数据，报告 HR@1/5/10 与 NDCG@5/10 的离线下一物品推荐。
- **关键结果 / 消融** · Arts 的 HR@5 为 SynGR 0.1145、MACRec 0.1046。Games 的 HR@1 为 0.0245 对 0.0208。Instruments 的 HR@10 为 0.1768，对表中最强基线 0.1375，约 +28.58%。
- **适用条件 / 局限** · 主要学习物品侧图文协同，尚未纳入更丰富的交互协同信号，也未覆盖音视频。离线指标不直接代表线上偏好变化。

## 505 · OneSearch: A Preliminary Exploration of the Unified End-to-End Generative Framework for E-commerce Search

- **问题 / 瓶颈** · 电商搜索级联系统把召回、粗排、精排分开优化，计算碎片化且信号冲突，希望用生成式检索同时建模强相关和用户偏好。
- **核心创新 / 方法** · OneSearch 用关键词增强层次量化构造商品语义 ID，注入短期和隐式长期行为及行为用户 ID，分阶段对齐语义、共现和个性化，再用偏好奖励进行加权重排。
- **Baseline** · 改进来源为联合建模查询、语义 ID 和多视角行为。线上实验对照为原多级 MCA、去排名的 MCA，以及 OneSearch 两版有无奖励重排。离线另比较行为消融。
- **Benchmark** · 快手商城搜索线上 A/B 与离线检索，观测商品 CTR、页面点击/转化、买家和订单量，另对比 MFU 与 OPEX。
- **关键结果 / 消融** · 表 4 完整 OneSearch 加奖励重排相较在线 MCA 的商品 CTR +1.67%、买家 +2.40%、订单 +3.22%。图 4 的 MFU 3.26%→27.32%、OPEX 降 75.40%。
- **适用条件 / 局限** · A/B 在同一平台特定搜索流量完成，收益与商品编码、行为日志和部署资源相关。直接生成仍依赖可用语义 ID 词表及购买偏好信号。

## 506 · Gated Relational Alignment via Confidence-based Distillation for Efficient VLMs

[原文](https://proceedings.mlr.press/v306/chen26am.html) · [关联 Insight](../../../papers/multimodal.md#chen26am-training-strategies)

- **问题 / 瓶颈** · 视觉语言模型的低比特部署容易损害任务表现，且直接蒸馏会把教师对低置信 token 的噪声也传给容量有限的学生。
- **核心创新 / 方法** · GRACE 结合权重 QAT 与蒸馏，用教师熵门控解耦的 token 蒸馏，用关系 CKA 转移视觉 token 间结构，并以自适应拉格朗日控制信号平衡容量和保真。
- **Baseline** · 改进来源为给可靠监督和结构信号更高权重，再学习分组量化尺度。实验对照含 RTN、AWQ、QAT、QAT 加普通蒸馏及浮点学生/教师。
- **Benchmark** · LLaVA-1.5、Qwen2-VL 的视觉问答、ScienceQA、MMBench 等，比较 INT4/8 与 BF16、准确率、吞吐、显存。
- **关键结果 / 消融** · LLaVA-1.5-7B 的 INT4 GRACE 在 ScienceQA 为 70.1%，同大小 BF16 为 66.8%，13B 教师为 71.6%。表 2 七集均分 INT4 为 67.2%、QAT 65.9%、BF16 66.5%。
- **适用条件 / 局限** · 当前只量化权重，训练依赖更大教师和额外离线开销。广义的激活量化、视频或音频模型尚待验证。

## 507 · Beyond Two-Stage Training: Cooperative SFT and RL for LLM Reasoning

[原文](https://proceedings.mlr.press/v306/chen26an.html) · [关联 Insight](../../../papers/llm.md#chen26an-training-strategies)

- **问题 / 瓶颈** · SFT 和可验证奖励 RL 的方向并非总一致，固定先监督后 RL 或同时加权，可能把学生推向对最终奖励帮助不大的专家分布。
- **核心创新 / 方法** · BRIDGE 交替更新学生主模型和 LoRA 教师。学生用联合 SFT 与 RL 梯度，教师比较联合更新后的奖励与仅 RL 的对照收益，以元目标选择有利的监督。
- **Baseline** · 改进来源为用反事实 RL-only 步评价监督增益。实验对照为单独 SFT/RL、常规 SFT→RL、直接混合、LUFFY、SRFT、CHORD 及元目标消融。
- **Benchmark** · Qwen2.5-3B、Llama3.2-3B、Qwen3-8B 的 MATH-500、Minerva、OlympiadBench、AIME24、AMC23，另评逻辑、代码、科学及噪声奖励。
- **关键结果 / 消融** · Qwen2.5-3B 的五项平均 36.0%，SFT→RL 32.2%、CHORD 32.5%、简单混合 29.4%。AIME24 为 13.3%，两阶段 9.0%，CHORD 6.7%。
- **适用条件 / 局限** · 实验集中在答案可验证、带专家轨迹的数据。辅助学生迭代增加显存，在 70B 以上未直接检验，主观奖励任务也未覆盖。

## 508 · EMFormer: Efficient Multi-Scale Transformer for Accumulative Context Weather Forecasting

[原文](https://proceedings.mlr.press/v306/chen26ao.html) · [关联 Insight](../../../papers/scientific-ml.md#chen26ao-training-strategies)

- **问题 / 瓶颈** · 自回归天气预报会累积误差，直接为多步重训又可能损伤短期指标并占用大量算力。
- **核心创新 / 方法** · EMFormer 等价合并中心对齐的 1×1、3×3、5×5 多尺度卷积。累计上下文微调保留先前步的 KV 并按注意力分数裁减缓存，再用随阶段变化的正弦权重组合天气变量与纬度相关的损失项。
- **Baseline** · 改进来源为训练和推理共用的多尺度卷积及能跨步复用的历史。实验对照为 Pangu、GraphCast、FuXi、Oneforecast，以及有无微调、累计记忆的消融。
- **Benchmark** · 1.4° ERA5 的 6 小时至 10 日归一化 RMSE、去标准化后的异常相关系数 ACC，另测 2024 年台风轨迹，以及 ImageNet-1K、ADE20K。
- **关键结果 / 消融** · ERA5 十日 EMFormer 微调后 RMSE/ACC=0.5094/0.5389，未微调为 0.5719/0.4614，Oneforecast 为 0.5918/0.4457。6 小时 RMSE 为 0.0599，Oneforecast 为 0.0549。
- **适用条件 / 局限** · 对外部预报基线使用论文所列分辨率和口径。长期结果来自再分析数据，实际应用受初始分析、状态变量和极端事件分布影响。

## 510 · The Unlearnability Phenomenon in RLVR for Language Models

[原文](https://proceedings.mlr.press/v306/chen26aq.html) · [关联 Insight](../../../papers/llm.md#chen26aq-evaluation)

- **问题 / 瓶颈** · 可验证奖励强化学习中，为什么一些困难样本即使出现过正确轨迹，训练结束后仍没有学会？
- **核心创新 / 方法** · 定义训练前后低成功率但有正奖励的样本组，分别改变采样、梯度正则与数据增广，并用正确轨迹的 LoRA 梯度余弦及推理轨迹检查表征。
- **Baseline** · 改进来源：GRPO 与 RLVR 的正奖励采样及样本梯度分析。实验对照：可学习困难题、始终无正奖励题、重放增采、调整裁剪或 KL、增强数据及中期训练模型。
