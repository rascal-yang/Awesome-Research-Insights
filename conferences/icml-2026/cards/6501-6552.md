## 6501 · Position: Text Embeddings Should Capture Implicit Semantics, Not Just Surface Meaning

[原文](https://proceedings.mlr.press/v306/sun26bb.html)

<a id="sun26bb-evaluation"></a>

**技术主题** · 用词袋对照检验embedding的隐含语义读出

- **问题 / 瓶颈** · 标准STS/IR平均分难揭示对隐含含义的跨层能力，词面捷径可能解释不少准确率。
- **核心创新 / 方法** · 将七已有数据转classification/pairwise/zero-shot label similarity，比较encoder、LLM与proprietary embeddings及random/Bag-of-Tokens；按semantic tier拆结果，提出训练数据/目标方向而非实际新loss。
- **Baseline** · MTEB协议、PUB/P-Stance/IHS/SBIC/PoliticalBias与Bag-of-Tokens为来源；实际多embedding的同任务pilot。暂定增量是词袋控制后的分层迁移失败经验，不将社会语言taxonomy/未来loss当新算法，最近对照先例待核。
- **Benchmark** · P-IMP/P-PRE/P-R&D语用、P-Stance、IHS/SBIC/PoliticalBias；accuracy，classification/pairwise及similarity读出按task区分，frozenfeature训练/validation/split详细参数待核。
- **关键结果 / 消融** · Bag-of-Tokens均值62.2，SBERT64.8，BGElarge68.0，GTEQwen75.2；LinqP-IMP80.3但P-Stance75.8低OpenAILarge83.7。BGElarge P-PRE75.5接Bag75.3，但其它任务有明显收益，不能说所有embeddings只略胜词袋。
- **适用条件 / 局限** · 分类准确率不等纯语义表示能力或真实对话推理，probe容量/label文本/数据泄漏和lexical confounds要匹配。主文不同任务读出未等同为cos性能，mean权重可改变排序；标准MTEB与pilot版本、训练/预算及不确定区间待核，不证明模型完全缺失implicit semantics。

## 6505 · Position: Time-Series Foundation Models Require Explicit Domain-Level Benchmarks

[原文](https://proceedings.mlr.press/v306/syed26a.html)

<a id="syed26a-evaluation"></a>

**技术主题** · 域与horizon分层的TSFM选型

- **问题 / 瓶颈** · 混合benchmark在series/observations上域权重不同，overall最优可能不是部署域最优。
- **核心创新 / 方法** · 72datasets平衡六域，七TSFM各用作者最强reported配置、统一point forecast评价；给MSE/MAE rank分布、domain win counts及固定horizon KruskalWallis测试。
- **Baseline** · GIFT-Eval/Monash/TSFM-Bench、Demšar rank分析为来源；实际Chronos/Sundial/TimeGPT/TimesFM/TimesMOE/ToTo/Moirai。暂定增量是域/horizon条件的ranking反转证据，非发明domain averaging，先例待核。
- **Benchmark** · 72数据六域Health/Finance/Energy/Nature/Transport/Retail；24/48/96 horizon，MSE/MAE及rank；Energy含AUSElecDemand/ElectricityWeekly/ETTh/m等，完整normalization/context/API版本待核。
- **关键结果 / 消融** · AUSElecDemand24 MSE Sundial.0452优ToTo.2572，但ElectricityWeekly24 ToTo.5357优Sundial4.0820；同energy内也反转。H24 Moirai MAE域效应p.0634不显著、MSE p.0123，不能称每model每metric均显著。
- **适用条件 / 局限** · 不同dataset scale/难度和normalization可驱动rawerror域检验，KW p值不直接认证domain×model交互或机制；重复horizon/dataset关联需控制。最强配置不等context/参数/compute匹配，未直接量gradient正交、forgetting或不可兼容priors，不由rank差推出通用model原则上不可能。

## 6507 · Position: Beyond Sensitive Attributes, ML Fairness Should Quantify Structural Injustice via Social Determinants

[原文](https://proceedings.mlr.press/v306/tang26aj.html)

<a id="tang26aj-theory-statistics"></a>

**技术主题** · 对群体阈值公平缓解做context分层审计

- **问题 / 瓶颈** · 同race/sex群体内机会分布可随context变，单attribute parity掩盖负担转移。
- **核心创新 / 方法** · 两region×两group模型给定人口分布和region条件score独立性、stochastic dominance及固定seats，分析quota造成的跨context threshold关系；以ACS地域统计与半合成资源分配作说明。
- **Baseline** · conditional/intersectional fairness、distributional dominance与classic quota为来源；实际不同region/attribute切片和equal/all-to-disadvantaged配置。暂定增量是条件阈值反效与context数据审计规则，最近公平先例待核。
- **Benchmark** · 两region admissions数学模型；US Census ACS/PUMA收入×ADI统计、医疗筛查半合成500runs；group/context分布、score thresholds及模拟earlydetection计数，非新训练算法/临床试验。
- **关键结果 / 消融** · 理论在Assumptions4.1–4.4下可出现poor nonURM threshold高于rich URM；ACS同BlackWomen低/中/高ADI median收入38000/23800/18800。半合成有条件资源分配改善，但不能从该模拟认证真实干预因果收益。
- **适用条件 / 局限** · score给定region与race条件独立、固定seats及dominance是构造条件，不普遍成立；quota与机会平等的目标不同，阈值差不自动定义唯一不公平。人口统计是关联，ADI粗分丢个人差异；半合成outcome受指定生成过程支配，证明与真实DL postprocessor实现待核。

## 6508 · Position: Good Embodied Reward Models Need Bad Behavior Data

[原文](https://proceedings.mlr.press/v306/tian26o.html)

<a id="tian26o-evaluation"></a>

**技术主题** · 真实失败视觉与偏好筛选dense负例的reward校准

- **问题 / 瓶颈** · 只学进度的reward可持续奖励看似接近目标但执行差的轨迹。
- **核心创新 / 方法** · 同task相近init RoboArena rollouts的人类scalar比较定义strict pairs，sum dense rewards诱导model排序；GVL分别加text、text-video、text-video-proxy-dense负例，dense由多次GVL采样筛到符合human pair排序者。
- **Baseline** · ReWind/OpenX、GVL、Dopamine、VOC和preference self-distillation为来源；实际三family排序评估，GVL三种负例提示对照。暂定增量是progress指标与真实失败偏好不一致的受控经验，先例待核。
- **Benchmark** · RoboArena七类tabletop manipulation：PickPlace/PushPull/OpenClose/Stack/Reorient/Pour/ToolUse；pair ordering accuracy、failure-window reward走势；三rewardmodel及GVL negative-context控制，pair数/留出设置待核。
- **关键结果 / 消融** · PickPlace三model排序accuracy约.72–.77，ToolUse约.52–.62；text-only基本不改善，text-video在简单类作者报≈8%增益，proxy-dense困难类≈10%，百分或百分点口径待核。复杂任务text-video也不足，非任意负例都有效。
- **适用条件 / 局限** · proxy dense只按总return排序选择，不是oracle每帧label，可能只是挑到偶然正确序列；示范/测试同pair或同task独立性是关键待核，不能预称泛化改善。sum rewards有长度/重复frame偏置，human ordinal不唯一决定dense reward；额外多次采样/上下文算力未匹配，因复杂度类别混task不识别因果复杂度律。

## 6513 · Position: RL Researchers Need to Distinguish Between Solving Simulators and Using Simulators as a Proxy

[原文](https://proceedings.mlr.press/v306/vandergrift26a.html)

<a id="vandergrift26a-evaluation"></a>

**技术主题** · 并行环境转单流时重配更新数据比

- **问题 / 瓶颈** · best saved policy、并行walltime和在线累计收益回答不同问题，直接将simulator配置带入部署会混淆交互权限和训练日程。
- **核心创新 / 方法** · 在MinAtar Asterix比较PQN128env与1env，分别保每env steps与匹配UTD，通过增加单env rollout长度调整；在MountainCar让PPO早期episode-end randomstate reset，2Msteps后停止，观察标准环境后续return。
- **Baseline** · multi-stream PPO/PQN、GoExplore/reset探索、online vs bestcheckpoint/AUC评价均成熟；候选限具体PQN转单流的schedule失配与reset撤去后的控制经验，非提出新的RL算法或普遍禁止parallel训练。
- **Benchmark** · MinAtar Asterix PQN128vs1env、30runs online undiscounted return；globalstep为每个可用env各一步；MountainCar-v0 PPO earlyreset、2Msteps后关闭；另learning-vs-savedcurve20runs。
- **关键结果 / 消融** · 缓存报告单env保原更新次数会降低性能，匹配UTD需增加rollout长度但丢原并行速度优势；MountainCar earlyreset关闭后仍超不reset PPO。具体终值/墙钟待核，不据图估数；横轴globalstep非总transition匹配。
- **适用条件 / 局限** · 部署多robot/多用户也可有真实parallel data，单流只是特定目标非RL定义；模拟器学好后冻结部署本身有效，不应混同持续learning。matchingUTD改变rollout长度/相关性而非所有因素固定；reset实验未证明新探索原理，walltime/总samples及tuning成本应分别计，最近重复控制待核。

## 6536 · Position: Vector Prompt Interfaces Should Be Exposed to Enable Customization of Large Language Models

[原文](https://proceedings.mlr.press/v306/yang26eb.html)

<a id="yang26eb-evaluation"></a>

**技术主题** · 将prompt接口容量诊断与黑盒可优化性分开

- **问题 / 瓶颈** · 文本prompt优化平台期可能来自接口或优化预算，二者需分开归因。
- **核心创新 / 方法** · 在冻结Llama3-8B-Instruct上比较人写、TextGrad式文本优化与既有vector prompt tuning，随32–8192监督量测SST5/Alpaca；用layer12/20 attention图作辅助诊断。
- **Baseline** · prompt tuning、black-box prompt search和text optimization均已有；候选是同任务监督量扫描的饱和差异与接口/优化能力区分，非新soft-prompt方法，最近对照原作待核。
- **Benchmark** · SST5情感分类accuracy、Alpaca token F1，Llama3-8B-Instruct固定；text/vector train-size curves及两层attention可视化，prompt长度、迭代/query/FLOPs配平待核。
- **关键结果 / 消融** · PDF5 Alpaca32/256/2048/8192样本下text F1 .348/.310/.313/.344，vector .340/.370/.379/.401，init .319；SST5曲线作者称text较早平台期，精确数值待核。梯度训练不是所倡导的纯黑盒部署验证。
- **适用条件 / 局限** · 所测text optimizer失败不证明离散接口容量上限，梯度可达值也非数学upper bound。attention稠密不证明持久控制因果机制；两任务、tokenF1非完整指令遵循，参数/上下文与优化预算不同可混杂。泄漏风险论证依black-box前提，不能当全接口安全证书。

## 6541 · Position: LLMs Should Incorporate Explicit Mechanisms for Human Empathy

[原文](https://proceedings.mlr.press/v306/you26g.html)

<a id="you26g-evaluation"></a>

**技术主题** · 语义相似之外单独测情绪与细节保真

- **问题 / 瓶颈** · 常规生成质量分可能给出高分，同时原文强度或细节密度被系统性改变。
- **核心创新 / 方法** · 定义SA=平均(E(reference)−E(output))/E(reference)，EGM比较不适内容每句密度的相对差，LD与CA另测语言距离/过早化解；在十模型以任务质量和这些proxy并列评价。
- **Baseline** · affect/salience与风格保留研究已有；候选增量是明确多轴proxy与跨模型常规分数失配实证，不是尚未实现的empathy-aware训练器，最近原作待核。
- **Benchmark** · Newsroom经LLM筛选后50高影响样本，给summary生文章；WMT2023中文文学→英文；ROUGE/CIDEr/Qwen3Embedding SemSim、chrF/COMET与SA/EGM/LD。其余对话任务的样本/多judge稳健性待核。
- **关键结果 / 消融** · PDF6 GPT5.2 Newsroom SemSim.898但SA.158/EGM.252；Llama4 SA.290但EGM.179，指标不是单轴一致。PDF7文学翻译COMET .790–.828，SA .406–.459，显示传统quality和所定义affect指标并不等价。
- **适用条件 / 局限** · SA在E(reference)=0时未定义且近零敏感，EGM双零/句数与judge实现待核；相似度高不证明事实正确，新proxy也未自动验证真实人类共情。没有matched pre/posttraining控制，不能把差异归因为alignment的结构必然；样本筛选、长度、文化语言与人评校准限制外推。

## 6543 · Position: AI for Science Should Treat Measurement-to-Dataset Pipelines as Inference Components

<a id="zhan26g-evaluation"></a>

**技术主题** · 把预处理配置作为观测模型做跨数据稳定性审计

- **问题 / 瓶颈** · 同一底层观测经不同pipeline产生的表示可能让科学结论翻转，后续神经拟合无法恢复已丢区别。

- **Benchmark** · MODMA/CISIR两独立EEG datasets的群体统计对比；864预处理配置×284pairwise统计算子=245376attempts，固定检验/多重比较与bootstrap方向/相对排序，非DL下游准确率实验。
- **关键结果 / 消融** · PDF6作者称仅1/245376满足两数据中的显著性与跨数据联合稳定准则，即约.0004%；该分母是审计尝试空间，不是所有科学pipeline或所有有效计算。PDF7明确率只对该审计成立。
- **适用条件 / 局限** · 联合准则严格程度、失败attempt处置、依赖配置与effective测试数、效应量/样本量和bootstrap协议待核；极低存活率不证明其余全错，也不确证唯一因果机制。两dataset shift可含样本差异，不能把全部失稳单因归为预处理；向深网收益尚待验证。

## 6549 · Position: Genomic Model Research Must Move Beyond Anecdotal Evaluation of Interpretability Methods

[原文](https://proceedings.mlr.press/v306/zhou26by.html)

<a id="zhou26by-evaluation"></a>

**技术主题** · 解释器一致性与忠实度分开验证

- **问题 / 瓶颈** · 不同解释器可对同一已训练网络给出相互冲突的重要性，预测性能本身不解决解释可靠性。
- **核心创新 / 方法** · 在三个不同架构上固定模型/输入，比较DeepLIFT、IG、ISM、LIME、CategoricalJacobian的通用归因统计；用Spearman和top20 Jaccard测一致性，另独立报告faithfulness曲线AUC及任务间变动。
- **Baseline** · 跨归因器比较、Samek2016/Petsiuk2018忠实度评测与负对照已有；候选为跨架构系统失配的失败证据，非新解释器，最近通用解释audit待核。
- **Benchmark** · 作者UniBind相关五项分类任务设置，DNABERT2、HyenaDNA、NTv3三个神经架构；全位置Spearman、top20 Jaccard及faithfulness AUC，数据划分/样本量与计算预算待核。
- **关键结果 / 消融** · PDF4平均pairwise Spearman均低于.4，最高示例ISM–LIME .373，IG–CJ −.021；PDF5报告方法与任务排名改变，没有一种始终最好。数字是作者当前设置下统计，不说明任一低一致归因必错误。
- **适用条件 / 局限** · 一致不等真、分歧也可来自不同解释对象/交互约简，必须先对齐attribution定义和基线。通用faithfulness proxy依输入分布变化，OOD与模型置信变化可混杂；已知注释重合不等因果ground truth，不能由本次差异推出所有解释器无效。
