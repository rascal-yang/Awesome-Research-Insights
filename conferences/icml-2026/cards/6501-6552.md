## 6501 · Position: Text Embeddings Should Capture Implicit Semantics, Not Just Surface Meaning

[原文](https://proceedings.mlr.press/v306/sun26bb.html)

<a id="sun26bb-evaluation"></a>

**技术主题** · 用词袋对照检验embedding的隐含语义读出

- **问题 / 瓶颈** · 标准STS/IR平均分难揭示对隐含含义的跨层能力，词面捷径可能解释不少准确率。
- **核心创新 / 方法** · 将七已有数据转classification/pairwise/zero-shot label similarity，比较encoder、LLM与proprietary embeddings及random/Bag-of-Tokens；按semantic tier拆结果，提出训练数据/目标方向而非实际新loss。
- **Baseline** · MTEB协议、PUB/P-Stance/IHS/SBIC/PoliticalBias与Bag-of-Tokens为来源；实际多embedding的同任务pilot。暂定增量是词袋控制后的分层迁移失败经验，不将社会语言taxonomy/未来loss当新算法，最近对照先例待核。
- **Benchmark** · P-IMP/P-PRE/P-R&D语用、P-Stance、IHS/SBIC/PoliticalBias；accuracy，classification/pairwise及similarity读出按task区分，frozenfeature训练/validation/split详细参数待核。
- **关键结果 / 消融** · Bag-of-Tokens均值62.2，SBERT64.8，BGElarge68.0，GTEQwen75.2；LinqP-IMP80.3但P-Stance75.8低OpenAILarge83.7。BGElarge P-PRE75.5接Bag75.3，但其它任务有明显收益，不能说所有embeddings只略胜词袋。
- **适用条件 / 局限** · 分类准确率不等纯语义表示能力或真实对话推理，probe容量/label文本/数据泄漏和lexical confounds要匹配。主文不同任务读出未等同为cos性能，mean权重可改变排序；标准MTEB与pilot版本、训练/预算及不确定区间待核，不证明模型完全缺失implicit semantics。

## 6505 · Position: Time-Series Foundation Models Require Explicit Domain-Level Benchmarks

[原文](https://proceedings.mlr.press/v306/syed26a.html)

<a id="syed26a-evaluation"></a>

**技术主题** · 域与horizon分层的TSFM选型

- **问题 / 瓶颈** · 混合benchmark在series/observations上域权重不同，overall最优可能不是部署域最优。
- **核心创新 / 方法** · 72datasets平衡六域，七TSFM各用作者最强reported配置、统一point forecast评价；给MSE/MAE rank分布、domain win counts及固定horizon KruskalWallis测试。
- **Baseline** · GIFT-Eval/Monash/TSFM-Bench、Demšar rank分析为来源；实际Chronos/Sundial/TimeGPT/TimesFM/TimesMOE/ToTo/Moirai。暂定增量是域/horizon条件的ranking反转证据，非发明domain averaging，先例待核。
- **Benchmark** · 72数据六域Health/Finance/Energy/Nature/Transport/Retail；24/48/96 horizon，MSE/MAE及rank；Energy含AUSElecDemand/ElectricityWeekly/ETTh/m等，完整normalization/context/API版本待核。
- **关键结果 / 消融** · AUSElecDemand24 MSE Sundial.0452优ToTo.2572，但ElectricityWeekly24 ToTo.5357优Sundial4.0820；同energy内也反转。H24 Moirai MAE域效应p.0634不显著、MSE p.0123，不能称每model每metric均显著。
- **适用条件 / 局限** · 不同dataset scale/难度和normalization可驱动rawerror域检验，KW p值不直接认证domain×model交互或机制；重复horizon/dataset关联需控制。最强配置不等context/参数/compute匹配，未直接量gradient正交、forgetting或不可兼容priors，不由rank差推出通用model原则上不可能。

## 6507 · Position: Beyond Sensitive Attributes, ML Fairness Should Quantify Structural Injustice via Social Determinants

[原文](https://proceedings.mlr.press/v306/tang26aj.html)

<a id="tang26aj-theory-statistics"></a>

**技术主题** · 对群体阈值公平缓解做context分层审计

- **问题 / 瓶颈** · 同race/sex群体内机会分布可随context变，单attribute parity掩盖负担转移。
- **核心创新 / 方法** · 两region×两group模型给定人口分布和region条件score独立性、stochastic dominance及固定seats，分析quota造成的跨context threshold关系；以ACS地域统计与半合成资源分配作说明。
- **Baseline** · conditional/intersectional fairness、distributional dominance与classic quota为来源；实际不同region/attribute切片和equal/all-to-disadvantaged配置。暂定增量是条件阈值反效与context数据审计规则，最近公平先例待核。
- **Benchmark** · 两region admissions数学模型；US Census ACS/PUMA收入×ADI统计、医疗筛查半合成500runs；group/context分布、score thresholds及模拟earlydetection计数，非新训练算法/临床试验。
- **关键结果 / 消融** · 理论在Assumptions4.1–4.4下可出现poor nonURM threshold高于rich URM；ACS同BlackWomen低/中/高ADI median收入38000/23800/18800。半合成有条件资源分配改善，但不能从该模拟认证真实干预因果收益。
- **适用条件 / 局限** · score给定region与race条件独立、固定seats及dominance是构造条件，不普遍成立；quota与机会平等的目标不同，阈值差不自动定义唯一不公平。人口统计是关联，ADI粗分丢个人差异；半合成outcome受指定生成过程支配，证明与真实DL postprocessor实现待核。

## 6508 · Position: Good Embodied Reward Models Need Bad Behavior Data

[原文](https://proceedings.mlr.press/v306/tian26o.html)

<a id="tian26o-evaluation"></a>

**技术主题** · 真实失败视觉与偏好筛选dense负例的reward校准

- **问题 / 瓶颈** · 只学进度的reward可持续奖励看似接近目标但执行差的轨迹。
- **核心创新 / 方法** · 同task相近init RoboArena rollouts的人类scalar比较定义strict pairs，sum dense rewards诱导model排序；GVL分别加text、text-video、text-video-proxy-dense负例，dense由多次GVL采样筛到符合human pair排序者。
- **Baseline** · ReWind/OpenX、GVL、Dopamine、VOC和preference self-distillation为来源；实际三family排序评估，GVL三种负例提示对照。暂定增量是progress指标与真实失败偏好不一致的受控经验，先例待核。
- **Benchmark** · RoboArena七类tabletop manipulation：PickPlace/PushPull/OpenClose/Stack/Reorient/Pour/ToolUse；pair ordering accuracy、failure-window reward走势；三rewardmodel及GVL negative-context控制，pair数/留出设置待核。
- **关键结果 / 消融** · PickPlace三model排序accuracy约.72–.77，ToolUse约.52–.62；text-only基本不改善，text-video在简单类作者报≈8%增益，proxy-dense困难类≈10%，百分或百分点口径待核。复杂任务text-video也不足，非任意负例都有效。
- **适用条件 / 局限** · proxy dense只按总return排序选择，不是oracle每帧label，可能只是挑到偶然正确序列；示范/测试同pair或同task独立性是关键待核，不能预称泛化改善。sum rewards有长度/重复frame偏置，human ordinal不唯一决定dense reward；额外多次采样/上下文算力未匹配，因复杂度类别混task不识别因果复杂度律。
