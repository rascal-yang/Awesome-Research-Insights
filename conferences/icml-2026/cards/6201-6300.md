## 6201 · IMPACT: Influence Modeling for Open-Set Time Series Anomaly Detection

[原文](https://proceedings.mlr.press/v306/zhou26as.html)

<a id="zhou26as-data-strategies"></a>

**技术主题** · 用验证风险影响区分污染清理与边界样本合成

- **问题 / 瓶颈** · 粗暴时序增强可能不真实，未标注污染又影响正常边界估计。
- **核心创新 / 方法** · IMPACT先用deviation loss训练并估Hessian逆梯度影响；正影响nominal候选翻异常标签，负影响正常样本作reference，剩余边界样本沿验证风险影响方向扰动，再以seen/unseen双head训练。
- **Baseline** · 经典Koh–Liang influence、label correction、特征对抗与双head已有；候选是依影响分流的去污染/异常合成规则及局部风险条件，最近同类原作待核。
- **Benchmark** · UCR/ASD/PSM/SMD等8时序dataset，unsupervised/open-set、不同污染比例；AUC及std，标签预算/验证构成及测试类划分待核。
- **关键结果 / 消融** · PDF7 SMD open-set AUC75.97±3.03 vsMOSAD71.20±0.38、WSAD-DT70.60±0.80；全方法结果不隔离去污染/生成独立贡献。PDF5–6推导为影响近似，不等有限幅度重新训练必降真实test risk。
- **适用条件 / 局限** · 验证风险需标签与独立数据，文中test-risk称谓不能掩盖评测泄漏风险；影响正不保证确实异常，Hessian可逆/近驻点和近似开销需核。新feature分布不等真实未知异常或时序可实现数据。

**可复用机制** · 开放集时序检测可用独立验证风险的influence估计选有害nominal样本作去污染，再对近边界样本做特征扰动并赋异常监督；需要将一阶风险代理与真实未知异常覆盖分开。

## 6202 · How Transformers Represent Hierarchies: A Local-to-Global Mechanism

[原文](https://proceedings.mlr.press/v306/zhou26at.html)

<a id="zhou26at-evaluation"></a>

**技术主题** · 逐层逐前缀探测层级解析信息

- **问题 / 瓶颈** · 仅末层或完整树probe难揭示因果可用信息如何跨层汇聚。
- **核心创新 / 方法** · 在50采样有限深PCFG上训练5layer/4head/512dim decoder，冻结模型以MLP probe每层每位置的Earley items与span-restricted completed constituents，并与显式局部到全局构造比较。
- **Baseline** · 语法probe、inside动态规划及Allen-Zhu–Li构造已有；候选是prefix对齐的逐层/不同span诊断与local-to-global条件机制，最近原作增量待核。
- **Benchmark** · 50二叉PCFG、终端1/2/3、未见序列；next-token分布拟合、Earley/CYK probe accuracy及SEM，构造深度对grammar长度的条件关系。
- **关键结果 / 消融** · PDF7短span在早层可恢复，大span较晚超过90%，最终层多数probe准确率下降；PDF6指出Earley最坏O(L)依赖不能直接解释所设O(logL)层构造。精确长度分布和因果干预控制待核。
- **适用条件 / 局限** · MLP probe成功不证明网络以Earley/CYK算法因果计算，构造存在不等SGD必学到或适用于自然语言。有限深二叉grammar的深度/长度关系与一般不平衡CFG不同；数据频率/罕见大span和probe容量需控制。

## 6203 · Neural Vector Lyapunov–Razumikhin Certificates for Delayed Interconnected Systems

[原文](https://proceedings.mlr.press/v306/zhou26au.html)

<a id="zhou26au-theory-statistics"></a>

**技术主题** · 在可达延迟历史域分外内两阶段验证

- **问题 / 瓶颈** · 任意组合延迟历史域过大且含不可达状态，单纯训练样本满足条件不能得到sISS保证。
- **核心创新 / 方法** · 学习各agent神经V与图掩码非负耦合Γ，缩放行和保证small-gain；训练条件逻辑¬A∨B。验证先在可达域检查条件递减，再在目标子水平集检查强收缩，网格覆盖补Lipschitz余量。
- **Baseline** · 向量Lyapunov/Razumikhin、small-gain和Lipschitz网格验证已有；候选是离散延迟系统的可达历史域/两阶段充分条件及可扩展验证安排，最近原作待核。
- **Benchmark** · mixed-autonomy platoons/drone formations/microgrids，control performance与验证时间/覆盖，扰动界、最大延迟和网络规模；具体对照数值待核。
- **关键结果 / 消融** · PDF5–6定理要求外域全覆盖、内部全level-set验证、正确Lipschitz裕量和R下界，才推出在指定初始历史集合内有限时进入并保持最终有界；不是仅经验rollout认证。
- **适用条件 / 局限** · 可达集需可靠outer approximation；由各投影笛卡尔积形成域可保守，裸随机采样不能替代覆盖。初始未知历史以平衡点padding仅训练方案非所有历史假设；认证为域内充分条件，dimension/degree/delay仍影响网格成本。

## 6204 · Extra-Merge: Tracing the Rank-1 Subspace of Model Merging in Language Model Pre-Training

[原文](https://proceedings.mlr.press/v306/zhou26av.html)

<a id="zhou26av-optimization"></a>

**技术主题** · 沿合并checkpoint主方向外推并验证选点

- **问题 / 瓶颈** · checkpoint averaging抑制震荡但通常只在历史凸包内取点，可能遗漏延续的低曲率下降方向。
- **核心创新 / 方法** · Extra-Merge固定PMA间隔/窗口，取最近K个merged checkpoint的PC1、按末两点位移定符号；步幅为投影位移的0.1倍，试k步，首个loss劣于anchor时停并返回最优候选。
- **Baseline** · SWA/PMA/LAWA、权重外推与river-valley分析已有；候选是合并轨迹主方向规律与速度尺度外推规则，最近同类外推方法待核。
- **Benchmark** · GPT2/LLaMA124M–2B晚期checkpoint，另Pythia12B zero-shot与Muon设置；validation loss、PC1方差占比和downstream accuracy，读取/搜索成本待核。
- **关键结果 / 消融** · PDF5 K5近期合并轨迹PC1解释>94%，更长K16且n>4仍>0.8；局部统计并非全局rank1。PDF6分析假设局部river方向与解耦SGD动态，不能直接扩展任意AdamW长轨迹。
- **适用条件 / 局限** · 重叠滑窗产生强相关，PCA rank还受K−1限制；验证搜索需独立预算，停止条件相对anchor非前一个候选，可能多次调用。PC1时间方向不保证下降，曲率/阶段切换和参数对齐限制外推安全距离。

**技术主题** · 在点对score图上卷积形成窗口注意力
