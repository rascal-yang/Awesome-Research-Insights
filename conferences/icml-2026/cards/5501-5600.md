## 5501 · Reconstructing Template-Memorized Images from Natural Prompts

[原文](https://proceedings.mlr.press/v306/yarkoni26a.html)

<a id="yarkoni26a-evaluation"></a>

**技术主题** · 隐私审计应检测模板结构而非只查逐像素拷贝

- **问题 / 瓶颈** · 模板化训练图像可部分重现而未达到整图重复阈值。
- **核心创新 / 方法** · 研究template-memorized image现象，比较source/generated布局、个体视觉线索和interpolation，跨旧/新生成模型观察；用于defensive数据去重/输出相似度审计。
- **Baseline** · 训练数据提取与重复图像检测已有；候选为自然任务prompt下结构模板/插值绕过verbatim检查的失效经验，最近memorization原作及独立增量待核。
- **Benchmark** · SD1.4及SD3.5/Flux-Schnell/Midjourney等生成结果与web/部分已知训练source比对；memorization prevalence、样本选择及总生成预算待核。
- **关键结果 / 消融** · PDF5–6给可定位source/generated例，新模型较少但仍有template resemblance；定性存在性证据不等总体泄露率。部分模型training corpus未知，不能把网络近似图必然当训练成员。
- **适用条件 / 局限** · layout相似不唯一证明memorization；需要独立source attribution、random chance/nearest-neighbor与duplicate threshold。插值可能共享模板或新合成，审计应区分完整复制、结构复用和可识别局部，不给强身份归因。

## 5502 · Complexity of Decentralized Optimization with Mixed Affine Constraints

[原文](https://proceedings.mlr.press/v306/yarmoshik26a.html)

<a id="yarmoshik26a-theory-statistics"></a>

**技术主题** · 按约束算子分别预算分布式优化成本

- **问题 / 瓶颈** · 不同约束和网络condition numbers使一次迭代成本不均。
- **核心创新 / 方法** · 将mixed equality constraints组织为B u=b，用APAPC类accelerated primal-dual correction仅经Bᵀ(Bu−b)接口；结合不同block preconditioning/滑动技术区分oracle复杂度。
- **Baseline** · APAPC、gradient sliding与decentralized affine optimization已有；候选为mixed-local/global结构的最优复杂度分解及lower-bound匹配，最近原作与真正新算法部分待核。
- **Benchmark** · smooth strongly-convex/general convex及nonsmooth，objective gapε/constraint residualδ；frozen-feature convex heads可条件用，神经实验/具体数值任务待核。
- **关键结果 / 消融** · PDF4表mixed regime给gradient约√κf、communication约√κf(√κAC+√κCshared)√κW忽略log，显示constraint conditioning额外成本；完整定义/optimal lower bound范围待核。
- **适用条件 / 局限** · convexity、feasible affine system和谱界条件实质；不适用于普通非凸网络权重或非线性约束。oracle optimal非walltime最优，matvec/communication可并行程度和额外preconditioner开销待核。

## 5503 · Gradient Flow Through Diagram Expansions: Learning Regimes and Explicit Solutions

[原文](https://proceedings.mlr.press/v306/yarotsky26a.html)

<a id="yarotsky26a-theory-statistics"></a>

**技术主题** · 联合宽度与初始化判断CP学习regime

- **问题 / 瓶颈** · 模型对称性和阶数改变gradient-flow极限，单一width经验不足。
- **核心创新 / 方法** · 以loss时间导数diagram/Wick expansions提取large-size Pareto monomials，按(p,H,σ)缩放识别free/NTK/mean-field等faces，再尝试生成函数PDE求显式loss。
- **Baseline** · diagrammatic NTK/mean-field与tensor GF已有；候选为CP order/symmetry依赖phase boundary及formal-series求和方法，最近原作待核。
- **Benchmark** · Gaussian初始化CP tensor learning，identity target及SYM/ASYM；loss vs rescaledGF time，p/H/σ扫描；实际有限尺度和数值误差待核。
- **关键结果 / 消融** · PDF6 ASYM balanced H≈p^(ν−1)，SYM even ν为H²≈p^ν；而fit identity的H=p不等该balanced scaling。作者称数值吻合，非所有非线性网络通用phase diagram。
- **适用条件 / 局限** · formal coefficientwise limit不自动可求和或交换time/size极限，作者明确可能需Borel且非一般有效；odd SYM未同等覆盖。continuous GF无Adam/SGD噪声，局部/有限time适用和数值控制待核。

**可复用机制** · 用tensor CP分解或multilinear神经模型时，应联合输入维p、宽H、初始化σ及tensor order选择lazy/rich scaling，不能把H增大一概当NTK化。

## 5505 · Time Series, Vision, and Language: Exploring the Limits of Alignment in Contrastive Representation Spaces

[原文](https://proceedings.mlr.press/v306/yashwante26a.html)

<a id="yashwante26a-evaluation"></a>

**技术主题** · 时间序列对齐应区分全局几何和局部邻域

- **问题 / 瓶颈** · 独立模态表征的共享结构与posthoc coupling效果易混为一谈。
- **核心创新 / 方法** · 冻结TS/image/text encoder后训练projection heads做三对contrastive loss，比较pair ablations、encoder size、caption压缩/扩写及plot样式，使用CKA/Procrustes/kNN/retrieval。
- **Baseline** · contrastive alignment/plot mediation及representation similarity已有；候选是34配置下global-vs-local dissociation和caption信息增益饱和的有限经验规律，最近原作待核。

- **关键结果 / 消融** · PDF5 global metrics较强而kNN低，TS更易对齐plot，TS–TXT随scale相关更强；摘要称caption richer到阈值后饱和，精确阈值/等token实验待核。

## 5506 · RiskZero: Plan More to Risk Less with a Learned Model

[原文](https://proceedings.mlr.press/v306/yassin26a.html)

<a id="yassin26a-architecture"></a>

**技术主题** · risk-sensitive搜索同时估历史与未来回报

- **问题 / 瓶颈** · 静态coherent risk通常time-inconsistent，仅未来risk greedy可能偏离总trajectory目标。
- **核心创新 / 方法** · RiskZero保MuZero表示/dynamics/policy，新增historical-return quantile head与distributional reward/value，MCTS抽样合成history+discounted tree rewards+leaf return后计算distorted-quantile risk并改进policy。
- **Baseline** · TQL trajectory history、distributional RL及risk MCTS已有；候选为learned-model搜索中的历史分布头/backup协议及stationary policy条件分析，最近原作待核。
- **Benchmark** · pixel MiniGrid，0.25-CVaR与1.0-CVaR、5seeds empirical episode risk；TQL/SampledTQL/QR-DQN/MuZero等，larger combinatorial任务名待核。
- **关键结果 / 消融** · 作者PDF6 MiniGrid约3×更少samples达TQL相近risk；PDF5 convergence需准确估计、softmax更新/positive isomorphism、每history正概率，不保证实际深网MCTS逐步真risk提升。
- **适用条件 / 局限** · static risk最优限选定stationary class/信息状态，非所有history-dependent policy全局最优。history/reward/value相关性若独立抽样可能失真，quantile tail与rare-event有限sample误差/搜索总预算待核。

## 5507 · Belief Propagation Converges to Gaussian Distributions in Sparsely-Connected Factor Graphs

[原文](https://proceedings.mlr.press/v306/yates26a.html)

<a id="yates26a-theory-statistics"></a>

**技术主题** · 按先验强度和图结构选择Gaussian BP

- **问题 / 瓶颈** · GBP便宜但非Gaussian因素何时可近似缺少边界。
- **核心创新 / 方法** · 用convolution cumulant衰减解释path信息传播，near-Gaussian乘积误差二阶，延至tree/computation-tree loopy BP；比较prior/pairwise variance ratio的排除区。
- **Baseline** · CLT smoothing、GBP与computation tree已有；候选为稀疏BP的条件Gaussian化与prior强度判断边界，最近原作待核。
- **Benchmark** · 固定拓扑synchronous BP，unary/binary shift-invariant factors、all moments/Lindeberg；synthetic path/tree/loop及stereo depth estimation，Gaussianity/accuracy指标待核。
- **关键结果 / 消融** · PDF5 path中R=σprior²/σpairwise²约≤6可让prior阻止Gaussian化，来自worst constructive nonGaussianity假设；tree/loop另需ε²≪ε，非通用6阈值。
- **适用条件 / 局限** · Gaussian形状收敛不等true posterior或mean正确，也非loopy BP算法稳定收敛。真实factor复用相关性在computation tree里当独立是BP近似，并非数据变独立；多峰强prior/高阶与Lie groups扩展未自动证。

## 5508 · Learning-Augmented Scalable Linear Assignment Problem Optimization via Neural Dual Warm-Starts

[原文](https://proceedings.mlr.press/v306/yavlovich26a.html)

<a id="yavlovich26a-inference"></a>

**技术主题** · 神经预测dual后投影可行再交精确匹配器

- **问题 / 瓶颈** · 直接神经匹配可能失去exactness，大图网络内存贵。
- **核心创新 / 方法** · RowDualNet共享row MLP及小k cost refinement，以solver dual MAE/slackness训练；v_j=min_i(Cij−u_i)保证dual feasibility，再seed augmenting-path solver，质量差时cold fallback。
- **Baseline** · learning-augmented dual warm-start/Dinitz2021和dual feasibility repair已有；候选为row-local scalable architecture与非迭代seed生成的工程选择，最近原作独立性待核。
- **Benchmark** · 1700余synthetic matrices，train N512/1536/2048/3072，test至16384；SciPy/LAP exact solver、end-to-end time，real tracking/transportation。
- **关键结果 / 消融** · 摘要报synthetic>2×、tracking1.25×、transport1.5×；PDF5明示complete-system计时。Min-Trick feasible只在solver正确接受seed并完成optimality判定时保exact。
- **适用条件 / 局限** · min仍读O(N²)成本矩阵，row state线性非整体线性memory；每row减同u不改变其k-nearest列排序，不能据此称捕捉全局竞争。O(N²)/O(N³) worst ratio不证明每个容易实例overhead忽略，fallback需budget保证。

## 5511 · Spectral Evolution Search: Efficient Inference-Time Scaling for Reward-Aligned Image Generation

[原文](https://proceedings.mlr.press/v306/ye26c.html)

<a id="ye26c-inference"></a>

**技术主题** · 固定高频只进化初始噪声低频

- **核心创新 / 方法** · SES以J-level DWT取D/4^J维low-frequency u，high-frequency固定；diagonal-Gaussian CEM sample/evaluate/elite-update后IDWT生成noise，预训练生成器不更新。
- **Baseline** · low-frequency search、wavelet subspace、CEM和noise optimization已有；候选为generative初始噪声频率敏感度与匹配预算的搜索维选择，最近原作待核。

- **关键结果 / 消融** · PDF4给dim reduction与完整CEM协议；作者称同compute优于强baseline，PDF5 perturbation Jacobian分析给power-law动机，指数/条件和实测曲线待核。
- **适用条件 / 局限** · 低频主导非任意generator/prompt/reward定律，高频细节任务可能损失；固定high-frequency不自动杜绝reward hacking。Jacobian沿轨迹time-order/mode mixing与线性化条件实质，theory非全局search optimum。

**可复用机制** · reward-guided生成若预算有限，可对初始noise的wavelet低频系数作CEM并固定high-frequency，优先搜索影响语义的大尺度方向；需保持同生成调用数比较。
