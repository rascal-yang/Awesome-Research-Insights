## 5503 · Gradient Flow Through Diagram Expansions: Learning Regimes and Explicit Solutions

[原文](https://proceedings.mlr.press/v306/yarotsky26a.html)

<a id="yarotsky26a-theory-statistics"></a>

**技术主题** · 联合宽度与初始化判断CP学习regime

- **问题 / 瓶颈** · 模型对称性和阶数改变gradient-flow极限，单一width经验不足。
- **核心创新 / 方法** · 以loss时间导数diagram/Wick expansions提取large-size Pareto monomials，按(p,H,σ)缩放识别free/NTK/mean-field等faces，再尝试生成函数PDE求显式loss。
- **Baseline** · diagrammatic NTK/mean-field与tensor GF已有；候选为CP order/symmetry依赖phase boundary及formal-series求和方法，最近原作待核。
- **Benchmark** · Gaussian初始化CP tensor learning，identity target及SYM/ASYM；loss vs rescaledGF time，p/H/σ扫描；实际有限尺度和数值误差待核。
- **关键结果 / 消融** · PDF6 ASYM balanced H≈p^(ν−1)，SYM even ν为H²≈p^ν；而fit identity的H=p不等该balanced scaling。作者称数值吻合，非所有非线性网络通用phase diagram。
- **适用条件 / 局限** · formal coefficientwise limit不自动可求和或交换time/size极限，作者明确可能需Borel且非一般有效；odd SYM未同等覆盖。continuous GF无Adam/SGD噪声，局部/有限time适用和数值控制待核。

**原文定位** · 初筛整理，原文与先例尚未统一核查。[原文第4页（PDF 第 4 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/yarotsky26a/yarotsky26a.pdf#page=4)；[原文第5页（PDF 第 5 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/yarotsky26a/yarotsky26a.pdf#page=5)；[原文第6页（PDF 第 6 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/yarotsky26a/yarotsky26a.pdf#page=6)

**可复用机制** · 用tensor CP分解或multilinear神经模型时，应联合输入维p、宽H、初始化σ及tensor order选择lazy/rich scaling，不能把H增大一概当NTK化。

## 5505 · Time Series, Vision, and Language: Exploring the Limits of Alignment in Contrastive Representation Spaces

[原文](https://proceedings.mlr.press/v306/yashwante26a.html)

<a id="yashwante26a-evaluation"></a>

**技术主题** · 时间序列对齐应区分全局几何和局部邻域

- **问题 / 瓶颈** · 独立模态表征的共享结构与posthoc coupling效果易混为一谈。
- **核心创新 / 方法** · 冻结TS/image/text encoder后训练projection heads做三对contrastive loss，比较pair ablations、encoder size、caption压缩/扩写及plot样式，使用CKA/Procrustes/kNN/retrieval。
- **Baseline** · contrastive alignment/plot mediation及representation similarity已有；候选是34配置下global-vs-local dissociation和caption信息增益饱和的有限经验规律，最近原作待核。
- **Benchmark** · CaTS aligned TS/plot/caption主实验、TRUCE只eval的generic/styled/annotated plots；R@1/5/10、cosine margin、RBF-CKA、mutual kNN；GPT2 caption total surprisal ID。
- **关键结果 / 消融** · PDF5 global metrics较强而kNN低，TS更易对齐plot，TS–TXT随scale相关更强；摘要称caption richer到阈值后饱和，精确阈值/等token实验待核。
- **适用条件 / 局限** · total surprisal=T×mean surprisal不是语义information density，长度/罕见措辞会混淆。模型size与architecture/pretraining/data未必独立；plot外显结构非所有TS成立，投影后CKA不能追溯未经耦合的Platonic共享空间。

## 5510 · Prompt Injection as Role Confusion

[原文](https://proceedings.mlr.press/v306/ye26b.html)

<a id="ye26b-evaluation"></a>

**技术主题** · 安全边界评估加入角色表征探测

- **问题 / 瓶颈** · provider标签与模型内部感知来源可能不一致，文本安全分数不能单独检测此边界。
- **核心创新 / 方法** · 以role probes量化user/tool/reasoning等表示方向，比较相同文本在correct/no/changed-tag条件的score，再检验role-confusion score与违规结果的相关。
- **Baseline** · representation probes、instruction hierarchy与role spoofing失效已有；候选为生成前role perception可量化并跨模型预测边界失效的协议，最近原作待核。
- **Benchmark** · STRONGREJECT313 requests及agent场景，gpt-oss/Qwen3/Nemotron等；ASR、role-probe score和benign role-attribution controls，训练/test splits待核。
- **关键结果 / 消融** · PDF6同文本三tag条件reasoning attribution约85/83/85%，支持tag alone未改变probe；摘要称生成前confusion预测ASR，完整校准/对照及泛化数据待核。
- **适用条件 / 局限** · linear projection overlap不等相同完整representation或authority；probe可能抓style不抓causal trust。ASR/score相关未排共同prompt难度因素，标签训练泄漏与跨模型calibration需核，不能断言所有模型角色边界不存在。

- **适用条件 / 局限** · 式7按字面是raw dotproduct求和而非softmax attention权重，实际实现待核；移动RoPE相位不等重新编码完整历史内容。深sink占用可变历史容量，topC信息丢失、重复回放与长时motion真实性待核。

## 5534 · Beyond Point-wise Neural Collapse: A Topology-Aware Hierarchical Classifier for Class-Incremental Learning

[原文](https://proceedings.mlr.press/v306/yi26e.html)

<a id="yi26e-inference"></a>

**技术主题** · 多局部原型与逐点残差漂移跟踪

- **问题 / 瓶颈** · 非线性feature drift下单点NCM不能覆盖类内多模态，整体刚性对齐不够。
- **核心创新 / 方法** · 层次聚类初始化球面SOINN节点，经SLERP/边龄清理；分数融合globalcos与maxlocalcos。STAR保存节点对应代表样本，比较当前与reference embedding，EMA残差加到未归一化节点，再归一化并同步globalmean。
- **Baseline** · NCM、多原型/KAC、SOINN/CHL和残差feature drift补偿为来源；实际七种CIL骨干替换classifier，固定DualPrompt/CODA比较FC/NCM/KAC与STAR。暂定增量是逐点非刚性运输接口，先例待核。

- **适用条件 / 局限** · STAR须访问旧代表样本，不能同时称完全exemplar-free；EMAreference更新/重复累计语义待核。max局部cos偏向节点多的类，图连边是否真正用于推断、同原型数预算与0.1Procrustes经验阈值普适性待核。

## 5535 · Improving CLIP Adaptation by Breaking Tail Alignment for Source-Free Cross-Domain Few-Shot Learning

[原文](https://proceedings.mlr.press/v306/yi26f.html)

<a id="yi26f-training-strategies"></a>

**技术主题** · CLIP弱patch抑制与强patch增强

- **问题 / 瓶颈** · 目标域标签极少时全patch对齐可能过拟合不具语义的弱响应。
- **核心创新 / 方法** · 每层class文本投影到visual空间，按maxclasscos选tophead与bottomtail；对head加其最相似文本、tail减其最不相似文本，学习层级α/β，并LoRA+CE训练。
- **Baseline** · CLIPLoRA、patchalignment/PACL与sourcefreeCDFSL为来源；实际CLIPLoRA与ATHA、head/tail控制，亦列使用source数据的DINO方法但非同条件来源。新增暂限相反符号token调制规则。
- **Benchmark** · 5way1/5shot，ISIC/EuroSAT/CropDiseases/ChestX，targetsupport适配100epoch；分类accuracy，sourcefree不用pretraining样本。此处仅图像分类证据。
- **关键结果 / 消融** · 1shot均值CLIPLoRA55.92→58.35，ISIC35.23→38.86、ChestX21.73→24.00；仍低部分使用source方法的ChestX24.17。pushawaytail观察支持该协议，不证明弱token普遍有害。
- **适用条件 / 局限** · tail按最大相似选却减最不相似文本，几何上不保证所有类别或原最大相似下降；文本投影非逆映射。α/β符号约束、fewshot调参泄漏、episode方差与测试时开销待核，不能视作跨域生物机制。

## 5536 · Language as a Wave Phenomenon: Semantic Phase Locking and Interference in Neural Networks

[原文](https://proceedings.mlr.press/v306/yildirim26a.html)

<a id="yildirim26a-architecture"></a>

**技术主题** · 复数频谱分支的相位消融

- **问题 / 瓶颈** · 频谱mixing可能将幅值与方向混合，参数效率改善难归因于复数表示本身。
- **核心创新 / 方法** · PRISM以复数embedding/phase位置与内容旋转、learned harmonic filter、Cartesian gate混合；混合架构增加实数bypass与attention refiner。用matchedreal、constrained/unconstrained及filter干预分离相位作用。
- **Baseline** · FNet/complexnetwork/ModReLU/FFTconvolution和Transformer为来源；实际Transformer/FNetHybrid、real→complex同拓扑与组件替换。暂定增量是受控phase证据与混合分支设计，最近complexsequence原作待核。

- **关键结果 / 消融** · 拓扑matchedreal PPL6.15、constrainedPRISM6.06、unconstrained5.80；WPT complex4.94对realstream5.55。phaseonly滤波相对原PPL仍恶化1.41/1.51倍，不应照概括称保持95%以上性能；L1/2输入出现重复生成。
- **适用条件 / 局限** · 有unitnorm输入不等整网所有状态unitnorm，Cartesiangate与LN可变幅/π翻转；无phasepreserving约束反而更好。FFT短序列失败是本架构经验而非通用信息论下界；seq-length迁移、训练公平与因果解释待核。
