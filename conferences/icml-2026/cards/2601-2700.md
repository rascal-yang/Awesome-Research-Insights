## 2601 · A Factorized Low-Rank RNN Framework for Uncovering Independent Neural Latent Dynamics and Connectivity

[原文](https://proceedings.mlr.press/v306/li26ha.html)

<a id="li26ha-representation-learning"></a>

**技术主题** · 神经群体动力学的组间独立分解

- **问题 / 瓶颈** · 如何从神经活动中识别近独立的潜在动力学组及其对应的功能连接？
- **核心创新 / 方法** · FacRNN 以变分框架重写低秩循环网络，在拟合中加入组间偏相关惩罚，允许组内多维结构，并据组别分解连接。
- **Baseline** · 改进来源：将训练后的独立分量分析改为端到端组间分解。实验对照：普通 lrRNN、SVD 型 LINT、块对角 bdRNN、lrRNN＋ICA、全分解版本。
- **Benchmark** · 含两个秩 3 组的合成神经序列、猴 M1 八方向运动和小鼠背侧皮层电压成像，考察偏相关、潜变量 R²、连接相关及生理解释。
- **关键结果 / 消融** · 合成测试集 FacRNN 的组间偏相关指标约 0.13，真实值约 0.10，普通 lrRNN 约 0.86。真实数据用连接及任务对齐模式作解释。
- **适用条件 / 局限** · 作者指出组数和组大小要预先指定，线性编码器与解码器才能直接解释连接，真实实验拟合未显式输入任务或刺激。

**原文定位** · [§3.1 变分重写（PDF 第 2 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/li26ha/li26ha.pdf#page=2) · [§3.2 组分解（PDF 第 3 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/li26ha/li26ha.pdf#page=3) · [§4 对照（PDF 第 4 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/li26ha/li26ha.pdf#page=4) · [§4.1–4.2 合成与猴 M1（PDF 第 5 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/li26ha/li26ha.pdf#page=5) · [§4.3 小鼠实验（PDF 第 8 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/li26ha/li26ha.pdf#page=8) · [作者局限（PDF 第 9 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/li26ha/li26ha.pdf#page=9)

## 2602 · GOCM: Single-Step Graph Outlier Synthesis via Origin Consistency Model

[原文](https://proceedings.mlr.press/v306/li26hb.html)

<a id="li26hb-data-strategies"></a>

**技术主题** · 潜空间单步合成图异常

- **问题 / 瓶颈** · 图异常标签稀少时，如何低成本生成异常节点并保留属性和关系结构？
- **核心创新 / 方法** · GOCM 训练原点一致性函数从流轨迹状态预测起点，用 VGAE 或多关系 MiVGAE 表达图潜空间，单次函数求值得到节点后解码属性与各类边。
- **Baseline** · 改进来源：用区间条件的原点一致性替代多步图扩散增强。实验对照：GODM、DiffGAD、DAGAD、常规 GNN 和专用图异常检测器。
- **Benchmark** · GADBench 七图，含同构 Weibo、Elliptic、Tolokers、Questions、DGraph 及异构 Amazon、Yelp。测 AUC、AP、Recall@k 与训练、推理总耗时。
- **关键结果 / 消融** · Weibo 上 GOCM 的 AUC／AP／召回为 99.62%／97.92%／93.94%，GODM 为 99.57%／97.54%／93.08%。Questions 的总耗时为 71.13 秒，GODM 为 172.35 秒。
- **适用条件 / 局限** · 范围：监督图异常检测的数据增强，当前在潜空间生成。作者将直接在原图空间生成和引入其他生成建模方法列为后续。

## 2603 · From Text to Forecasts: Bridging Modality Gap with Temporal Evolution Semantic Space

[原文](https://proceedings.mlr.press/v306/li26hc.html)

<a id="li26hc-representation-learning"></a>

**技术主题** · 文本线索向时序演化原语的映射

- **问题 / 瓶颈** · 怎样把文本事件对数值序列的影响表达成可解释条件，改善非平稳序列预测？
- **核心创新 / 方法** · TESS 将文字经冻结语言模型分类为均值变化、波动变化、形态及迟滞—衰减四种原语，按置信度门控，将其送入 PatchTST 预测器。
- **Baseline** · 改进来源：在文字与序列之间插入可由数值定义的演化语义空间。实验对照：TimeMixer、TimesNet、Nonstationary Transformer、NewsForecasting 等和去门控消融。
- **Benchmark** · 在 Bitcoin、FNSPID、Electricity、Environment 四套数据按官方划分测 MAE、MSE、RMSE，并分非平稳程度比较。
- **关键结果 / 消融** · Bitcoin 上相对 NewsForecasting 的 MAE、MSE、RMSE 分别降低 18.2%、29.1%、15.8%。Environment 上不到 1% 落后于 Nonstationary Transformer。
- **适用条件 / 局限** · 作者指出四个固定原语可能遗漏周期性、季节性和细粒度因果效应，诊断实验的领域及语言模型覆盖有限。

**原文定位** · [§4.1 四种语义原语（PDF 第 4 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/li26hc/li26hc.pdf#page=4) · [§4.2 文本提取（PDF 第 5 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/li26hc/li26hc.pdf#page=5) · [§4.3–5.1 条件预测和基准（PDF 第 6 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/li26hc/li26hc.pdf#page=6) · [表 1–2 结果（PDF 第 7 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/li26hc/li26hc.pdf#page=7) · [§7 作者局限（PDF 第 9 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/li26hc/li26hc.pdf#page=9)

## 2604 · Differentially Private Continual Release with Relative Error

[原文](https://proceedings.mlr.press/v306/li26hd.html)

<a id="li26hd-theory-statistics"></a>

**技术主题** · 相对误差下的差分隐私持续发布

- **问题 / 瓶颈** · 差分隐私的数据流上，允许相对误差后能否降低每轮发布极值或极值索引的加性误差？
- **核心创新 / 方法** · MaxSum、MinSum、MaxSelect 用 AboveThreshold 监测现有答案，必要时重算。非自适应 MinSelect 用势函数限制更新次数，并对自适应攻击构造下界。
- **Baseline** · 改进来源：把纯加性发布改为相对误差与加性误差并用。理论对照：纯加性界、自适应与非自适应数据流、纯及近似差分隐私。实验对照：未报告。
- **Benchmark** · 理论设置为长度 T、维度 d 的 [0,1] 向量流，每轮估计累计极值或选对应坐标，指标为全程相对与加性误差、隐私参数和成功概率。
- **关键结果 / 消融** · 在固定相对误差与隐私条件下，前三任务和非自适应 MinSelect 的加性误差仅为 d、T 的多对数级。自适应 MinSelect 在纯差分隐私下仍有 Ω(min{d/ε, √(T/ε), T}) 的加性误差下界。
- **适用条件 / 局限** · 作者指出上下界仍有多对数间隙。结论取决于数据流是否可适应既往发布和不同具体任务，且对应定理约束隐私与成功概率。

**原文定位** · [§1.1–1.2 结论与机制（PDF 第 2 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/li26hd/li26hd.pdf#page=2) · [表 1 界汇总（PDF 第 3 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/li26hd/li26hd.pdf#page=3) · [§2.2、定理 3.1（PDF 第 5 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/li26hd/li26hd.pdf#page=5) · [定理 4.3 自适应下界（PDF 第 7 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/li26hd/li26hd.pdf#page=7) · [§5 范围及后续（PDF 第 8 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/li26hd/li26hd.pdf#page=8)

**可复用机制** · 每轮要发布私有累计统计量时，可保留尚在相对误差容许范围内的结果，用私有阈值触发重新计算，并用触发次数控制总隐私成本。

## 2605 · OBJVanish: Prompt-Driven Generation of Physically Realizable 3D LiDAR-Invisible Objects

**技术主题** · 用可实现的物体组合排查 LiDAR 漏检

- **问题 / 瓶颈** · 车载 LiDAR 检测可能漏掉现实物体组合，单个点的扰动难复现这种实体几何造成的漏检。
- **核心创新 / 方法** · OBJVanish 在受限的真实三维对象与姿态组合空间生成测试资产，先用替代检测器搜索，再在独立检测器、模拟环境和封闭实地采集中验证。
- **Baseline** · 改进来源为以物体组合为单位的物理压力测试。实验对照包括随机提示、潜空间扰动、组合范围消融与原有点云攻击。
- **Benchmark** · CARLA/KITTI 风格仿真和封闭试验场，测六种 LiDAR 3D 检测器。无框或 IoU 小于 0.1 计作攻击成功，IoU 超过 0.5 计检出。
- **关键结果 / 消融** · 表 2 汇总六种检测器，OBJVanish 的模拟攻击成功率为 87.7±7.9%，随机提示 71.0±6.6%，潜空间扰动 78.0±11.2%。表 5 的 CARLA PointRCNN 单模型对照为 94.6%，AdvPC 为 64.2%。
- **适用条件 / 局限** · 优化需要可微的替代模型，实体测试覆盖有限的对象、参与者及传感器设置。生成器对复杂几何关系和罕见组合的控制有限。

## 2606 · SpecForge: A Flexible and Efficient Open-Source Training Framework for Speculative Decoding

[原文](https://proceedings.mlr.press/v306/li26hf.html)

<a id="li26hf-training-strategies"></a>

**技术主题** · 为草稿训练拆开目标模型执行

- **问题 / 瓶颈** · 投机解码草稿的训练效率受冻住的目标模型和可训练草稿共用执行栈的限制，多步训练模拟的注意力也会占用大量激活显存。
- **核心创新 / 方法** · SpecForge 将目标模型交给 SGLang 推理后端，草稿独立用 ZeRO-2 等训练。两端分别配置混合并行，并用稀疏树注意力和原地损失反传优化多步展开。
- **Baseline** · 改进来源为 EAGLE-3、分离的训练/推理后端和内核优化。实验对照为原 EAGLE-3 实现的 ZeRO-2/3、原生内核与其优化变体。
- **Benchmark** · 八张 H200、序列长度 4,096，比较 Llama、Qwen 大小模型的训练令牌吞吐；SpecBundle 另在 SGLang 测草稿接受和推理效率。
- **关键结果 / 消融** · 表 1 的 Qwen3-235B-A22B 中，SpecForge TP=8 达 20,227.2 token/s，ZeRO-3 基线 2,025.7 token/s，约 9.99×；ZeRO-2 基线显存不足。
- **适用条件 / 局限** · 提升取决于后端、并行配置、模型规模和批设置，目标与草稿放到独立 GPU 的资源调度仍待扩展。

## 2607 · Statistical Consistency and Generalization of Contrastive Representation Learning

[原文](https://proceedings.mlr.press/v306/li26hg.html)

<a id="li26hg-theory-statistics"></a>

**技术主题** · 按锚点规模配置对比学习负例

- **问题 / 瓶颈** · 对比表征需要了解两个关系，上游损失最优能否得到最佳检索排序，以及多加负样本为何先改善、再饱和。
- **核心创新 / 方法** · 以 AUC 型检索总体目标证明 Fisher 一致性和风险校准不等式，把对比学习泛化差分成内部负例误差和外部锚点误差，分别处理逐锚条件采样及共享独立负例。
- **Baseline** · 改进来源为似然比排序、校准界和复合风险分解。理论对照为总体最优检索以及两种负采样机制，实验比较不同锚点和负例数量。
- **Benchmark** · 从 DFN 为 FastCLIP 取 6M/10M/14M 锚点，测 ImageNet 零样本准确率及 MSCOCO、Flickr 双向 Recall@1。
- **关键结果 / 消融** · 定理 3.1 将最小对比风险与最优排序连接。定理 4.5/4.6 在各自采样条件下给出忽略对数因子的 O(1/m+1/√n) 与 O(1/√m+1/√n) 泛化界，m 是负例数、n 是锚点数。
- **适用条件 / 局限** · 理论依赖采样及有界网络范数等假设，实测共享负例的临界数量介于 √n 与 n 的尺度之间。

## 2609 · Scaling Robot Policy Evaluation via Discrete Diffusion World Model

[原文](https://proceedings.mlr.press/v306/li26hi.html)

<a id="li26hi-evaluation"></a>
