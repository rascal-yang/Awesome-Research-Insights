## 6401 · Position: Quantum Deep Learning Still Needs a Quantum Leap

[原文](https://proceedings.mlr.press/v306/gundlach26a.html)

<a id="gundlach26a-evaluation"></a>

**技术主题** · 量子DL加速先交叉筛运行成本与可行规模

- **问题 / 瓶颈** · 理论指数/平方加速可能在可运行问题规模内完全被硬件和数据装载成本覆盖。
- **核心创新 / 方法** · 沿Choi QEA框架更新硬件趋势，将preprocess、Grover search、matmul/attention和training量子算法映到经济优势/可行qubit/时限区域，逐项列QRAM及输出形式前提。
- **Baseline** · QEA成本模型、Grover/HHL/qmeans已有；候选为面向DL workload的定量交叉约束/否定性适用分析，最近quantum resource估计待核。
- **Benchmark** · 分析型benchmark为classical DL clustering、hyperparameter/action search、dense matmul/attention与NN training；QEA crossing、logical qubit和1month subroutine时限，非实机DL实验。
- **关键结果 / 消融** · PDF2以量子常数慢10^13、sqrtN vsN为例，优势需N>10^26，且仍须满足qubit/时限。PDF5指出matrix-vector优势在classical batching后可能缩小；这些是成本假设下推演非2030年代确定预测。
- **适用条件 / 局限** · 硬件价/速趋势、纠错和QRAM可靠性不确定；必须计state preparation/readout并按同精度/输出比。经典baseline有时取生产常见立方matmul/平方attention，若更优classical实现适用需重算，不能普遍否定所有quantum ML。

**可复用机制** · 评估量子DL子程序应同时计算门速/纠错/美元并行常数后的优势交点、可用logical qubits和允许墙钟，而非仅比较大O；QRAM/输入输出准备可直接改变是否值得实现。

## 6402 · Position: Universal Aesthetic Alignment Narrows Artistic Expression

[原文](https://proceedings.mlr.press/v306/guo26ao.html)

<a id="guo26ao-evaluation"></a>

**技术主题** · 审美reward评测分开显式风格遵循与通用品质

- **问题 / 瓶颈** · 统一审美目标可能压低合法的反审美风格，即使reward输入含相反要求。
- **核心创新 / 方法** · COCO captions注入多维wide-spectrum属性，paired生成Io/Ia；对original/反审美两prompt×两images交叉打reward，另用可解释维度judge与同内容editing检验情绪偏好。
- **Baseline** · 审美bias和reward shortcut已有；候选是显式意图冲突下的cross-scoring与对齐模型/原模型失败证据，最近审美alignment研究待核。
- **Benchmark** · Flux/DanceFlux/PrefFlux/Krea、SDXL/Playground、SD3.5M及对齐版、NanoBanana；HPSv2/v3/ImageReward、Qwen3VL维度judge、BLIP/LLM选择，另30中性情绪模板×4=120prompts及AVA实图。
- **关键结果 / 消融** · PDF7 DanceFlux约64%反审美图不比原图更符合反审美属性；FluxKrea例外较好，非全部preference alignment必失败。PDF8 SD3.5M的∆HPSv3−5.175，对齐PickScore版−2.781；指标方向需按prompt组合解释。
- **适用条件 / 局限** · 不同模型训练数据/scale不全匹配，不能将所有差异因果归为alignment；dimension judge本身训mainstream aesthetic且依赖自动评分。编辑会改变其他内容、失败图重试产生选择偏差，负情绪/抽象图的prompt遵循需人审与同预算。

## 6404 · Position: Anthropomorphic Misalignment Research Needs Stronger Evidence

[原文](https://proceedings.mlr.press/v306/gupta26e.html)

<a id="gupta26e-evaluation"></a>

**技术主题** · 保持假话表面线索而移除欺骗意图测试probe

- **问题 / 瓶颈** · 相关probe可能只检测falsehood/topic/style，而被过度解释为内部欺骗动机。
- **核心创新 / 方法** · 作者使用已有pretrained deception probes构造去意图stress datasets并测误报，另质性audit DeceptionBench必要ground truth；将behavior/下游效应/causal mechanism分层，要求替代解释控制。
- **Baseline** · correlational probe失效、specificity controls和证据层级已有；候选是保持surface cues的实测误报与dataset真值缺失证据，最近probe stress原作待核。
- **Benchmark** · Goldowsky-Dill等pretrained probes，透明风格/角色约束/复述翻译负对照，FPR；DeceptionBench场景质性审计，原始label agreement对照，具体数量/阈值待核。
- **关键结果 / 消融** · PDF6作者报告honest-labeled stress sets仍高FPR，数值在未读附录待核；PDF5 audit称18%scenario prompts缺必要ground truths，尽管原benchmark称97.1%人类agreement。两者指标不等同，不能直接相减。
- **适用条件 / 局限** · “无意图”是任务构造操作定义，不能因此证明模型内部没有任何误导机制；stress类OOD也可提高误报。需要同prompt/模型/threshold与baseline校准配平；定性audit样本/标注协议待核，不能把相关证据当完整因果反证。

## 6409 · Position: What Cézanne Knew About Visual Intelligence That Vision-Language Models Miss

[原文](https://proceedings.mlr.press/v306/hasan26a.html)

<a id="hasan26a-evaluation"></a>

**技术主题** · 分离因果文字与链结构评分并扫scaffolding

- **问题 / 瓶颈** · 流畅解释可能掩盖链结构无效，单一prompt评测无法看出格式和示例依赖。
- **核心创新 / 方法** · 在同一图像/问题上测full、partial、minimal三prompt，分别评分text与chain，CDD=(text−chain)/text、SS=chainfull−chainminimal；跨judge并在部分图人工检查。
- **Baseline** · 结构化因果链、prompt robustness和分离格式评分已有；候选为VLM家族中受控scaffolding变化与文字/链失配的失败经验，最近原作待核。
- **Benchmark** · COCOval500images×9questions=4500items，每模型3conditions=13500responses；LLaVA-NeXT13B/RLHF13B/CoT11B，GPT4o+Claude4.5 judges0–10及30image人工子集，CDD/SS。
- **关键结果 / 消融** · PDF6 Level3 RLHF CDDfull0.30、partial0.90、minimal0.87，full含2467blank responses；CoT0.76/0.86/0.66。blank会同时压低两通道，不能把更低CDD直接解释为更好因果能力。
- **适用条件 / 局限** · 文字链score gap不证明缺乏时间本体或内部因果表征，scaffold敏感也不等无能力。模型参数量/AnyRes/训练不同，不能只归因目标。NeXT原始text7.85/chain7.42与表CDD0.00对应口径待核，不替作者修值；无干预真值任务仅测结构proxy。

## 6411 · Position: Interestingness is an Inductive Heuristic for Future Compression Progress

[原文](https://proceedings.mlr.press/v306/herrmann26a.html)

<a id="herrmann26a-theory-statistics"></a>

**技术主题** · 压缩进展型任务选择区分突破新近度与幅度

- **问题 / 瓶颈** · 仅以过去累计compression gain预测未来收益可能忽略长期已停滞的对象。
- **核心创新 / 方法** · 定义time-bounded Kolmogorov/runtime与log-size-complexity profiles，分别在Length/Solomonoff/Speed priors条件下推断最后突破后仍有压缩进展的概率和期望；比较recentness与progress size。
- **Baseline** · compression progress/interestingness与算法统计已有；候选是给定部分profile时后续突破的条件分布与先验差异，原文比较既有进展幅度启发式，最近理论原作待核。
- **Benchmark** · 理论binary strings/理想prefix universal machine、可行profile与三个priors；突破概率/expected compression；三种通用计算范式的经验验证位于未读附录，具体程序规模/误差待核。
- **关键结果 / 消融** · PDF7 Length prior下进一步突破概率和期望约2^(−(t−mhat)+O(log nhat))；Algorithmic prior条件有突破时预期压缩幅度不同。PDF8 Speed prior更保守，原文也指出BusyBeaver极端runtime会制造强保守性。
- **适用条件 / 局限** · t是复杂度cutoff不是神经训练step/墙钟；profile转换用不可计算BusyBeaver，完整K/profile不可由常规loss观测直接获得。指数结论有log精度与先验条件，不代表所有迟发能力收益消失；神经surrogate/curriculum控制增益待验证。

## 6422 · Position: Epistemic Uncertainty Estimation Methods are Fundamentally Incomplete

[原文](https://proceedings.mlr.press/v306/jimenez26a.html)

<a id="jimenez26a-evaluation"></a>

**技术主题** · 数据重采样与seed双层UQ参照

- **问题 / 瓶颈** · 小ensemble disagreement可能掩盖共同偏差，learned aleatoric variance可吸收模型误差。
- **核心创新 / 方法** · 用proper-score/Bregman bias-variance分析区分偏差、dataset变化与procedure变化；建立nd独立数据×nγ seeds reference，与同数据DeepEnsemble/其他secondorder方法对比，低噪声复杂函数区与高噪声简单区分开。
- **Baseline** · 经典total variance、GneitingRaftery/Adlam分解、Zhang2024 bias/variance与Rossellini2024 synthetic为来源；实际10member ensemble对20datasets×10seeds reference。暂定增量限具体来源遗漏的可复用诊断证据，非发明分解，最近重复性待核。
- **Benchmark** · 1D heteroscedastic synthetic，x Beta分布、noise variance x4，MLP输出Gaussian mean/variance；known true mean/noise与estimated confidencebands、reference data/procedure variance，realdata/其他模型细节待核。
- **关键结果 / 消融** · 缓存图中低真实noise复杂函数区mean偏差大，但estimated aleatoric高、ensemble epistemic低；20×10reference CI更宽于同数据10ensemble。未猜coverage率或面积数值，结果是特定设定失效而非所有Bayes模型必低估。
- **适用条件 / 局限** · reference是跨data算法抽样分布，未必等固定dataset的Bayesian posterior目标；bootstrap/后验有不同estimand，不能一概说错误。真实data分区代重采并不独立同分布；variance identity需匹配loss和条件，finite DNN universal approximation也不自动零误差。200models成本与先例已有同类演示待核。

## 6425 · Position: Quantum Kernel Machines Should Move Beyond Scalar-Valued Kernels to Realize Their Potential

[原文](https://proceedings.mlr.press/v306/kadri26a.html)

<a id="kadri26a-architecture"></a>

**技术主题** · 非separable部分迹矩阵kernel与电路边界

- **问题 / 瓶颈** · scalar或fixed-output-matrix separable kernel难表达随输入变的输出依赖，量子fidelity kernel也受此限制。
- **核心创新 / 方法** · K(x,z)=TrX[U(ρY⊗σxz)U†]，U非tensor-product以耦合input/output；channel POC用σiσj和CNOT/SWAP组合、kernel ridge；另给pure outputρ的swap-test式电路，但其σxz为Hermitian density。
- **Baseline** · classical OVK/entangled kernel(HuusariKadri2021)、quantum fidelity与swap test为来源；实际separable QSVK vs nonseparable QOVK ridge。暂定增量为partial-trace构造/电路接口，经典等价与最近quantum先例待核。
- **Benchmark** · single-qubit bitflip/dephasing channel matrix-valued regression，例a.2、n100、regularization .1且CV选参；比较恢复Choi matrix图。一般frozen-feature多输出头是条件用途，非本文已有深网/机器人验证。
- **关键结果 / 消融** · POC图中QOVK恢复matrix结构较QSVK接近目标，主文未见独立重算数值故未补猜；dense block Gram由n变np，直接time O(n³p³)/memory O(n²p²)，结构表达增加有实际成本。
- **适用条件 / 局限** · 非separable U不自动证明任意σxz是positive operator kernel，需合法cross-feature构造；ridge输出也非自动physical CPTP约束。实验σiσj一般非Hermitian，而电路只给density σ，不能当实验kernel已实现。没有量子加速/shot复杂度优势证据，对classical entangled OVK公平比较及full error表待核。
