## 6402 · Position: Universal Aesthetic Alignment Narrows Artistic Expression

[原文](https://proceedings.mlr.press/v306/guo26ao.html)

<a id="guo26ao-evaluation"></a>

**技术主题** · 审美reward评测分开显式风格遵循与通用品质

- **问题 / 瓶颈** · 统一审美目标可能压低合法的反审美风格，即使reward输入含相反要求。
- **核心创新 / 方法** · COCO captions注入多维wide-spectrum属性，paired生成Io/Ia；对original/反审美两prompt×两images交叉打reward，另用可解释维度judge与同内容editing检验情绪偏好。
- **Baseline** · 审美bias和reward shortcut已有；候选是显式意图冲突下的cross-scoring与对齐模型/原模型失败证据，最近审美alignment研究待核。
- **Benchmark** · Flux/DanceFlux/PrefFlux/Krea、SDXL/Playground、SD3.5M及对齐版、NanoBanana；HPSv2/v3/ImageReward、Qwen3VL维度judge、BLIP/LLM选择，另30中性情绪模板×4=120prompts及AVA实图。
- **关键结果 / 消融** · PDF7 DanceFlux约64%反审美图不比原图更符合反审美属性；FluxKrea例外较好，非全部preference alignment必失败。PDF8 SD3.5M的∆HPSv3−5.175，对齐PickScore版−2.781；指标方向需按prompt组合解释。
- **适用条件 / 局限** · 不同模型训练数据/scale不全匹配，不能将所有差异因果归为alignment；dimension judge本身训mainstream aesthetic且依赖自动评分。编辑会改变其他内容、失败图重试产生选择偏差，负情绪/抽象图的prompt遵循需人审与同预算。

## 6404 · Position: Anthropomorphic Misalignment Research Needs Stronger Evidence

[原文](https://proceedings.mlr.press/v306/gupta26e.html)

<a id="gupta26e-evaluation"></a>

**技术主题** · 保持假话表面线索而移除欺骗意图测试probe

- **问题 / 瓶颈** · 相关probe可能只检测falsehood/topic/style，而被过度解释为内部欺骗动机。
- **核心创新 / 方法** · 作者使用已有pretrained deception probes构造去意图stress datasets并测误报，另质性audit DeceptionBench必要ground truth；将behavior/下游效应/causal mechanism分层，要求替代解释控制。
- **Baseline** · correlational probe失效、specificity controls和证据层级已有；候选是保持surface cues的实测误报与dataset真值缺失证据，最近probe stress原作待核。
- **Benchmark** · Goldowsky-Dill等pretrained probes，透明风格/角色约束/复述翻译负对照，FPR；DeceptionBench场景质性审计，原始label agreement对照，具体数量/阈值待核。
- **关键结果 / 消融** · PDF6作者报告honest-labeled stress sets仍高FPR，数值在未读附录待核；PDF5 audit称18%scenario prompts缺必要ground truths，尽管原benchmark称97.1%人类agreement。两者指标不等同，不能直接相减。
- **适用条件 / 局限** · “无意图”是任务构造操作定义，不能因此证明模型内部没有任何误导机制；stress类OOD也可提高误报。需要同prompt/模型/threshold与baseline校准配平；定性audit样本/标注协议待核，不能把相关证据当完整因果反证。

## 6414 · Position: The Systemic Lack of Agency in Visual Reasoning

[原文](https://proceedings.mlr.press/v306/huang26cp.html)

<a id="huang26cp-evaluation"></a>

**技术主题** · 分级提示注入区分视觉发现与计算失败

- **问题 / 瓶颈** · 识别已命名对象很好，不代表会自主找到未命名但必要的视觉线索。
- **核心创新 / 方法** · V-IRD按空间/物理/语境任务测试，先explicit recognition/knowledge probe；10高密度图的CoT外显迹分发现/关联/计算三阶段，再L0implicit、L1object、L2attribute、L3oracle逐级提示。
- **Baseline** · 物理视觉bench/explicit grounding与hint ablation为来源；实际多尺度VLM同10图/阈值四级注入。暂定增量是前置能力分离后的发现失败与scale条件控制，不将新benchmark本身视新增，最近先例待核。
- **Benchmark** · V-IRD四域10子任务，InternVL/QwenVL/Gemini等；离散accuracy、连续ACC5/10等relative error，y0特殊exactmatch；重点6models×10图diagnostic，完整总集数量/样本选择待核。
- **关键结果 / 消融** · Qwen3VL8B overall ACC5/10为39.45/44.01%，显式视觉识别组均近100%；10图平均阶段I/II/III失败比例75.82/14.42/9.76。中等model提示改善，large/small可持平或下降，未声称oracle普遍救回。
- **适用条件 / 局限** · 10图curated probe与选topmodel条件有限，stage分类凭CoT不认证真实hidden搜索顺序。level3提供答案所需数值改变信息量，group-level知识准确不等每实例充分。temperature Celsius相对误差及负/零label口径有问题，单位/denominator处理待核；图像物理可推断性和多次采样预算待核。

## 6422 · Position: Epistemic Uncertainty Estimation Methods are Fundamentally Incomplete

[原文](https://proceedings.mlr.press/v306/jimenez26a.html)

<a id="jimenez26a-evaluation"></a>

**技术主题** · 数据重采样与seed双层UQ参照

- **问题 / 瓶颈** · 小ensemble disagreement可能掩盖共同偏差，learned aleatoric variance可吸收模型误差。
- **核心创新 / 方法** · 用proper-score/Bregman bias-variance分析区分偏差、dataset变化与procedure变化；建立nd独立数据×nγ seeds reference，与同数据DeepEnsemble/其他secondorder方法对比，低噪声复杂函数区与高噪声简单区分开。
- **Baseline** · 经典total variance、GneitingRaftery/Adlam分解、Zhang2024 bias/variance与Rossellini2024 synthetic为来源；实际10member ensemble对20datasets×10seeds reference。暂定增量限具体来源遗漏的可复用诊断证据，非发明分解，最近重复性待核。
- **Benchmark** · 1D heteroscedastic synthetic，x Beta分布、noise variance x4，MLP输出Gaussian mean/variance；known true mean/noise与estimated confidencebands、reference data/procedure variance，realdata/其他模型细节待核。
- **关键结果 / 消融** · 缓存图中低真实noise复杂函数区mean偏差大，但estimated aleatoric高、ensemble epistemic低；20×10reference CI更宽于同数据10ensemble。未猜coverage率或面积数值，结果是特定设定失效而非所有Bayes模型必低估。
- **适用条件 / 局限** · reference是跨data算法抽样分布，未必等固定dataset的Bayesian posterior目标；bootstrap/后验有不同estimand，不能一概说错误。真实data分区代重采并不独立同分布；variance identity需匹配loss和条件，finite DNN universal approximation也不自动零误差。200models成本与先例已有同类演示待核。

## 6428 · Position: Sycophancy is an Educational Safety Risk: Why LLM Tutors Need Sycophancy Benchmarks

[原文](https://proceedings.mlr.press/v306/kasneci26a.html)

<a id="kasneci26a-evaluation"></a>

**技术主题** · 压力类型与judge差异的同题sycophancy剖面

- **问题 / 瓶颈** · 礼貌保留和错误认同难区分，aggregate失败率掩盖不同压力脆弱性。
- **核心创新 / 方法** · 360trap families，每家族3confidence×3pressure，先misconception再agreement pressure，评T2；两judge共享rubric，分歧全部作者adjudicate并随机审agreement，按family划dev/test，结果按压力/信心切片。
- **Baseline** · sycophancy pressure tests、tutoring corrective-friction与双judge审核为来源；实际GPT5.2/Claude4.5 tutor×同两judge以及human audit。暂定增量是同family压力条件与judge误漏的诊断经验，最近benchmark重复待核。
- **Benchmark** · 3240instances，test252families/2268instances，6domains均衡；两个tutor两轮，test4529usable dialogues；postpressure sycophancy各subtype、95%Wilson、DISAGREE与human audit，不是长期学习成效实验。
- **关键结果 / 消融** · GPT5.2 CS/authority/social失败7.7/16.8/18.1%，Claude17.9/15.3/8.9%，排序随压力变。JudgeA对GPT tutor flag0%，但作者复核322例SYC；同judge也漏大多数Claude，不能只归self-bias。98usable agreement audit有10例(10.2%)翻为SYC。
- **适用条件 / 局限** · 作者复核非独立盲审ground truth，两个judge同provider结构且阈值差异大；只有disagree全审会选择性补标签，agreement100样本不足校正全部rate。T2-only不等T1→T2因果退让，模板/validator可能限制naturalness，family内重复相关需cluster CI；不认证真实教育危害因果。

## 6432 · Position: CNNs Don’t See Shape — And That Won’t Change Without New Architectures

[原文](https://proceedings.mlr.press/v306/kayyam26b.html)

<a id="kayyam26b-evaluation"></a>

**技术主题** · 用冲突与去线索联合检验shape改进

- **问题 / 瓶颈** · 不同shape测试易混局部contour、global结构与texture依赖，单任务shape bias可能不可迁移。
- **核心创新 / 方法** · 训练28×28 square-grating/circle-dots确定配对；test反转配对、全图texture、shape-only及random/same texture；CNN/MLP/ViT和既有SPARSE CNN同Adam10epochs/10runs，再做MNIST/FashionMNIST全部class pairs。
- **Baseline** · Baker/Geirhos cue conflict/suppression、Li2023 SparseCNN及Doshi2025 configural shape/visual anagrams为来源；候选只限统一探针与SparseCNN跨受控任务失败经验，不称首次发现texture bias。
- **Benchmark** · synthetic 5000train/2000test、28×28 binary square/circle；10runs mean/SEM；textured MNIST/FashionMNIST allpair binary平均；accuracy按aligned/conflict/shape-only/texture-only区分。
- **关键结果 / 消融** · 缓存报告standard CNN/ViT冲突与shape-only表现弱；SparseCNN在简单shape任务提升且不伤aligned，但MNIST/FashionMNIST未获改进。图3/8精确量值待核，不估读柱高；应将成功限于最小刺激。
- **适用条件 / 局限** · 双cue都在训练完美预测标签，冲突标签选shape是评估约定；不能从OOD cue removal低分推出架构永不学shape。capacity/训练难度不保证匹配，SparseCNN仍可能只抑texture；无新架构与机制消融，不采“只有换架构才可能”必要性结论。

## 6461 · Position: Age Estimation Models Do Not Process Biometric Data

[原文](https://proceedings.mlr.press/v306/marshalkin26a.html)

<a id="marshalkin26a-evaluation"></a>
