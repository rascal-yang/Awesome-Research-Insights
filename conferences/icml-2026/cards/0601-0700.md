## 601 · OmniVideo-R1: Reinforcing Audio-visual Reasoning with Query Intention and Modality Attention

[原文](https://proceedings.mlr.press/v306/chen26ed.html) · [关联 Insight](../../../papers/multimodal.md#chen26ed-reinforcement-learning)

- **问题 / 瓶颈** · 音视频推理模型怎样按问题意图从声音和画面找证据，并减少只依赖单一模态？
- **核心创新 / 方法** · OmniVideo-R1 先用查询密集的定位方法建立推理模式，再对完整音视频、静音画面和音频三组 rollout 比较，奖励充分利用完整模态的输出。
- **Baseline** · 改进来源：多模态强化学习、自监督定位及模态对比。实验对照：原 Qwen3-Omni、仅 QI、QI+MA、不同训练方案及替换骨干。
- **Benchmark** · Daily-Omni、WorldSense、IntentBench、VideoHolmes、OmniVideoBench 和视觉单模态任务；记录准确率、训练策略和跨骨干结果。
- **关键结果 / 消融** · OmniVideoBench 上 Qwen2.5-Omni-7B 从 29.3 升至 38.7，MiniCPM-o-2.6 从 29.7 至 36.2；论文也比较只做查询定位与加入模态奖励。
- **适用条件 / 局限** · 模态奖励依赖单模态和全模态打分构造；数据或问题可由单一模态解答时，收益和解释会不同。

## 602 · DynaTok: Token-Based 4D Reconstruction from Partial Point Clouds

[原文](https://proceedings.mlr.press/v306/chen26ee.html) · [关联 Insight](../../../papers/computer-vision.md#chen26ee-representation-learning)

- **问题 / 瓶颈** · 只有不完整、无序且无对应关系的点云序列时，怎样重建完整几何并维持跨帧动态？
- **核心创新 / 方法** · DynaTok 将帧编码为紧凑 token，用时空 Transformer 聚合观察，以残差 token 分离几何与运动，再用条件流匹配统一解码四维点云。
- **Baseline** · 改进来源：潜空间点云重建、时序 token 和流匹配。实验对照：Shape2VecSet、TripoSG、TRELLIS、Motion2VecSets 以及只按帧编码的版本。
- **Benchmark** · DT4D 的未见运动和个体、Kubric 动态场景及真实零样本示例；用重建准确距离、完整距离、法向一致性和推断成本。
- **关键结果 / 消融** · DT4D 未见个体的完整距离与法向一致性为 0.026 和 0.877，Motion2VecSets 为 0.065 和 0.824；只用逐帧表征时为 0.301 和 0.531。
- **适用条件 / 局限** · 点云缺失严重时几何和动态仍有歧义，真实场景主要为展示；所测对照的输入点数限制影响部分比较。

## 603 · A Causal Decomposition Approach for Fair Contextual Multi-Armed Bandits

[原文](https://proceedings.mlr.press/v306/chen26ef.html) · [关联 Insight](../../../papers/reinforcement-learning.md#chen26ef-theory-statistics)

- **问题 / 瓶颈** · 在线情境赌博机要获得收益并控制因果不公平时，如何把直接、间接及伪关联效应纳入逐轮约束？
- **核心创新 / 方法** · 用反事实效应定义多种公平限制，非参数方法用乐观估计、镜像下降和 Bregman 投影，logistic 方法用参数置信界及探索阶段估计约束。
- **Baseline** · 改进来源：结构因果模型、带约束情境赌博机及 logistic bandit。实验对照：无约束 GLM-UCB、GLB-OMD 和采用另一公平指标的 CCLB；理论以最佳可行策略为参照。
- **Benchmark** · 有限上下文及参数化 logistic 理论；结构因果模型每轮构造 10 个动作特征，实证测不公平动作记零收益的惩罚遗憾、累计收益与耗时。
- **关键结果 / 消融** · 定理 1 在适当探索率下给非参数次线性遗憾和违反量；定理 2 给 logistic 遗憾的领先阶约 n√T，并在本文条件下让累计违反次线性，两者均不需 Slater 条件。
- **适用条件 / 局限** · 公平解释依赖已识别的因果结构和反事实可辨识假设；实证为合成数据，参数化结论需模型假设。

## 604 · AppWorld-UL: Benchmarking Diverse Agent-User Interactions for Tool-Use

[原文](https://proceedings.mlr.press/v306/chen26eg.html) · [关联 Insight](../../../papers/llm.md#chen26eg-evaluation)

- **问题 / 瓶颈** · 需要澄清、确认或说明不可行的工具任务，如何测量代理与用户交互及最终执行的成功率？
- **核心创新 / 方法** · AppWorld-UL 改写原任务以引入模糊或执行限制，由知识边界明确的语言模型模拟用户，再分别检查任务和多情境整体目标。
- **Baseline** · 改进来源：AppWorld 和用户在环工具使用。实验对照：代码代理、函数调用及不同骨干，并比较默认交互与预先提供 oracle 信息。
- **Benchmark** · 九个模拟应用、516 项任务，含不可行、欠明确、需确认与组合情况；报告交互任务 I-TGC 和情境 I-SGC 成功率。
- **关键结果 / 消融** · Claude Opus 4.7 的代码代理总体 I-TGC 48.6%、I-SGC 30.2%；组合题分别 35.7% 和 21.3%，同模型函数调用的总体为 27.3% 和 12.2%。
- **适用条件 / 局限** · 用户由受控模拟器担任，任务来自九款模拟应用；跨真实偏好、反馈或 API 的表现仍需验证。

## 605 · A Bayesian Approach to Quantify the Uncertainty of Human Ratings in a Single-Instance Multimodal Framework

[原文](https://proceedings.mlr.press/v306/chen26eh.html) · [关联 Insight](../../../papers/ml-foundations.md#chen26eh-theory-statistics)

- **问题 / 瓶颈** · 每个样本只有一次主观评分时，能否借助客观辅助模态估计那个评分的不确定性？
- **核心创新 / 方法** · 贝叶斯图模型把评分与辅助数据的共同内容和评分变异拆开，以条件先验建模隐不确定性，再用多模态摊销变分推断。
- **Baseline** · 改进来源：多模态变分模型和异方差不确定性估计。实验对照：异方差回归、深集成、证据回归、MVAE、MMVAE、MoPoE 和去变量版本。
- **Benchmark** · 十种子合成真值恢复和 ABIDE I/II、ACE 的静息态 fMRI 加行为评分，测重建误差、与真不确定性的相关、预测覆盖和区间宽度。
- **关键结果 / 消融** · 合成标准设置中不确定性估计与真值相关 0.666。真实测试的名义 90% 区间覆盖 0.819、宽 9.262，深集成为 0.849、17.595，体现覆盖和宽度取舍。
- **适用条件 / 局限** · 真实资料中没有评分不确定性真值，预测区间是代理；假设的潜变量结构和辅助模态质量决定可辨程度。

## 606 · Learning Rate Scaling across LoRA Ranks and Transfer to Full Finetuning

[原文](https://proceedings.mlr.press/v306/chen26ei.html) · [关联 Insight](../../../papers/ml-foundations.md#chen26ei-optimization)

- **问题 / 瓶颈** · 改变 LoRA 秩或切换到全量微调时，学习率是否可以按可预测的规律迁移？
- **核心创新 / 方法** · 最大更新适配 µA 用权重宽度、秩及初始化跟踪特征增量量级，要求特征更新稳定且不消失，并与全参数层的宽度缩放比较。
- **Baseline** · 改进来源：LoRA 训练动力学、最大更新和超参数迁移。实验对照：A 或 B 随机初始化、不同 LoRA 缩放和秩、全量微调、同配方学习率扫描。
- **Benchmark** · Tulu-3、OpenThoughts-114k、ANLI、ImageNet-1K、LLaVA-Instruct、GSM8K 和文本到图像微调，比较验证表现对应的学习率峰值。
- **关键结果 / 消融** · A 随机且 B 为零、缩放 α=r^{-γ} 时，稳定学习率量级为 n^{-1/2}r^{-(1−γ)/2}；B 随机、α=1 时为 n^{-1} 且与秩无关，与该全量分析的宽度规律一致。
- **适用条件 / 局限** · 理论是固定步数的渐近分析，有限宽度与秩可能有偏差；全量迁移的匹配是必要条件，文中实证支持其适用性。

## 607 · Beyond the Proxy: Trajectory-Distilled Guidance for Offline GFlowNet Training

[原文](https://proceedings.mlr.press/v306/chen26ej.html) · [关联 Insight](../../../papers/ml-foundations.md#chen26ej-training-strategies)

- **问题 / 瓶颈** · 只有静态离线轨迹、无法主动查询奖励时，怎样训练 GFlowNet 探索多样高奖励区域？
- **核心创新 / 方法** · TD-GFN 用逆强化学习从离线轨迹提取稠密边奖励，只用于图剪枝和优先反向采样；损失仍用离线记录的真实终点奖励。
- **Baseline** · 改进来源：离线 GFlowNet、逆强化学习及反向轨迹采样。实验对照：Dataset-GFN、Proxy-GFN、FM/QM-COFlowNet、BC、GAIL、CQL 和 IQL。
- **Benchmark** · Hypergrid、DBAASP 抗菌肽和分子设计；测高奖励样本、不同模式数量、多样性和达到收敛所需轨迹。
- **关键结果 / 消融** · 分子设计中 Reward-100 为 7.450、收敛需 2.749 万轨迹；QM-COFlowNet 为 7.296 和 4.423 万，Proxy-GFN 为 7.281 和 43.735 万。
- **适用条件 / 局限** · 依赖已有轨迹覆盖及终点奖励质量，剪枝可能排除有效区域；结果集中在给定离散设计空间。

## 608 · Multiview Self-Representation Learning across Heterogeneous Views

[原文](https://proceedings.mlr.press/v306/chen26ek.html) · [关联 Insight](../../../papers/computer-vision.md#chen26ek-representation-learning)

- **问题 / 瓶颈** · 同一张图经不同预训练模型得到不同特征，如何在无标注迁移中融合成跨视图稳定表征？
- **核心创新 / 方法** · MSRL 从多视图线性自表示做逐步信息传递，约束不同视图聚类分配概率分布一致，使共识表征保留互补信息。
- **Baseline** · 改进来源：多视图聚类与自表示学习。实验对照：CMVC、SparseMVC、HSACC、BONE、CPP、CLUDI、MIM-Refiner、TURTLE，以及平均融合消融。
- **Benchmark** · DINOv2 和 CLIP 提取异构视图，在 Pets、GTSRB、DTD、Aircraft、Flowers、CIFAR-10/100、ImageNet-1K 聚类；测 ACC、NMI、ARI。
- **关键结果 / 消融** · ImageNet-1K 的 ACC/NMI/ARI 为 73.24/88.26/62.80，TURTLE 为 70.10/86.58/58.42；去一致性项的平均融合 ACC 为 72.31。
- **适用条件 / 局限** · 依赖预训练领域和视图互补性；聚类结果随视图组合变化，新增视图并不保证实际准确率单调上升。

## 609 · Discrete Tilt Matching

[原文](https://proceedings.mlr.press/v306/chen26el.html) · [关联 Insight](../../../papers/llm.md#chen26el-loss-functions)

- **问题 / 瓶颈** · 掩码扩散 LLM 的奖励微调通常需要估计难以计算的边际似然，近似会影响策略更新。
- **核心创新 / 方法** · DTM 用离散 Esscher 变换把奖励指数倾斜分成小步，把倾斜后的解掩码后验写成当前模型下的奖励加权矩，用交叉熵拟合并用控制变量降方差。
- **Baseline** · 改进来源为连续扩散的 Tilt Matching，微调 LLaDA-8B-Instruct。实验对照为原模型、LLaDA-1.5、d1、wd1、UniGRPO 和 SPG。
- **Benchmark** · 网格迷宫检查路径是否连通且合法。LLaDA 测 MATH500、GSM8K、Countdown（零样本）及 Sudoku（三样本），半自回归生成长度 256 或 512，报准确率。
- **关键结果 / 消融** · 长度 512 的 Sudoku 准确率为 99.4%，原模型 26.2%，SPG 93.1%。同用 8 张 H100 时 DTM 的 Sudoku 奖励曲线优于 SPG。迷宫实验支持控制变量稳定训练。
- **适用条件 / 局限** · 依赖可前向评估的任务奖励。MATH500、GSM8K 虽优于原模型，仍低于 SPG。

## 610 · Steering Beyond the Support: Adversarial Training on Unsupervised Jailbroken Activation Simulation

[原文](https://proceedings.mlr.press/v306/chen26em.html) · [关联 Insight](../../../papers/llm.md#chen26em-training-strategies)

- **问题 / 瓶颈** · 监督训练的激活转向依赖已知越狱样本，换用训练时未见的攻击族容易失效。
- **核心创新 / 方法** · ULDD 从拒答状态中发现潜在方向，内层沿这些方向生成模拟越狱激活，外层学习由势函数导出的转向场，把它们推回拒答区域并约束对正常输入的影响。
- **Baseline** · 改进来源为拒答向量干预和无监督潜在方向发现。实验对照为原模型、CB、LAT、ROSI、AlphaSteer。
- **Benchmark** · 在 LLaMA-3-8B、Mistral-v2-7B 等三种模型上，用 HarmBench 的 GCG、AutoDAN、GPTFuzz、PAIR、TAP、FewShot 测 StrongReject；用 OR-Bench 假阳性率及 ARC-C、TruthfulQA、GSM8K 准确率测效用。
- **关键结果 / 消融** · LLaMA-3-8B 上六攻击平均 StrongReject 由 14.93% 降至 4.01%，CB 为 3.85%。OR-Bench 假阳性率为 16.6%，低于 CB 的 49.0% 和 AlphaSteer 的 24.4%。
- **适用条件 / 局限** · 需要读取与干预内部激活。作者指出线性外推无法保证覆盖所有失效模式，Base64 或密码编码触发的状态可能难以触及。

## 611 · OrchJail: Jailbreaking Tool-Calling Text-to-Image Agents by Orchestration-Guided Fuzzing

[原文](https://proceedings.mlr.press/v306/chen26en.html) · [关联 Insight](../../../papers/multimodal.md#chen26en-evaluation)

- **问题 / 瓶颈** · 工具调用式文生图代理的单步动作可能均通过检查，但工具组合可以产生有害输出，传统提示攻击缺少对整条执行链的信号。
