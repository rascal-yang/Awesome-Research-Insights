## 5701 · POLIA: Policy Optimization with Visual-Object-Level Intrinsic Advantage for Multimodal Reasoning

[原文](https://proceedings.mlr.press/v306/zeng26b.html)

<a id="zeng26b-reinforcement-learning"></a>

**技术主题** · 按相同对象集合归组的坐标优势

- **问题 / 瓶颈** · 答案groupreward无法区分视觉证据定位质量和语言推理成功。
- **核心创新 / 方法** · candidate预测boxes匹配GTobjects，按引用objectset组成group；ri,o=answerformatreward×IoU/L1confidence，withinobjectgroup标准化；Aext给全部tokens，Aint只给对应boxcoordinate tokens。
- **Baseline** · GRPO/DAPO、objectgrounding与processreward为来源；actualGRPO/DAPO、去extrinsic/intrinsic及不同backbone，最近objectlevelreward原作待核。新增暂限两级分组及坐标tokencredit规则。
- **Benchmark** · Qwen2.5VL3/7B在VSR/TallyQA训练，测试VSR/TallyQA/GQA/MathVista/MathVision/LogicVista/MME；accuracy及groupstability、额外训练开销，GTboxes来源/标注预算待核。
- **关键结果 / 消融** · 7B VSR81.3对GRPO59.0、Tally56.7对48.0、MathVista74.8对65.5；但MathVision29.4远低Gemini73.3且许多baseline来自officialreport，非全面可比。3BGQA60.2低fewshotSFT64.6。
- **适用条件 / 局限** · 所谓intrinsicadvantage使用GTboxes，并非无监督内在reward；withinsetgroup可能singleton/零std，filter处理待核。reward乘confidence是相关代理非对象因果贡献，同对象集合不同推理不可当counterfactual；额外grounding格式成本待核。

## 5702 · Symbiosis-Inspired Knowledge Distillation for Incremental Object Detection

[原文](https://proceedings.mlr.press/v306/zeng26c.html)

<a id="zeng26c-loss-functions"></a>

**技术主题** · 重叠query修正与旧类秩蒸馏

- **问题 / 瓶颈** · 旧模型将新物体误报旧类，同时重叠场景可能保留可迁移线索，直接KD会传播偏差。
- **核心创新 / 方法** · 按oldconfidence与新GTIoU分anchor/symbiotic/residual；MHA+MLP只修非anchor，以同类anchorcos训练；anchorboxes/logitsKD、各layer置信weightedlogitKD；oldclassconfidenceprototype做softrank关系蒸馏。
- **Baseline** · CLDETR/DyQ/DCA、prototypedistillation和rankrelationalKD为来源；actualRawKD/SpSD/SeSD及exemplar/noexemplar明确分列。新增暂限重叠query处理和slotaligned监督组合，最近原作待核。
- **Benchmark** · COCO2017 70+10/40+40及40+10×4/40+20×2，DeformableDETR，AP/AP50/75/size、oldAP及FPP；4RTX4090，旧数据不访问的主协议，marked*另用exemplars。
- **关键结果 / 消融** · 70+10 RawKD41.1、SpSD42.3、SeSD43.9、joint44.3AP；oldFPP5.1→1.3。40+10首增量43.6低DCA44.0，初40类45.4低DCA48.0，非每stage领先。
- **适用条件 / 局限** · 同旧预测classanchor可能强化新物体旧标签bias，空anchor及teacherfeaturealignment待核；slotidentity不自动空间对应。额外CFE训练/旧模型forward成本、GTnewbox监督和relative-rank操作可导近似待核，symbiosis非物理因果识别。

## 5705 · Beyond Euclidean Summaries: Online Change Point Detection for Distribution-Valued Data

[原文](https://proceedings.mlr.press/v306/zeng26f.html)

<a id="zeng26f-evaluation"></a>

**技术主题** · Wasserstein参考切向场的双统计监测

- **问题 / 瓶颈** · 均值/方差summary漏分布形状变动，单全局distance难定位方向与残差漂移。
- **核心创新 / 方法** · 估W2barycenter，OTplan的条件均值减reference位置得field；functionalPCA，HotellingT2与SPE双统计，prechangeempiricalquantile阈值，任一超界报警；理论给光滑transport下有限rank逼近。
- **Baseline** · Wassersteintangent/OTembedding、functionalPCA/T2/SPE和onlineCPD为来源；actualmomentcharts/ScanB/NEWMA/logKDE/FréchetCPD。暂定增量是distribution-valuedCPD的双方向监测与条件逼近边界，最近tangentCPD原作待核。
- **Benchmark** · syntheticcontinuous/discretebatchstreams含Gaussiantranslation、Poissonspike/orderedcategorical，N100示例；matchedARL0下ARL1/delay，卡仅通用统计证据，真实数据补充不作操作提取。
- **关键结果 / 消融** · d1 σ1小meanshift，IDDARL1 5.3±1.6劣Hotelling4.2±1.1；d2同shift2.4±.6优2.7±.7。简单meanshift不必换OT，ordinalmassflow更适合，图示范围无猜值。
- **适用条件 / 局限** · iidprechangeGaussianfield是null分布条件，empiricalthreshold不自动sequentialARL/anytime保证；双统计各自α需联合误报校准。discreteOTbarycentricfieldnorm≤W2且可能多coupling同field，不能称avoidallinformationloss；OT每batch成本、regularization与ARLmatch待核。

## 5708 · UCPO: Uncertainty-Aware Policy Optimization

[原文](https://proceedings.mlr.press/v306/zeng26i.html)

<a id="zeng26i-reinforcement-learning"></a>

**技术主题** · 确定回答与弃答的双通道优势

- **问题 / 瓶颈** · 同group对/错/不确定共用均值会压弃答或鼓励无差别弃答，固定uncertainreward难调。
- **核心创新 / 方法** · Sdet对/错标准化；uncertainadvantage=γ(q)×Aright，γ由Pw/(Pu+Pw)·(1−Pu)−Pr/(Pr+Pw)·Pu构成；缺对或错的group过滤，配标准RLpolicyobjective。
- **Baseline** · GRPO-UC、abstention/calibrationRL及dynamicreward为来源；actualpromptuncertainty/GRPO/固定reward .2/.5/.8及TAD/DURA/NTF控制。新增暂限分离channel与动态比例公式，最近prior待核。
- **Benchmark** · Qwen3/Llama3.1 8B，DAPOMath17k训练、AIME/AMC/MATH500/Minerva/Olympiad；generalGPQA/MMLURedux；PAQ与F1及uncertaintyratio，PAQ严格定义待统一核。
- **关键结果 / 消融** · Qwenmath平均PAQ79.63对baseline75.46，F175.90对75.46仅+.44；generalPAQ79.68高GRPO73.48，但F170.79低73.00。AIME UCPO F176.54低固定.2的78.82，不能称全指标可靠性提升。
- **适用条件 / 局限** · γ可负，uncertain并非总正优势；过滤极难全错/全对样本改变训练分布，可能不学真正边界。符号弃答不等校准概率或真实epistemic，比例小group高方差及labeljudge/parser、同有效rollout预算待核。

## 5711 · PonderLM-2: Pretraining LLM with Latent Thoughts in Continuous Space

[原文](https://proceedings.mlr.press/v306/zeng26l.html)

<a id="zeng26l-training-strategies"></a>

**技术主题** · 逐token隐状态回馈的Jacobi预训练

- **问题 / 瓶颈** · 直接每token多一次hiddenfeedback会形成顺序依赖，使普通teacherforced训练难并行。
- **核心创新 / 方法** · 每可见token后插最后hiddenstate作连续输入；训练先vanillaforward估H0，再交替token/Hk并行更新Hk+1，K轮后在latent位置算nexttokenCE；推断每token先latentstep再发token，可chain更多latent。
- **Baseline** · PonderLM/CoConut、Pause/LoopedTransformer、Jacobiiteration与continuousreasoning为来源；actualsameparam与2×param、2×/4×/8×FLOPs控制，最近latentpretraining原作待核。新增暂限Jacobi近似训练而非hiddenfeedback本身。
- **Benchmark** · Pythia410M/1.4B Pile300B、Llama1.4B从头与Llama3 3B CPT5BSlimPajama；PPL/9taskavgaccuracy、tokens/s、GSM8Ktesttimescaling及K消融。
- **关键结果 / 消融** · Pythia1.4B0shot58.5对vanilla54.1与2.8B57.3，但PIQA72.9低2.8B73.8；Llama1.4B2×FLOPs throughput111.55对2.8B110.50，Avg52.3对49.8。数据token相同不代表Jacobi训练FLOPs相同。
- **适用条件 / 局限** · 有限K未自动达到sequentialfixedpoint，训练位置mask、stopgradient与收敛率待核；前向依赖可有限传播，不意味任意K保证足够。2×inferenceFLOPs非任何batch/hardware等时延，多latentKV/attention成本与训练compute匹配待核。
