## 4704 · CAT-Q: Cost-efficient and Accurate Ternary Quantization for LLMs

[原文](https://proceedings.mlr.press/v306/wang26dr.html)

<a id="wang26dr-optimization"></a>

**技术主题** · soft-ternary-proxy

- **问题 / 瓶颈** · 极低比特PTQ直接学习尺度和阈值易失真。
- **核心创新 / 方法** · CAT-Q令代理W帽=(W-µ)/α，学习µ、α及阈值修正；最终W近似αT而不加回µ。平滑双tanh函数随校准时间加锐，再转硬量化；滑窗输出重构沿SliderQuant。
- **Baseline** · TWN、BitNet的absmean、可学习量化尺度及SliderQuant皆有先例；新增提取代理偏移与最终重构解耦及软硬接力。比较直接学习、硬三值及保留µ对照。
- **Benchmark** · Llama2、Qwen3、Ring-flash dense/MoE共10模型；512条C4×2048校准，五项常识准确率。
- **关键结果 / 消融** · Llama2-70B W1.58A16均值72.72，FP16为76.53，SliderQuant W2为71.08；Qwen3-4B降68.25到57.06。表6–10检验软化、尺度与µ处理。
- **适用条件 / 局限** · 不同QAT预训练起点与token预算不同，不能把对照全当等成本。默认60校准epochs；有限sharpness的双tanh不严格限于[-1,1]；滑窗与部署内核决定实际成本，名义1.58bit不等同端到端存储。

## 4705 · Decomposing the Basic Abilities of Large Language Models: Mitigating Cross-Task Interference in Multi-Task Instruct-Tuning

[原文](https://proceedings.mlr.press/v306/wang26ds.html)

<a id="wang26ds-training-strategies"></a>

**技术主题** · gradient-component-regrouping

- **问题 / 瓶颈** · 任务特定参数或MoE仍共享大量激活，正交初始化会漂移。
- **核心创新 / 方法** · BADIT沿PiSSA分解主奇异子空间为多个LoRA专家，冻结残差；归一化rank1梯度做球面聚类，再对中心SVD正交化并等容量重新指派。
- **Baseline** · PiSSA提供SVD初始化，LoRAMoE提供专家；新增是训练中梯度方向的rank1重组。比较LoRA、OLoRA、LoRAMoE、PiSSA、GainLoRA及BAD/DOG消融。
- **Benchmark** · SuperNI，六种LLM，mixed和sequential instruct tuning；ROUGE、遗忘和forward/backward transfer，五种子。
- **关键结果 / 消融** · Qwen3-4B mixed ROUGE55.22对LoRAMoE53.63；sequential50.74对48.58，遗忘5.95对8.50；表2消融分解和动态分组。
- **适用条件 / 局限** · 正交中心不等于所有参数/真实能力严格正交；“基本能力”是解释假说。重组需梯度统计和指派开销，实际时间比较见表3；未验证机器人迁移。

## 4710 · Muon in Associative Memory Learning: Training Dynamics and Scaling Laws

[原文](https://proceedings.mlr.press/v306/wang26dx.html)

<a id="wang26dx-theory-statistics"></a>

**技术主题** · frequency-aligned-matrix-sign

- **问题 / 瓶颈** · GD对低频关联学习更慢；坐标级sign不具旋转适应性。
- **核心创新 / 方法** · 分析零初始化、总体梯度、无动量Muon；利用分频组的梯度块对称结构证明matrix-sign在下降阶段近似任务基底的单位更新，并构造oracle TRA-SignGD作分析对照。
- **Baseline** · Muon/SpecGD操作已存在；新增是频率分组下动力学与缩放边界。对照GD、SignGD、不可实现的oracle TRA-SignGD；额外报告AdamW和实际Muon实验。
- **Benchmark** · 理论d=K正交等范数embedding、M组每组C同频，M远小于C；带噪幂律β>1。数值、长尾MNIST两层MLP与LLaMA预训练。
- **关键结果 / 消融** · 在论文联合渐近时间/分组条件下，GD超额风险下界约T^-(1-1/β)，Muon在η约logK/T时上界约(logK/T)^2；oracle aligned SignGD经学习率比例可匹配Muon。
- **适用条件 / 局限** · 这些界不是现实Muon/AdamW保证；频率组、正交特征、零初始化及总体梯度是关键。TRA-SignGD需未知任务表示而非实用算法。真实预训练只作趋势检验，不能声称指数加速普遍成立。

## 4711 · Learning Attribute–Affordance Hierarchies in Hyperbolic Space for Open-Vocabulary 3D Object Affordance Grounding

[原文](https://proceedings.mlr.press/v306/wang26dy.html)

<a id="wang26dy-loss-functions"></a>

**技术主题** · counterfactual-affordance-cones

- **问题 / 瓶颈** · 平面对齐只关联整体外观，难表达属性与功能的有方向关系。
- **核心创新 / 方法** · AAH用超图聚合图像region，再将属性、功能和点特征映入Lorentz空间；双向对比配合属性到功能及功能到点云ordering loss，反事实exclusion loss要求真实功能在反事实锥外。
- **Baseline** · hypergraph convolution、hyperbolic entailment cones已有先例；与GREAT及其加对比、Euclidean+hierarchy、hyperbolic+standard比较，增量是属性/反事实的3D grounding约束。
- **Benchmark** · PIADv2 seen、unseen-object、unseen-affordance；同PointNet++与DINO-ViT-S；AUC/aIoU/SIM/MAE。
- **关键结果 / 消融** · unseen-affordance AUC/aIoU70.90/13.26，同backbone GREAT69.82/12.06；Euclidean+hierarchy70.25/12.35；hyperbolic+standard70.05/12.20。
- **适用条件 / 局限** · 几何增益在此基准较小；MLLM生成的反事实并不验证真实属性必要性，不能称因果发现。依赖点级监督；无机器人闭环成功率。

## 4716 · Towards Understanding Massive Activations in Attention Sink Mechanism

[原文](https://proceedings.mlr.press/v306/wang26ed.html)

<a id="wang26ed-evaluation"></a>

**技术主题** · 注意力汇与巨激活的作用分离

- **问题 / 瓶颈** · 零掉巨激活导致sink消失，容易误判巨激活是sink生成的必要原因。
- **核心创新 / 方法** · 给自注意力Jacobian界分离注意力集中系数与隐藏态范数；比较RMSNorm前后扰动、单层/全层缩放及额外清零sink value。
- **Baseline** · 来源：Sun/Gu等对attention sink、巨激活与归一化的研究；新增作用分离与干预，非新KV偏置或门控模块。

- **Baseline** · 均值差steering与线性组合沿用既有激活控制；新增可复用诊断是SLM/flow交叉条件对照，非将steering本身当新。
- **Benchmark** · CosyVoice2、IndexTTS2，CREMA-D与IEMOCAP；混合情绪、文本情绪不一致及自然度。
- **关键结果 / 消融** · CosyVoice2 N300表1 SLM-driven F0/energy CCC0.109/0.308，flow-driven0.305/0.737；语速STD0.691对0.518。SLM情绪分化更强。
- **适用条件 / 局限** · 结论限所测混合架构；低CCC是不同情绪间差异，不代表真实性或通用控制保证。线性可分性是注入位置代理指标，过强steering存在表现力/自然度权衡。
