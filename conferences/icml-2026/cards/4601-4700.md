## 4601 · Reward-Preserving Counterfactual State Editing for Offline Reinforcement Learning

[原文](https://proceedings.mlr.press/v306/wang26s.html)

<a id="wang26s-data-strategies"></a>

**技术主题** · Reward-Preserving Counterfactual State Editing for Offline Reinforcement Learning

- **问题 / 瓶颈** · 离线轨迹含奖励伪相关，但任意反事实状态与原后继不一定满足动力学。
- **核心创新 / 方法** · CVAE推断奖励扰动代理并固定它生成状态编辑；以奖励误差及标准化位移上限验收，位移下限惩罚防止近复制。仅替换观测token；另用局部卷积与动作attention软监督，保留事实后继而不宣称为编辑状态的有效转移。
- **Baseline** · 来源为SCM及Decision Transformer；比较DT、DC、LSDT、ReBRAC、EDAC，另测伪相关干扰。
- **Benchmark** · D4RL MuJoCo、Antmaze及KuaiRand/KuaiRec/VirtualTB；归一化回报与干扰下下降。
- **关键结果 / 消融** · Hopper-medium归一化回报93.4；确定性干扰下CSET回报降幅HalfCheetah5%、Hopper6%、Walker2d3%，DT为20%、32%、37%。PDF7同架构删编辑后Hopper-medium93.4→92.8，Antmaze-umaze83.1→81.5，较DT的全部提升不能单独归于编辑。
- **适用条件 / 局限** · 奖励误差界是局部模型精度δ加验收ε，非因果识别或动力学有效性保证；架构与数据联合贡献需区分。保持当前奖励不保证原动作仍最优或整段轨迹动力学一致；位移半径不保证落在真实状态流形。

## 4603 · Text Before Vision: Staged Knowledge Injection Matters for Agentic RLVR in Ultra-High-Resolution Remote Sensing Understanding

[原文](https://proceedings.mlr.press/v306/wang26u.html)

<a id="wang26u-training-strategies"></a>

**技术主题** · Text Before Vision: Staged Knowledge Injection Matters for Agentic RLVR in Ultra-High-Resolution Remote Sensing Understanding

- **问题 / 瓶颈** · 只加工具RL或视觉领域数据可能损害单次正确率，难区分知识不足和证据搜索不足。
- **核心创新 / 方法** · 固定骨干、通用RL数据与训练日程，改变领域知识注入阶段及文本CoT；用领域文本冷启动后预热视觉难例再做zoom-in RL。
- **Baseline** · 复用DeepEyes工具GRPO；比较普通GRPO、SFT、视觉领域QA、领域文本去CoT与数学CoT。
- **Benchmark** · Qwen2.5-VL-7B；XLRS-Bench，SuperRS-VQA及148777领域文本QA；pass@1、pass@32。
- **关键结果 / 消融** · 领域文本CoT完整方案60.40/96.25；去CoT54.49/95.75；数学CoT46.98/90.87；差异显示知识内容与推理格式贡献不同。
- **适用条件 / 局限** · 仅遥感领域受控证据；pass@32为固定采样预算的可达性代理，非模型能力上界；文本数量等成本并非所有比较完全匹配。

## 4605 · DARTS: Distribution-Aware Active Rollout Trajectory Shaping for Accelerating LLM Reinforcement Learning

[原文](https://proceedings.mlr.press/v306/wang26w.html)

<a id="wang26w-data-strategies"></a>

**技术主题** · DARTS: Distribution-Aware Active Rollout Trajectory Shaping for Accelerating LLM Reinforcement Learning

- **问题 / 瓶颈** · 只按prompt调度长尾，无法改变同一prompt内无效冗长分布。
- **核心创新 / 方法** · 每题生成冗余候选，选K条最短和L条最长完整响应，K远大于L；按长度方差和开销模型分配冗余预算。
- **Baseline** · 基于GRPO、DAPO与VeRL；比较同框架VeRL和RollPacker Tail Batching，以及逐组件消融。
- **Benchmark** · Qwen2.5系列和Qwen3 MoE；数学五基准、BBH；500步平均吞吐及准确率。
- **关键结果 / 消融** · 相对VeRL加速1.29–1.77倍；14B消融streaming1.09、加sampling1.40、加allocation1.63倍；BBH Qwen3为84.4，低于基线85.8。
- **适用条件 / 局限** · 采样改变训练分布，短长奖励排序仅为启发性分析；不是所有任务性能无损；冗余生成成本需系统profile。

## 4606 · Implicit Turn-Wise Policy Optimization for Proactive User-LLM Interaction

[原文](https://proceedings.mlr.press/v306/wang26x.html)

<a id="wang26x-reinforcement-learning"></a>

**技术主题** · Implicit Turn-Wise Policy Optimization for Proactive User-LLM Interaction

- **问题 / 瓶颈** · 高随机性多轮对话中，token隐式奖励波动影响价值回归与信用分配。
- **核心创新 / 方法** · 用相对参考模型的token对数概率比训练隐式PRM，轮内求和；softmax轮权重乘终局奖励，再做轮级策略更新。
- **Baseline** · 继承PRIME隐式PRM；比较轨迹终奖、均分、LLM Judge、PRIME、ITPO与Norm-ITPO。
- **Benchmark** · 模拟用户数学辅导、文档写作、推荐；PPO/GRPO/RLOO；准确率、BLEU、token成本及组合score。
- **关键结果 / 消融** · RLOO数学准确率29.06→32.50，token1.44k→0.62k；PPO文档BLEU40.57→45.16；未归一ITPO并非所有任务准确率提高。
- **适用条件 / 局限** · 需要额外PRM和用户模拟器；softmax归因不是因果证明；终奖为零时该分配所有轮皆零，温度控制集中程度。

**可复用机制** · 把隐式过程奖励聚合到整轮后用softmax分配终局奖励，保持总奖励尺度并减少token级归因噪声。

## 4607 · ProphetKV: User-Query-Driven Selective Recomputation for Efficient KV Cache Reuse in Retrieval-Augmented Generation

[原文](https://proceedings.mlr.press/v306/wang26y.html)

<a id="wang26y-inference"></a>

**技术主题** · Layer-fused query scoring for cache repair

- **问题 / 瓶颈** · 分块独立预计算的缓存缺少跨块信息；只在首层选重算token可能遗漏深层query相关内容。
- **核心创新 / 方法** · 第一阶段只让短query经过模型全层并注意预计算缓存，按query维汇总每层注意力；均匀平均层分数选统一top-p集合，第二阶段对该集合跨层重算。
- **Baseline** · query-aware重算已有A3首层策略；CacheClip用微调辅助模型末层；CacheFocus已有跨层累计文档注意力剪枝。实际主要对比CacheBlend、EPIC、KVShare；附录同设置隔离首层、末层、平均层策略，非完整A3/CacheClip系统比较。
- **Benchmark** · RULER及LongBench；Llama3.1-8B、Qwen2.5-14B、Qwen3-14B；受限重算比例下任务准确率、层策略及chunk尺寸消融。
- **关键结果 / 消融** · PDF15表5 Qwen2.5-14B的RULER-MV首层48.75、末层77.50、平均91.25；HQA42.50/57.10/58.10。Llama HQA平均50.70略低于末层50.90，MQue均24.40，融合非每项最优。
- **适用条件 / 局限** · 已有跨层聚合原则，新增量局限token修复层策略；近似缓存注意力可能被噪声检索误导，小chunk/低重算比例退化；语义误差上界及被选token恢复假设非全网络准确性保证；尚未完整集成优化推理引擎。

## 4608 · CurvZO: Adaptive Curvature-Guided Sparse Zeroth-Order Optimization for Efficient LLM Fine-Tuning

[原文](https://proceedings.mlr.press/v306/wang26z.html)

<a id="wang26z-optimization"></a>

**技术主题** · CurvZO: Adaptive Curvature-Guided Sparse Zeroth-Order Optimization for Efficient LLM Fine-Tuning

- **问题 / 瓶颈** · 固定稀疏扰动掩码不能随训练辨认重要参数，而一阶重要度需反传。
- **核心创新 / 方法** · 用方向差分Δ和稀疏扰动v累积Δ²v_i²分数，按总扰动能量归一化并EMA平滑；按分数平方根分配带上限的采样概率，以Δv_i/π_i修正非均匀掩码偏差，按集中度调预算。实现按原生参数张量作block。
- **Baseline** · 沿用MeZO及稀疏ZO；比较MeZO、DiZO、LoRA组合；理论优化的是Fisher对角方差上界。
- **Benchmark** · OPT2.7B/6.7B与Llama系列；1000训练样本NLP任务；准确率、时间及显存。
- **关键结果 / 消融** · OPT2.7B八任务均值66.8，MeZO64.2、DiZO61.4；LoRA版65.1，MeZO+LoRA62.1；实际实现按原生参数张量作block。
- **适用条件 / 局限** · 代理曲率非完整Hessian，忽略参数耦合；理论最优概率以真实Fisher为条件，实用plug-in不等价全局最优。分数含采样频率和共享梯度能量项，不是无偏Fisher/Hessian对角估计；有限差分仍有O(ε²)偏差。

## 4609 · DiL: Discrete-anchored Representation Alignment for Semi-Supervised Continual Learning

[原文](https://proceedings.mlr.press/v306/wang26aa.html)

<a id="wang26aa-representation-learning"></a>

**技术主题** · DiL: Discrete-anchored Representation Alignment for Semi-Supervised Continual Learning

- **问题 / 瓶颈** · 无标签流上密集蒸馏与错误伪标签放大旧新类干扰。
- **核心创新 / 方法** · 用二值原型筛选判别维度并分开蒸馏旧新类；按锚混淆度选新类块支撑以减少与旧混淆类重叠。
- **Baseline** · 来源为原型锚与ECOC；比较USP、直接原型蒸馏DPD、随机/聚类分配及有无混淆矩阵。
- **Benchmark** · CIFAR10/100、ImageNet100半监督持续学习；平均/末任务准确率及不同buffer。
- **关键结果 / 消融** · CIFAR10-30中选择蒸馏末准确率68.20，替换DPD64.78；去混淆引导再降2.29百分点；20K buffer CIFAR100上iCaRL+DiL仍低于USP。
- **适用条件 / 局限** · 依赖类别增量及可识别原型；块支撑有限，混淆错误可能误导分配；不同backbone和数据上并非统一优势。

## 4610 · AgentNoiseBench: Benchmarking Robustness of Tool-Using LLM Agents Under Noisy Condition

[原文](https://proceedings.mlr.press/v306/wang26ab.html)

<a id="wang26ab-evaluation"></a>

**技术主题** · AgentNoiseBench: Benchmarking Robustness of Tool-Using LLM Agents Under Noisy Condition

- **问题 / 瓶颈** · 理想工具环境得分不能诊断真实交互中证据通道受损的失败。
- **核心创新 / 方法** · 在保留任务可解性的约束下注入用户与工具噪声，分别在早中晚阶段测试，联合记录成功、步数和token。
- **Baseline** · 继承VitaBench、τ2-Bench与Search任务；比较有无噪声、不同来源、思考与非思考模型及阶段。
- **Benchmark** · 多模型工具交互；每任务4次独立试验；Avg@4及相对鲁棒性变化。
- **关键结果 / 消融** · 工具执行失败类别平均分0.31；多数受测模型中段注入伤害更大；思考模型在多数场景的相对鲁棒性低于非思考模型。
- **适用条件 / 局限** · 模型比较非严格配对因果实验；中段脆弱性的机制解释是假说；不能把场景内经验视为所有代理的普遍定律。可解性由生成/审核协议约束而非形式证明；轨迹全程有效的门控会排除中途偏离后恢复的成功，需与最终任务成功率分开解读。

## 4612 · RA-Det: Towards Universal Detection of AI-Generated Images via Robustness Asymmetry

[原文](https://proceedings.mlr.press/v306/wang26ad.html)

<a id="wang26ad-evaluation"></a>
