## 5604 · Fine-to-Coarse Fairness-Informed Multi-View Clustering

[原文](https://proceedings.mlr.press/v306/yu26ad.html)

<a id="yu26ad-loss-functions"></a>

**技术主题** · 耦合样本簇状态与锚点簇计数的目标

- **问题 / 瓶颈** · anchor配置与样本簇不匹配时可能欠表示复杂或大簇。
- **核心创新 / 方法** · 引入离散sample-cluster和anchor-cluster指示矩阵，以图相似/簇离散状态项与标签对齐耦合，并对anchor簇比例超出(1±δ)/k施加平方hinge惩罚；交替逐行重分配。
- **Baseline** · 多视图anchor graph、离散聚类与平衡分配为来源；候选是簇状态反馈和anchor计数的联合目标，最近fairness/size-aware anchor原作待核。
- **Benchmark** · FORETYP、CITSER、NUSWINE、NUECTEN、YTFATEN、YTFSFLF（缓存拼写待核）；ACC/NMI/Purity/Fscore及时间/空间随样本量变化。
- **关键结果 / 消融** · 缓存FORETYP ACC82.79低于UOVSC84.51，但NMI63.42高于62.56；CITSER ACC49.58低于HOMGC52.46，不能笼统写每集最优。
- **适用条件 / 局限** · 显式anchor计数项接近均匀容差，不是直接强制与样本簇规模成比例；“公平”不是敏感群体公平保证。线性规模需固定anchor数/簇数/迭代，非任意维度全线性。

## 5605 · MAnchors: Memorization-Based Acceleration of Anchors via Rule Reuse and Transformation

[原文](https://proceedings.mlr.press/v306/yu26ae.html)

<a id="yu26ae-inference"></a>

**技术主题** · 缓存低精度高覆盖规则再映射细化

- **问题 / 瓶颈** · Anchors每个输入从空规则开始会重复大量昂贵模型查询。
- **核心创新 / 方法** · 记忆低精度高覆盖中间anchor；命中后按特征相似度水平替换谓词，再从该起点纵向增加条件，继续Anchors采样/beam/KL-LUCB精度判定。
- **Baseline** · 原Anchors及检索/规则复用已有基础；候选是中间规则缓存与水平映射的搜索初始化，vertical并非新搜索器，最近缓存解释先例待核。
- **Benchmark** · Adult RF/GBT/NN、RT-Polarity RF/Llama及图像YOLOv8；时间、采样数、precision/coverage、解释长度，缓存流顺序和阈值。
- **关键结果 / 消融** · 缓存Llama情感解释513.06s到58.70s为8.74×、采样减87%；NN表格0.23s到0.12s约1.87×。允许coverage/长度一定变化，不等于逐例相同解释。
- **适用条件 / 局限** · 近邻和谓词映射错配仍需重新采样；precision是指定扰动分布下的统计条件，不保证因果解释；缓存热启动/构建、顺序与质量阈值调参预算待核。

## 5607 · Local Intrinsic Dimension of Representations Predicts Alignment and Generalization in AI Models and Human Brain

[原文](https://proceedings.mlr.press/v306/yu26ag.html)

<a id="yu26ag-evaluation"></a>

**技术主题** · 用局部而非全局维度诊断表示对齐

- **问题 / 瓶颈** · 单一全局维度不能充分反映不同模型的对齐/泛化差异。
- **核心创新 / 方法** · 使用已有kNN距离比MLE维度估计，按K扫描局部到全局；比较模型—模型、模型—脑对齐与ImageNet泛化，加入匹配样本数的全局对照。
- **Baseline** · 既有局部ID估计和ID—泛化关联为来源；候选是局部/全局尺度的控制诊断，估计器本身不新，最近Ansuini/Sharma等原作待核。
- **Benchmark** · NSD八受试者自然图像fMRI、ImageNet模型表现及跨模型表示；PCA300训练集拟合、对齐分数、ID尺度相关及1000邻居/同样本全局控制。
- **关键结果 / 消融** · 缓存发现局部K附近的低维度更稳定关联较强AI-AI/AI-Brain对齐及泛化，而同样本量全局估计不足解释；精确相关/置信区间待核，不把散点关联写成因果机制。
- **适用条件 / 局限** · 无证据表明主动压低ID能改善模型；架构、数据和规模仍可混杂，kNN尺度与距离集中/PCA影响待核；不能据此无标签保证选到最高泛化模型。

## 5608 · SPARKLING: Balancing Signal Preservation and Symmetry Breaking for Width-Progressive Learning

[原文](https://proceedings.mlr.press/v306/yu26ah.html)

<a id="yu26ah-optimization"></a>

**技术主题** · 扩宽时只重置新通道状态并独立重热身

- **问题 / 瓶颈** · 完全复制虽减少瞬间loss跳变，却可能让新增通道长期与旧通道同梯度更新。
- **核心创新 / 方法** · 区分随机/单侧复制与双侧复制的fan-in尺度，复制扩宽后仅重置新参数优化器状态，新参数从当前lr热身到按比例新峰值，旧参数沿原schedule。
- **Baseline** · Net2Wider类函数保持扩展、RMS重标定与已有optimizer-state scaling为来源；候选是中期扩宽的非对称状态/LR操作，最近progressive-width原作待核。
- **Benchmark** · dense/MoE中间维/hidden及联合2×扩宽；100B token扩展后至200B、预训练loss及ARC/MMLU等下游均值、训练FLOPs。
- **关键结果 / 消融** · 缓存非对称reset优于同时drop/copy状态；额外严格optimizer-state缩放无附加增益。最终下游可更好但预训练loss略差于从头大模型；最多35%成本节约口径待核。
- **适用条件 / 局限** · RMS分析有分布/相关性假设，非精确函数保持；新旧状态/LR及复制布局需正确分组，随机训练噪声也可能破对称；扩宽时点、优化器、总token与等成本条件待核。

## 5613 · Improving LLM-Based Recommenders with Conservative Generative Flow Networks

[原文](https://proceedings.mlr.press/v306/yu26am.html)

<a id="yu26am-loss-functions"></a>

**技术主题** · 在离线SubTB中惩罚无支持流量

- **问题 / 瓶颈** · 只约束已见subtrajectories未必唯一决定未见动作概率。
- **核心创新 / 方法** · CFlower在SubTB加unsupported forward flow的递增ϕ penalty，按subtrajectory长度加权；constrained on-policy用masked/renormalized P_F沿dataset DAG采样，在prefix tree中无需backward额外正则。
- **Baseline** · conservative offline RL、SubTB和constrained token decoding已有；候选为unsupported flow而非仅policy概率的penalty及非识别诊断，最近COFlownet原作待核。
- **Benchmark** · 三Amazon recommendation datasets，distributional matching、accuracy/exposure、作为SDPO reference；具体dataset名称、指标和采样总预算待核。
- **关键结果 / 消融** · PDF4写清LC-SubTB与三种nonidentifiability来源，PDF5给masked sampling；非识别结论限observed constraint system，不能泛称完整GFlowNet训练始终不识别。
- **适用条件 / 局限** · unsupported不等低真实reward，过度保守会阻止有效新items；流scale和ϕ/α可能使penalty失衡。token-prefix唯一parent条件关键，通用DAG backward compensation仍需处理；on-policy仅树内非环境在线。

## 5614 · Practical and Optimal Algorithm for Linear Contextual Bandits with Rare Parameter Updates

[原文](https://proceedings.mlr.press/v306/yu26an.html)

<a id="yu26an-inference"></a>

**技术主题** · 奖励参数少更新而Gram探索逐步更新

- **问题 / 瓶颈** · rare parameter updates与strictly batched action rule常被混为同一限制。
- **核心创新 / 方法** · BLCE用static update grid，interval中reward-free Sherman–Morrison更新H−1，先最大confidence-radius探索再按历史θ exploit，boundary才用累积reward重估并eliminate。BLCE-G保G-design作对照。
- **Baseline** · batched elimination、G-optimal design及rare switching已有；候选为放开context adaptivity后免design而保最优regret的计算选择，最近原作待核。
- **Benchmark** · iid context sets、linear reward（noise条件待核），small/large K，regret约min(√(dT logK),d√T)含logs；frozen-neural-feature用途条件迁移，原实验数据待核。
- **关键结果 / 消融** · PDF6算法显式区间内更新Gram，BLCE-G定理同时覆盖两K regime；摘要BLCE同最优且更低runtime，GLM扩展条件和完整复杂度待核。
- **适用条件 / 局限** · 不是严格batched，仍每轮O(d²)Gram/arm-selection与context访问。iid contexts、realizability/feature norm条件实质；若神经representation在线变化，原linear confidence无效；少参数更新非少全部计算。

## 5615 · Spectral-Informed Neural Networks Outperform Spectral methods in High-dimensional PDEs

<a id="yu26ao-architecture"></a>

**技术主题** · 按解正则性缩放谱系数并嵌入基底

- **问题 / 瓶颈** · 普通SINN在稀疏频率训练下难预测未见谱系数。
- **核心创新 / 方法** · Modified SINN输出z_a(k)uθ(k,t)乘衰减；analytic Fourier例用exp(−||α⊙k||1)，非光滑改power decay且zero-frequency因子设1；basis embedding编码低维结构。
- **Baseline** · SINN、spectral decay prior与basis encoding已有；候选为learned amplitude envelope×basis embedding的缺失频率外推选择，最近原作/双项消融待核。

- **关键结果 / 消融** · PDF4–5给两类regularity scaling与zero-frequency处理，作者称稀疏/高维更准；完整数值和稀疏grid prior匹配控制待核，不泛称所有spectral methods被超越。

## 5616 · Understanding Generalization from Embedding Dimension and Distributional Convergence

[原文](https://proceedings.mlr.press/v306/yu26ap.html)

<a id="yu26ap-theory-statistics"></a>

**技术主题** · 用维数诊断时同时计tail敏感性与信息丢失

- **问题 / 瓶颈** · 参数数目不足解释已训练表征的population-vs-heldout差异。
- **核心创新 / 方法** · 以Wasserstein empirical distribution convergence按upper Wasserstein dimension给rate，再由loss与network/Bayes tail Lipschitz传播，取layerwise bound最小项，另加label-surrogate residual。
- **Baseline** · Weed–Bach分布维数rate与Lipschitz generalization已有；候选为固定model多层posthoc分解/diagnostic协议，最近原作增量待核。
- **Benchmark** · fixed trained predictor、independent held-out n，bounded embedding support/surrogate noise和smooth loss；多架构数据的dimension-generalization correlation，具体名称待核。
- **关键结果 / 消融** · PDF5 bound含n^(−1/(d*+ε))、tail/Bayes Lipschitz、2E||Y−F*k(Z)||；final layer去掉network tail不等去掉Bayes/loss敏感性或irreducible term。
- **适用条件 / 局限** · 不是对同训练集可自适应模型的uniform training generalization证书；unknown constants/upper dimension难估。低dimension可能丢标签信息，提高noise项；correlation非因果，也未必优于fixed-model标准held-out concentration。

## 5617 · AvAtar: Learning to Align via Active Optimal Transport

[原文](https://proceedings.mlr.press/v306/yu26aq.html)

<a id="yu26aq-data-strategies"></a>

**技术主题** · 按全局transport效用梯度主动询问对应

- **问题 / 瓶颈** · 局部uncertainty不一定改善整体alignment，直接反传Sinkhorn迭代贵。
- **核心创新 / 方法** · AvAtar把global f(T)的adjoint化成含diag marginals/T blocks的PSD线性系统，用CG求adjoint，得pair impact；object impact=Σ_j T_ij I(pair_ij)，动态更新OT与监督。
- **Baseline** · active alignment、implicit OT gradients和adjoint/CG已有；候选为global utility query impact及object posterior聚合规则，最近原作待核。
- **Benchmark** · multi-network alignment、multimodal alignment、point-cloud registration三task；query budget vs alignment accuracy、CG runtime，具体数据名/n/m待核。

[原文](https://proceedings.mlr.press/v306/yu26bs.html)

<a id="yu26bs-optimization"></a>

**技术主题** · 为adapter塑形的投影量化

- **问题 / 瓶颈** · 普通PTQ最小总输出误差未考虑adapter有限rank，散布残差占用适配容量。
- **核心创新 / 方法** · E=(W−Wq)X，rankrd右singularvectors构P；对X(I−P)运行PTQ减orthogonalerror，交替更新；最终按rankra对whitenedresidualSVD初始化BA，再任务训练。
- **Baseline** · LoftQ、CALDERA、GPTQ/AWQ及SVDLLM为来源；covarianceawareinit明确来自Liu2024。实际同SVDadapter对照PTQ、LoftQ/CALDERA；暂定新增是补空间量化noise-shaping，最近activationawarelowrank原作待核。
- **Benchmark** · Llama2 7/13B、Qwen2.5 7/14/32B、Qwen3 4/8/32B，2/3/4bit；WikiText2/PTB/C4PPL、ARCc/e/PIQA/StoryCloze平均zero-shotaccuracy及GSM8K，rd/ra64示例。
- **关键结果 / 消融** · 2bit Qwen3 8B C4PPL42.02低LoftQ54.71但高CALDERA39.36；commonacc41.96高41.15。故不是所有模型/指标最佳；3bit对4bit等性能范围和SVD补偿训练成本待核。
- **适用条件 / 局限** · Theorem5.2比较constructedseparableupperbound，需ra≥rd+taskrank及谱集中假设，低上界不证明真实jointLoRAloss更小或必保plasticity。calibration子空间到downstream迁移、singularcov逆平方根稳定与PTQ交替globaloptimum待核。

## 5649 · Uncovering Hidden Triggers: Backdoor Attribution in Language Models

[原文](https://proceedings.mlr.press/v306/yu26bw.html)

<a id="yu26bw-evaluation"></a>

**技术主题** · 后门组件稀疏但需要联合移除

- **问题 / 瓶颈** · 表示可分不直接定位行为通路，单head作用和总体ASR下降可能不一致。
- **核心创新 / 方法** · 以representationprobe识别触发相关信号，按高层activation干预归因定位组件，再联合消融验证；这里只保留防御诊断与移除统计，不整理注入、激活控制或向量构造步骤。
- **Baseline** · linearprobe/SVM、activationpatching/causaltracing与headablation为来源；实际Llama2/Qwen2.5多类后门下排序及移除数量控制。新增暂限稀疏但需协同的实证失效边界，随机/同数控制与最近attribution原作待核。
- **Benchmark** · 7B注入模型，多类label/fixedoutput/行为后门，triggerpresentASR与probe/interlayeraccuracy；干净task保留、触发泛化及误报率待核；只评估防御性指标。
- **关键结果 / 消融** · Qwen2.5 label类示例top16heads ASR91.94→59.68、top32→30.65，分别降约35.1%/66.7%，不足支持所有设定移除约3%即降90%。1–8heads不稳定，需联合较多组件。
- **适用条件 / 局限** · 跨样本meanactivation不消除全部语义混杂，干预有outofdistribution效应；probability归因和生成ASR不等。已知poisonpaired样本与whitebox访问限制部署，干净能力损失及未见trigger覆盖必须核，不视作通用消毒保证。

## 5650 · Causal Fine-Tuning under Latent Confounded Shift

[原文](https://proceedings.mlr.press/v306/yu26bx.html)

<a id="yu26bx-training-strategies"></a>

**技术主题** · 冻结与微调双视图的稳健分解

- **问题 / 瓶颈** · fine-tune可能加强与标签相关但会在deployment反转的来源线索。
- **核心创新 / 方法** · R0冻结预训练、R1finetuned作two-viewconsistency提稳定proxyC；10patch低层embeddingmean学shift-sensitiveΦ；利用训练样本localfeature分布平均prediction实现adjustment，推断去掉冻结副本。
- **Baseline** · multi-viewcontentstyle识别、VonKugelgen2021、backdooradjustment与SWA/WISE为来源；actualSFT/SWA/WISE及identicalviews/CFTN/C/Φ控制。增量暂限pairedview加局部线索adjustment的训练接口，最近因果finetune先例待核。

- **关键结果 / 消融** · Yelptest10 CFT58.40高SFT49.24，但低SWA62.92；Amazontest10 56.40高49.33但低SWA59.75。噪声加强时CFT可较SWA略好，范围有限；identicalviews近SFT是关键负控制。
- **适用条件 / 局限** · SCM是识别scaffold非真实textDGP，C只是proxy非恢复groundtruthcause；算法是否满足两视图独立变化/mediation假设待核。平均Φ是所设干预目标，不保证任何testdistribution最优，frozen训练额外内存/梯度成本待核。

## 5651 · Conditional Quantile Adjusted Conformal Prediction for Time Series

[原文](https://proceedings.mlr.press/v306/yu26by.html)

<a id="yu26by-theory-statistics"></a>

**技术主题** · 单调分位曲线投影与固定不对称比

- **问题 / 瓶颈** · tailquantile估计噪声与crossing造成区间不稳定，不同α的独立宽度优化破坏嵌套。
- **核心创新 / 方法** · 在quantilegrid拟合CornishFisher/Hermite系数，约束单调；quantilelevelCV选K；referenceα0选择ρt，其他α均用[Q(ρα),Q(1−α+ρα)]。替换SPCI的rawconditionalquantile并滚动更新。
- **Baseline** · SPCI/EnbPI、CFexpansion/monotonicquantile与conformalcalibration为来源；actualSPCI/EnbPI/ACI/PID/ECI及DeepAR/TFT。新增暂限曲线共享降噪与跨α固定不对称比，最近quantileprojection先例待核。
- **Benchmark** · RealizedVolatility/IndexReturn/ExchangeRates/Electricity，α.1、5runs；coverage与normalizedavgwidth、跨αnesting；条件残差curvelearner/pointpredictor与滚动窗口细节待核。
- **关键结果 / 消融** · Volatilitycoverage SPCI89.0→CQ90.1%，width .8→.9%略变宽；Electricity88.9→90.0%、width9.3→9.2%。不能称区间永远更窄；coverage是经验边际，非直接观测逐历史条件覆盖。
- **适用条件 / 局限** · conditionalcoverage仅渐近，需中心概率区间、smoothness、design良态与投影一致；不认证任意dependence有限样本。gridmonotonic到全curve的约束实现、CV对noisybase而非truth的偏好、极端tail外推与MSE gain条件待核。
