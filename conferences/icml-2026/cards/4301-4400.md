## 4301 · Origo: Interpretable Multi-physics PDE Foundation Model through Neural Operator Splitting

[原文](https://proceedings.mlr.press/v306/sun26aa.html)

<a id="sun26aa-architecture"></a>

**技术主题** · latent-conditioned-operator-splitting

- **问题 / 瓶颈** · 异构PDE预训练难分离共享全局传播与局部本构。
- **核心创新 / 方法** · 上下文预测物理控制码；频域指数线性流与稀疏KAN算子库组成对称split-step，有限门控CNN补偿剩余误差。

- **适用条件 / 局限** · 理论需可谱对角化线性半群、局部Lipschitz与交换子界；二阶收敛依赖局部误差O(h³)，部署码误差另计；可解释读出非任意PDE因果辨识。

- **问题 / 瓶颈** · SAT图表示未显式编码正负literal的共享与反对称信息。
- **核心创新 / 方法** · 子句-literal超图传播配合变量不变/等变分量；正负表征由二者加减构成，用全体符号翻转的两视图约束预测与表征。

- **适用条件 / 局限** · 预测不是不可满足证明；需核心变量标签；对一般符号任务的迁移属改造设想，原证据限SAT；某些SR指标HG未优。

## 4305 · Amortized Simulation-Based Inference in Generalized Bayes via Neural Posterior Estimation

[原文](https://proceedings.mlr.press/v306/sun26ae.html)

<a id="sun26ae-inference"></a>

**技术主题** · temperature-amortized-posterior

- **问题 / 瓶颈** · 每组观测和温度重跑GBI采样成本高。
- **核心创新 / 方法** · 训练q(θ|x,β)；一路学习联合score后离线温化合成，另一路以似然或比率的β−1次幂做SNIS加权NPE。
- **Baseline** · 来源：NPE/NLE/NRE、ACE及SNVI；实比非摊销power-posterior参考采样与两训练路径。

- **适用条件 / 局限** · 只针对likelihood power posterior，非任意损失GBI；NRE权重有限方差界限β∈[1/2,1]；推理免MCMC不代表训练免采样。

## 4311 · Randomized Advantage Transformation (RAT): Computing Natural Policy Gradients via Direct Backpropagation

[原文](https://proceedings.mlr.press/v306/sun26ak.html)

<a id="sun26ak-optimization"></a>

**技术主题** · 有限步优势预条件求解

- **问题 / 瓶颈** · 显式Fisher或共轭梯度给策略优化带来较高成本。
- **核心创新 / 方法** · 对每个on-policy rollout内累计梯度估计g，用小批量残差y-Hg求解带局部阻尼的Gram系统，经变换优势反传；配合梯度范数裁剪，共享actor-critic用伪优势统一。

- **Benchmark** · 600案例，DL3DV/游戏/生成图；61帧与≥250帧回访轨迹；PSNR/SSIM/LPIPS、相机误差、MEt3R和FPS。
- **关键结果 / 消融** · 长时普通RoPE与重映射PSNR14.03/16.27；加Context Forcing后18.94，LPIPS0.371；720p24FPS需8×H800及量化并行/流式解码。
- **适用条件 / 局限** · 模拟视频几何一致性不代表可执行物理仿真；相机回访评测依赖姿态估计与尺度归一；24FPS是系统组合结果，不能归因单一训练目标。

## 4327 · AgentHijack: Benchmarking Computer Use Agent Robustness to Common Environment Corruptions

- **问题 / 瓶颈** · 普通桌面干扰破坏代理定位、状态追踪及初始化。
- **核心创新 / 方法** · 分别评测9种常见环境扰动及强度/时空位置；辅助onlooker比较状态并给出行为摘要、检查初始化，辅助已强化grounding的动作生成器。

## 4328 · Teaching Models to Teach Themselves: Reasoning at the Edge of Learnability

[原文](https://proceedings.mlr.press/v306/sundaram26a.html)

<a id="sundaram26a-data-strategies"></a>

**技术主题** · 以学生真进步奖励课程生成

- **问题 / 瓶颈** · 初始极低成功率使直接RLVR奖励稀疏，内部自奖励课程可能退化。
- **核心创新 / 方法** · 外循环RLOO生成候选题答集；复制学生分别做10步内循环RLVR，以困难训练子集准确率增量作题集奖励；超过阈值提升学生基线并保存课程。
- **Baseline** · 来源为课程学习、非对称自博弈与双层优化；比较Hard-Only、Intrinsic-T、SeRL、基础教师与额外真实课程。
- **Benchmark** · Llama3.2-3B为主，MATH/HARP fail@128划分train/test，留出test pass@1–32；OlympiadBench迁移，6–12 seeds。
- **关键结果 / 消融** · 保存课程PQ在留出集pass@32较Hard-Only提升MATH9.3、HARP4.2个百分点；基线增4倍采样计算仅提升2.8点；教师本身直接解题未明显改善。
- **适用条件 / 局限** · 0/128是有限采样筛选而非不可解证明；需要有标签困难训练题供奖励，非无数据；多学生分支和奖励评估昂贵；问题结构的重要性为受控数学范围经验。
