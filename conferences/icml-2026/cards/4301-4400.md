## 4301 · Origo: Interpretable Multi-physics PDE Foundation Model through Neural Operator Splitting

[原文](https://proceedings.mlr.press/v306/sun26aa.html)

<a id="sun26aa-architecture"></a>

**技术主题** · latent-conditioned-operator-splitting

- **问题 / 瓶颈** · 异构PDE预训练难分离共享全局传播与局部本构。
- **核心创新 / 方法** · 上下文预测物理控制码；频域指数线性流与稀疏KAN算子库组成对称split-step，有限门控CNN补偿剩余误差。
- **Baseline** · 来源：Strang splitting、谱神经算子、KAN；实比DPOT、MoE-POT、OmniArch及去splitting/机制路由。
- **Benchmark** · FNO/PDEBench/PDEArena/CFDBench十数据；未见1D KdV、2D Allen-Cahn零样本；相对L2。
- **关键结果 / 消融** · KdV完整0.0103、去split0.0421、去机制0.0284；Allen-Cahn0.0952、0.285、0.193；MoE-POT零样本为0.0237/0.152。
- **适用条件 / 局限** · 理论需可谱对角化线性半群、局部Lipschitz与交换子界；二阶收敛依赖局部误差O(h³)，部署码误差另计；可解释读出非任意PDE因果辨识。

## 4302 · Unsat Core Prediction through Polarity-Aware Representation Learning over Clause-Literal Hypergraphs

[原文](https://proceedings.mlr.press/v306/sun26ab.html)

<a id="sun26ab-representation-learning"></a>

**技术主题** · polarity-invariant-equivariant-decomposition

- **问题 / 瓶颈** · SAT图表示未显式编码正负literal的共享与反对称信息。
- **核心创新 / 方法** · 子句-literal超图传播配合变量不变/等变分量；正负表征由二者加减构成，用全体符号翻转的两视图约束预测与表征。
- **Baseline** · 来源：NeuroSAT/NeuroCore、DeepSAT、NeuroBack；实比二部图与逐项加HG、DE、REG。
- **Benchmark** · SR、CA、PS不同难度；unsat-core变量Precision、PR/ROC-AUC；SATCOMP2023–2025 Glucose限5000秒。
- **关键结果 / 消融** · CA平均Precision二部图0.238、HG0.360、加分解0.383、加REG0.408；Glucose增加解出15/7/6例。
- **适用条件 / 局限** · 预测不是不可满足证明；需核心变量标签；对一般符号任务的迁移属改造设想，原证据限SAT；某些SR指标HG未优。

## 4305 · Amortized Simulation-Based Inference in Generalized Bayes via Neural Posterior Estimation

[原文](https://proceedings.mlr.press/v306/sun26ae.html)

<a id="sun26ae-inference"></a>

**技术主题** · temperature-amortized-posterior

- **问题 / 瓶颈** · 每组观测和温度重跑GBI采样成本高。
- **核心创新 / 方法** · 训练q(θ|x,β)；一路学习联合score后离线温化合成，另一路以似然或比率的β−1次幂做SNIS加权NPE。
- **Baseline** · 来源：NPE/NLE/NRE、ACE及SNVI；实比非摊销power-posterior参考采样与两训练路径。

- **适用条件 / 局限** · 只针对likelihood power posterior，非任意损失GBI；NRE权重有限方差界限β∈[1/2,1]；推理免MCMC不代表训练免采样。

## 4312 · From Prior to Pro: Efficient Skill Mastery via Distribution Contractive RL Finetuning

- **核心创新 / 方法** · 冻结生成策略与视觉编码器，用同一latent驱动动作块残差；值提升且Q不超过MC回报加负裕量时关闭残差平方惩罚；结合多候选期望训练和best-of-N执行。

- **适用条件 / 局限** · 门控依赖critic与MC回报质量，是启发式而非收缩保证；动作熵降低不自动推出闭环稳定定理；多候选增加推理计算。

**技术主题** · 低秩Value漂移缓存
