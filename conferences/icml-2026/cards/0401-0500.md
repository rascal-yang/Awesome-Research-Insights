## 401 · Where Detectors Fail: Probing Generative Space for Generalizable AI-Generated Image Detection

[原文](https://proceedings.mlr.press/v306/cao26s.html)

<a id="cao26s-data-strategies"></a>

**技术主题** · 合成图检测

- **问题 / 瓶颈** · AI 图像检测器在新生成器上泛化差，常规生成采样难覆盖接近当前判别边界的困难样本。
- **核心创新 / 方法** · PROBE 把检测器作评判信号，在扩散生成器内部流形上搜索可逃过判别的逼真图像，以感知正则保持外观，再用这些图像重训检测器。
- **Baseline** · 改进来源为难例训练和生成模型内部编辑。对照包括 UnivFD、BFree、DDA、未作边界探索的 DINOv2/ResNet50 和常规增广。
- **Benchmark** · 用 GenImage、AIGI-Quality-Paradox、Synthbuster、Chameleon、SynthWildX、WildRF、AIGI-Bench 七项，比较平衡准确率并考察图像后处理。
- **关键结果 / 消融** · GenImage SD 1.4 训练组中，ResNet50 加 PROBE 后七项平均平衡准确率从 63.5% 升至 78.1%。
- **适用条件 / 局限** · 作者指出边界搜索需接入可修改的扩散生成器，当前每次只用一种生成器来探索，纯黑盒扩展仍待验证。

## 402 · Causal Feature Learning via Generalized Rayleigh Quotients

[原文](https://proceedings.mlr.press/v306/cao26t.html)

<a id="cao26t-representation-learning"></a>

**技术主题** · 跨环境特征提取

- **问题 / 瓶颈** · 过程监测的时序特征若只相关于局部目标或只求跨环境不变，调整工况后可能漏检或误报。
- **核心创新 / 方法** · CFL 用广义 Rayleigh 商最大化滞后特征的目标关联，并惩罚跨环境均值偏移，解广义特征问题提取稳定的预测子空间。
- **Baseline** · 改进来源为时序潜变量和跨环境不变性约束。实验对照含 Mahalanobis、SFA 等 15 种过程监测法。
- **Benchmark** · Tennessee Eastman Process 用虚警约束比较故障检出率、实际虚警率和延迟，平均值覆盖 18 个可检出的故障。
- **关键结果 / 消融** · CFL 平均检出 94.6%、实际虚警 1.3%，Mahalanobis 与 SFA 检出分别为 93.7%、93.5%。移除滞后嵌入后 CFL 检出为 92.5%。
- **适用条件 / 局限** · 作者指出均值不变和滞后相关是预测代理，不能单独确证因果。TEP 的时段分组主要反映缓慢漂移。

## 403 · Hierarchical Policy Learning via Spectral Decomposition

[原文](https://proceedings.mlr.press/v306/cao26u.html)

<a id="cao26u-architecture"></a>

**技术主题** · 频域分层动作策略

- **问题 / 瓶颈** · 机器人动作块内，低频运动意图与细粒度对准、接触调整依赖不同信息，独立生成可能损害精度。
- **核心创新 / 方法** · CSP 用 DCT 分出低、高频动作，先从观察和语言预测粗轨迹，再以实际粗轨迹为条件生成高频修正，另用仿遥操作噪声做增强。
- **Baseline** · 改进来源为动作分块和频域分解。实验对照包括 ACT、BAKU、Action Binning 及非分层、独立频谱预测。
- **Benchmark** · 在 LIBERO、MimicGen 风格模拟和真实机械臂按键、堆叠与盖合任务上测成功率，并测试动作块长、可控干预与示范噪声。
- **关键结果 / 消融** · 真实薄块堆叠中 CSP 为 9/10，Action Binning 为 6/10、BAKU 为 3/10。按 C 键则为 8/10、5/10、3/10。
- **适用条件 / 局限** · 实证限于所测控制频率和精细操控，每个真实任务每方法仅 10 次。作者单列局限未报告。

**可复用机制** · 把动作块的低频规划和高频修正分开，并用已生成的粗轨迹条件化细节，可缓解端到端预测同时学习路径与精细操作的难度。

## 404 · T2AV-Compass: Towards Unified Evaluation for Text-to-Audio-Video Generation

[原文](https://proceedings.mlr.press/v306/cao26v.html)

<a id="cao26v-evaluation"></a>

**技术主题** · 音视频生成评测

- **问题 / 瓶颈** · 单模态生成指标难以同时评估文本指令遵循、声画同步和音视频真实感。
- **核心创新 / 方法** · T2AV-Compass 通过分类体系创建 500 个复合提示和检查表，结合客观声画指标与多模态 LLM 评审，给出跨维度诊断。
- **Baseline** · 改进来源为单模态及既有声画基准。实验对照为 15 个代表性生成系统，另用人工与模型评审比较分数。
- **Benchmark** · 测视频和音频质量、跨模态对齐、双模态指令遵循与真实感，并按提示类型、复杂度和难度分析。
- **关键结果 / 消融** · Veo-3.1 四项主观均值 70.29，Sora-2 为 69.83。Veo-3.1 的视频真实感 87.14，音频真实感 49.95。
- **适用条件 / 局限** · 结果取决于 500 条提示分布和评审协议，主观得分需结合人工一致性比较。作者单列局限未报告。

## 405 · DLO-Lab: Benchmarking Deformable Linear Object Manipulations with Differentiable Physics

[原文](https://proceedings.mlr.press/v306/cao26w.html)

<a id="cao26w-evaluation"></a>

**技术主题** · 柔性线状物体操作

- **问题 / 瓶颈** · 绳索和线缆的接触、塑性与拓扑变化难以由只支持简单材料的仿真平台覆盖，也使抓点决定复杂。
- **核心创新 / 方法** · DLO-Lab 用可微物理统一伸长、弯曲塑性和接触等行为，代理提议抓点，并以视觉语言反馈拆解及修正长任务。
- **Baseline** · 改进来源为可微线状物仿真和模型规划。实验对照含现有模拟器、无模型或一阶基于模型的强化学习、采样与梯度规划。

- **关键结果 / 消融** · 闭环 Wiring-ring 的实机成功率约 58%，部分聚拢与布线开环策略也可直接迁移。
- **适用条件 / 局限** · 迁移结果依赖校准材料、夹持条件和所测试硬件配置。作者单列局限未报告。

## 406 · Understanding Behavior Cloning with Action Quantization

[原文](https://proceedings.mlr.press/v306/cao26x.html)

<a id="cao26x-theory-statistics"></a>

**技术主题** · 行为克隆动作量化

- **问题 / 瓶颈** · 自回归行为克隆把连续动作量化，需分清动作离散误差、样本误差和长时滚动的相互作用。
- **核心创新 / 方法** · 分析离散动作的 log-loss 学习、回报误差及概率平滑性。对量化动作配一个转移模型做增强，以减轻对专家策略平滑度的要求。
- **Baseline** · 改进来源为 log-loss 行为克隆、分箱与学习量化器。理论对照为信息论下界、标准与模型增强方案。实验对照未报告。
- **Benchmark** · 理论设置为时域 H 的连续控制、有限策略类、确定或随机专家与量化误差 εq。衡量累积回报差。实验数据集未报告。
- **关键结果 / 消融** · 随机量化专家在稳定性和平滑性下的回报差为 O(H√(log(|Π|/δ)/n)+H²εq)。模型增强在转移类可实现时将量化项降为 O(Hεq)。
- **适用条件 / 局限** · 模型增强依赖转移类的可实现性和复杂度，确定专家的界还依赖量化方案及边界附近的平滑条件。

**原文定位** · [定理 2、3（PDF 第 5 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/cao26x/cao26x.pdf#page=5)，[定理 7（PDF 第 8 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/cao26x/cao26x.pdf#page=8)，[下界与结论（PDF 第 9 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/cao26x/cao26x.pdf#page=9)

**可复用机制** · 用量化动作及经验转移模型构造行为克隆增强，可把价值误差归因于动作分箱和概率平滑性，并减弱专家平滑度要求。

## 408 · DynaSchedBench: Calibrated Dynamic Scheduling Benchmarks and Observability Paradox in LLM-based Scheduling Agents

[原文](https://proceedings.mlr.press/v306/cao26z.html)

<a id="cao26z-evaluation"></a>

**技术主题** · 动态调度评测

- **问题 / 瓶颈** · 动态柔性作业车间调度的静态题易过拟合，随机实例也会把调度器效果与难度差异混在一起。
- **核心创新 / 方法** · DynaSchedBench 用 SESC 按事件序列校准目标压力指数 SSI，提供快照仿真，从而对照不同观测、反思、工具和规则调度。
- **Baseline** · 改进来源为动态调度基准和事件校准。实验对照含演化校准、L1/L2/L3 观测配置，以及 24 条复合优先派工规则。
- **Benchmark** · 按难度分层的动态柔性车间实例上测完工时间相对差、词元开销、校准 L₂ 误差及耗时，比较多种 LLM 与规则。
- **关键结果 / 消融** · L2 CoT 的平均相对最优完工时间差为 0.65%，观测更全的 L3 CoT 为 1.66%。Qwen3-8B 和最强固定规则的差异在配对检验中不显著。
- **适用条件 / 局限** · 观测效应来自论文的校准实例、提示和逐步在线流程。结论依赖可观测信息组织与候选派工规则。

## 409 · Learning to Label: A Reinforced Self-Evolving Framework for Semi-supervised Referring Expression Segmentation

- **核心创新 / 方法** · L2L 让多模态 LLM 提供语义和空间软先验，用不确定性感知融合指导分层分割。强化模块探索并奖励有用的伪标签。
- **Baseline** · 改进来源为弱强增广的半监督一致性及多模态先验。实验对照含 RESMatch、仅监督、无多模态先验及固定权重线性融合。

- **适用条件 / 局限** · 实证以所测三个数据集及生成先验的多模态模型为范围。错误的语义或空间先验可能传入伪标签。作者单列局限未报告。

- **Baseline** · 改进来源为以外挂序列时间换网络深度并按计算依赖稀疏读取。理论对照含 Wu 等单次前向的上下文梯度下降及带、无动态掩码的复杂度。

## 499 · Split Group Knockoffs: Controlling False Discovery Rate in Transformational Group Sparsity

[原文](https://proceedings.mlr.press/v306/chen26af.html)

**技术主题** · 组级变量发现

- **问题 / 瓶颈** · 当效应系数经线性变换后才呈组稀疏时，直接对原变量或单变量做 knockoff 无法合适控制组级假发现率。
- **核心创新 / 方法** · 分样本先估计回归系数，再为分组变换量构造拆分 knockoff。比较原组与仿造组进入正则化路径的统计量，用符号阈值选组。
- **Baseline** · 改进来源为在变换后按组建仿造特征并分样本估计。理论对照为单变量 Split Knockoff 与普通组 knockoff。验证含模拟、模型行为审计及脑影像关联。
- **Benchmark** · MMLU-Pro 不同学科的 LLM的行为偏离审计以目标 FDR q=0.2，回归与筛选的样本量比 0.35。模拟测经验 FDR、选择功效，脑影像比较可重复选择的区域或连接。
- **关键结果 / 消融** · 定理 3.1 在其设计条件下对任意 ν>0，SGK 控制修正组 FDR≤q、SGK+ 控制标准组 FDR≤q。审计在计算机科学选中 Qwen-Thk、Qwen-Ins 和 GPT-5，在工程未选中模型。
- **适用条件 / 局限** · 恢复一致性需设计及信号分离假设。审计选中表示对指定参考行为的统计偏差，不能单独解释偏差来源或代表模型总体好坏。
