## 402 · Causal Feature Learning via Generalized Rayleigh Quotients

[原文](https://proceedings.mlr.press/v306/cao26t.html)

<a id="cao26t-representation-learning"></a>

**技术主题** · 跨环境特征提取

- **问题 / 瓶颈** · 过程监测的时序特征若只相关于局部目标或只求跨环境不变，调整工况后可能漏检或误报。
- **核心创新 / 方法** · CFL 用广义 Rayleigh 商最大化滞后特征的目标关联，并惩罚跨环境均值偏移，解广义特征问题提取稳定的预测子空间。
- **Baseline** · 改进来源为时序潜变量和跨环境不变性约束。实验对照含 Mahalanobis、SFA 等 15 种过程监测法。
- **Benchmark** · Tennessee Eastman Process 用虚警约束比较故障检出率、实际虚警率和延迟，平均值覆盖 18 个可检出的故障。
- **关键结果 / 消融** · CFL 平均检出 94.6%、实际虚警 1.3%，Mahalanobis 与 SFA 检出分别为 93.7%、93.5%。移除滞后嵌入后 CFL 检出为 92.5%。
- **适用条件 / 局限** · 作者指出均值不变和滞后相关是预测代理，不能单独确证因果。TEP 的时段分组主要反映缓慢漂移。

## 403 · Hierarchical Policy Learning via Spectral Decomposition

[原文](https://proceedings.mlr.press/v306/cao26u.html)

<a id="cao26u-architecture"></a>

**技术主题** · 频域分层动作策略

- **问题 / 瓶颈** · 机器人动作块内，低频运动意图与细粒度对准、接触调整依赖不同信息，独立生成可能损害精度。
- **核心创新 / 方法** · CSP 用 DCT 分出低、高频动作，先从观察和语言预测粗轨迹，再以实际粗轨迹为条件生成高频修正，另用仿遥操作噪声做增强。
- **Baseline** · 改进来源为动作分块和频域分解。实验对照包括 ACT、BAKU、Action Binning 及非分层、独立频谱预测。
- **Benchmark** · 在 LIBERO、MimicGen 风格模拟和真实机械臂按键、堆叠与盖合任务上测成功率，并测试动作块长、可控干预与示范噪声。
- **关键结果 / 消融** · 真实薄块堆叠中 CSP 为 9/10，Action Binning 为 6/10、BAKU 为 3/10。按 C 键则为 8/10、5/10、3/10。
- **适用条件 / 局限** · 实证限于所测控制频率和精细操控，每个真实任务每方法仅 10 次。作者单列局限未报告。

## 406 · Understanding Behavior Cloning with Action Quantization

[原文](https://proceedings.mlr.press/v306/cao26x.html)

<a id="cao26x-theory-statistics"></a>

**技术主题** · 行为克隆动作量化

- **问题 / 瓶颈** · 自回归行为克隆把连续动作量化，需分清动作离散误差、样本误差和长时滚动的相互作用。
- **核心创新 / 方法** · 分析离散动作的 log-loss 学习、回报误差及概率平滑性。对量化动作配一个转移模型做增强，以减轻对专家策略平滑度的要求。
- **Baseline** · 改进来源为 log-loss 行为克隆、分箱与学习量化器。理论对照为信息论下界、标准与模型增强方案。实验对照未报告。
- **Benchmark** · 理论设置为时域 H 的连续控制、有限策略类、确定或随机专家与量化误差 εq。衡量累积回报差。实验数据集未报告。
- **关键结果 / 消融** · 随机量化专家在稳定性和平滑性下的回报差为 O(H√(log(|Π|/δ)/n)+H²εq)。模型增强在转移类可实现时将量化项降为 O(Hεq)。
- **适用条件 / 局限** · 模型增强依赖转移类的可实现性和复杂度，确定专家的界还依赖量化方案及边界附近的平滑条件。

**原文定位** · [定理 2、3（PDF 第 5 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/cao26x/cao26x.pdf#page=5)，[定理 7（PDF 第 8 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/cao26x/cao26x.pdf#page=8)，[下界与结论（PDF 第 9 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/cao26x/cao26x.pdf#page=9)

**可复用机制** · 用量化动作及经验转移模型构造行为克隆增强，可把价值误差归因于动作分箱和概率平滑性，并减弱专家平滑度要求。

## 416 · Reinforcement Learning with Pairwise Preferences in Long-Term Decision Problems

[原文](https://proceedings.mlr.press/v306/carr26a.html)

<a id="carr26a-theory-statistics"></a>

**技术主题** · 长期偏好强化学习

- **问题 / 瓶颈** · 成对偏好能表达非传递目标，长时任务却难高效求解，也需知道平稳策略能否达到历史依赖策略的水平。
- **核心创新 / 方法** · 定义 Markov decision contest，以状态动作占用度和平均偏好差写极小极大问题。给出线性规划及 HPI 与裁剪版的策略迭代。
- **Baseline** · 改进来源为长期平均报酬 MDP 与成对偏好博弈。理论比较历史依赖策略和既有复杂度，实验对照为 SPPO。
- **Benchmark** · 13 项长时 MuJoCo 任务含 11 个 v5 与 2 个非传递偏好任务，默认 2,048 步，报回报或反转最优差曲线 AUC，10 个种子。
- **关键结果 / 消融** · 有限单链竞赛存在最优随机平稳策略，可多项式时间精确解。非周期时 HPI 的最优差按 K⁻¹ᐟ² 收敛。两种 HPI 各有 12/13 项 AUC 区间与 SPPO 重叠或更高。
- **适用条件 / 局限** · 理论针对平均偏好准则及有限单链，迭代率另需非周期。线性规划随状态空间增大不实用，深度实现实证限于所测 MuJoCo 任务。

## 417 · Discrete Diffusion Samplers and Bridges: Off-Policy Algorithms and Applications in Latent Spaces

[原文](https://proceedings.mlr.press/v306/carter26a.html)

<a id="carter26a-training-strategies"></a>

**技术主题** · 离散扩散采样

- **问题 / 瓶颈** · 离散能量分布的扩散采样器在目标只知未归一化密度时容易遗漏模态，纯在线执行的轨迹也未充分用于训练。
- **核心创新 / 方法** · 将经验回放及重要性加权优先回放引入离散扩散采样损失，复用访问过的轨迹。将该机制扩展到数据分布与只知能量的目标分布之间的离散 Schrödinger 桥，并用于图像生成模型的潜空间后验。
- **Baseline** · 改进来源为用行为分布以外的轨迹缓解采样覆盖不足。实验对照有在线 LV、MH MCMC、MDNS，以及普通与重要性回放。
- **Benchmark** · 16×16 Ising 和 q=3 Potts、离散化合成密度、图像离散潜空间。表 1 以五种子报告 ELBO、EUBO、Sinkhorn 距离、磁化与相关误差。
- **关键结果 / 消融** · Potts 的逆温度 β=1.005 时，在线 LV 的 Sinkhorn 距离为 136.86±7.12，LV 加 Buffer 为 83.32±1.92，MH MCMC 为 90.36±1.10。对应磁化误差由 0.81±0.01 降至 0.04±0.03。
- **适用条件 / 局限** · 回放轨迹仍需额外存储和采样，扩散方法需指定加噪核。训练粗时间网格与采样细时间网格的离散极限尚无完整理论。

## 418 · Steering Out-of-Distribution Generalization with Concept Ablation Fine-Tuning

[原文](https://proceedings.mlr.press/v306/casademunt26a.html)

<a id="casademunt26a-training-strategies"></a>

**技术主题** · 微调泛化干预

- **问题 / 瓶颈** · 微调语言模型时，窄任务上的规律可能迁移为意外的分布外行为，而目标分布数据未必可取得。
- **核心创新 / 方法** · CAFT 用 PCA 或稀疏自编码器找到微调后变化的方向，再解释并标记非预期概念。训练时在残差流投影到这些方向张成空间的正交补，部署时移除投影，保留训练得到的参数。
- **Baseline** · 改进来源为仅在学习时削弱错误概念的表征，训练数据保持同一口径。实验对照为常规微调、较早停止、随机或排名靠前的方向消融及 PCA/SAE。
- **Benchmark** · 在 Qwen 与 Mistral 上观察不安全代码微调引出的通用问答不对齐，并测域内代码漏洞率。另两个场景分析打破虚假线索后选择题的准确率。
- **关键结果 / 消融** · PCA-CAFT 将连贯回答中的不对齐率在 Qwen 上从 7.0% 降到 0.51%，Mistral 从 6.6% 降到 1.2%。SAE 版分别为 2.4% 和 4.6%。域内写作漏洞表现有小幅下降，但不对齐减少超过仅提前停止的前沿对照。
- **适用条件 / 局限** · 依赖识别可解释且相对独立的潜在方向。部分虚假线索任务失败，Mistral 的主要改善集中在少数问题类型，证据未覆盖一般部署分布。

## 421 · Balanced LoRA: Removing Parameter Invariance to Accelerate Convergence

[原文](https://proceedings.mlr.press/v306/castin26a.html)

<a id="castin26a-optimization"></a>

**技术主题** · LoRA 收敛

- **问题 / 瓶颈** · LoRA 的同一矩阵更新可由多组因子实现，但这些表示的损失曲率不同，引起不同收敛速度。
- **核心创新 / 方法** · BaLoRA 每步把 A、B 变换到 AᵀA=BBᵀ 的平衡流形，保持乘积 AB。平衡映射用低秩矩阵计算，可接 Adam 或 GD。GD 版对应秩约束流形上的内禀更新。
- **Baseline** · 改进来源为消除优化过程中可控的因子失衡。实验对照为 LoRA、DoRA、OLoRA、LoRA-RITE、LORO 和也保持平衡的 RefLoRA。
- **Benchmark** · 理论比较矩阵分解最小点的非零 Hessian 条件数。实验用 Qwen2.5-3B，Alpaca、CodeFeedback、OpenHermes、OpenOrca、WizardLM 的 r=8 验证损失，并扫 DM Mathematics/arXiv 的秩。
- **关键结果 / 消融** · 命题 2.4 在目标秩 r 时，平衡最优点的最小条件数为 2σ₁/σᵣ。r=8 的 OpenOrca 相比 LoRA，验证损失为 0.773 对 0.774。RefLoRA 也是 0.773。论文报告 r=64/128 时改进更明显。
- **适用条件 / 局限** · 条件数结论由低秩近似理论提供。Adam 版的完整收敛理论未给出。低秩时终点损失的优势在部分任务较小。

**可复用机制** · 每次 LoRA 更新后在不改矩阵乘积的条件下平衡两因子 Gram 矩阵，可消减因子不唯一造成的病态优化。

## 422 · Conditional Diffusion Sampling

**技术主题** · 条件扩散采样

- **问题 / 瓶颈** · 多模态能量分布难以在少量密度调用下覆盖全局模态，神经扩散采样往往另需训练成本。
- **核心创新 / 方法** · CDS 构造条件插值过程并推导其精确条件 SDE。先用并行回火采短时间的初始条件分布，再沿 SDE 运输样本，靠回火探索模态、扩散完成局部移动。
- **Baseline** · 改进来源为以闭式条件 score 避免学习或嵌套估计 score。实验对照含非可逆 PT、OASMC、DiGS、HMC 和 MALA。
- **Benchmark** · 八个目标，含 2/16 维高斯混合、Lennard-Jones 分子、丙氨酸二肽及 550 维贝叶斯神经网络，比较密度评估次数和各类质量指标构成的 HVR。

- **适用条件 / 局限** · 线性插值可穿过奇异高能区，初始化时间过短又使分布尖锐、削弱回火交换。数值积分仍有离散误差。

## 423 · A Unifying View of Variational Generative Wasserstein Flows

[原文](https://proceedings.mlr.press/v306/caucheteux26a.html)

<a id="caucheteux26a-theory-statistics"></a>

**技术主题** · Wasserstein 生成模型

- **问题 / 瓶颈** · 生成模型往往都在缩小分布差异，却采用不同损失与更新。希望判断哪些目标及算法共享同一优化形式，以及 Wasserstein 近端项有何作用。
- **核心创新 / 方法** · 用 Wasserstein 梯度流及 JKO 隐式时间离散表示分布更新，约束分布由参数化生成映射产生。证明若干 f 散度算法等价，并扩展到 IPM 和平方 MMD，得到与 GAN 相关的近端训练。
