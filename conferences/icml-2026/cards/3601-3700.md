## 3601 · Quantile-Free Uncertainty Quantification in Graph Neural Networks

[原文](https://proceedings.mlr.press/v306/park26x.html)

<a id="park26x-theory-statistics"></a>

**技术主题** · 用覆盖与宽度联合目标学习图上的预测区间

- **问题 / 瓶颈** · 图节点依赖会挑战交换性和常见覆盖假设，逐点重新采样或校准又增加时间与数据需求。
- **核心创新 / 方法** · QpiGNN 采用两头网络和无分位输入的联合损失优化中心、宽度与误覆盖，分析渐近覆盖及近最小宽度。
- **Baseline** · 从量化回归出发，比较 SQR、RQR 调整版等区间对照及不同宽度惩罚。
- **Benchmark** · 19 个真实和合成图回归数据集，90% 目标报告 PICP 覆盖及 MPIW 宽度，另测 ER 图噪声和结构扰动。
- **关键结果 / 消融** · 表 1 ER 上经惩罚搜索的覆盖率为 0.98、宽度 0.63，SQR 为 0.75/0.60；跨数据集存在覆盖与宽度取舍。
- **适用条件 / 局限** · 理论依赖理想化节点独立性和对称条件误差；经验扰动结果不能保证任意依赖图上的覆盖。

**原文定位** · [双头损失与覆盖（PDF 第 4 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/park26x/park26x.pdf#page=4) · [理论及局限（PDF 第 5 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/park26x/park26x.pdf#page=5) · [19 个数据集主表（PDF 第 7 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/park26x/park26x.pdf#page=7) · [鲁棒性（PDF 第 8 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/park26x/park26x.pdf#page=8)

**可复用机制** · 将节点回归中心与区间宽度分头预测，用标注直接训练覆盖率和区间紧致度，部署无需额外分位点输入或后校准。

## 3602 · SeisMark: A Large-Scale Open Benchmark for Robust 3D Seismic Fault Detection

[原文](https://proceedings.mlr.press/v306/park26y.html)

<a id="park26y-evaluation"></a>

**技术主题** · 以共享三维标签和真实纹理梯度评估地震断层模型

- **问题 / 瓶颈** · 纯合成地震数据标注明确但外观简单，真实解释标签又难以精确验证；单一测试域容易低估纹理变化造成的失效。
- **核心创新 / 方法** · SeisMark 将结构地质程序和扩散风格合成结合，保留同一断层标注，构造两个测区来源的高低纹理版本与净对照。
- **Baseline** · 零样本比较预训练 FaultSeg3D、FaultSeg3D+、Fault-Net、RGF；同模型在五种纹理版互作参照。
- **Benchmark** · Clean、北海和澳大利亚两强度，共约 65 GB 含 Ground Truth；以 IoU 与 0/1/2 体素容差的精确率、召回、F1 衡量，另检查结构 SSIM。
- **关键结果 / 消融** · 高强度澳大利亚、容差 2 时 Fault-Net F1 0.675，FaultSeg3D 0.480、RGF 0.510；高强度纹理显著降低若干模型的得分。
- **适用条件 / 局限** · 仍是合成标注及两类真实纹理先验，严格容差容易受带限波形引起的亚体素定位歧义影响。

## 3603 · Beyond Generative Priors: Minority Sampling with JEPA-Guided Diffusion

[原文](https://proceedings.mlr.press/v306/park26z.html)

<a id="park26z-inference"></a>

**技术主题** · 用 JEPA 表示密度引导稀有图像采样

- **问题 / 瓶颈** · 相对生成器自身密度稀有的输出来得可能只是模型的异常，不一定对应现实中少见而语义有效的实例。
- **核心创新 / 方法** · 用 JEPA 诱导的局部密度替代生成先验的稀有度，引入随机 SVD 与包络定理近似梯度，并延后启用引导。
- **Baseline** · 沿用预训练扩散模型，对照 ADM/DDIM、MG、SGMS、BnS、CADS、MinorityPrompt 等。
- **Benchmark** · CelebA 无条件、ImageNet 类条件、MS-COCO 提示下 SD1.5/SDXL-Lightning 文生图；测 JEPA-SCORE、cFID/sFID、生成精确率召回率、文本对齐和人评。
- **关键结果 / 消融** · 表 2 SD1.5 的 JEPA-SCORE 为 −355.40，DDIM −292.27，CLIPScore 为 31.46 对 31.52，显示罕见性提升时文本对齐接近。
- **适用条件 / 局限** · 语义罕见度取决于 JEPA 与参考样本；每个引导步仍需 Jacobian 和随机 SVD，有额外成本。

**原文定位** · [JEPA 稀有度（PDF 第 4 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/park26z/park26z.pdf#page=4) · [近似方法（PDF 第 5 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/park26z/park26z.pdf#page=5) · [生成对照（PDF 第 7 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/park26z/park26z.pdf#page=7) · [设计消融与局限（PDF 第 8 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/park26z/park26z.pdf#page=8)

**可复用机制** · 把样本罕见程度定义在独立世界模型的表示空间，仅在去噪后段对低密度方向加引导，尽量保留既有条件。

## 3604 · Generative Neural Operators through Diffusion Last Layer

[原文](https://proceedings.mlr.press/v306/park26aa.html)

<a id="park26aa-architecture"></a>

**技术主题** · 在神经算子末层的随机系数上做扩散

- **问题 / 瓶颈** · 确定性神经算子只给点估计，逐网格独立高斯丢失跨空间依赖，全分辨扩散又增加成本。
- **核心创新 / 方法** · DLL 借鉴 Karhunen–Loève 扩展构造条件低秩函数展开，用条件扩散生成系数，作为可替换的神经算子输出头。
- **Baseline** · 对照 FNO、FNO-d、重参数化 PNO、像素扩散 DM 与潜扩散 LDM。
- **Benchmark** · 随机 Burgers 一维 256 点、Darcy 二维 128² 网格，每系统训练 10,000 对；32 个测试输入各 64 个 realization，测 ED、SWD 及矩的归一 RMSE；另测自回归 rollout。
- **关键结果 / 消融** · Burgers 中 DLL 的 ED/SWD 为 1.285/0.213，DM 1.355/0.239，LDM 1.373/0.249。
- **适用条件 / 局限** · 低秩展开要求主要随机变化可由有限基捕获；结果主要在规则网格及文中方程上验证。

**可复用机制** · 以输入依赖的空间基表示整个输出场，再扩散学习系数联合分布，既表达全场相关不确定性又减小采样维度。

## 3605 · TsLLM: Augmenting LLMs for General Time Series Understanding and Prediction

[原文](https://proceedings.mlr.press/v306/parker26a.html)

<a id="parker26a-architecture"></a>

**技术主题** · 给语言模型加可读写数值时序的 patch 接口

- **问题 / 瓶颈** · 文字序列化长数列成本高且不足以学习数值结构；传统时序模型缺少把文档上下文与信号联合推理的能力。
- **核心创新 / 方法** · TsLLM 增加 patch 编解码器，在逾 250 亿时序与文本交错 token 上训练下一 token 预测，覆盖预测、分类、异常、问答和报告。
- **Baseline** · 比较通用 Gemini/GPT、ChatTime/ChatTS、ECG 专用模型，并区分是否预先训练 ECG-QA。
- **Benchmark** · ECG-QA 的分类问题按 EM 比较，TimeSeriesExam 测合成时序多选准确率，Context Is Key 测上下文条件预测。
- **关键结果 / 消融** · 表 1 ECG-QA TsLLM 平均 EM 为 65.0%，Q-Heart 61.4%；无该训练集的少样本版本仍为 50.8%，同类 GPT o4-mini 为 45.9%。
- **适用条件 / 局限** · 训练和推断成本高于传统时序模型；论文目标为联合时序与文本，不覆盖各专用榜单的最优性。

- **适用条件 / 局限** · 等深和随机文法假设限制适用范围；递归造成的变深语法及属性或依存文法尚未覆盖。

## 3607 · Constrained Adaptive Rejection Sampling

[原文](https://proceedings.mlr.press/v306/parys26a.html)

<a id="parys26a-inference"></a>

**技术主题** · 把已证无效的约束前缀缓存到拒绝采样 Trie

- **问题 / 瓶颈** · 贪心约束解码在采样中改变原模型条件分布；朴素拒绝采样忠实却可能一再生成同类不合法输出。
- **核心创新 / 方法** · CARS 对前缀做自适应裁剪，追踪合法剩余概率并据此重归一，从而精确遵从原模型在约束上的条件分布。
- **Baseline** · 在 RS 与观察到坏样本才拒绝的 ARS 基础上扩展，比较 RSFT 以及机制近似的 GCD、AWRS 等。
- **Benchmark** · SyGuS 程序、三类分子生成和 Spider 开发集 Text-to-SQL，用有效样本成本、多样性和 SQL 执行准确率评估。
- **关键结果 / 消融** · Spider 上 CARS 平均 1.11 次采样/题，RS 为 2.06；执行准确率为 0.578±0.013 对 0.576±0.014。
- **适用条件 / 局限** · 需要可靠的合法性判断；可早期判前缀无效时节省更大，trie 需要内存并依赖约束稳定。

**原文定位** · [精确条件采样（PDF 第 3 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/parys26a/parys26a.pdf#page=3) · [Trie 与归一化（PDF 第 4 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/parys26a/parys26a.pdf#page=4) · [分子评测（PDF 第 7 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/parys26a/parys26a.pdf#page=7) · [SQL 表与开销（PDF 第 8 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/parys26a/parys26a.pdf#page=8)

## 3608 · Stable Deep Reinforcement Learning via Isotropic Gaussian Representations

[原文](https://proceedings.mlr.press/v306/pasand26a.html)

**技术主题** · 用随机投影把 RL 表征约束为各向同性高斯

- **问题 / 瓶颈** · RL 的目标和数据分布持续移动，表征容易降秩、神经元休眠，导致线性或近线性读出适应不稳。
- **核心创新 / 方法** · 分析各向同性高斯在线性读出中的追踪与最大熵性质，用 SIGReg 对选取投影中的表征分布加入高斯正则。
- **Baseline** · 在 PQN、PPO 等骨干上比较基础或加 SIGReg，另比 VICReg 白化、范数控制、simplex 表征、正交权重与 KFAC 类优化。

- **适用条件 / 局限** · 理论假设线性读出和近似平稳的表征协方差；强任务结构未必适合纯各向同性边际分布。

- **Baseline** · 改进来源：会话持久记忆与 LLM 评委。实验对照：18 模型、不同防御提示、余弦和独立模型筛选、单轮与模拟多轮。
- **Benchmark** · 500 样本含 200 跨域、200 迎合、100 有益记忆。18 个开放与闭源模型，以分组失败率及 bootstrap 区间评判。
- **关键结果 / 消融** · 跨域和迎合的中位失败率 53% 和 97.8%，有益为 16.5%。余弦筛选阈值升到 0.60 时跨域均值降至 0%，但有益失败升至 97%。
- **适用条件 / 局限** · 题目经设计用于暴露失效，不能直接解读为生产发生率。测试注入已存记忆，即时检索、长期写入及真实使用各有额外变数。
