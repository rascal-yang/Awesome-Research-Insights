## 2401 · Improving the Robustness-Utility Trade-off in Decentralized Learning over Sparse Networks

[原文](https://proceedings.mlr.press/v306/li26i.html)

<a id="li26i-optimization"></a>

**技术主题** · 缩放去中心化偏差校正的对偶更新

- **问题 / 瓶颈** · 稀疏通信拓扑的去中心化优化怎样减轻拜占庭误差积累，同时缩短线性加速前的过渡期？
- **核心创新 / 方法** · BRED 在增广拉格朗日框架下缩放对偶更新，把稳健聚合接入 Exact Diffusion；另提出动量版 BRED-M。
- **Baseline** · 改进来源：缩放对偶上升抑制偏差校正引起的误差积累。实验对照：BR-DSGD、BR-EXTRA、BR-GT 及对应动量方案。
- **Benchmark** · MNIST、CIFAR-10，设定拓扑谱隙和恶意邻居比例，模拟攻击及异质数据；表 4 为 32 节点、ALIE、中位数聚合，测分类准确率。
- **关键结果 / 消融** · 小恶意比例条件下，BRED 的过渡复杂度对谱隙为 O((1−λ)⁻²)；表 4 在 λ=0.81、δ=0.125 时 BRED-M 为 59.62%，BR-DSGD 为 52.25%。
- **适用条件 / 局限** · 收敛与过渡界受量化假设和攻击比例约束；经验结果来自所选聚合器、攻击和网络拓扑。

## 2402 · Thinking with Geometry: Active Geometry Integration for Spatial Reasoning

[原文](https://proceedings.mlr.press/v306/li26j.html)

<a id="li26j-modules"></a>

**技术主题** · 用同帧查询和重要性门按需读取几何

- **问题 / 瓶颈** · 多模态空间推理中，怎样从外部三维编码器读取与当前推理相关的几何证据，并减少跨帧误配？
- **核心创新 / 方法** · GeoThinker 在选定的视觉语言层插入空间接地融合，让语义视觉词元在同一帧内交叉注意几何特征，并以重要性门和全局缩放调节注入。
- **Baseline** · 改进来源：按当前表征主动检索同帧几何，而非全局融合。实验对照：VG-LLM、Cambrian-S、基座与去掉帧约束和重要性门等消融。
- **Benchmark** · VSI-Bench 和 VSI-Debiased，测试 16–128 帧推理，另测 RefSpatial-Bench 和 NAVSIM 的下游指标。
- **关键结果 / 消融** · 表 4 的 32 帧推理下，GeoThinker 的 32 帧训练版 VSI 为 72.6，Cambrian-S-7B 为 63.6，VG-LLM-8B 比较项为 62.2。
- **适用条件 / 局限** · 依赖外部几何特征质量及层选择；增加帧数会提高推理负担，复杂空间场景仍需验证。

**原文定位** · [§3.2 空间融合（PDF 第 4 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/li26j/li26j.pdf#page=4) · [§3.3 选层（PDF 第 5 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/li26j/li26j.pdf#page=5) · [表4 帧数比较（PDF 第 6 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/li26j/li26j.pdf#page=6) · [表7 消融（PDF 第 8 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/li26j/li26j.pdf#page=8)

## 2403 · Do Activation Verbalization Methods Convey Privileged Information?

[原文](https://proceedings.mlr.press/v306/li26k.html)

<a id="li26k-evaluation"></a>

**技术主题** · 让目标模型和描述器持有冲突知识

- **问题 / 瓶颈** · 把语言模型激活转成自然语言时，输出反映目标模型内部知识，还是成功重构输入后调用描述器自身知识？
- **核心创新 / 方法** · 把输入重建后问答作为对照，并用 PersonaQA 真实、打乱、虚构人物设定分别控制目标和描述器持有哪些事实。
- **Baseline** · 改进来源：通过两模型知识不一致区分事实来源。实验对照：Patchscopes、LIT、零样本问答、输入重建后解释和线性探针。
- **Benchmark** · Llama3、Ministral；原有激活解读基准与 PersonaQA 六项属性抽取，分别检查标签打乱、虚构知识及跨模型家族。
- **关键结果 / 消融** · 当只有目标模型持有初版虚构人物知识时，Patchscopes 和 LIT 在该设置未超过零准确率；表 7 中仅描述器掌握虚构知识时，两者仍能答对部分属性，喜欢的食物分别为 0.38、0.45。
- **适用条件 / 局限** · 主要检验较小模型上的问答及特定解读方法；线性可读性和自然语言忠实性各有评估边界。

## 2404 · LayerT2V: A Unified Multi-Layer Video Generation Framework

[原文](https://proceedings.mlr.press/v306/li26l.html)

<a id="li26l-architecture"></a>

**技术主题** · 共享去噪轨迹以联合生成可编辑视频层

- **问题 / 瓶颈** · 文生视频能否一次产生可继续编辑的合成画面、独立背景以及多前景 RGB 和透明遮罩？
- **核心创新 / 方法** · LayerT2V 把各层压缩潜变量沿时间轴串联，用共享 DiT 联合生成，再用 LayerAdaLN 和分层交叉注意力区分各层条件；分阶段训练遮罩 VAE、联合生成和多前景。
- **Baseline** · 改进来源：在一个共享去噪轨迹中建模层间一致性并保留层身份。实验对照：LayerFlow、原始遮罩 VAE、位置编码和层感知模块消融。
- **Benchmark** · VidLayer 的 200 条留出提示，分前景、背景和合成层测 VBench 的美观、运动、闪烁、主体和文本对齐，并进行用户比较。
- **关键结果 / 消融** · VAE LoRA 版的前景主体一致性 0.9829、合成层文本对齐 0.2136，LayerFlow 为 0.9440、0.1941；用户研究的前景质量获选比例为 0.768 对 0.156。
- **适用条件 / 局限** · 多层输出会加长潜在序列并增加推理成本；训练遮罩和自动筛选的噪声会影响层间边缘。

## 2405 · Building Reliable Long-Form Generation via Hallucination Rejection Sampling

[原文](https://proceedings.mlr.press/v306/li26m.html)

<a id="li26m-inference"></a>

**技术主题** · 在长文本片段进入上下文前重采样

- **问题 / 瓶颈** · 长文本早期幻觉会引发后续错误，怎样在无外部检索条件下生成更多受支持内容？
- **核心创新 / 方法** · SHARS 逐段生成、拒绝高风险片段并重采样，持续失败时停止；HalluSE 拆成原子事实，为每个事实提出问题，按候选答案的语义熵判定。
- **Baseline** · 改进来源：在片段进入后续上下文前检测和剔除错误。实验对照：贪心、DoLa、ChatProtect、自我背书，另适配 FactAlign 并对照朴素熵。
- **Benchmark** · FactScore、LongFact 等长文生成基准；报告受支持事实数、无支持事实数、事实精度、应答率及长度控制。
- **关键结果 / 消融** · FactScore 约 200 词的 Qwen3-32B 中，Ours-Info 的事实精度 71.0%、应答率 98.4%、支持事实 29.1；贪心为 58.0%、98.9%、22.4。
- **适用条件 / 局限** · 重采样无法补足模型从未掌握的知识；阈值和多轮采样在精度、覆盖率及计算之间带来折衷。

**原文定位** · [§3 片段重采样（PDF 第 3 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/li26m/li26m.pdf#page=3) · [§4.3 语义熵（PDF 第 5 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/li26m/li26m.pdf#page=5) · [表2 长度控制（PDF 第 7 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/li26m/li26m.pdf#page=7) · [§6 局限（PDF 第 9 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/li26m/li26m.pdf#page=9)

**可复用机制** · 长文生成可先将候选句段拆为原子事实，通过重复问答的语义不确定性拒收可疑部分；保留的内容再作为下段上下文，并以应答率和受支持事实数共同校准阈值。

- **Baseline** · 改进来源：用观测时延的分布统计和 KV 代价替代逐请求长度预测。实验对照：知道真实解码长度的 TRAIL+、SJF、Sarathi 和仅按阶段提升的 DistBoost。

- **适用条件 / 局限** · 选择尾指标会牺牲部分均值；优先级与抢占的效果随显存、缓存块和负载分布变动。

## 2409 · Unifying Heterogeneous Multi-Modal Remote Sensing Detection Via Language-Pivoted Pretraining

[原文](https://proceedings.mlr.press/v306/li26q.html)

<a id="li26q-training-strategies"></a>

**技术主题** · 用共享语言概念预对齐不同遥感传感器

- **问题 / 瓶颈** · 不同传感器的语义对齐和检测目标若一起留给下游微调，优化会互相牵制，混合精度可出现训练不稳定。
- **核心创新 / 方法** · BabelRS 以 CSIA 将各传感器映射到共享概念的语言指令，以 LVSA 逐步聚合多尺度特征，缓解全局语义到密集检测的粒度落差。
- **Baseline** · 对照简单联合微调、DA、UniDet、不确定性损失、SM3Det；同 ViT-L 与微调设置下另比 CLIP、RemoteCLIP、MAE、BEiT、DINOv2 等预训练。

- **Benchmark** · GSM8K、MATH、HumanEval、MBPP 用 256 生成长度报告正确率和 token/s；另测 512/1024 以及 Dream-7B、LLaDA-MoE。
- **关键结果 / 消融** · GSM8K 无缓存 34.2 token/s、5.0 倍、79.4%；Dual Cache 为 77.3 token/s、11.2 倍、78.8%。无缓存去 TSPD 与去 CE 降到 20.0 与 30.3 token/s。
- **适用条件 / 局限** · TSPD 需从冻结底座收集轨迹训练小传感器；收益受缓存、序列长度和硬件影响，报出的速度倍数有各自的任务设定。
