## 3301 · Hidden in Plain Tokens: Simply Robust, Gradient-Free Watermark for Synthetic Audio

[原文](https://proceedings.mlr.press/v306/milis26a.html)

<a id="milis26a-inference"></a>

**技术主题** · 用 Codec 混淆关系提高语音水印重编码鲁棒性

- **问题 / 瓶颈** · 语音生成水印若绑定精确的 codec token，检测端重新编码时即便波形听起来近似，也会得到不同 token，破坏生成端嵌入的统计偏置。
- **核心创新 / 方法** · 从原始语音与变换后语音的 token 转移估计混淆关系，构建分组并在下降维的组词表上做采样偏置和显著性检测，同时让声学生成仍走原 codec。
- **Baseline** · 本文在已有神经音频编解码和 token 水印框架上改动水印词表。实验对照 WMAR、带数据增强的设置，以及不加水印的语音。
- **Benchmark** · 使用 LibriSpeech 和 Moshi 会话语音，另考查 CosyVoice3、Spark-TTS；在平滑、滤波、加噪等变换后以检测 −log(p) 及相对未变换信号的检测损失衡量。
- **关键结果 / 消融** · Moshi 会话表 2 中本法未变换和平滑后的 −log(p) 分别为 42.47、32.68，WMAR 为 17.44、1.61，增强对照为 13.72、3.73。
- **适用条件 / 局限** · 依赖可操作的音频 token 采样和特定 codec 的混淆统计；裁剪、变速会造成重新同步困难，强变换下检测会继续下降。

**原文定位** · [混淆建模（PDF 第 3 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/milis26a/milis26a.pdf#page=3) · [嵌入与检测（PDF 第 4 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/milis26a/milis26a.pdf#page=4) · [表 2 会话鲁棒性（PDF 第 7 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/milis26a/milis26a.pdf#page=7) · [局限（PDF 第 11 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/milis26a/milis26a.pdf#page=11)

**可复用机制** · 先测量连续两次编解码之间哪些音频 token 会互换，再将高混淆 token 归并为水印符号，使播放、重录或信号处理后的检测保留组级信息。

## 3302 · Particle-Guided Diffusion Models for Partial Differential Equations

[原文](https://proceedings.mlr.press/v306/millard26a.html)

<a id="millard26a-inference"></a>

**技术主题** · 用粒子重采样引导 PDE 扩散求解

- **问题 / 瓶颈** · PDE 逆问题和正问题需要同时匹配稀疏观测与物理规律；单轨迹确定性引导不能通过候选粒子探索多个可行解。
- **核心创新 / 方法** · 提出 SOSaG 随机二阶引导积分方法，并将 PDE 物理似然与观测似然放入序贯蒙特卡洛权重；粒子在扩散时间步传播和选择，无需重训 score。
- **Baseline** · 沿用 DiffusionPDE 的预训练 score；比较 ODE DiffPDE、GEM、GEM-TDS、GEM-pBS，以及 SOSaG 有无 pBS。
- **Benchmark** · Darcy、Poisson、Helmholtz 和两类 Navier–Stokes 设置均测正向及逆向，报告相对 L2 误差，Darcy 逆向用错误率；主表粒子版采用 4 个粒子。
- **关键结果 / 消融** · 表 1 Darcy 正反向 SOSaG-pBS 为 3.96、5.28，DiffPDE 为 5.58、8.31；Poisson 逆向为 24.61，DiffPDE 为 19.88，收益随方程和任务改变。
- **适用条件 / 局限** · 依赖可计算的 PDE 残差、观测似然和可用的扩散先验；粒子数增大会增加 score 评估及推断成本。

**原文定位** · [随机引导（PDF 第 4 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/millard26a/millard26a.pdf#page=4) · [粒子重采样（PDF 第 6 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/millard26a/millard26a.pdf#page=6) · [表 1 五类方程（PDF 第 7 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/millard26a/millard26a.pdf#page=7) · [粒子成本（PDF 第 8 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/millard26a/millard26a.pdf#page=8)

**可复用机制** · 以随机二阶扩散积分器生成候选，再按观测匹配和 PDE 残差加权重采样，给已有扩散先验补上采样时的物理约束。

## 3303 · SEMIR: Semantic Minor-Induced Representation Learning on Graphs for Visual Segmentation

[原文](https://proceedings.mlr.press/v306/miller26a.html)

<a id="miller26a-representation-learning"></a>

**技术主题** · 让图 minor 沿稀疏分割目标边界收缩

- **问题 / 瓶颈** · 体数据的小肿瘤在常规体素图中只占很小比例；盲目合并相邻体素会把少数类边界并入背景。
- **核心创新 / 方法** · SEMIR 从图 minor 的合法收缩与删除构造超节点，在少样本标注上优化边界对齐，用区域形态和邻接特征训练 GNN，并利用体素至超节点映射提升回原图。
- **Baseline** · 图 minor 表示接常规 GNN；对照相同划分的 nnU-Net，以及原文列出的 BraTS、KiTS、LiTS 专门分割模型和固定超参数方案。
- **Benchmark** · BraTS 2021、KiTS23、LiTS 比较肿瘤目标 Dice、运行时间和图规模；另在 NWPU VHR-10 航拍图子集测小目标 IoU 和消融。
- **关键结果 / 消融** · BraTS 增强肿瘤二分类 Dice 为 0.894±0.006，匹配划分的 nnU-Net 为 0.812；去掉边收缩后降至 0.441。训练时间报告使用不同 GPU。
- **适用条件 / 局限** · 缩图需要能代表目标边界的少样本标注以及适合图构造的特征；二维证据来自一个航拍图子集，跨模态泛化范围有限。

**原文定位** · [图 minor 与提升（PDF 第 4 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/miller26a/miller26a.pdf#page=4) · [少样本边界优化（PDF 第 5 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/miller26a/miller26a.pdf#page=5) · [表 4、5 对照及消融（PDF 第 8 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/miller26a/miller26a.pdf#page=8) · [讨论（PDF 第 9 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/miller26a/miller26a.pdf#page=9)

**可复用机制** · 先用少量标注调节收缩、删边与删点，使缩图的超节点尽量贴合小目标边界，再将图上的预测无歧义提升回原分辨率。

## 3304 · GIST: Targeted Data Selection for Instruction Tuning via Coupled Optimization Geometry

[原文](https://proceedings.mlr.press/v306/min26a.html)

<a id="min26a-data-strategies"></a>

**技术主题** · 在 LoRA 验证梯度子空间筛选指令数据

- **问题 / 瓶颈** · 梯度相似度选指令数据要存储大量训练样本梯度，而随机投影会保留与目标任务无关的方向，压缩精度有限。
- **核心创新 / 方法** · GIST 对目标验证样本梯度结构做 SVD，提取任务相关子空间，投影候选数据的梯度特征并用对齐分数排序，最后在所选数据上做 LoRA 微调。
- **Baseline** · 源于 LESS 式梯度匹配与 LoRA 微调；在同等抽样比例比较 LESS 等数据选择方法，并列全量微调参照。
- **Benchmark** · 在指令候选池按目标任务筛选，使用 MMLU、TyDiQA 和 BBH 等评测 Llama-2 系列模型；同时测选样所用存储和计算。
- **关键结果 / 消融** · 表 2 的 Llama-2-7B 用 5% 训练数据时 MMLU 为 51.2±0.7，LESS 为 50.2±0.5，全量为 51.6。作者另报告相对已有选样方法仅用 0.29% 的存储及 25% 的计算时间。
- **适用条件 / 局限** · 依赖目标任务验证样本和可提取的 LoRA 梯度；数据池和目标分布改变时需要验证子空间仍有代表性。

**原文定位** · [效率指标（PDF 第 1 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/min26a/min26a.pdf#page=1) · [子空间构造（PDF 第 5 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/min26a/min26a.pdf#page=5) · [选样流程及评测（PDF 第 6 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/min26a/min26a.pdf#page=6) · [表 2 Llama-2-7B（PDF 第 7 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/min26a/min26a.pdf#page=7)

## 3305 · Bridging Dynamics and Data: A Unified Diffusion Framework for Mechanistically-Informed Epidemic Forecasting

[原文](https://proceedings.mlr.press/v306/min26b.html)

<a id="min26b-inference"></a>

**技术主题** · 用机理后验不确定性分配疫情扩散引导

- **问题 / 瓶颈** · 纯数据模型可能给出不合机理的疫情轨迹，而机理参数难以完全准确估计，统一强度的机理约束会传递局部误差。
- **核心创新 / 方法** · EpiDiff 融合机理模型的预测后验与条件扩散；以机理预测及不确定性定义似然，对重建的干净轨迹施加梯度后重新映射到当前噪声尺度。
- **Baseline** · 接续传染动力学模型和条件时间序列扩散；对照 PatchSIR、AR/ARMA、EARTH、EpiColaGNN，并消融是否使用机理估计和不确定性。
- **Benchmark** · covid-US 州级、covid-JP 都道府县级和 influenza-US 区域疫情序列的 7/14 步预测；报告 RMSE 和 MAE。
- **关键结果 / 消融** · covid-US 7 步的 RMSE 为 1096±5、MAE 为 374±1，EpiColaGNN 为 1825±84、745±58；三套数据中 7/14 步 RMSE 均低于表内对照。
- **适用条件 / 局限** · 结果覆盖这三组观察序列和短期预测；依赖机理估计能够提供有信息量的轨迹与不确定性。

## 3306 · Questioning the Coverage-Length Metric in Conformal Prediction: When Shorter Intervals Are Not Better

**技术主题** · 用预测集稳定性揭示边际覆盖的投机改进

- **问题 / 瓶颈** · 边际覆盖只汇总成功频率，会掩盖分组内完全不覆盖；按边际覆盖和平均长度评估，可能奖励这种投机。
- **核心创新 / 方法** · 构造 Prejudicial Trick，以随机规则给一部分输入空集、给其余输入较高置信度的区间；提出从稳定性补充评估，并分析区间宽度随覆盖目标变化的性质。
- **Baseline** · 针对现有边际共形预测，比较原始 VCP、加投机规则后的 VCP 及局部版本；论文重点在评估性质。
- **Benchmark** · 合成回归按误覆盖率和随机分组概率比较覆盖、区间长度；实际回归数据含 MEPS 测稳定性，并讨论分类预测集。
- **关键结果 / 消融** · 表 1 误覆盖率 0.10、分组概率 0.96 时，原 VCP 覆盖率 0.906、平均长度 22.894，投机版为 0.909、22.614；表 3 MEPS-19 上原 VCP 稳定性指标为 0，投机版为 1.26。
- **适用条件 / 局限** · 研究针对边际共形评估和选定区间生成方式；稳定性补充整体覆盖诊断，无法单独确定任意子群的条件覆盖。

## 3309 · Compass-RoPE: Isotropic Rotary Position Embeddings for Vision Transformers

[原文](https://proceedings.mlr.press/v306/min26f.html)

<a id="min26f-architecture"></a>

**技术主题** · 让二维 RoPE 在大图分辨率均匀分配方向

- **问题 / 瓶颈** · 从训练分辨率直接推到更大的二维 token 网格时，轴向 RoPE 的方向覆盖有限，混合式 RoPE 也可能出现角度偏好。
- **核心创新 / 方法** · Compass-RoPE 极坐标参数化二维相位，独立安排径向频率和均匀方向，并用 DFT 混合方向成分，直接替换注意力中的视觉位置编码。
