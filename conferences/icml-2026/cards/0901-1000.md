## 901 · Listening Through the Noise: Cauchy-Driven Diffusion Bridges for Robust Gastrointestinal Auscultation and Clinical Benchmarking

[原文](https://proceedings.mlr.press/v306/ding26a.html)

<a id="ding26a-inference"></a>

**技术主题** · 重尾扩散桥的肠鸣音分离

- **问题 / 瓶颈** · 如何从含重尾语音干扰的听诊录音中恢复肠鸣音，并保留少见异常声？
- **核心创新 / 方法** · 用 Cauchy 驱动扩散桥对重尾干扰建模，推导密度和分数，并用高斯尺度混合的共享尺度进行 DBIM 采样。
- **Baseline** · 改进来源：扩散桥、重尾随机过程和 DBIM。实验对照：Demucs、Mel-Roformer、SCNet、BDBM、DDBM、DBIM，及每步重采样变体。
- **Benchmark** · ClinBS 超过 25 小时、1,531 名患者，叠加 VCTK/AISHELL 语音，测 MAE、PSNR、SSIM、LSD、FID 及异常声识别准确率。
- **关键结果 / 消融** · 去噪 MAE 为 8.28、PSNR 为 24.39，DBIM 为 16.49、18.23。ResNet 异常声识别由带噪的 48.23% 提至 88.01%，DBIM 为 84.39%。
- **适用条件 / 局限** · 主要临床语音干扰以混合录音模拟，检测效果受采集与噪声分布影响，临床决策效益未报告。

## 902 · Near-Optimal and Efficient First-Order Algorithm for Multi-Task Learning with Shared Linear Representation

[原文](https://proceedings.mlr.press/v306/ding26b.html)

<a id="ding26b-optimization"></a>

**技术主题** · 多任务分解的两阶段梯度校正

- **问题 / 瓶颈** · 多个任务共享低秩线性表示时，能否用高效一阶似然方法联合学习表示和任务权重？
- **核心创新 / 方法** · TPGD 先用未正则平方损失热启动，再以带校正正则项的一阶更新提高估计效率，避免每轮 SVD 或 QR。
- **Baseline** · 改进来源：共享线性多任务表示和非凸矩阵分解。实验对照：GD+Loss 1、GD+Loss 2 与 NSGD，理论比较矩估计、谱法和既有似然法。
- **Benchmark** · 线性多任务仿真，d 为输入维、k 为表示维、T 为任务数、N 为每任务样本，以参数估计误差随迭代及样本量变化评估。
- **关键结果 / 消融** · 在论文条件下用 Õ(1) 次迭代达到 Õ(dk/(TN)) 估计误差，较既有相类似然保证少一个 k 因子；仿真中两阶段比单阶段更快稳定。
- **适用条件 / 局限** · 依赖共享线性表示、任务谱和样本条件，实证为合成设置，未覆盖非线性任务。

**原文定位** · [表1 理论对照（PDF 第 2 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/ding26b/ding26b.pdf#page=2) · [§4 TPGD（PDF 第 5 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/ding26b/ding26b.pdf#page=5) · [定理5.1（PDF 第 6 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/ding26b/ding26b.pdf#page=6) · [§6 仿真（PDF 第 7 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/ding26b/ding26b.pdf#page=7) · [图1 结果（PDF 第 8 页）](https://raw.githubusercontent.com/mlresearch/v306/main/assets/ding26b/ding26b.pdf#page=8)

## 905 · OmniSIFT: Modality-Asymmetric Token Compression for Efficient Omni-modal Large Language Models

[原文](https://proceedings.mlr.press/v306/ding26e.html)

<a id="ding26e-modules"></a>

**技术主题** · 音视频非对称 token 压缩

- **问题 / 瓶颈** · 音视频全模态语言模型怎样在删减 token 时保住需要跨模态配合的线索？
- **核心创新 / 方法** · OmniSIFT 先按帧内结构和帧间重复剪视频 token，再用视觉引导音频选择，通过直通估计做端到端优化。
- **Baseline** · 改进来源：视觉 token 剪枝和 Omni-LLM 跨模态对齐。实验对照：全 token、OmniZip、适配的 DyCoke、随机剪枝，以及模态剪枝消融。
- **Benchmark** · Qwen2.5-Omni-7B/3B，用 AVoCaDO SFT；测 VideoMME、DailyOmni、WorldSense、OmniVideoBench、video-SALMONN-2 的得分、内存和延迟。
- **关键结果 / 消融** · 7B 在 WorldSense 保留 35% token，得分为 50.0 对全量的 49.7；峰值内存从 27.59 GB 到 22.91 GB，端到端延迟从 4.94 秒到 2.86 秒。
- **适用条件 / 局限** · 精确音画对应依赖局部证据，容易受裁剪损伤；视频剪枝的建模范围受块级处理约束。

## 906 · DDSVM: A Differentiable Framework for Deep Support Vector Machines with Iterative Geometry-Aware Optimization

[原文](https://proceedings.mlr.press/v306/ding26f.html)

<a id="ding26f-representation-learning"></a>

**技术主题** · 用 SVM 边界精炼视觉表征

- **问题 / 瓶颈** · 能否用支持向量机的决策边界反过来塑造深度分类模型的表示，尤其在样本很少时？
- **核心创新 / 方法** · DDSVM 交替在 L2 归一特征上重拟合线性 SVM，并沿球面切空间中的增间隔方向更新骨干，并以几何扰动平滑训练。
- **Baseline** · 改进来源：深度表示学习、线性 SVM 和球面间隔。实验对照：交叉熵、角间隔方法、几何扰动消融、OVR 与 Cramér–Singer SVM。
- **Benchmark** · ResNet-18 在 CIFAR-10/100、STL-10、SVHN 完整及约 8% 数据和 CIFAR-10-C 上，测 top-1 错误率、种子方差及训练时间。
- **关键结果 / 消融** · 约 8% 数据下 CIFAR-10 错误率从 30.75% 至 23.21%，STL-10 从 47.29% 至 38.98%；SVHN 则从 6.08% 至 6.79%。
- **适用条件 / 局限** · 完整数据下多数收益有限；OVR 成本随类别线性增长，未覆盖 episodic few-shot 和大规模预训练。

## 907 · Understanding Private Learning From Feature Perspective

[原文](https://proceedings.mlr.press/v306/ding26g.html)

<a id="ding26g-theory-statistics"></a>

**技术主题** · 隐私训练的信号学习与噪声记忆

- **问题 / 瓶颈** · 隐私梯度噪声如何改变网络对真实类别特征与训练数据噪声的学习？
- **核心创新 / 方法** · 在多 patch 二分类和多项式 ReLU 的两层 CNN 中分解权重轨迹，分离类别信号、数据噪声、初始化及隐私噪声。
- **Baseline** · 改进来源：DP 训练理论和特征—噪声分解。实验对照：NoisyGD 与非私有 GD，控制 SNR 与隐私预算，附录另测 CIFAR-10。
- **Benchmark** · 主试验使用 SNR 0.2、0.6、3 与 ε 0.2、1、5 的合成数据，比较特征对齐和噪声记忆系数的训练轨迹。
- **关键结果 / 消融** · 在 ε=0.2 时，SNR=0.6 不足以维持私有训练的信号优势，升至 3 后恢复；非私有训练已记忆数据噪声的条件下，私有训练也会记忆。
- **适用条件 / 局限** · 理论限定特定数据模型、两层 CNN 和无梯度裁剪的 NoisyGD，不能直接覆盖一般带裁剪 DP-SGD。

**技术主题** · 序列锚定的 token 策略更新

- **问题 / 瓶颈** · 可验证奖励只在序列级给出时，怎样兼顾稳定更新和 token 级信用分配？
- **核心创新 / 方法** · TGPO 用序列重要性比锚定 token 更新，并根据信任度调节局部信号；信任度结合 token 更新一致性和相对锚点漂移。

- **适用条件 / 局限** · 证据集中于可判真伪的数学训练和两个骨干，其他奖励任务的迁移未报告。

## 913 · Learning Self-Correction in Vision–Language Models via Rollout Augmentation

[原文](https://proceedings.mlr.press/v306/ding26m.html)

<a id="ding26m-reinforcement-learning"></a>

**技术主题** · 错到对的自纠正轨迹重组

- **问题 / 瓶颈** · 视觉语言推理中有意义的纠错轨迹很稀少，只靠终局奖励或加一句“再检查”很难学会修订错误。
- **核心创新 / 方法** · Octopus 把同题已有轨迹在 <sc> 处重组，自然生成正确与错误的对应修订对，无须新增 rollout。两阶段训练用响应掩码将直接解题与纠错的学习信号分开。
- **Baseline** · 改进来源为 Qwen3-VL-8B 与 GSPO/RLVR。比较相同基模的 GRPO、DAPO、GSPO、SRPO、仅 SFT、随机增强及不增强。
- **Benchmark** · MathVista、MathVerse、WeMath、HallBench、MMStar、MMMUval、CharXivRQ，报准确率、纠错前后正确/错误转移、每步 rollout 与总训练秒数；训练以 8 条采样增至 16。
- **关键结果 / 消融** · 平均 71.7%，基模 62.2%，去轨迹重组 67.4%，随机增强 68.6%，去第一阶段 69.8%。单阶段塑形奖励中出现先蓄意答错再做平凡修正。
- **适用条件 / 局限** · 需要同题可判分的正确与错误轨迹及可识别的修订标记。实证重点是八十亿参数 VLM 的可核验任务，开放任务未报告。

## 921 · Native Spatio-Temporal 4D Variational Autoencoder

[原文](https://proceedings.mlr.press/v306/ding26u.html)

<a id="ding26u-architecture"></a>

**技术主题** · 原生四维体素自编码

- **问题 / 瓶颈** · 2D pointmap 投影看不到遮挡面且可能打乱跨帧几何，对部分或完整动态三维重建都产生时空失真。
- **核心创新 / 方法** · 4D VAE 直接在动态带色体素内编码、解码，保持显式时空坐标，在 4D 局部窗口做注意以支持不同压缩比，用可微稀疏体素光栅化加渲染损失。
- **Baseline** · 改进来源为 4D VAE、稀疏体素编码。对照 PointMapVAE、DyMesh VAE 以及不使用时空注意、渲染损失或 Plücker 射线的版本。
- **Benchmark** · 4D-Dyn 部分内容与 DyMesh 完整网格重建，报阈值 precision/recall、CD-L1、PSNR，并对照点图主干与网格预处理。

- **核心创新 / 方法** · MIRO 在预训练保留原样本，将多个奖励码与文本共同条件化扩散。推理用高低目标奖励的引导形成软偏向，并解释其为奖励倾斜采样。
- **Baseline** · 改进来源为奖励条件扩散与 classifier-free guidance。对照无奖励、单奖励的同训练设置，并区分真实/合成图注。
- **Benchmark** · CC12M+LA6 训练，GenEval 测颜色、计数、关系等组合能力，PartiPrompts 测 AestheticScore、PickScore、ImageReward、HPSv2、CLIP 等及 Best-of-N。
- **关键结果 / 消融** · 不带合成字幕的比较 GenEval 由 52 到 57，颜色归属 29 到 38。达到基线最终分数所需训练步数，对美学约快 19 倍、对 HPSv2 约 6.2 倍。
- **适用条件 / 局限** · 需要预先计算奖励和选定目标向量，自动奖励可能带偏好或评估泄漏。达到特定分数的步数加速取决于奖励项。

## 996 · Tightening the Score Matching Gap for Diffusion Models

[原文](https://proceedings.mlr.press/v306/dupuis26a.html)

<a id="dupuis26a-theory-statistics"></a>

**技术主题** · 扩散分数误差的时间加权界

- **问题 / 瓶颈** · 扩散 ELBO 中的全路径 score loss 虽可计算，但与最终样本分布差距在实际模型上通常很松。
- **核心创新 / 方法** · 在分数估计的单侧 Lipschitz 或耗散假设下，推导随噪声时间变化的权重，压低较高噪声误差对最终正向/反向 KL 和 Wasserstein 界的贡献。
- **Baseline** · 理论对照经典 ELBO、既有扩散收敛界和常见训练权重；经验比较各噪声区间 score loss 及扰动后的实际 KL。
- **Benchmark** · 单位圆合成分布可直方图估 KL。CIFAR-10 训练的 DDPM U-Net 用点对估 Lipschitz/耗散并测各噪声时刻扰动敏感性。
- **关键结果 / 消融** · 正向 KL 的一类界用指数时间权重替换未加权误差。圆数据上小噪声 score loss 更紧随真实 KL，扰动试验的加权损失比经典 ELBO 更贴近 KL。
- **适用条件 / 局限** · 收紧依赖特定漂移正则性以及理想连续过程，图像实验检验部分假设。高维真实生成分布的精确 KL 未报告。

**技术主题** · 对比学习的困难负例组批

- **问题 / 瓶颈** · 双编码 InfoNCE 的随机批内负样本常太容易，显式负例挖掘有计算成本，还可能选入潜在正例。
- **核心创新 / 方法** · HOBIT 每轮按单调子模目标贪心构造批次，优先挑对查询难、与正例不冲突的样本；HOBIT-C 用缓存嵌入减少重排序成本。
- **Baseline** · 改进来源为 InfoNCE 批内负例。比较随机、NGAME、BatchSampler、B3，并与 ANCE、TriSampler 显式负采样叠加。
- **Benchmark** · RoBERTa-base/e5-large-unsupervised，在 MS MARCO Passage 测 MRR@10/100，在 NQ、TriviaQA 测 Recall@10/100，另测缓存加速。

- **适用条件 / 局限** · 重组有额外计算，较难批次可让收敛需要更多轮。与已有 ANCE 叠加不总增益，缓存版有精度取舍。
