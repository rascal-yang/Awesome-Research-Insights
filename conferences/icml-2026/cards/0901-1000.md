## 901 · Listening Through the Noise: Cauchy-Driven Diffusion Bridges for Robust Gastrointestinal Auscultation and Clinical Benchmarking

[原文](https://proceedings.mlr.press/v306/ding26a.html) · [关联 Insight](../../../papers/scientific-ml.md#ding26a-inference)

- **问题 / 瓶颈** · 如何从含重尾语音干扰的听诊录音中恢复肠鸣音，并保留少见异常声？
- **核心创新 / 方法** · 用 Cauchy 驱动扩散桥对重尾干扰建模，推导密度和分数，并用高斯尺度混合的共享尺度进行 DBIM 采样。
- **Baseline** · 改进来源：扩散桥、重尾随机过程和 DBIM。实验对照：Demucs、Mel-Roformer、SCNet、BDBM、DDBM、DBIM，及每步重采样变体。
- **Benchmark** · ClinBS 超过 25 小时、1,531 名患者，叠加 VCTK/AISHELL 语音，测 MAE、PSNR、SSIM、LSD、FID 及异常声识别准确率。
- **关键结果 / 消融** · 去噪 MAE 为 8.28、PSNR 为 24.39，DBIM 为 16.49、18.23。ResNet 异常声识别由带噪的 48.23% 提至 88.01%，DBIM 为 84.39%。
- **适用条件 / 局限** · 主要临床语音干扰以混合录音模拟，检测效果受采集与噪声分布影响，临床决策效益未报告。

## 902 · Near-Optimal and Efficient First-Order Algorithm for Multi-Task Learning with Shared Linear Representation

[原文](https://proceedings.mlr.press/v306/ding26b.html) · [关联 Insight](../../../papers/ml-foundations.md#ding26b-optimization)

- **问题 / 瓶颈** · 多个任务共享低秩线性表示时，能否用高效一阶似然方法联合学习表示和任务权重？
- **核心创新 / 方法** · TPGD 先用未正则平方损失热启动，再以带校正正则项的一阶更新提高估计效率，避免每轮 SVD 或 QR。
- **Baseline** · 改进来源：共享线性多任务表示和非凸矩阵分解。实验对照：GD+Loss 1、GD+Loss 2 与 NSGD，理论比较矩估计、谱法和既有似然法。
- **Benchmark** · 线性多任务仿真，d 为输入维、k 为表示维、T 为任务数、N 为每任务样本，以参数估计误差随迭代及样本量变化评估。
- **关键结果 / 消融** · 在论文条件下用 Õ(1) 次迭代达到 Õ(dk/(TN)) 估计误差，较既有相类似然保证少一个 k 因子；仿真中两阶段比单阶段更快稳定。
- **适用条件 / 局限** · 依赖共享线性表示、任务谱和样本条件，实证为合成设置，未覆盖非线性任务。

## 903 · Disentangling Latent Risk Pathways via Bayesian Hypergraph Inference

[原文](https://proceedings.mlr.press/v306/ding26c.html) · [关联 Insight](../../../papers/scientific-ml.md#ding26c-theory-statistics)

- **问题 / 瓶颈** · 在罕见疾病与风险因素共享的电子健康记录中，如何估计可重叠的疾病关联结构及其不确定性？
- **核心创新 / 方法** · BHPI 用贝叶斯超图表示潜在疾病子集及风险因素的调制，排斥先验减少超边冗余，以结构化变分推断学习后验。
- **Baseline** · 改进来源：多疾病关联、超图及结构化变分推断。实验对照：逐病最优逻辑回归、LightGBM、Binary Relevance、Classifier Chain、RAkELd 和去排斥先验。
- **Benchmark** · 30 疾病模拟与英国生物银行约 277,291 人、66 病、71 因素，测 AUC、Brier、ECE、超边和风险因素关联的恢复率。
- **关键结果 / 消融** · 模拟 N=2,000 的预测 AUC 为 75.00%、最优逻辑回归 73.86%；恢复超边结构 AUC 96.96%。UKB 的 Brier 同为 0.041，ECE 为 0.005 对 0.001。
- **适用条件 / 局限** · 超边表达关联，不能直接确定因果通路；现有设计未显式估计纵向变化，高维遗传特征需额外扩展。

## 904 · Whom to Query for What: Adaptive Group Elicitation via Multi-Turn LLM Interactions

[原文](https://proceedings.mlr.press/v306/ding26d.html) · [关联 Insight](../../../papers/llm.md#ding26d-inference)

- **问题 / 瓶颈** · 调查预算受限且有人未答时，怎样同时决定下一题和要询问的参与者，以推断群体特征？
- **核心创新 / 方法** · 用 LLM 维护响应预测和个体不确定性，以贪心信息增益选问题和受访者，再经异质图向未询问成员传播部分回答。
- **Baseline** · 改进来源：自适应问卷、异质图推断和次模信息增益。实验对照：Meta-Random、Meta-Greedy、Meta-Greedy-Imp，以及多步前瞻和插补消融。
- **Benchmark** · CES、OpinionQA、TWIN-2K 的多选调查，固定受访者与问题预算，在未询问题上测准确率、困惑度和 Brier。
- **关键结果 / 消融** · CES 只询问 10% 受访者时，相对最强对照的准确率优势从第一轮 17.1% 到第四轮 12.6%；另在 10% 预算的多步前瞻对照中，第四轮总体 0.485，贪心为 0.488。
- **适用条件 / 局限** · 理论依赖次模结构等条件，评估以既有多选问卷作为响应来源，真实互动中的回答偏移未验证。

## 905 · OmniSIFT: Modality-Asymmetric Token Compression for Efficient Omni-modal Large Language Models

[原文](https://proceedings.mlr.press/v306/ding26e.html) · [关联 Insight](../../../papers/multimodal.md#ding26e-modules)

- **问题 / 瓶颈** · 音视频全模态语言模型怎样在删减 token 时保住需要跨模态配合的线索？
- **核心创新 / 方法** · OmniSIFT 先按帧内结构和帧间重复剪视频 token，再用视觉引导音频选择，通过直通估计做端到端优化。
- **Baseline** · 改进来源：视觉 token 剪枝和 Omni-LLM 跨模态对齐。实验对照：全 token、OmniZip、适配的 DyCoke、随机剪枝，以及模态剪枝消融。
- **Benchmark** · Qwen2.5-Omni-7B/3B，用 AVoCaDO SFT；测 VideoMME、DailyOmni、WorldSense、OmniVideoBench、video-SALMONN-2 的得分、内存和延迟。
- **关键结果 / 消融** · 7B 在 WorldSense 保留 35% token，得分为 50.0 对全量的 49.7；峰值内存从 27.59 GB 到 22.91 GB，端到端延迟从 4.94 秒到 2.86 秒。
- **适用条件 / 局限** · 精确音画对应依赖局部证据，容易受裁剪损伤；视频剪枝的建模范围受块级处理约束。

## 906 · DDSVM: A Differentiable Framework for Deep Support Vector Machines with Iterative Geometry-Aware Optimization

[原文](https://proceedings.mlr.press/v306/ding26f.html) · [关联 Insight](../../../papers/computer-vision.md#ding26f-representation-learning)

- **问题 / 瓶颈** · 能否用支持向量机的决策边界反过来塑造深度分类模型的表示，尤其在样本很少时？
- **核心创新 / 方法** · DDSVM 交替在 L2 归一特征上重拟合线性 SVM，并沿球面切空间中的增间隔方向更新骨干，并以几何扰动平滑训练。
- **Baseline** · 改进来源：深度表示学习、线性 SVM 和球面间隔。实验对照：交叉熵、角间隔方法、几何扰动消融、OVR 与 Cramér–Singer SVM。
- **Benchmark** · ResNet-18 在 CIFAR-10/100、STL-10、SVHN 完整及约 8% 数据和 CIFAR-10-C 上，测 top-1 错误率、种子方差及训练时间。
- **关键结果 / 消融** · 约 8% 数据下 CIFAR-10 错误率从 30.75% 至 23.21%，STL-10 从 47.29% 至 38.98%；SVHN 则从 6.08% 至 6.79%。
- **适用条件 / 局限** · 完整数据下多数收益有限；OVR 成本随类别线性增长，未覆盖 episodic few-shot 和大规模预训练。

## 907 · Understanding Private Learning From Feature Perspective

[原文](https://proceedings.mlr.press/v306/ding26g.html) · [关联 Insight](../../../papers/ml-foundations.md#ding26g-theory-statistics)

- **问题 / 瓶颈** · 隐私梯度噪声如何改变网络对真实类别特征与训练数据噪声的学习？
- **核心创新 / 方法** · 在多 patch 二分类和多项式 ReLU 的两层 CNN 中分解权重轨迹，分离类别信号、数据噪声、初始化及隐私噪声。
- **Baseline** · 改进来源：DP 训练理论和特征—噪声分解。实验对照：NoisyGD 与非私有 GD，控制 SNR 与隐私预算，附录另测 CIFAR-10。
- **Benchmark** · 主试验使用 SNR 0.2、0.6、3 与 ε 0.2、1、5 的合成数据，比较特征对齐和噪声记忆系数的训练轨迹。
- **关键结果 / 消融** · 在 ε=0.2 时，SNR=0.6 不足以维持私有训练的信号优势，升至 3 后恢复；非私有训练已记忆数据噪声的条件下，私有训练也会记忆。
- **适用条件 / 局限** · 理论限定特定数据模型、两层 CNN 和无梯度裁剪的 NoisyGD，不能直接覆盖一般带裁剪 DP-SGD。

## 908 · CSPLoRA: Confidence-Guided Structural Planning for Low-Rank Adaptation

[原文](https://proceedings.mlr.press/v306/ding26h.html) · [关联 Insight](../../../papers/llm.md#ding26h-training-strategies)

- **问题 / 瓶颈** · 同一 LoRA 参数预算下，能否在训练前识别重要模块并复用不均匀秩分配？
- **核心创新 / 方法** · CSPLoRA 按预测不确定性对探测样本加权，聚合 Taylor 梯度显著性并做对数平滑和预算投影，得到可跨后端复用的结构先验。

- **Benchmark** · RoBERTa-large 的 GLUE、LLaMA-2/3 八项常识推理、GSM8K 和 MATH，比较平均得分、参数预算、探测和复用开销。
- **关键结果 / 消融** · RoBERTa-large 的 GLUE 平均由统一 LoRA 85.30 至 86.21，RTE 增 5.78 分；LLaMA-2-7B 常识分由 73.49 至 74.74。
- **适用条件 / 局限** · 先验按固定任务与模型复用，依赖后端容量；当前只测文本，LLaMA-3.1-8B 的 LoRA+ 略降。

- **适用条件 / 局限** · 证据集中于可判真伪的数学训练和两个骨干，其他奖励任务的迁移未报告。

## 910 · NL2Repo-Bench: Towards Long-Horizon Repository Generation Evaluation of Coding Agents

[原文](https://proceedings.mlr.press/v306/ding26j.html) · [关联 Insight](../../../papers/llm.md#ding26j-evaluation)

- **问题 / 瓶颈** · 给编码代理一份自然语言规格和空工作区时，能否独立完成可安装、可通过上游测试的 Python 仓库？
- **核心创新 / 方法** · NL2Repo-Bench 从现有库构建需求文档、安装环境和上游测试，在统一环境中评估架构设计、实现与依赖管理的端到端结果。
- **Baseline** · 改进来源：代码代理评估和仓库级测试。实验对照：OpenHands CodeAct 下的多种模型，以及 Claude Code 和 Cursor CLI 的同类模型组合。
- **Benchmark** · 104 项任务、9 类 Python 库，规格平均约 18,800 token；按代码规模分难度，用平均测试通过率、全通过任务数和交互轮数评估。

- **Baseline** · 改进来源为视频扩散模型与 DMD2。对照有常规 AMT-S/L、GIMM-VFI、BiM-VFI，以及 ViBiDSampler、FCVG、Framer。
- **Benchmark** · DAVIS 与 DiversityVideo 测 PSNR、SSIM、LPIPS、FID、FVD。A100 上 17→65 帧、832×448 测 NFE 和秒数，另消融注意及训练损失。
- **关键结果 / 消融** · 部分注意单步 9.98 秒，全注意 10.72 秒，Framer 30 步 150.69 秒。去掉流及像素损失的消融 FVD 1627.51，三损失齐用 370.77。
- **适用条件 / 局限** · 整段生成受训练长度与显存约束。局部注意在相同步数早期优化较慢，文中用更长训练弥补。

## 921 · Native Spatio-Temporal 4D Variational Autoencoder

[原文](https://proceedings.mlr.press/v306/ding26u.html) · [关联 Insight](../../../papers/computer-vision.md#ding26u-architecture)

- **问题 / 瓶颈** · 2D pointmap 投影看不到遮挡面且可能打乱跨帧几何，对部分或完整动态三维重建都产生时空失真。
- **核心创新 / 方法** · 4D VAE 直接在动态带色体素内编码、解码，保持显式时空坐标，在 4D 局部窗口做注意以支持不同压缩比，用可微稀疏体素光栅化加渲染损失。
- **Baseline** · 改进来源为 4D VAE、稀疏体素编码。对照 PointMapVAE、DyMesh VAE 以及不使用时空注意、渲染损失或 Plücker 射线的版本。

- **适用条件 / 局限** · 依赖可构造的动态体素和输入几何/位姿，稀疏渲染与局部注意的效果由体素分辨率和可见证据决定。

## 922 · Discriminative Attribute Graph Clustering Through Topology-Guided Contrastive Learning

- **问题 / 瓶颈** · 属性图的原始邻接噪声会污染消息传递，自编码器和图视图间的冗余又会降低聚类表示的判别性。
- **核心创新 / 方法** · 求 k 近邻与原邻接的交集，再用全局 k-means 语义过滤，重建拓扑，随后在 AE/GAE 视图上用对比和相关去冗余训练。

- **Benchmark** · DBLP、CITE、ACM、AMAP，十次运行报 ACC、NMI、ARI、macro-F1，做 Friedman 后的 Nemenyi 检验。
- **关键结果 / 消融** · DBLP ACC 80.89±0.42%，DFCN 76.00±0.80%；ARI 56.25±0.77% 对 47.00±1.50%。16 个组合赢 15 个，但 Nemenyi 对 DFCN 的差异未显著。
- **适用条件 / 局限** · 依赖属性和原图能支持近邻、聚类语义，过强过滤可能移除有用异类链接。实验覆盖四静态图，CITE 的 NMI 低于 DFCN。

- **核心创新 / 方法** · TKNO 用 Transformer 编码全局椭圆耦合、KAN 提供非线性响应，同时用少量已标注磁通量锚点和 PDE 残差约束分支与形状。
