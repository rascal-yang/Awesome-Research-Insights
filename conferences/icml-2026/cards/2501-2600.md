## 2501 · Initialization is Half the Battle: Generating Diverse Images from a Guidance Potential Posterior

[原文](https://proceedings.mlr.press/v306/li26de.html)

<a id="li26de-inference"></a>

**技术主题** · 从引导势的后验挑生成初噪声

- **问题 / 瓶颈** · 标准 Gaussian 初噪对引导势没有感知，去噪前已有大量轨迹集中到少数模式。
- **核心创新 / 方法** · DivIn 以引导势重新加权初始化分布，用 Langevin 近似采样，保持原生成器并可叠加轨迹多样化。
- **Baseline** · 比较原模型、初始化法 SAIL，以及 PG、CADS、IG 轨迹法和它们叠加 DivIn。
- **Benchmark** · SD v1.4 在 ImageNet-1K 每设置生成 1 万张 256² 图，SD3.5 在 500 提示每题生成四张 512² 图，评 Recall、Coverage、Vendi、FID 等。
- **关键结果 / 消融** · ImageNet 上单用 DivIn，Recall 由 0.503 到 0.569，FID 由 16.696 到 16.158；IG 叠加后 Vendi 增而 FID 略变差。
- **适用条件 / 局限** · 需在初始化多做引导势求解，性能与 Langevin 温度有关；生成模式塌缩若来自模型本身缺失覆盖，改初始化的作用有限。

## 2504 · NorMuon: Making Muon more efficient and scalable

[原文](https://proceedings.mlr.press/v306/li26dh.html)

<a id="li26dh-optimization"></a>

**技术主题** · 先正交化矩阵更新，再按神经元二阶矩归一

- **问题 / 瓶颈** · Muon 正交化后仍可有严重的行范数不均，少数神经元更新支配训练，直接分布式正交化也贵。
- **核心创新 / 方法** · NorMuon 用行级二阶矩归一化正交化输出并给出 FSDP2 分布式实现；非二维参数沿用 AdamW。
- **Baseline** · 同模型比 AdamW、Muon、Dion，另测移除正交或归一等变体；5.4B 的 Dion 因资源未跑。
- **Benchmark** · SlimPajama 预训 1.1B、5.4B，FineWeb 预训 124M、350M，测达到同验证损失的步数、墙钟、显存和下游成绩。
- **关键结果 / 消融** · 1.1B 与 5.4B 达 AdamW 最终损失少 21.74%/13.17% 步，Muon 为 10.43%/5.60%。
- **适用条件 / 局限** · 节省步数依赖模型和目标验证损失，墙钟取决于硬件和分片；实验主要针对 Transformer 的二维权重。

## 2506 · Dynamic Decision Learning: Test-Time Evolution for Abnormality Grounding in Rare Diseases

[原文](https://proceedings.mlr.press/v306/li26dj.html)

<a id="li26dj-inference"></a>

**技术主题** · 先演化定位提示，再以变换后框的一致性计置信

- **问题 / 瓶颈** · 罕病脑影像缺训练标签，冻结视觉模型容易受提示措辞和单次感知不稳影响。
- **核心创新 / 方法** · DDL 由 DAPE 演化指令，用视觉扰动与匹配形成框共识，输出位置和可靠性而不更新骨干。
- **Baseline** · 比同骨干 Vanilla、其它共识方式、训练适配与监督微调，并跨 3B、7B、32B、72B 评测。
- **Benchmark** · BTD 三类脑肿瘤和 NOVA 的 281 种罕见病理，评 mAP@25/50/75、置信校准与不同难度。
- **关键结果 / 消融** · NOVA 7B 的 mAP@75 由 0.036 到 0.075，表报相对提升 104.7%；72B 从 0.065 到 0.107。
- **适用条件 / 局限** · 提示演化依赖开发集，视觉多视图增加推断次数；结论来自回顾脑影像 benchmark，尚无临床部署验证。

## 2508 · FiX: Introducing Fine-grained Forget Gate into Softmax Attention

[原文](https://proceedings.mlr.press/v306/li26dl.html)

<a id="li26dl-modules"></a>

**技术主题** · 借 RMSNorm 的尺度消除把逐维遗忘施加在值上

- **问题 / 瓶颈** · Softmax 注意的分母耦合各位置，直接引入逐维遗忘难组合，FoX 通常只用标量门。
- **核心创新 / 方法** · FiX 将分母的公共尺度与 RMSNorm 结合，构造值–输出的细粒度遗忘门，能和查询–键上的 RoPE 并存。
- **Baseline** · 同语料比 RoPE、FoX、FoX-RoPE、FiX 与 FiX-RoPE，比较缓存与实现。
- **Benchmark** · FineWeb-Edu 的约 340M/760M 预训，WikiText、LAMBADA 困惑度，八项零样本任务，以及 CodeParrot、PG-19、NarrativeQA、BABILong 外推。
- **关键结果 / 消融** · 表 1 的 FiX 在 LAMBADA 困惑度为 12.69，RoPE 13.39，FiX+RoPE 12.32；八项算术平均 FiX 55.24 对 RoPE 54.82。
- **适用条件 / 局限** · 改写依赖后续归一化处理公共尺度，有限精度与门的累积需要实现处理；还需管理额外逐通道缓存。

## 2510 · Signal Strength Estimation in Logistic Regression Using Data Splitting

[原文](https://proceedings.mlr.press/v306/li26dn.html)

<a id="li26dn-theory-statistics"></a>

**技术主题** · 用两个独立分半拟合的共同信号反解逻辑回归信噪比

- **问题 / 瓶颈** · 维度与样本同阶时，逻辑回归的渐近偏差/方差依赖未知信号强度，分离数据又会让普通极大似然发散。
- **核心创新 / 方法** · 使用数据驱动非可分的广义 ridge 保持存在性，通过两半的交叉二阶量和数值求逆估 κ，另给留一近似。
- **Baseline** · 理论与 ProbeFrontier 等旧估计方法讨论比较；实验比较直接分半与另一实现、已知/估计协方差，真实基因结果与 Dai 等核对。
- **Benchmark** · 单位或一般协方差模拟估 κ、渐近偏差与方差，报绝对误差和 95% 区间覆盖；scRNA-seq 的 2400 细胞和 600 特征。
- **关键结果 / 消融** · 模拟样本增大时误差下降，单位协方差覆盖近 95%；一般协方差下估计残差尺度可能使覆盖偏高。真实数据校正后选出 23 个基因。
- **适用条件 / 局限** · 一致性依赖所设比例渐近、协方差及可识别单调映射；真实信号识别是统计关联，需额外生物验证。

## 2512 · Trust Region Masking for Long-Horizon LLM Reinforcement Learning

[原文](https://proceedings.mlr.press/v306/li26dp.html)

<a id="li26dp-reinforcement-learning"></a>

**技术主题** · 按整条轨迹的最大 KL 偏离掩码策略梯度

- **问题 / 瓶颈** · 后端精度、MoE 路由或采样滞后造成 off-policy 差，经典序列长度平方的误差界无法约束很长的 rollout。
- **核心创新 / 方法** · TRM 推导最大 token KL 下的 Pinsker–Marginal 与 Mixed 界，给出按最大/平均信赖域开关的序列损失。
- **Baseline** · 同 Qwen3-8B-Base GRPO 对照 DAPO 范围 [0.8,1.28] 的 PPO 裁剪，比较 TRM-Max、Avg 和联用。
- **Benchmark** · 去重 DAPO-MATH-17k，vLLM rollout、PyTorch FSDP 训练，组大小 16，AIME25 avg@32 与训练/采样绝对 log PPL 差。
- **关键结果 / 消融** · 误差长度项由旧 O(T²) 到 O(T¹·⁵) 或 O(T)；主实验两种 TRM 抑制 PPL 差并避免基线塌缩，放宽阈值时联用优于单项。
- **适用条件 / 局限** · 界依赖最大逐词 KL 及其它条件，平均阈值是实用补充；掩码比例、阈值和收益受推断与训练前后端差异影响。

## 2517 · Towards One-for-All Anomaly Detection for Tabular Data

[原文](https://proceedings.mlr.press/v306/li26du.html)

<a id="li26du-representation-learning"></a>

**技术主题** · 跨表格域的统一异常距离特征

- **问题 / 瓶颈** · 怎样让一个表格异常检测器适用于新特征空间和新数据域，无需在每张目标表重新训练？
- **核心创新 / 方法** · OFA-TAD 将原始列映射为多视图近邻距离曲线，各视图用专家评分并由门控融合。训练以多种合成异常提供监督。
- **Baseline** · 改进来源：用跨域可比的邻居距离替代原始异构列。实验对照：iForest、LOF、kNN、DeepSVDD、LUNAR、DRL、DisentAD 等九种通常在目标集训练的方案。
- **Benchmark** · ADBench 的 7 个源数据集联合训练、34 个目标数据集评估含域内外切分。各视图用 80 个近邻，推理使用目标训练子集的正常上下文。测 AUROC、AUPRC、F1 和平均排名。
- **关键结果 / 消融** · 34 个目标集的平均 AUROC／AUPRC 排名为 3.57／3.28，均居首。相应最接近基线为 DisentAD 4.32 和 DRL 4.41。
- **适用条件 / 局限** · 范围：推理需要目标表的正常上下文。作者将扩大源数据量并改进视图、路由和上下文构造列为后续工作。

## 2519 · Tackling Length Inflation Without Trade-offs: Group Relative Reward Rescaling for Reinforcement Learning

[原文](https://proceedings.mlr.press/v306/li26dw.html)

**技术主题** · 组相对奖励重缩放控制长度

- **问题 / 瓶颈** · RL 对齐训练引发回答变长时，怎样压低冗长输出又保留高质量推理？
- **核心创新 / 方法** · GR3 将原奖励乘以由回答长度除以组均长度决定的缩放系数，并用典型高奖励回答的非负优势条件校准长度惩罚。
- **Baseline** · 改进来源：将绝对长度惩罚改为组相对乘法调节。实验对照：GRPO、LC-R1、Laser、AdaptThink、DLER 和原始模型。
- **Benchmark** · DeepSeek-R1-Distill-1.5B／7B 的数学与代码 RLVR，测平均准确率及 token 数。Qwen3-4B／8B 以奖励模型对人类偏好数据强化更新，测聊天质量及长度。

- **适用条件 / 局限** · 范围：约束针对典型高质量回答，校准存在采样误差。论文指出高密度奖励时无法保证每条正确轨迹都为正优势，全高奖励组需线上过滤。

## 2520 · How Can Mamba Learn In Context with Outliers and Generalize Provably?

[原文](https://proceedings.mlr.press/v306/li26dx.html)

<a id="li26dx-theory-statistics"></a>

**技术主题** · Mamba 在含异常示例的上下文学习

- **问题 / 瓶颈** · Mamba 如何在含异常演示的提示中学习任务，面对未见任务和分布变化的异常还能否泛化？
- **核心创新 / 方法** · 对两种相关模式决定标签的二元分类族分析单层 Mamba 的训练收敛、门控与泛化，比较线性 Transformer，并测试异常位置影响。
- **Baseline** · 改进来源：把状态空间模型的上下文学习分析延伸到可含异常和异常分布变化的提示。理论对照：单层线性 Transformer。实验对照：线性 Transformer 及不同异常位置。
- **Benchmark** · 合成正交模式任务测泛化及门控，SST-2 每题八个演示并插入异常短语，测试异常离查询最远、最近或随机时的分类准确率。

## 2600 · LoRe: Adaptive Interaction-Evaluation Routing with Per-step Interaction Budgets for Iterative Graph Solvers

[原文](https://proceedings.mlr.press/v306/li26gz.html)

<a id="li26gz-inference"></a>

**技术主题** · 逐步预算下的动态交互求解

- **问题 / 瓶颈** · 在大图迭代求解中，怎样限制每一步的昂贵交互，延后显存耗尽并保留解质量？
- **核心创新 / 方法** · LoRe 在每步固定交互预算下保留静态骨架，按状态和时间变化路由热点交互，对其余关系用低成本聚合近似。封装现有求解器且无需训练。
- **Baseline** · 改进来源：将完整交互逐步求值转为随迭代状态变化的预算路由。实验对照：同 checkpoint、步数与解码的完整 DIFUSCO，另比较固定、随机或其他受限路由。
- **Benchmark** · 最大独立集 MIS、旅行商 TSP，跨图规模与拓扑，使用 RTX PRO 6000 96GB 记录端到端耗时、峰值显存及解质量保留。
- **关键结果 / 消融** · 在 ER MIS 的一万节点设置，LoRe／完整 DIFUSCO 分别需 196／1601 秒和 3.31／38.6 GB。完整法在约两万节点显存溢出，LoRe 可达五万节点。
- **适用条件 / 局限** · 作者指出该方法受任务规模和截断质量折衷影响，小 TSP 有额外开销。更紧的截断稳定性与精度界待研究。
