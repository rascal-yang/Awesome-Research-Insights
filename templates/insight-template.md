# Insight 条目模板

[English](../en/templates/insight-template.md)

在主技术分类的 H2 方法族下新增 H3。中英文条目使用同一个英文锚点。

```markdown
<a id="insight-title"></a>

### 用一句话写出技术机制

**来源**

链接关联的[论文卡](paper-card-template.md)与论文原文，并定位小节、公式、图或实现代码。

**核心思路**

一到两句话概括可复用的做法。

**实现机制**

讲清楚改哪里、接在哪里、需要什么数据或条件。必要时注明它用在训练还是推理中。

**设计动机**

说明作者观察到了什么问题。

**论文证据与适用条件**

概括相关实验、定理或反例，注明验证场景、关键假设及结论范围。

**迁移设想（可选）**

如有具体用法，说明它需要满足哪些条件。
```
