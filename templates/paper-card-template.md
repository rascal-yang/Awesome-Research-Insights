# 六字段论文卡

每篇论文维护一张中文论文卡。先读原文的方法、实验和必要的附录，再填写下面六项。技术索引直接链接到[卡内机制](#卡内机制)。

| 字段 | 填写内容 |
| --- | --- |
| **问题 / 瓶颈** | 具体任务和现有做法的失效条件。 |
| **核心创新 / 方法** | 论文改变了哪个机制、训练信号、流程或理论条件。 |
| **Baseline** | 分开记录方法的改进来源和实际比较的对照。理论工作可填写比较的已有界、假设或算法。 |
| **Benchmark** | 评测数据、任务、设置和指标。记录影响比较的模型规模、训练预算、采样或重复次数。 |
| **关键结果 / 消融** | 在对应设置下给出对照值、改进值、代价或关键消融。理论结果写明界及其成立条件。 |
| **适用条件 / 局限** | 写出适用前提、观察到的失败以及验证范围，区分原文结论和可迁移设想。 |

原文没有提供的项目标为「未报告」。对无实验的理论论文可写「未报告（无实验）」，并指向定理或反例。用原文小节、表格、图或公式定位证据。指标的百分比和增量的百分点分别写清楚。

## 卡内机制

用一到两句话写清楚这个做法可以复用在哪里、需要哪些输入或前提，以及发生在训练还是推理。需要展开时，在同一张卡内补充实现、原文证据和验证范围。新增机制用独立锚点，技术索引直接链接到该锚点。迁移设想注明所需条件和待验证之处。

## 批量填写

TSV 使用 UTF-8。每个字段占一列，每条记录占一行，第一行按此顺序填写。

```text
pmlr_id	problem	method	baseline	benchmark	results	limits	evidence
```

`evidence` 使用 Markdown 链接指向原文中的证据。多处证据用「 · 」隔开。ICML 2026 论文使用[底册](../conferences/icml-2026/papers.tsv)的 `pmlr_id`。ReconVLA 的 ID 是 `reconvla`。
